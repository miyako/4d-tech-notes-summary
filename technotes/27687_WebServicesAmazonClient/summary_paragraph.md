This Tech Note describes a Web Services client application built using the Amazon.com Software Development Kit of the era, which provided the request/response format needed to call Amazon's then-available web service (an early precursor to the modern Amazon Product Advertising API). Developers are encouraged in the teaser to download the Amazon SDK themselves before modifying the example database, implying the example closely tracks Amazon's official schema. Only the short on-page teaser text could be recovered here, so the specific SOAP calls and 4D Internet Commands usage are not detailed, but the note is a good, concrete real-world illustration of 4D 2003's Web Services client capability being applied to a major commercial e-commerce API of the time.
