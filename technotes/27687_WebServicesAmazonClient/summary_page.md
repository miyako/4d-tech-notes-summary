## Overview
A Tech Note demonstrating a Web Services client for Amazon.com's early SOAP-based API, built in 4D 2003 using the Amazon SDK, SOAP, and 4D Internet Commands.

## Key Points
- Built using the Amazon.com SDK of the era to construct a working Web Services client in 4D.
- Uses SOAP and 4D Internet Commands as the underlying communication mechanism.
- Recommends developers obtain the Amazon SDK before modifying the example database.

## Featured Technology
- SOAP
- 4D Internet Commands
- Amazon.com Web Services (early API)

## Historical Context
Amazon's early web services (circa 2002-2003) were SOAP-based, before evolving into the modern REST/JSON Amazon Product Advertising API; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

Amazon's original SOAP-based web service used in this example has long been retired in favor of its modern REST/JSON Product Advertising API (with different authentication and request formats), making this note's specific integration code obsolete; it remains an interesting historical snapshot of how early e-commerce API integration looked in the SOAP era.
