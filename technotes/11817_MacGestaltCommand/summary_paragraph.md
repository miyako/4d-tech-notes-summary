This Tech Note documents 4th Dimension's support for the Macintosh Gestalt Manager, a feature of the Mac OS that allowed programmers to determine what hardware features and system services were installed on the computer running their software. The Gestalt Manager was created by Apple as a standardized mechanism for runtime feature detection, enabling applications to adapt their behavior based on the capabilities of the host system. In the classic Mac OS era, this was essential because Macintosh hardware and system software configurations varied significantly, and applications needed to detect available features like specific processors, memory configurations, QuickTime versions, or networking capabilities before attempting to use them. 4D's support for the Gestalt command gave developers access to this system-level information directly from within their 4D databases. This was particularly important for cross-platform 4D applications that needed to detect and adapt to the specific Mac OS environment they were running on.
