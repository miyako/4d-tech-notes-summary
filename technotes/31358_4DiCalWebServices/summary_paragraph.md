Written by Sati Hillyer, a Technical Support Engineer at 4D, Inc., this Tech Note explains how to trigger scheduled 4D operations at precise dates and times by combining 4D 2003's new SOAP Web Services with Apple's iCal 1.5.1 calendar application and AppleScript, since iCal's newest version had just gained the ability to call web services through AppleScript. The note works through two concrete scenarios: scheduling a bi-monthly database backup at 9pm on the 1st and 15th of each month, and printing a weekly inventory Quick Report every Monday at 8am — both tasks that neither 4D Single User's manual scheduling nor 4D Server's built-in backup scheduler (which only supports simple intervals like every minute/hour/day/week) could handle directly. In each case, a 4D method is written (using commands like `BK Begin full backup`, `BK Start copy`, and `BK Get state` for the backup, or Quick Report project generation/printing commands for the report) and then exposed by enabling "Offered as a Web Service" and "Published in WSDL" in its Method Properties, with the 4D Web Server started and "Allow Web Services Requests" enabled. An AppleScript is then written using the `call soap` command, pointing at the local SOAP endpoint (`http://127.0.0.1:8080/4DSOAP/`) and the target method name, which displays a confirmation dialog with 4D's response. Finally, an iCal event is created with a recurrence pattern matching the desired schedule, with its alarm set to "Open File" pointing at the AppleScript file, so that when the alarm fires, iCal launches the script, the script calls 4D via SOAP, and 4D executes the backup or report and returns a confirmation. The note notes this pattern is fully cross-platform on the 4D side since Web Services are platform-independent, even though iCal itself only runs on Mac OS X, and references a companion Tech Note (30140) covering 4D/iCal integration from a different angle.
