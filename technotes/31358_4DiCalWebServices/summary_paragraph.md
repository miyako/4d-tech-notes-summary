This Tech Note explores an early cross-application automation scenario combining three distinct technologies from 2004: 4D's newly added Web Services support, Apple's iCal calendar application, and AppleScript. It opens by noting that 4D 2003 incorporated a powerful element — Web Services — which allows 4D methods to be called remotely, giving designers freedom to maintain their database anywhere while permitting end users to take advantage of customized functionality from other applications. The note then turns to iCal, Apple's built-in calendar application, observing that its then-newest version (1.5.1) had implemented the ability to trigger AppleScripts, small programs capable of a wide variety of automated actions (from playing an iTunes song to emptying the trash), and crucially that the latest version of AppleScript itself had gained support for calling Web Services. Putting these pieces together, the tech note explains that a user can schedule a calendar event in iCal that, when triggered, executes an AppleScript which communicates with a 4D database via Web Services — effectively turning calendar events into triggers for 4D business logic. The note walks through the steps needed to wire up this integration and outlines a few illustrative scenarios to show developers how the technique might be applied in practice, such as time-based automated tasks driven by a user's calendar rather than by manual intervention or a server-side scheduler. The featured technology combination — iCal, AppleScript, and 4D SOAP Web Services — reflects the Mac-centric, automation-curious spirit of 4D's developer community in this era.
