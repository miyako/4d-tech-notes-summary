Written by Cha Yang, a Technical Support Engineer at 4D, Inc., this Tech Note explains how to implement "4D Clipboard," a private multi-item clipboard within 4D that lets a user copy multiple text or picture items and later paste any one of them individually, going beyond the operating system's single-slot public clipboard (the "desk scrap"). It opens with a primer on Mac/Windows clipboard concepts -- the desk scrap, private scraps, standard data formats ("TEXT", "PICT") versus optional ("snd", "movv", "styl") and private four-character formats -- and 4D's own clipboard command set: APPEND TO CLIPBOARD, CLEAR CLIPBOARD, GET CLIPBOARD, GET PICTURE FROM CLIPBOARD, Get text from clipboard, SET PICTURE TO CLIPBOARD, SET TEXT TO CLIPBOARD, and Test clipboard, noting that SET/Get TEXT TO/FROM CLIPBOARD are limited to 32,000 characters (a 4D text-variable limitation) whereas APPEND TO CLIPBOARD/GET CLIPBOARD work with blobs and arbitrary custom data types without that limit. The 4D Clipboard implementation stores five interprocess BLOB variables (<>clipboard_1 through _5), each tagged internally with a 4-byte "TEXT" or "PICT" marker prefix so the correct retrieval logic can be applied. Copying to 4D Clipboard is triggered by Ctrl+6 or a palette button, which invokes CLEAR CLIPBOARD then POST KEY(67;Command key mask) to simulate a native Ctrl+C into the public clipboard; because POST KEY doesn't actually fire until the calling method returns, a second process (SaveToBlob) is spawned to wait via DELAY PROCESS, then test the public clipboard's type with Test clipboard("PICT")/Test clipboard("TEXT") and retrieve the data into a blob with GET PICTURE FROM CLIPBOARD or GET CLIPBOARD, tagging it and storing it in the chosen clipboard slot. Pasting reverses the process: PasteFromClipboard_N reads the 4-byte type tag from the slot's blob, restores the payload to the public clipboard with SET TEXT TO CLIPBOARD or SET PICTURE TO CLIPBOARD, then simulates Ctrl+V via POST KEY(86;Command key mask) to complete the paste into the user's selected target.
