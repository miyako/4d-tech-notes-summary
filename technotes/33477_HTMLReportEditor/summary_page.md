## Overview
This Tech Note explains how to work with the HTML template used by the Quick Report editor, a reporting tool introduced in 4th Dimension 2003 that added a new set of commands and features, including the ability to generate an HTML file directly from a report. It notes that the Quick Report Wizard makes producing an HTML report especially easy for end users, but that understanding the underlying HTML template — needed for customizing the generated output — can be difficult without guidance, which is the specific gap this note fills. The note walks through the structure of the HTML template so developers can adapt or extend the default report-to-HTML output for their own applications' branding or presentation needs. This reflects 4D's mid-2000s push to make its reporting tools capable of producing web-ready output directly, at a time when 'publishing to the web' was a major theme across the 4D product line (alongside the 4D Web Server, 4D Internet Commands, and XML/XSLT support introduced in the same era). As a template-customization reference, the note targets developers who need report output beyond the Quick Report Wizard's default HTML formatting.

## Historical Context
**Status:** superseded

This note documents customizing the HTML export template of 4D's early-2000s Quick Report editor, a reporting tool that has since been substantially reworked and, in later 4D versions, largely superseded by improvements to the Print form/List Box printing engine and other reporting approaches. The specific HTML template mechanics described are tied to that legacy Quick Report editor implementation and are unlikely to transfer directly to current 4D reporting tools, though the general need to generate customizable HTML report output from application data remains a common requirement met today through other means (custom HTML generation, PDF export, or third-party reporting tools).
