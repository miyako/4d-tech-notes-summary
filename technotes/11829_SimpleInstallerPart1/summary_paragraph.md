This Tech Note provides a simple, ready-to-use installer for deploying 4D-based applications, addressing common installation problems that developers encountered. The note identifies typical issues such as users copying only some essential documents, or the read-only attribute being set when copying files from CD-ROM or diskette on Windows, which could cause problems when running a 4D database. The installer solution is script-based, requiring developers only to edit an installation script using a text editor like SimpleText on Mac OS or WordPad on Windows. This pragmatic approach reflected the era when standardized cross-platform installer frameworks were not readily available, and 4D developers often needed to create their own deployment solutions. The note is identified as Part 1, suggesting a multi-part series covering increasingly sophisticated installation scenarios. It represents a practical solution to a real-world deployment challenge of the late 1990s.
