# Tech Note 99-04: A Simple and Ready-to-Use Installer, Part 1

**Author:** Not specified
**Published:** March 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11829

## Overview
This Tech Note provides a simple, script-based installer for 4D applications that addresses common deployment problems such as incomplete file copies and incorrect file attributes.

## Key Points
- Addresses common installation problems: incomplete file copies, read-only attributes from CD-ROM/diskette copies.
- Provides a ready-to-use installer requiring only script editing.
- Installation script can be edited with SimpleText (Mac OS) or WordPad (Windows).
- Part 1 of a multi-part series on application installation.
- Cross-platform solution for Mac OS and Windows deployment.

## Featured Technology
- 4D v6.0
- Script-based installer
- Cross-platform deployment

## Historical Context
**Status:** Obsolete

Custom script-based installers were a practical necessity in the late 1990s when standardized cross-platform installer frameworks were not widely available. Modern 4D's Build Application feature handles application packaging, and standard OS installer technologies (macOS .pkg/.dmg, Windows .msi) have entirely replaced custom approaches.
