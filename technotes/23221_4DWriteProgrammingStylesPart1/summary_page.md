Part I of a Tech Note series demonstrating how to use the 4D Write plug-in for controlled, style-driven data entry within a document.

## Key Points
- Part I of a two-part series on 4D Write programming styles and entry control.
- Demonstrates using 4D Write in a controlled data-entry environment with extensive use of text styles.

## Historical Commentary
**Status:** Obsolete

The classic 4D Write plug-in referenced here has been succeeded by 4D Write Pro, which offers a substantially different, more modern document and styling model, making this note's specific techniques obsolete for current 4D document development, though the general goal of controlled, style-driven data entry remains a valid application design pattern.
