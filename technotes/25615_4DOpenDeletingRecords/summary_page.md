- Completes a basic-operations trilogy alongside the companion notes on adding and updating records remotely.

- Remote record deletion

## Historical Context
4D Open was the classic plug-in mechanism for cross-database connectivity before native remote datastore/ORDA capabilities existed; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

4D Open as a distinct plug-in is obsolete; modern 4D applications would use ORDA remote datastores or REST APIs to delete records on a remote 4D Server rather than this legacy plug-in mechanism.
