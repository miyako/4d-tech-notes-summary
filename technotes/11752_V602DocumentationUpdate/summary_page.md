# Tech Note: 4D 6.0.2 Documentation Update

**Author:** Not specified in source document
**Published:** June 1, 1997 | **Product/Version:** 4D Server v6.0.2 | **Platform:** Mac & Win

## Overview

This short Tech Note announces that a major revision of the 4D documentation set was released alongside 4D and 4D Server 6.0.2, and that this updated documentation was also distributed via the Partner CD.

## Key Points

- Documentation underwent a major revision coinciding with the initial 4th Dimension 6.0 release.
- The revised documentation ships with 4D and 4D Server 6.0.2.
- Also made available via the Partner CD distribution channel.
- The note is brief and largely administrative/announcement in nature; the teaser likely captures most of its substantive content.

## Featured Technology

- 4D 6.0.2 documentation set
- 4D Server 6.0.2
- Partner CD physical distribution

## Historical Context

Reflects 4D's mid-1990s software/documentation distribution model, which relied on physical CD-ROM media (including the Partner CD channel for partners/resellers) tied to specific point releases like 6.0.2 — a distribution approach long since replaced by continuously updated online documentation and digital software delivery.

## Historical Commentary
**Status:** Obsolete
