This brief Tech Note is essentially a release announcement rather than a technical how-to: it informs customers that, coinciding with the initial release of 4th Dimension 6.0, the 4D documentation set underwent a major revision. It clarifies that this updated documentation version is the one shipped alongside 4D and 4D Server 6.0.2, and notes that it was also made available separately via the Partner CD — a physical CD-ROM distribution channel 4D used at the time to get software and materials into the hands of its partner network. As only the teaser is available (and the note's content appears to be almost entirely captured within that teaser given its brief, administrative nature), there is little additional technical substance to summarize beyond this documentation-versioning announcement. Its practical value in 1997 was to alert customers and partners that the documentation bundled with their existing installation might be out of date relative to this newly revised 6.0.2-era version, and where to obtain the update if needed.
