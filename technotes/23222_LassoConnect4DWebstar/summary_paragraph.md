This Tech Note introduces Lasso 4D, a WebSTAR plug-in provided by Blueworld, which allows WebSTAR to serve as the web server front end for a 4D database. It specifically calls out developers already familiar with Lasso FMP (the FileMaker-targeted version of Lasso) as an ideal audience, since Lasso 4D would be a natural, familiar choice when moving an application from FileMaker to 4D while retaining the same Lasso-based web-serving toolchain.
