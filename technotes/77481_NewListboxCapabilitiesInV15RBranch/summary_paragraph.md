This Tech Note is a feature tour of listbox enhancements added across the 4D v15 R3 and R4 maintenance releases, at a time when 4D shipped incremental "R" releases between major versions. From R3, it documents Single-Click Edit, a mode allowing users to enter cell-edit mode with a single click rather than the previous double-click/select-then-type interaction, including how to enable it, its interaction with selection mode, the On Click event method, and how to set the behavior on specific cells only. From R4, it covers Truncate with Ellipsis Display, letting overflowing cell text be clipped with a trailing ellipsis rather than silently cut off, including control over the clipping location; Hiding Extra Blank Rows, which removes the trailing empty rows a listbox would otherwise render past the last real record, tied to specific form events; and a new Row Control Array mechanism enabling per-row Hidden, Disabled, and Non-selectable states, including how to combine multiple such options on the same row and a small UI for configuring these row-level properties. Listboxes were (and largely remain) one of the most heavily used display objects in classic 4D form-based applications, so incremental UX refinements like these mattered a great deal to real-world application polish at the time. The specific features described (single-click edit, ellipsis truncation, row control arrays) are still present and functional in current 4D listboxes, since classic form-based listboxes were never deprecated even as ORDA and other data-access paradigms were introduced — so this note remains a largely accurate, still-useful reference for classic-listbox development, aside from predating things like collection-type listboxes and View Pro-based grids introduced later.
