Tom Fitch's Tech Note explores an under-the-radar use of SVG in 4D v12: rather than just generating original vector graphics, SVG documents can embed existing raster pictures via the <image> element and then have arbitrary SVG transforms/effects applied to that embedded image. The note walks through three concrete manipulation techniques — resizing embedded pictures, adding reflections, and implementing a fade effect — each described conceptually and then demonstrated in an included sample database. It positions SVG as a complementary option alongside PHP libraries and native commands like TRANSFORM PICTURE for 4D v12 image handling. The conclusion encourages developers to use the three demonstrated styles as a springboard for building further custom image manipulations beyond what's covered explicitly.
