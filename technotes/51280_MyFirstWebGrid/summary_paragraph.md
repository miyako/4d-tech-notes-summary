This Tech Note introduces developers to the 4D Ajax Framework's Data Grid 2.0, a Web 2.0 component for displaying, searching, and editing tabular data in web applications via AJAX and JavaScript. The note explains how the Data Grid functions within the 4D Ajax Framework Client (where tables appear with preset query tabs or sidebar, inline editing, column sorting, and full-screen record editing by default), and then demonstrates how to integrate the same Data Grid into a custom HTML page by using the framework's JavaScript API to construct and manipulate the grid programmatically. Key concepts include referencing predefined CSS files (e.g., leopard.css) for consistent styling, loading necessary JavaScript libraries (resources_en.js, compile.js, and others), and using Data Grid constructors and functions to define layout, bind data from tables or Developer Created Selections (DCS), and enable features like search, add/delete buttons, column header sorting, and field visibility toggles. The note covers basic HTML shell structure, the use of localization files for multi-language support (French, German, Spanish, Japanese), CSS customization for look-and-feel, and practical examples of how developers can build web interfaces that closely mimic desktop 4D list box and grid behavior using a browser-based AJAX frontend connected to a 4D backend.
