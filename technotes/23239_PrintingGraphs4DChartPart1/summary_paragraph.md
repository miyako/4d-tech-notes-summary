This Tech Note is Part I of a two-part series answering common questions about printing graphs created in 4D Chart: what different printing techniques are available, what advantages each offers, how to control the size at which a graph prints, and what convenient interfaces can be provided to let the user trigger printing. Part I evaluates the different available techniques to help developers choose the one best suited to a given situation, and describes the most convenient printing interfaces a developer could offer end users. Part II (also covered in this batch) goes on to cover coding details for handling trickier printing issues, with an accompanying example database.
