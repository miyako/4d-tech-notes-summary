This Technical Note introduces the Maintenance and Security Center (MSC), a new interface in 4D v11 SQL designed to repair, maintain, and report on a database's structure and data files, organized into Information, Activity Analysis, Verify, Backup, Compact, Rollback, Restore, and Repair sections, and available across all 4D developer and deployment applications. It explains that the MSC consolidates functionality previously scattered across several separate places in earlier 4D versions: the "About" dialog box, the Open Database dialog, backup preference settings, and — notably — the entire standalone 4D Tools application, which no longer exists as a separate product once a database is running under 4D v11 SQL. The note details the two operating modes of the MSC: Standard Mode, entered when the database is opened normally (Design/Application environments remain accessible) and limited to Information, Activity Analysis, Verify, Backup, and Restore functions; and Maintenance Mode, required for Compact, Rollback, and Repair operations, during which Design/Application access is unavailable and which is entered automatically if the structure or data file is detected as damaged. It documents the several ways to invoke the MSC — via the Help menu, an MSC toolbar button in Design mode, a custom menu item assigned the "Open MSC" standard action, the OPEN SECURITY CENTER language command, or directly from the operating system's file-open dialog — and notes that compacting, repairing, rollback, and restore are restricted to Administrator or Designer user accounts. It then walks through the Information page in depth, describing how the Program/Tables tabs mirror the old About box while new Data/Structure tabs graphically depict file space usage (used vs. free, in green shading) with warning icons flagging when maintenance is needed, noting that the Structure tab is only available in 4D Developer and 4D Server. As a workflow-and-administration-focused note tied to 4D v11's overhaul of database housekeeping tools, it reflects the broader consolidation and modernization effort that accompanied the introduction of 4D's native SQL engine.
