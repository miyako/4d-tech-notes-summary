# Tech Note 98-14: Creating HTML Tables and Pages from 4th Dimension

**Author:** Not specified
**Published:** October 1, 1998 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11816

## Overview
This Tech Note demonstrates using native 4D commands to generate HTML pages and tables for web publishing, combining record data with static content and leveraging 4D's built-in web server.

## Key Points
- Uses native 4D commands and functions to generate HTML pages and tables.
- Supports both on-demand dynamic generation and periodic static site building.
- Mixes record data with static text to create directories, catalogs, and listings.
- Embeds hypertext links to other documents within generated pages.
- Combines 4D's built-in web-serving with custom HTML-generation code.
- Described as an ideal way to build data-serving web sites.

## Featured Technology
- 4D v6.0
- HTML generation
- 4D built-in web server
- Dynamic and static web content generation
- Server-side web publishing

## Historical Context
**Status:** Obsolete

This note captures 4D's early web publishing capabilities during the late-1990s internet boom. Modern 4D provides a completely modernized web server with REST API support, ORDA for data access, and integration with contemporary web frameworks.
