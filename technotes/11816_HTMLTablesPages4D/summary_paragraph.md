This Tech Note demonstrates how to use native 4th Dimension commands and functions to generate HTML pages and tables for web publishing. The note covers both on-demand dynamic generation and building static sites on an infrequent basis. Developers can mix record data with static text to create directories, catalogs, or listings that include embedded hypertext links to other documents. The approach combines 4D's built-in web-serving capabilities with custom HTML-generation code to build web sites that serve a mix of static web pages and dynamically or statically created tables and pages. This was described as an ideal way to build web sites that serve data, reflecting the late-1990s approach to web development where server-side HTML generation was the standard paradigm. The note captures a pivotal moment in 4D's evolution as it embraced web technologies during the internet boom. These techniques represented cutting-edge web integration for database-driven applications of the era.
