This first installment of a two-part technical note introduces GDIPlus_Image, a Windows-only 4D plug-in built by Thomas Maul (General Manager, 4D Germany) around Microsoft's GDI+ graphics API, and documented by Thang Nguyen of 4D Technical Support. GDI+, the successor to classic Windows GDI, adds features like gradient brushes, alpha blending, scalable regions, and broad multi-format image support (BMP, JPEG, GIF, PNG, TIFF, ICON, WMF, EMF), and the plug-in exposes these capabilities to 4D developers so pictures can be opened, displayed, converted, and saved without recompression. A key motivation is eliminating the requirement to install Apple QuickTime on Windows machines for picture compression and conversion, since GDI+ ships built into Windows XP and Windows Server 2003 (and can be added via a redistributable DLL on earlier Windows versions). The accompanying sample database demonstrates a codec/decoder listing screen, an "Open Picture Document" interface for loading and browsing images, a "Picture Display Properties" panel offering zoom, scroll, crop, rotate/flip, and matrix transformations (rotate, scale, translate, shear, with append/pre-pend ordering), and a "Save Picture Document" screen for converting and exporting into the supported formats with configurable compression and color depth. Part II of the note (not covered here) was planned to cover the plug-in's method-level API in detail. The note positions GDIPlus_Image as a practical, Windows-native alternative to QuickTime-based image handling for 4D applications of that era.
