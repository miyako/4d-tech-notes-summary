# Tech Note 02-50: 4D View Style sheets

**Author:** Not specified in source document

## Overview
A Tech Note on creating 4D View style sheets both interactively and procedurally, including a sample generic routine for saving and reapplying user formatting preferences.

## Key Points
- Covers both interactive (user environment) and procedural (code-based) creation of 4D View style sheets.
- Sample database lets users save formatting preferences and reuse them as globally applicable style sheets.

## Featured Technology
- 4D View
- Style sheets
- Procedural formatting

## Historical Context
4D View was 4D's classic spreadsheet-style area component; style sheets provided a reusable way to apply consistent formatting across 4D View areas.

## Historical Commentary
**Status:** Obsolete

4D View has been discontinued as a standalone product, making the specific style-sheet commands described here obsolete for current development; the general design pattern of saving and reapplying user formatting preferences remains a useful, still-applicable UX idea realized differently in current 4D form objects or web-based UIs.
