This Tech Note explores the Postcard portlet within 4D Portal, which allows a user to select a picture of their choice, add up to 200 characters of personal text, and have the resulting postcard stamped with the current date before being sent — either embedded entirely within the body of an email, or hosted on the server with only a link sent to the recipient. This is a good example of the kind of consumer-facing, socially shareable feature 4D Portal's portlet architecture was designed to support.
