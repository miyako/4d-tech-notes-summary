# Tech Note: Converting the Graph Commands to 4D Chart

**Author:** Not specified
**Published:** September 1, 1998 | **Product/Version:** 4D Chart v6.0.x | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11873

## Overview
This Tech Note is a migration guide for developers transitioning from the legacy GRAPH commands (from 4D v3 era) to the 4D Chart module integrated into 4D v6. It covers implementing Graph command features using 4D Chart, with a focus on creating graphs from arrays.

## Key Points
- Legacy GRAPH, GRAPH TABLE, and GRAPH SETTINGS commands still work in 4D v6 (4D Chart acts as the engine behind them)
- Developers are encouraged to use 4D Chart directly for greater capabilities
- Focuses on array-based graph creation with 4D Chart
- References companion Tech Note 98-22 ("The GRAPH Command in 4D V6")
- Two example databases are provided
- "4D V3" references encompass 4D 3.x.x and 4D Server 1.x.x

## Featured Technology
- 4D Chart (built-in charting module in 4D v6)
- Legacy GRAPH, GRAPH TABLE, GRAPH SETTINGS commands
- Array-based data visualization
