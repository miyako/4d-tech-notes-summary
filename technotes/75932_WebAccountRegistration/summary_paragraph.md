This Tech Note delivers a ready-made Web Account Component (WAC) that adds self-service account registration to any 4D web application, motivated by common patterns like Yahoo!'s account system for gating features, personalizing user data, and building an email list. The component (`WebAccount_1.0.4dbase`), together with the 4D Internet Commands and 4D Pack plug-ins and two sample HTML pages, is installed by copying files into the host database's Components/Plugins folders and wiring five calls — `WAC_Initialize`, `WAC_Shutdown`, `WAC_IsOnWebConn`, `WAC_Settings`, and `WAC_ValidateAccount` — into the On Startup/On Exit/On Web Connection database methods. A GUI-driven settings system lets an administrator configure the web address, post-signup/post-password-change messages, SMTP server details (with optional authentication), and the automated confirmation email's subject/body/signature with username/password placeholders, plus a simple user-administration list showing accounts, passwords, and login timestamps. `WAC_IsOnWebConn` inspects the incoming URL to detect and route `/wac/signup` and `/wac/changepwd` requests coming from the bundled `signup.html`/`changepwd.html` pages (driven by small JavaScript functions that POST via `makeCall`), then redirects the browser afterward to a configured URL or path. All account and settings data is stored outside the 4D data file in easily-imported XML files rather than in database tables. The note positions this as a drop-in building block, leaving the actual login widget and how accounts are used entirely up to the developer.
