# Tech Note: Sending Email from 4th Dimension Version 6.5

**Author:** Not specified in source document
**Published:** June 1, 1999 | **Product/Version:** 4D Internet Commands v6.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11840

## Overview
A practical guide to sending email and attachments from 4D v6.5 using the Internet Commands plug-in's SMTP capabilities.

## Key Points
- Uses the Internet Commands plug-in (formerly PDM's Internet Toolkit) for email
- Demonstrates sending email with attachments to a selection of contacts
- Covers SMTP for sending; notes POP3 available for receiving
- Made 4D a tool for email automation in business workflows

## Featured Technology
- 4D v6.5
- 4D Internet Commands
- SMTP
- POP3
- Email Automation

## Historical Context
**Status:** Obsolete

Email automation via 4D Internet Commands was cutting-edge in 1999. The Internet Commands plug-in (originally PDM's Internet Toolkit) has been superseded by 4D's built-in SMTP/POP3/IMAP transporter classes introduced in v17+, which provide a modern, object-oriented email API without requiring any plug-in.

### Related Updates
- 4D's built-in SMTP/IMAP/POP3 Transporter classes (v17+) replaced Internet Commands for email
- 4D Internet Commands plug-in has been deprecated
