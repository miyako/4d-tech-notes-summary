This Tech Note demonstrates administrative connectivity between a 4th Dimension database and a WebSTAR web server using the 4D WebSTAR API, applied to a concrete example: an employee information database that grants access to specific data based on which department's credentials are used to log in. WebSTAR was 4D's (then StarNine/Quarterdeck/4D-affiliated) web server product for the Macintosh, and this note shows how a 4D database can programmatically interact with and administer aspects of the running WebSTAR server rather than simply being served by it.
