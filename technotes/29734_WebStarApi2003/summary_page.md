## Overview
A Tech Note showing how to use the 4D WebSTAR API for administrative connectivity with a WebSTAR web server, illustrated via a department-based access-control example for employee data.

## Key Points
- Demonstrates administrative connectivity between a 4D database and a WebSTAR web server via the 4D WebSTAR API.
- Worked example: department-based access control for an employee information database.

## Featured Technology
- 4D WebSTAR API
- WebSTAR web server administration

## Historical Context
WebSTAR was a widely used Macintosh web server of the 1990s-2000s with close ties to 4D; this note documents its administrative API integration with 4D databases, and only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

WebSTAR as a web server product is long discontinued and effectively obsolete, and 4D's own built-in web server (used for both the 4D application server and web publishing) has for many years been the standard way to serve 4D web content, making the specific WebSTAR API integration in this note obsolete for current development.
