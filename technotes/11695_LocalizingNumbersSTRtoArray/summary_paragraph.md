This May 1996 Tech Note by Kent Wilbur presents an example database ("Numbers") that converts numeric values into their full textual representation — as currency, plain quantities, or calendar years — across four languages (English, French, German, and Spanish), with currency support for US Dollars, French Francs, German Marks, and Mexican Pesos, and the ability to mix any currency with any display language (e.g. showing French Francs in German). The note walks through a "Try Me" runtime layout demonstrating the conversion interactively, then contrasts two implementation approaches: BUILD CURR and BUILD LITERALS procedures that hard-code every currency name and number word (zero through billion, in each language) directly into 4D arrays inside procedure code, versus a resource-based approach using STR RSRC CURR and STR RSRC LITERA, which instead load the same data at runtime from STR# resources (numbered 15001-15004 and 16001-16004) using the STRtoArray external from ACI_PACK, editable externally with ResEdit or Resorcerer. It highlights that the resource-based procedures are dramatically shorter and that editing behavior requires no code changes — only editing the resource strings — which the note frames as a key localization/maintenance advantage of using resources as a form of externalized, editable configuration data. The Summary reflects on language-specific quirks encountered, noting French and English are structurally closest, German concatenates numbers into long single words, and Spanish is a hybrid that concatenates only some digits. As a fully readable full-PDF Tech Note, this summary reflects the complete document (the bulk of which consists of literal number/currency word tables for each language, summarized here rather than reproduced in full).
