This Tech Note offers 4D developers a comprehensive list of the default keyboard shortcuts available in 4D v11 SQL, organized by topic and listed for both Mac OS and Windows platforms. It opens with a diagram of US keyboard key names and locations on Mac and PC keyboards, then works through shortcuts for opening a database, the general 4D menu, Design mode's File/Edit/Run/Design/Records/Window menus, the Structure Window, Explorer, Method Editor, Form Editor, Property List, Menu Bar Editor, List Editor, Picture Library, Web Services Wizard, Debugger, and User/Runtime mode. It continues into more specialized areas such as data entry in forms and lists, the Label Editor, 4D Chart, and the Export Editor. A closing note reminds readers that these are 4D's defaults, and that shortcuts can be changed by editing the shortcuts.xml file found in the 4D Extensions folder. The note is a straightforward reference document intended to help developers work more efficiently within the 4D Design environment by replacing mouse-driven actions with keyboard shortcuts.
