# Tech Note 09-47: Shortcuts in 4D v11 SQL

**Author:** Luis Piñeiros, Technical Services Team Member, 4D Inc.
**Published:** December 18, 2009 | **Product/Version:** 4D v11.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=75972
**Download:** https://kb.4d.com/DLTN/TN/2009/Windows/TN_2009_46-48_(DEC)/09-47_ShortcutsIn4D.pdf

## Proposition
This note is a comprehensive Mac/Windows reference of 4D v11 SQL's default keyboard shortcuts across its Design-mode menus and editors, intended to help developers work faster by replacing mouse actions with keystrokes.

## Key Points
- Includes a **US keyboard key diagram** covering both Mac and PC extended keyboards.
- Documents shortcuts for **opening a database**, the general 4D menu, and Design mode's **File, Edit, Run, Design, Records, and Window menus**.
- Covers editor-specific shortcuts for the **Structure Window, Explorer, Method Editor, Form Editor, Property List, Menu Bar Editor, List Editor, Picture Library, Web Services Wizard, and Debugger**.
- Also documents shortcuts for **User/Runtime mode**, data entry in forms and lists, the **Label Editor, 4D Chart, and Export Editor**.
- Notes that shortcuts are 4D's **defaults** and can be customized by editing the **shortcuts.xml** file in the 4D Extensions folder.

## Featured Technology
- 4D Design mode keyboard shortcuts (Structure Editor, Method Editor, Form Editor, Debugger, etc.)
- shortcuts.xml customization file

## Best Practices Highlighted
1. Learn and use keyboard shortcuts for frequent Design-mode actions to speed up daily development work.
2. Customize shortcuts.xml when a team's workflow benefits from different key bindings than the defaults.

## Context / Positioning
Published as a practical reference document rather than a technique write-up, giving 4D developers a single consolidated shortcut cheat-sheet across the entire v11 SQL Design environment.

## Historical Commentary
**Status:** Obsolete

This note is a comprehensive reference of default keyboard shortcuts across 4D's Design-mode editors (Structure Editor, Method Editor, Form Editor, Debugger, and more) for both Mac and Windows, and notes that shortcuts.xml can be edited to customize them.

The general value of keyboard shortcuts is timeless, but this specific reference is tied to the pre-Project-mode 4D Design environment and interface layout of v11 SQL; the editors, menu structure, and many shortcuts have since changed substantially (especially with the move to Project mode in v17 and subsequent IDE redesigns), so this document is a historical snapshot rather than an accurate current reference.
