This Technical Note by Luis Pineiros revisits the "Mashup" concept first introduced with 4D Live Window (TN 07-07), updating it for 4D v11 SQL's new Web Area control. It frames Mashups within the then-emerging "Web 2.0" trend of combining data from multiple sources for a richer user experience. Using a Clients/Sales demo database, the note shows how to build a Google Map URL from a client's address and load it into the Web Area via WA OPEN URL, display a client's own website, generate a FedEx tracking URL from a stored tracking number, show product information pages, and dynamically build an HTML correspondence document (complete with header graphics and CSS styling) addressed to a contact — all rendered inside the same embedded browser control. The note closes by encouraging developers to explore further "Mashup" ideas that combine a company's proprietary data with external web content.
