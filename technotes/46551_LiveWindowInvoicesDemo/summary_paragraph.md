This Technical Note by Robert Molina of 4D Inc. explores an Invoices demo database that integrates 4D Live Window (4DLW) 1.1, a Web 2.0 Pack plug-in area that lets a 4D form display live external content — HTML pages, PDFs, Word/Excel documents — using new 1.1 features to capture user click actions in the plug-in area and drive 4D code from them. It first recaps 4DLW 1.0's contribution (viewing arbitrary document types without a special single-purpose third-party plug-in) and lists 1.1's additions: control of the context menu/new window behavior, callbacks to 4D before/during/after clicks, a callback on page load error, get/set content with different encodings, and evaluation of JavaScript functions in the loaded page. Using files from the demo's Extras folder (an Invoice.html template with embedded 4D HTML tags, hide.gif/show.gif icons, and an on-the-fly-generated InvoiceDisplay.html), the note walks through a "v1.0-style" example achievable even without 1.1: pulling Invoice.html into a BLOB, setting 4DLW preferences via `Web_SetPreferences`, processing the embedded 4D HTML tags with `PROCESS HTML TAGS` (the same mechanism used by the 4D Web Server), saving the resulting BLOB as InvoiceDisplay.html on disk, and displaying it in the Live Window area via `Web_SetURL`, with a `DELAY PROCESS` inserted to give the OS time to finish writing the file. It then demonstrates the genuinely new 1.1 capability: capturing clicks on an invoice reference number inside the Live Window area to open the related [Invoices] record in a new process/window, implemented by setting the `Web_kNavigate` preference to cancel default navigation and call a developer method (`W_BrowserNavigate`), combined with `Web_kNavigateFilter` to restrict navigable URLs to those containing "/Browser/". The full form-level "On Load" event code is reproduced, showing platform-specific path handling (colon-to-slash/pipe conversion for Mac vs. Windows) alongside the BLOB/HTML-processing/display sequence. As with the companion 4DAF-focused notes of this period, the Technical Note flags 4D Web 2.0 Pack's subscription-based, fast-iterating nature and directs readers to the daxipedia wiki for the latest 4DLW information.
