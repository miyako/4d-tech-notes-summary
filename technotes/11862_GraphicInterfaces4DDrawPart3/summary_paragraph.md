This Tech Note, authored by Tim Tonooka of ACI Technical Support, is the third installment in the interactive graphic interfaces series for 4D Draw v6.5. It focuses on the "Image Data" page of the "BMP Picture Properties" window in the v65Trace example database, where a BMP picture is displayed in a 4D Draw area and users can click on any pixel to display detailed information about it. The note provides exhaustive code walkthroughs of over a dozen methods: DRW_BMPInfoWindow (which sets up the properties window in a new process), DRW_BMPInfoCoordinates (which configures the 4D Draw area with hidden interface elements, disabled tools via DR EXPERT COMMAND and DR EXPERT MODE, event filtering for Ctrl/Cmd-click, and background image placement), the tab control method for lazy page initialization, DRW_BMPPixelInfo (which handles pixel click responses including coordinate calculation, cursor drawing/moving/toggling, and BMP color data extraction from BLOB storage), and several helper methods for coordinate translation, cursor geometry, range restriction, and unit conversion. The note demonstrates sophisticated 4D Draw techniques including DR EVENT FILTER for selective event handling, DR SET HANDLE STATE for hiding selection handles, DR SET UPDATE MODE for performance optimization during multiple object modifications, and DR SET PREFERENCES for suppressing save dialogs.
