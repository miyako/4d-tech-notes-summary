This Tech Note explains how to integrate the OpenSearch standard — the XML-based description format adopted by browsers like Chrome, Firefox, and Internet Explorer — with a 4D Web Server so that end users can search a 4D database's data directly from their browser's built-in search box rather than navigating to the site. It walks through the anatomy of an OpenSearch description document (ShortName, Description, Image, and URL elements), explains how to make the search provider discoverable to browsers, and then covers the 4D-side implementation: building keyword indices, parsing a user's search string into keywords, constructing a query from those keywords using DISTINCT VALUES and related commands, and returning HTML result pages back to the browser. A bundled sample database populated with Wikipedia articles demonstrates the complete round trip from browser search box to 4D-generated results page. The note positions 4D's Web Server as a capable, standards-compliant participant in the broader web ecosystem, not just a static content host. It is squarely aimed at developers wanting to make 4D-hosted content more discoverable and search-friendly for end users already accustomed to browser-integrated search tools.
