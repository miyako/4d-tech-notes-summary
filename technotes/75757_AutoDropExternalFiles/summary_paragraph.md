This Tech Note explores drag-and-drop functionality for 4D form objects, focusing on the newly introduced Automatic Drag and Automatic Drop properties in 4D v11 SQL. Unlike the older Draggable/Droppable properties (available since 4D 2004) which require the developer to write code in On Begin Drag Over, On Drag Over, and On Drop form events, Automatic Drag/Drop let 4D handle the insertion of external data itself whenever possible — triggering only the On Data Change and On After Edit events, with no code required at all. The note's included demo database has a form with three droppable area types — Picture Variable, Web Area, and Text Variable — and it systematically documents what happens when different file types are dropped into each: dragging a JPG or a PDF into a Picture Variable (noting that only the first page of a multi-page PDF is captured), dragging pictures, PDFs, rich text, plain text, a text selection, HTML files, and QuickTime movies into a Web Area (a new object type in v11 SQL supporting many external formats), and dragging a text selection into a Text Variable. Practical tips and caveats are given throughout, aimed at developers wanting to add polished, low-code drag-and-drop file handling to their 4D solutions.
