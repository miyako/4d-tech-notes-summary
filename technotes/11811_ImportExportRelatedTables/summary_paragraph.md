This Tech Note addresses the limitation that 4D's built-in Export Data and Import Data menu items in User mode only work with the current table, not related tables. It presents two solutions for importing and exporting related table data. The first approach uses 4D's Quick Report feature in User mode to generate a text (ASCII) document that can then be imported or opened in other applications. The second approach uses 4D programming commands from the Communication category — SET CHANNEL, SEND PACKET, RECEIVE PACKET, and SEND RECORD — to write custom export and import methods in Runtime or User mode. These workarounds were necessary because the standard import/export workflow in 4D v6 did not support traversing relationships to include data from multiple tables in a single operation. The note provided practical solutions to a common data management challenge.
