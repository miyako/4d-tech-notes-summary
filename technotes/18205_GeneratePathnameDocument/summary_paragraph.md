This Tech Note (TN 01-42, 4D v6.5, Mac & Win, published September 30, 2001) by Pascal Pradier of 4D, S.A. shows how to programmatically construct a 4D Client "pathname" (.PTH) document -- the file that lets a 4D Client connect to a specific 4D Server database automatically, without the user manually selecting a server or typing a login. Pradier documents the file's exact 148-byte binary layout: an 80-byte Pascal string holding the server's TCP/AppleTalk/IPX address (or a database name plus machine name for DHCP environments) at offset 0, a 31-byte Pascal string for the username at offset 52, a 31-byte Pascal string for the password at offset 72, and a 2-byte network-component identifier at offset 146 whose byte order must match the target platform (Mac vs. Windows). The accompanying MakeKey method builds this structure using SET BLOB SIZE and TEXT TO BLOB/INTEGER TO BLOB, after which the resulting blob is written to disk with BLOB TO DOCUMENT and, on Mac, tagged with the correct file type and creator codes (SET DOCUMENT TYPE/SET DOCUMENT CREATOR) so 4D Client recognizes it as a pathname document. This lets a developer generate per-customer or per-server connection files automatically -- for example at install time or when a database's true production name differs from its interpreted-mode development name -- rather than requiring users to create them by hand through the 4D Password editor.
