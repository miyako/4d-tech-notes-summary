This Tech Note (TN 01-42, 4D v6.5, Mac & Win, published September 30, 2001) presents a technique for automatically generating a document referenced by a full pathname in 4D. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_41-45_(SEP)/01-42_Generate_Pathname_Doc.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: The purpose of this technical note is to show you how you can generate a pathname document automatically. Its featured technology centers on 4D document/pathname commands, File system automation, reflecting typical concerns of the 4D 6.5 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This short note shows how to automatically generate a document referenced by a full pathname in 4D, a foundational file-handling task. The classic-language document and pathname-handling commands it relies on remain part of current 4D versions and function essentially the same way today, making the core technique still directly applicable, even as 4D has since added higher-level File/Folder object commands for more structured file-system access.
