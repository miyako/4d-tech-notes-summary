This Technical Note introduces two new companion plug-in products released alongside 4D 2004 — 4D for MySQL and 4D for PostgreSQL — designed to give 4D databases a more direct communication path to these two popular open-source relational database management systems than was previously available through generic ODBC. The teaser frames MySQL and PostgreSQL as leading open-source SQL-based DBMSs that some 4D solutions were already interfacing with via ODBC, and positions the new plug-ins as a more streamlined alternative specifically tailored to those two targets. The note states that it covers the steps developers need to know when implementing a 4D database that works with MySQL and PostgreSQL, demonstrated through the two new plug-ins, though the specific installation steps, command syntax, and worked examples are not recoverable since only the brief on-page teaser (not the full PDF/example archive) was available for this entry. As one of several ODBC/external-database-focused notes published in this period, it reflects 4D's push in the mid-2000s to broaden interoperability with the open-source database ecosystem beyond the Windows-centric ODBC world.
