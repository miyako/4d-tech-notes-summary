4D v11 SQL Release 3 introduces many improvements and features to the 4D v11 SQL line of products. One particularly useful feature is the support of schemas in 4D’s integrated SQL engine. The implementation of this feature has resulted in modifications to the interface and the introduction of new SQL commands. This technical note describes the changes to the interface as well as the new SQL commands. A sample database component is included. Published December 10, 2008 as Technical Note 08-43 for 4D v11.3 (Mac &amp; Win), this note was written by Timothy Aaron Penner, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
