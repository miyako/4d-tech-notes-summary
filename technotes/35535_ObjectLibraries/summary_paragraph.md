Written by Jonathan Le of 4D Technical Support, this Tech Note introduces Object Libraries, a 4D 2004 feature that lets developers store form objects -- complete with their properties and object methods -- in an external, shareable file without needing the separate 4D Insider tool. It explains how an Object Library differs from a 4D Insider library (Object Libraries hold only form objects, but are usable directly by any database and by end users through the new EDIT FORM command, whereas Insider libraries can hold anything but require the Insider application) and walks through creating, dragging, and pasting objects between a form and a library window. A significant portion covers writing "generic" objects that work regardless of the table or database they're dropped into, using commands like Current form table and Table name instead of hard-coded table pointers, and discusses the tradeoffs of "standalone" objects versus objects that depend on companion project methods delivered via a Template or Component. The note demonstrates the EDIT FORM command, which lets end users in Custom Menus mode edit "Editable Forms" using a developer-supplied Object Library (excluding any objects that carry object code, since compiled databases can't add code at runtime), and closes by showcasing bundled Object Libraries for Microsoft Office 2003/2004 and Mac iApps (Word, Excel, iCal, Address Book) built with LAUNCH EXTERNAL PROCESS, APPLY XSLT TRANSFORMATION, and PROCESS HTML TAGS.
