The Object Library is a new addition to 4th Dimension that provides a type of permanent storage for objects. Unlike the traditional 4D Insider libraries components, these object libraries can be integrated directly into databases 4D without the need to install, move, or copy anything from Insider. This 2005-era Tech Note (TN 05-02) was published for 4D version 2004 on Mac & Win, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). Only the short on-page teaser paragraph for this note could be recovered in this archive pass — the full PDF/example download was not accessible — so the summary here reflects only that teaser text rather than the complete technical content of the original note. Featured technology associated with this note includes: 4D Object Libraries, 4D Insider component libraries, Structure-file object storage. This note introduces Object Libraries, a new-in-2004 mechanism for storing reusable objects directly inside a 4D database's binary structure without needing the separate 4D Insider tool. This was an early step toward modularizing structure-file content, foreshadowing (though very different from) the later component and Project Mode architectures. The specific Object Library mechanism belongs to the binary Design Mode era and has been superseded by 4D's modern component system and Project Mode's plain-text, filesystem-based structure organization.
