This Technical Note (26-02, published February 27, 2026, requires 4D 21 LTS and OpenSSL 3.0+) documents integrating the OpenSSL command-line tool into a 4D application asynchronously via the `4D.SystemWorker` class, replacing legacy blocking `LAUNCH EXTERNAL PROCESS` calls with a non-blocking, callback-driven architecture. A class-based pattern (`OpenSSLWorker`) centralizes five SystemWorker callbacks — `onResponse`, `onData`, `onDataError`, `onError`, and `onTerminate` — each receiving the SystemWorker object and an event object, with the class constructor accepting a completion function and a `timeout` property to guard against hung processes. The core `Execute_OpenSSLAsynch` method detects whether it is already running inside a worker process (`Process info(Current process).type`) and, if not, spawns one via `CALL WORKER`, since asynchronous callbacks only fire inside a worker created that way, not via `New process`; it never calls `wait()`, so the calling code returns immediately while the OpenSSL command executes in the background. A generic `onFileGenerated` callback handles post-completion behavior uniformly across private-key, CSR, certificate, and signed-XML generation, converting output paths to 4D `File` objects and using the `platformPath` property so `SHOW ON DISK` works correctly on both Windows and macOS. An `openssl.cnf` configuration file with `prompt = no` automates Distinguished Name fields and serial numbers for headless CSR generation, and XML documents are signed via OpenSSL's `smime` command with the critical `-binary` flag (to prevent line-ending corruption that would invalidate the signature) and `-nodetach` (to bundle signature and content together). The resulting certificate/key files are copied to `cert.pem`/`key.pem` in the project root and loaded via the `4D.WebServer` class to enable HTTPS. Security guidance covers restrictive private-key file permissions (chmod 600 / NTFS ACLs), never committing keys to version control, and using CA-issued (not self-signed) certificates in production, alongside troubleshooting for missing OpenSSL binaries and invalid XML signatures caused by omitting `-binary`.
