This Tech Note is Part I of the LDAP series covered in this batch (Part II is also included), motivated by the growing enterprise adoption of LDAP servers and the resulting need to integrate 4D into an LDAP environment for user authentication. It shows how to write a custom LDAP plug-in usable within 4D to log into an LDAP server and authenticate a user, since 4D had no native LDAP support at the time. Only the short on-page teaser text could be recovered here, so the specific plug-in implementation details are not available, but this represents a substantial engineering effort — building a protocol-level plug-in — undertaken to solve a common enterprise integration need.
