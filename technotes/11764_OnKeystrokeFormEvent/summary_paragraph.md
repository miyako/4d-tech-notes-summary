This Tech Note explains and demonstrates the On Keystroke form event, one of the new V6 Form Events that let a 4D program capture and respond to user actions — in this case, individual keystrokes — while the user is typing in an enterable form object. It explicitly contrasts this with the prior V3 approach, which required using On Event Call along with considerably more manual coding effort to achieve similar results; On Keystroke is presented as a much simpler, more direct way to react to user typing in real time. The note covers how 4D handles enterable objects and the user actions performed on them, the issues involved in maintaining an enterable object's value correctly while intercepting keystrokes, and the concrete steps needed to implement On Keystroke-based logic. It is accompanied by an example database containing interactive demonstrations of possible On Keystroke use cases, along with ready-to-use example code that developers could drop directly into their own applications. As a practical, code-forward Tech Note built around one of 4D v6's flagship new event-handling features, it targets developers looking to build more responsive, validated, or formatted data-entry interfaces without the heavier V3-era workarounds.
