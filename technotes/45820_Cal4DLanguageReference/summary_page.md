# Tech Note 07-10: Cal4D Component - Language Reference

**Author:** Dave Batton (Cal4D component author)
**Published:** March 14, 2007 | **Product/Version:** 4D 2004 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=45820
**Download:** https://kb.4d.com/DLTN/TN/2007/Windows/TN_2007_10-12_(MAR)/07-10_Cal4D_Language.exe

## Overview
This is Part Two of a two-part Technical Note documenting the Cal4D component, a full-featured calendar add-on written by Dave Batton that a 4D developer could add to any 4D 2004 database. Part One (Tech Note 07-09) covered installation and basic use; this Part Two is specifically the language reference for the component's public methods.

## Key Points
- Cal4D is described as a "full-featured Calendar" component installable into any 4D 2004 database.
- This note's specific scope is the language reference — documenting the public methods exposed by the component for programmatic interaction.
- A sample database with source code was distributed alongside the note, offered separately for Windows and Mac.
- The demonstration is explicitly noted as subject to 4D's Partnerware component licensing agreement, indicating Cal4D is a third-party/partner-contributed component rather than a first-party 4D feature.

## Featured Technology
- Cal4D calendar component (public method / language reference)
- 4D 2004 partnerware component model
