This Tech Note is the third in a series on mapping in 4D (following TN 09-29 on Google Maps and TN 09-30 on geocoding), and it introduces OpenStreetMap and the OpenLayers JavaScript framework as an alternative to Google Maps' API, motivated by Google's restrictive terms of service and gaps in map data. It first shows the simplest approach — directly loading the OpenStreetMap website into a 4D Web Area via a constructed URL with latitude/longitude/zoom parameters — then demonstrates using `WA Execute JavaScript` to inject custom JavaScript that hides unwanted page chrome (sidebar, navigation) or even calls OpenLayers' own JavaScript API to place a marker. The bulk of the note then walks through building a self-contained OpenLayers page from scratch: a helper method (`Geo_OpenLayerOSM`) uses `PROCESS HTML TAGS` to substitute `#4DVAR` placeholders (longitude, latitude, zoom) into an HTML template, writes the result to the temporary folder, and loads it into the Web Area. Later sections cover adding multiple map layers, incorporating Google Maps tiles as an OpenLayers layer, handling click events, and exporting the rendered map as a picture. The note licenses OpenStreetMap data under Creative Commons Attribution-Share Alike and clarifies when that license does or doesn't extend to an application's own output.
