Written by Jonathan Baltazar of 4D, Inc. Technical Support, this Tech Note introduces the 4D v6.7 Web Assistant, a component-based tool that lets developers publish database tables to the Internet or intranet without hand-writing web-serving code. It covers installing the Web Assistant into an existing database via 4D Insider's Components menu (requiring manual additions to the On Web Connection, On Web Authentication, and, for 4D Server, On Server Startup/On Server Shutdown methods, plus specific Database Properties settings) versus simply checking 'Install 4D Web Assistant' when creating a new database, which configures everything automatically. Once installed, the wbaPalette method opens a floating palette with four functions: Start/Stop Web Service; Set Tables and Fields, which manages per-user table visibility and read/add/modify/delete ('r'/'a'/'m'/'d') access, plus List View (sort order, records-per-page), Detail View, and Search Fields configuration per table; an HTML Editor for customizing the header/footer of the Home, Login, List View, Detail View, Search Screen, and Message pages using predefined tags (Message, NavBar, DatabaseName, Another4Dsolution, Login, LoginPict, SearchPict); and an Appearance Editor for table-rendering preferences like list/detail border widths. The note closes with a hands-on walkthrough publishing the sample Music_Library database (Album, Artist, Tracks tables) end-to-end, from setting Guest access levels to customizing the Home page's message and navigation bar using the HTML Editor's tags.
