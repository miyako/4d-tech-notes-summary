This Tech Note describes integrating computer-vision facial detection and recognition capabilities into 4D by calling out to Python and the OpenCV library. It explains the theory behind Haar Cascade classifiers for face detection — Haar-like features, feature detection, boosting features via AdaBoost, and cascading classifiers — before showing the corresponding OpenCV Python API (CascadeClassifier and its detectMultiscale method) and how detected faces are displayed to the user. It then covers facial recognition using the Local Binary Patterns Histogram (LBPH) algorithm via OpenCV's FaceRecognizer, including building a labeled training set, normalizing training images, and running prediction against new images. The bridge between 4D and Python is achieved through 4D's mechanism for running Python functions from 4D code, and the note packages this into three demo-ready 4D functions: PY_DETECT_FACES(image;dest;preview;...) for locating faces in an image, PY_CROP_FACES(image;folder;...) for extracting detected faces to files, and PY_CREATE_RECOGNIZER(savePath;images;labels) for training a recognizer. This is a good example of a 4D Tech Note that leans on an external, actively-maintained ecosystem (Python/OpenCV) rather than purely native 4D commands, which is both a strength (the vision algorithms have not gone stale) and a liability (the specific Python/OpenCV API calls shown — e.g., createLBPHFaceRecognizer(), Haar Cascade classifiers — reflect OpenCV's older Python 2-era API; OpenCV has since introduced deep-learning-based face detection/recognition (DNN modules, dlib, face_recognition libraries) that are far more accurate than Haar Cascades and LBPH, which are now considered legacy computer-vision techniques even within the OpenCV world itself). 4D's cross-language interoperability mechanism for calling Python is also an area that has evolved considerably since 2016.
