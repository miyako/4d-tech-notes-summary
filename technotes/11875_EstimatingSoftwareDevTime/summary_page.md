# Tech Note: Estimating Software Development Time

**Author:** Not specified
**Published:** April 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11875

## Overview
This Tech Note discusses the skill of estimating software development time, framing it as one of the most important yet least understood skills a programmer needs. It positions estimation within the broader context of non-coding skills required for successful software development.

## Key Points
- Software development success requires more than coding skills
- Important non-coding skills include interpersonal abilities (e.g., empathy for understanding end-user needs) and technical skills (e.g., project management)
- Development time estimation is identified as "probably one of the least understood and implemented skills, yet one of the most important"
- Teaching institutions often ignore these skills, leaving programmers to learn them independently

## Featured Technology
- Software project management
- Development time estimation methodologies
