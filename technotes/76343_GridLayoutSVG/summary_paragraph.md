This Tech Note introduces grid layouts — a way of displaying data in tiled grid form rather than the traditional row-based output — as a then-novel presentation option made practical in 4D thanks to the SVG component's integration. It defines what a grid layout is and its common uses, then presents a dedicated Grid Layout component whose input parameters are arrays and whose output is a rendered picture, documenting its full method set: GL_Attribute_Get, GL_Attribute_Set, GL_DrawGrid_Image, GL_DrawGrid_Text, GL_Error_Get, GL_Initialize, GL_Template_Create, GL_Template_Delete, and GL_Template_GetNames, along with the ID array and attribute system that drives them. It covers how to install and use the component (sizing, vertical/horizontal scaling, picture format, context menu behavior) and walks through five demo scenarios covering text, images, interactive events, attributes, and templates. The note closes with suggested next steps — pagination, mixed text-and-image grids, and per-piece text styling — for developers wanting to extend the component further. It is aimed at developers wanting a visually distinctive, tile-based alternative to conventional list/table displays.
