Thomas Maul, General Manager of 4D Germany, shows how to control the free, cross-platform cURL command-line tool from 4D 2004 using the new LAUNCH EXTERNAL PROCESS command, avoiding the need to build a dedicated plug-in for HTTP(S)/FTP(S) client work. cURL ships preinstalled on Mac OS X and can be distributed alongside a Windows database via the new "4D Extras" folder for automatic Client installation. The example database's RunCurl (text results) and RunCurlBlob (binary results up to full PDFs or images) methods wrap calls to the tool. The first demo does a simple GET of a URL; a second, more complex demo automates HTTP POST against a real EU VAT-number-validation web service, building the POST body manually (Lang=EN&MS=..&ISO=..&VAT=..) and parsing the plain-text reply for "valid"/"invalid" phrases — the note walks through using Firefox's "View Page Info" to discover a target page's actual HTML form field names. A third, most elaborate demo performs an automated Google Image search, chaining curl's cookie-jar support (-b/-c cookies.txt) to preserve a session, a spoofed User-Agent and Referrer (-A, -e) to satisfy Google's bot checks, MacRoman-to-ISO/URL character encoding for the search term, and a form-driven On Timer loop to fetch each of the first 20 result thumbnails one at a time via RunCurlBlob so the UI does not freeze — explicitly flagged as being for educational purposes only, given Google's terms of service against automated queries. The note closes with Windows-specific installation guidance (bundling curl.exe via Get 4D folder(Extras Folder), optional OpenSSL for the SSL build) and recommends packet-sniffing tools (Ethereal/MacSniffer, HTTPLook) for debugging cURL sessions.
