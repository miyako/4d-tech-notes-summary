This Tech Note introduces cURL as a free, open-source, cross-platform command-line tool for performing HTTP(S) GET and POST requests with full support for cookies, Referrer and User-Agent headers, and authentication, alongside FTP(S) and other protocol support and the ability to automatically fill and submit web forms. The note highlights cURL's practical advantages for 4D developers of the era: it requires no installation on Windows and ships already available on Mac OS X, making it an accessible, dependency-light way to add rich HTTP/FTP client capabilities to a 4D application. The key enabling technology tying it to 4D is the then-new LAUNCH EXTERNAL PROCESS command introduced in 4D 2004, which lets a 4D method invoke an external command-line program (cURL) and interact with its input/output, effectively turning cURL into an ad-hoc HTTP/FTP client library for 4D long before 4D had any native HTTP client commands of its own. This external-process-based integration pattern reflects a broader theme visible across this era's Tech Notes: as 4D increasingly needed to talk to the web (dynamic publishing, XML, emerging web services), developers filled gaps in 4D's built-in networking capabilities by shelling out to capable, freely available external tools like cURL.
