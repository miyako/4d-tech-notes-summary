This Tech Note demonstrates how to use 4D's FTP commands to build a cross-platform FTP client application that allows users to connect to an FTP site and upload files, all from within a 4D database application. The included sample application works on both Mac and Windows platforms. Users need access to an FTP site with privileges that allow directory creation and file uploading, and the code must be adapted slightly to specify the specific site details before use. The note leverages 4D Internet Commands, the plug-in that provided FTP, HTTP, SMTP, POP3, and other internet protocol support to 4D applications during this era. Written in December 1999, FTP was still a primary method for file transfer, especially for web publishing and file sharing. The full PDF was not recoverable from the original page.
