Written by Gou Yang of 4D Technical Support, this Tech Note demonstrates how 4D 2003's new native XML-parsing commands can retrieve and publish RSS (Really Simple Syndication) feeds, since RSS is itself a dialect of XML; it recommends reading the earlier Tech Note #03-6 on general XML parsing first. The note covers three of RSS's seven historical versions -- 0.91, 1.0, and 2.0 (the others being considered obsolete) -- and walks through the `RSS_1` project method, credited to Justin Leavens of Lizeric Inc. and modified by Yang, which handles 0.91 and 2.0 feeds: it opens the source with `Parse XML source`, optionally reads the version via `GET XML ATTRIBUTE BY NAME`, then walks the document tree with nested `Get First XML element`/`Get Next XML element` loops, watching for `Item` tags and, within them, `Title`/`Link`/`Description` tags, storing each parsed headline into an `[RSS]` table (creating a new record via a `[Counter]` sequence or updating an existing one matched by headline) before finally releasing the parsed document with `CLOSE XML` to avoid a memory leak. It then explains why that same method fails on RSS 1.0 feeds -- their `<Item>` elements sit at the same hierarchy level as `<Channel>` rather than nested beneath it -- and presents a modified `RSS_2` method that handles this flatter structure by checking for `"Item"` and `"Channel"`/`"image"` tag names at the top level of the loop. The note closes by showing the front-end picker that lets a user choose which feed to load (4Dtoday's own RSS 0.91 feed, or the public xml.com sample feeds for each version) and calls `SEND HTML FILE("RSS.html")` to publish the parsed, ordered results as a web page.
