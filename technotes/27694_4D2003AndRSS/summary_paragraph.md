This Tech Note demonstrates how 4D retrieves an RSS (Really Simple Syndication) feed and then publishes its content, made possible because RSS is a form of XML and 4D 2003 gained the ability to parse XML documents. The note explicitly recommends first reading technical note #03-6, "Parsing XML Documents" by Dave Dell'Aquila (also covered in this batch), since familiarity with basic XML parsing and interpretation is assumed as a prerequisite. This is a good concrete, timely application of 4D 2003's new XML capabilities to a real-world, popular content-syndication format of the era.
