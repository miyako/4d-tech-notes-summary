Authored by Timothy Tse of 4D Inc. in February 2017, this tech note demonstrates how to build an interactive, modern-looking toggle switch UI control in classic 4D forms — a control 4D never provided natively — by exploiting two features new in 4D v16: the "On Mouse Up" form event, which fires when the user releases the mouse button over a picture object, and the "Is waiting mouse up" command, which reports whether the mouse button is still held down. The note explains the toggle switch concept (a round button riding over a background container, togglable by click or by dragging), then walks through implementation: using two picture variables (button and container), populating them via READ PICTURE FILE, detecting drag gestures through the new mouse-up event/command pair, updating the container's background image based on toggle state, and finally encapsulating all of a toggle's state (position, value, associated container/button variable names) into a single 4D object so multiple independent toggle switches can be created and managed on one form via a reusable initialization method (TogObj_Init). A working demo database accompanies the note. This is a classic "developer craftsmanship" technical note: it takes a genuinely new but narrow platform capability (the v16 mouse-up event) and builds a complete, reusable UI pattern around it, encapsulated in a 4D object for cleanliness. The underlying commands remain supported in current 4D, so the code itself would still run, though contemporary UI needs — especially for anything beyond a classic desktop form — are increasingly met by native toggle/switch widgets in web-based (Qodly) interfaces rather than hand-built picture-swap tricks.
