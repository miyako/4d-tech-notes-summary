Tech Note: Custom Password System with 4D Ajax Framework (TN 08-16, 4D Web 2.0 Pack v11.1, April 30, 2008) — By default the 4D Ajax Framework ships wired to 4D's built-in Password System for user authentication, but this note walks through swapping in a fully custom authentication scheme instead — covering which framework configuration hooks and login-flow methods must be overridden so a database can use its own user/password table and validation logic rather than 4D's native password system.
