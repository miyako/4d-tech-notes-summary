This Tech Note demonstrates a less common use of 4D: establishing a dialog with a microcontroller (specifically a BASIC Stamp) to acquire real-world sensor data. In the example, 4D interfaces with the microcontroller to retrieve and process data coming from a temperature sensor, an early example of 4D being used for hardware/IoT-style integration well before "IoT" was a common term. Only the short on-page teaser text could be recovered here, so the specific serial communication protocol and 4D commands used to talk to the BASIC Stamp are not available, but this is a genuinely unusual and creative use case for a business-application development platform.
