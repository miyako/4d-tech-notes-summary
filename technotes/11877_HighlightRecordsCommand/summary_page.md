# Tech Note: Introducing the HIGHLIGHT RECORDS command

**Author:** Not specified
**Published:** September 1, 1999 | **Product/Version:** 4D v6.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11877

## Overview
This Tech Note introduces the HIGHLIGHT RECORDS command, a new addition to 4D v6.5, which enables developers to programmatically highlight (select) records displayed in standard 4D output forms. This fills a key gap in building keyboard-driven database applications.

## Key Points
- Previously, selecting records in 4D output forms required the mouse—no programmatic alternative existed
- HIGHLIGHT RECORDS allows fully keyboard-driven database interfaces for the first time
- A working example is demonstrated in the "4D MetaBASE" database
- The command works with standard 4D output forms on both Mac and Windows

## Featured Technology
- HIGHLIGHT RECORDS command (new in 4D v6.5)
- Keyboard-driven UI design patterns
- Standard 4D output forms and record selection

## Historical Context
**Status:** Still relevant

The HIGHLIGHT RECORDS command remains available in current versions of 4D. The broader UI landscape in 4D has evolved significantly since 1999—list boxes, ORDA-based entity selections, and web-based interfaces have largely supplanted the classic output form paradigm that this command was designed for. Nevertheless, the command is still useful for developers maintaining or working with classic 4D form-based interfaces.
