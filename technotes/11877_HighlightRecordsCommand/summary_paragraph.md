This Tech Note introduces the HIGHLIGHT RECORDS command, new to 4D v6.5, which enables developers to programmatically select records in output forms without requiring mouse interaction. The author describes a longstanding challenge in 4D interface design: creating fully keyboard-driven applications was previously impossible because selecting records in output forms always required the mouse. The HIGHLIGHT RECORDS command solves this limitation, making it possible to build database applications that are completely keyboard-driven. A working example is provided in the "4D MetaBASE" database, which was originally developed for other purposes but demonstrates this technique. The note reflects the 1999 era's focus on accessibility and power-user interfaces where keyboard efficiency was highly valued. The command remains available in modern 4D, though the UI patterns around it have evolved significantly.
