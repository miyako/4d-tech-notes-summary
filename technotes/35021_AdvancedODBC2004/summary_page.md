# Tech Note 04-48: 4D 2004 Advanced ODBC

**Author:** Not specified in source
**Published:** December 2, 2004 | **Product/Version:** 4D ODBC v2004 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=35021
**Download:** https://kb.4d.com/DLTN/TN/2004/Windows/TN_2004_46-48_(OCT)/04-48_2004_Advanced_ODBC.exe

## Overview
This note introduces the new low-level commands added to the 4D ODBC plug-in for 4D 2004, intended for developers who already have general DBMS knowledge and familiarity with SQL, going beyond basic ODBC connectivity into finer-grained control.

## Key Points (from available teaser)
- Provides an overview of the new low-level 4D ODBC commands introduced in 4D 2004.
- Demonstrates a technique for applying these commands for different purposes.
- The accompanying example reportedly shows several capabilities achievable via the new native ODBC support.
- Explicitly aimed at readers already comfortable with SQL and general DBMS concepts, not ODBC beginners.

## Featured Technology
- 4D ODBC plug-in (low-level command set)
- SQL / relational DBMS connectivity concepts
- Open Database Connectivity (ODBC) standard

## Historical Context
**Note:** Only the on-page teaser paragraph for this Tech Note could be recovered; the full PDF and example database were not accessible in this environment (old archive format could not be retrieved), so specific commands and code examples cannot be summarized here. Broadly, ODBC-based external database connectivity concepts remain valid, but 4D's own data access architecture has evolved substantially since 2004, first with a native SQL engine (4D v11 SQL, ~2007) and later with ORDA (2018), both of which reduced how central low-level ODBC plug-in commands are to everyday 4D development.
