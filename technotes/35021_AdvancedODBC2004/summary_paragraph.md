This Technical Note introduces the new low-level command set added to the 4D ODBC plug-in in 4D 2004, positioning it for developers who already have general DBMS knowledge and familiarity with SQL. According to the teaser, the note provides both an overview of these new low-level ODBC commands and a technique for applying them to a variety of purposes, moving beyond the simpler high-level ODBC access that most 4D developers were accustomed to. The accompanying demonstration is said to include several capabilities achievable through the new native 4D ODBC support, though the specific commands, code samples, and worked examples are not recoverable from the teaser alone, since only the on-page summary paragraph (not the full PDF or example database) was available for this archive entry. The note is explicitly scoped to intermediate/advanced users: readers are expected to already understand SQL and general database concepts, distinguishing it from more introductory ODBC primers published around the same period. As with other 2004-era 4D-and-external-database notes, its practical value today is limited by the many database-access advances 4D has made since, including a built-in SQL engine and ORDA.
