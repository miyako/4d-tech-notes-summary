This Tech Note, written by Jamras Komoncharoensiri (4D Technical Support), is the first of a two-part series covering 4D Blogger, a web-logging (blog) system built in 4D that combines standard HTTP publishing with the SOAP Web Services technology introduced in 4D 2003. It describes 4D Blogger's two-application architecture: a WebLog Server (a 4D database that records blog posts and serves them over HTTP or SOAP) and a WebLog Client (a rich 4D SOAP-client application with a calendar, search, and a 4D Write-based log editor). The bulk of the note documents the SOAP methods published by the server -- SOAP_CreateWebLog, SOAP_ModifyWebLog, SOAP_DeleteWebLog, SOAP_SetArchive, SOAP_Search, SOAP_SearchByDate, and SOAP_ReceiveMonthArchives -- each declared with `SOAP DECLARATION` for its Is Text/Is LongInt/array inputs and outputs, and shows how the On Web Authentication database method gates which SOAP calls require a valid username/password via a custom FN_isValidUser check. On the client side, it explains two necessary modifications to auto-generated SOAP proxy methods: installing a SOAP_Err_Handler method (via ON ERR CALL) that inspects Get Web Service error info to handle SOAP faults, HTTP errors (401/403 triggering re-authentication via AUTHENTICATE WEB SERVICE, 302 redirects), parse faults, and network faults; and replacing the hard-coded server IP address with a variable so the client can connect to any WebLog Server. The note closes by noting Part II will cover new features planned for the next version of 4D Blogger.
