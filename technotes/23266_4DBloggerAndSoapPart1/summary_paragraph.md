This Tech Note is the first of a two-part series providing an overview of what a Blog is and discussing the SOAP (Simple Object Access Protocol) implementation underlying the 4D Blogger application's client/server communication. Blogging was a fast-emerging web phenomenon at the time, and this note uses it as a compelling, topical use case for demonstrating 4D 2003's new SOAP-based Web Services capability in both directions (a WebLog Server and a WebLog Client communicating over SOAP). The teaser notes the second part will cover new features planned for the next version of 4D Blogger. Only the short on-page teaser text could be recovered here, so specific protocol/method details are not available.
