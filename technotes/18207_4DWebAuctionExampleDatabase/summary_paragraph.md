This Tech Note (TN 01-44, 4D v6.7, Mac & Win, published September 30, 2001) by Cha Yang, a 4D, Inc. Technical Support Engineer, walks through the 4D Web Auction example database (originally written by Ruffin Scott, updated for 6.7 by Eric Saltzen), a non-contextual web interface where visitors browse auction items and submit bids that are immediately reflected for all other users. The note traces the flow from the On Web Connection database method sending index.htm, through the W_GenItemTable method that selects all Item records and sends items.shtm, where 4D's tag set is put to work: <!--4DHTMLVAR--> displays a status variable, <!--4DLOOP [Item]--> iterates the current selection with alternating row colors driven by a <!--4DIF--> test on record parity, and <!--4DVAR VarName--> injects live field values into the page. Clicking an item ID calls W_ViewItem to display a single item's bid.shtm form, and submitting a bid invokes W_SubmitBid, which creates a Bid record, compares the new amount to the item's current highest bid, and returns a congratulatory or rejection message accordingly. The note also documents a SetNoCacheHeaders method that uses SET HTTP HEADER to set Pragma, Cache-Control, and Expires headers so browsers and proxies won't cache the auction data, ensuring bidders always see current figures -- a small but instructive technique alongside the tag-based dynamic HTML the note primarily demonstrates.
