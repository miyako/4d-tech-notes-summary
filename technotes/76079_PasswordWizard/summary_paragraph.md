This Tech Note pairs a discussion of what makes a password secure — covering entropy, cryptographic strength, and the time required to brute-force a password — with a self-contained 4D v11 SQL component called the Password Wizard that gives host databases the tools to create and manage passwords. The component supports three password-generation strategies: user-entered passwords with dynamic strength rating, passwords generated from a predefined pattern, and fully random passwords built from developer-specified criteria. It also provides a mechanism for encrypting passwords into BLOBs suitable for storage in the host database's data file, using public/private key pairs kept inside the component itself rather than in plain view. The API exposes methods such as PW_By_User_Rated, PW_GeneratePattern, PW_GenerateByMachine, PW_GenerateKeyPair, and PW_EncryptPassword, alongside host database callbacks for integration. A demonstration database illustrates all three password-creation techniques in action. The note targets 4D developers who need to add credible password security to an application without researching cryptographic theory from scratch.
