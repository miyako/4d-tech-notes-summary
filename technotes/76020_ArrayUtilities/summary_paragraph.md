This Tech Note presents Array Utilities, a self-contained 4D v11 SQL component that adds a broad library of helper methods for working with classic 4D arrays, organized into several functional groups. Array Information methods (ARR_IsAnArray, ARR_IsNumericArray, ARR_IsTextArray, ARR_IsNdxValid) validate arrays and indexes, while sizing/populating methods (ARR_SizeArrays, ARR_InsertRows, ARR_DeleteRows, ARR_DeleteRowsByIndex) manage array dimensions. Set-style operations (ARR_Distinct, ARR_Intersect, ARR_Difference, ARR_Union, ARR_ArrayToSet) let developers treat arrays as mathematical sets. A large group of statistical functions (ArrayStats_GetMean, GetMedian, GetMode, GetStandardDeviation, GetVariance, GetWeightedMean, and more) computes descriptive statistics directly over array contents, complemented by running-value methods (ARR_Running_Average, Running_Total, Running_WeightedAverage) and array math helpers. Search utilities (ARR_FindInArray_All, Find_Between_Values, Find_GreaterThan, Find_LessThan, ARR_LookUp) and copy/fill utilities (ARR_Clear, ARR_CopyElements, ARR_CopySegment, ARR_FillValue variants, ARR_Convert_from_Text/to_Text, ARR_Shuffle, ARR_Push, ARR_Pop) round out the component. A demonstration database illustrates the methods in practice. The note targets 4D developers who frequently manipulate classic arrays and want a ready-made, tested library rather than writing these routines from scratch.
