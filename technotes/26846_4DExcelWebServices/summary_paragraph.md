This Tech Note frames Web Services as an exciting technology enabling different applications to interact via common, standardized protocols — mostly SOAP and WSDL — and notes that 4th Dimension 2003 makes it easy to both publish and call Web Services. This particular note restricts its scope to the server-side capability (publication), demonstrating how a 4D 2003 database can expose methods as Web Services that Microsoft Excel (or another SOAP-aware client) can then call. Only the short on-page teaser text could be recovered here, so the specific published methods and Excel-side consumption steps are not available, but the note reflects 4D 2003's dual client-and-server Web Services story, with this installment specifically covering the server/publishing side.
