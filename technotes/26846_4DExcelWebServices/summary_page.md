## Overview
A Tech Note covering 4D 2003's server-side (publishing) Web Services capability, demonstrated through interaction with Microsoft Excel via SOAP.

## Key Points
- Focuses specifically on 4D 2003's server-side Web Services capability (publishing SOAP services), not the client side.
- Demonstrates interaction with Microsoft Excel as the SOAP-consuming client application.

## Featured Technology
- SOAP
- WSDL
- 4D 2003 Web Services (server-side)
- Microsoft Excel interop

## Historical Context
Published at the launch of 4D 2003's new Web Services feature set, reflecting the broader early-2000s push toward SOAP/WSDL-based application interoperability; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

The SOAP/WSDL-based server publication technique described here has been broadly superseded by REST/JSON APIs as the standard way to expose application data to Office and other clients, and modern Excel-to-4D integration would more likely use REST endpoints, Power Query, or direct database connectivity than a SOAP-published service.
