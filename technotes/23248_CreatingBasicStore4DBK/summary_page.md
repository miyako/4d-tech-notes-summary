## Overview
A getting-started Tech Note showing how to set up a basic online store using 4D Business Kit, focusing on the required HTML pages and 4DBK-specific tags.

## Key Points
- Step-by-step guide to setting up a basic online store using 4D Business Kit.
- Focuses on the HTML pages and 4DBK-specific HTML tags needed for a working storefront.
- Assumes basic familiarity with 4DBK and HTML.

## Featured Technology
- 4D Business Kit
- HTML storefront tags

## Historical Context
4D Business Kit was 4D's turnkey e-commerce platform of the early 2000s; this note served as an entry-point guide for developers new to the platform.

## Historical Commentary
**Status:** Obsolete

4D Business Kit has been discontinued for many years, making this note's specific HTML-tag-based storefront setup obsolete; anyone building a modern e-commerce storefront today would use current web frameworks or dedicated e-commerce platforms rather than 4DBK.
