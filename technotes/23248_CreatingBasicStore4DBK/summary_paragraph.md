This Tech Note shows how to set up a basic store using 4D Business Kit (4DBK), focusing mainly on the HTML pages and the necessary 4DBK-specific HTML tags required to get a store online. It briefly touches on how 4DBK itself is configured, but assumes the reader already has basic familiarity with 4DBK and HTML. This is a practical, getting-started-style guide compared to the more advanced 4DBK notes elsewhere in this batch (build-to-order stores, Flash integration, payment processing), serving as an entry point for developers new to the platform.
