Written by David Adams, this technical note introduces the XML_Utilities component, a small set of methods that add convenience on top of 4th Dimension 2003's native XML parsing commands, distributed both as source code and as an installable 4D Insider component. The four public methods are xutil_CountOccurrences (counts how many times a named element appears within an XML tree), xutil_ElementExists (returns True/False for whether a named element is present), xutil_GetValue (returns the text value of a specific occurrence of a named element, optionally cleaned of whitespace), and xutil_StripWhitespace (removes XML-defined whitespace characters -- tab, line feed, carriage return, space -- from text). The note carefully documents the "preorder," top-to-bottom, left-to-right traversal strategy the component uses to walk XML trees recursively, working through a worked sample XML document to show exactly which nodes are visited in which order and what each function returns for it. It also explains why the private xutilStringsAreEqual helper method performs a manual, byte-by-byte ASCII comparison rather than relying on 4D's native string equality, since XML names are case-sensitive while 4D's own text comparisons are not (and can also ignore diacritical marks). Full, well-commented code listings are provided for every method, making this both a practical utility library and a worked tutorial on recursive XML tree navigation in classic 4th Dimension.
