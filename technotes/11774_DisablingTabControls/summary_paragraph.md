This Tech Note documents one of the new active objects introduced in 4D V6: the tab control, which allows a developer to present information in a multi-page format that changes as the user clicks on a tab, usable either as a page-navigation tool or to organize information into categories. It notes that individual tabs can be disabled, as demonstrated in the note's example database. Tab controls get their values from arrays or lists, and a developer can detect which item was clicked using the "Selected list item" command, which returns the "List" item reference number. That reference number can then be passed to other commands, notably SET LIST ITEM PROPERTIES, to enable or disable a tab by setting its list item's "Enterable" property to True or False. The note's stated purpose is specifically to explain how to enable and disable tab controls using this mechanism. No further specifics of the example database, exact code sequence, or edge cases (such as behavior when the active/selected tab itself is disabled) are present in the recovered teaser text; the concrete implementation details from the original PDF could not be recovered for this summary.
