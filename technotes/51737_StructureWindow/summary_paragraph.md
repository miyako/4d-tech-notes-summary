The Structure Window is the central visual interface for database design in 4D v11 SQL, offering a comprehensive view of tables (up to 32,767 per database), fields (up to 32,767 per table), and their many-to-one / one-to-many relations. The window includes a toolbar with buttons for adding objects (tables, fields, indexes, relations), applying layout tools (Optimal Size, Align Left/Top, Sort by Alphabetic/Type/Indexed/Related/Visibility/Creation/Custom), changing colors, managing indexes, using folder-based organization, and controlling display options (Show All, Invisible Tables/Fields, Not Related Fields, Not Indexed Fields, Relations). An Information bar displays context-sensitive details about hovered elements (table name/number/triggers, field properties and type/nullability/uniqueness, relation type). The floating Inspector palette allows developers to customize the background, rename/add comments to tables/fields/relations, configure field properties (indexing, data entry controls), set up relation deletion controls, and check SQL compatibility. A search field supports filtering by table/field name using Contains or Starts with operators, or by table number. The note emphasizes structure organization through visual tools: coloring, folder grouping, field sorting, and zooming, making database design more legible and maintainable. Index management is handled through a dedicated Index List window supporting creation, editing, deletion, and rebuilding of indexes.
