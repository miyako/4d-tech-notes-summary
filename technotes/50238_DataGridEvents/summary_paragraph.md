The Data Grid supports a number of events that can be used for many purposes such as drag and drop functionality and passing custom values to and from 4D. For this Technical Note, we will go over the user interface events that fire when the end user interacts with the grid. We will also evaluate the information that becomes available once each event is triggered. A sample database is provided. Published June 26, 2008 as Technical Note 08-24 for 4D Web 2.0 Pack v11.2 (Mac &amp; Win), this note was written by Joe Resuello, Technical Marketing Engineer, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
