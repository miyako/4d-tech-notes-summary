This technical note provides a comprehensive guide to the five primary user-interface events supported by the 4D Ajax Framework's Data Grid component, enabling developers to capture and respond to column header clicks, row selections, and cell-level interactions. The note is structured around five progressively complex event scenarios: On Column Header Click (via onDataColumnClick, which passes column index and field reference object, exposing field ID, field alias, field data type, and searchability), On Row Click (onDataRowClick, yielding row number and record ID), On Cell Click (onDataCellClick, returning row, column, record ID, and full field metadata), On Row Double Click (onDataRowDblClick), and On Cell Double Click (onDataCellDblClick). Each event section includes the JavaScript function signature, parameter documentation, available return values, a direct code example demonstrating event binding and parameter introspection, and a URL to a working web page within the included sample database showing the event in action. The sample database is provided in three flavors (interpreted source for 4D 2004, interpreted source for 4D v11 SQL, and a merged compiled version for 4D 2004), with all grid event code residing on the web side and thus immediately modifiable/studyable. The note assumes intermediate HTML/JavaScript knowledge and emphasizes that event handlers are assigned directly via JavaScript method references (e.g., myGrid.onDataColumnClick = onColumnClick;), enabling developers to build interactive grids without backend coding—all event logic executes client-side in the browser."
