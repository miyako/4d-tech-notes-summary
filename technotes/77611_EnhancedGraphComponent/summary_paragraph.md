This Tech Note introduces the EnhancedGraph component, a graphical front-end built on top of the enhanced GRAPH command that debuted in 4D v15 R4 64-bit. Prior to this enhancement, charting in 4D required the GRAPH SETTINGS command and a comparatively limited configuration surface; the new enhanced GRAPH instead accepts a single OBJECT parameter exposing over thirty-five configurable elements covering scales, legends, colors, opacity, and more. Rather than asking developers to hand-write all of these object properties, the component supplies a two-step workflow: first, a Graph Designer form lets a developer visually build and save a reusable "graph template" (all display properties, no data); second, host-database methods (EG_GRAPH_ByDesigner and EG_GRAPH_ByUser) marry that template with live data at runtime. The designer form is organized into three pages (Document Basics; Scales and Legend; Colors and Opacity) and supports bar, proportional, stacked, picture, line, scatter, and pie graph types, plus utilities like mass color change, SVG export, and copying a graph to the pasteboard. Macros are provided to auto-generate the project-method code needed to feed the component from a host database's data. Because it targets the newly introduced 64-bit-only enhanced GRAPH command, the note is inherently tied to the specific v15 R4/R5 timeframe and the OBJECT-based graph parameter design. It is a solid example of the era's pattern of wrapping powerful but verbose low-level commands in reusable design-mode components and templates. The underlying enhanced GRAPH command and its OBJECT-parameter model remain part of the modern 4D language, so the conceptual approach is still valid, though the component itself (a Design Mode-era download) has not been actively maintained by 4D as an official offering.
