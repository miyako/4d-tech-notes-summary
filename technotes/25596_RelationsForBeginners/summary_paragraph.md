This Tech Note is aimed squarely at beginners confused by 4D's relational terminology — Automatic Relations, Manual Relations, Many to One, One to Many, and Many to Many — and promises to explain these concepts clearly. Classic 4D's relational model (defined at the structure level via automatic relations, or built manually in code via manual relations) was a core part of how developers modeled data connections between tables, and getting these concepts right was foundational to building correct 4D applications.
