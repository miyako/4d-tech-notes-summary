This Tech Note, Part 1 of a two-part series, addresses backup and recovery strategy for mission-critical 4D Server installations, a trend ACI Technical Support was observing among its customer base by 1997. Only the on-page teaser paragraph for this asset survives in this archive, so this summary reflects that teaser text only. According to the teaser, ACI was fielding daily calls from customers running 4D Server installations with as many as 100 simultaneous users and data files as large as five gigabytes — scale considered significant for the era — and these customers depended on the database running 24 hours a day, seven days a week without interruption. The note frames such deployments as "mission-critical," meaning the organization cannot function if the system goes down, and states that many customers had successfully kept 4D Server installations running for months or years with little to no downtime by applying sound database administration discipline. The stated purpose of this two-part note is to give administrators the information needed to set up and maintain an effective backup and recovery strategy for such a mission-critical 4D Server application, with Part 1 covering the initial groundwork and Part 2 (published the following month) continuing the discussion. Because only the teaser is available, the specific backup procedures, schedules, tools, or recovery steps the full note likely detailed cannot be summarized here.
