This Tech Note is a broad overview and comparison of the five major operating systems 4th Dimension supported as of mid-1996 — Macintosh OS, Windows 3.1x, Windows for Workgroups 3.11, Windows NT 3.5x, and Windows 95 — intended to help developers coming from one platform understand their options on the other. For each OS it summarizes strengths and weaknesses: Mac OS is praised for ease-of-use and built-in networking but noted as a minority player in corporate America; Windows 3.1x (requiring the Win32s 32-bit compatibility layer to run 4D at all) is described as having the largest installed base but frequent General Protection Faults requiring reboots and no built-in networking; Windows for Workgroups adds faster disk access and built-in peer-to-peer networking over plain Windows 3.1; Windows 95 is framed as "more like a Mac," addressing many Windows 3.1x stability/memory limitations while easing the eventual path to Windows NT; and Windows NT is recommended as the most robust, protected-memory option best suited for both 4D development and 4D Server hosting, despite a significantly higher price and slower relative speed. A detailed comparison table lays out minimum/preferred RAM, disk requirements, and pros/cons for each OS. A second section digs into cross-cutting comparisons: software compatibility (Windows 3.1x is most broadly compatible; Windows NT and OS/2 have more app-compatibility friction than either); hardware compatibility (Mac's single-vendor hardware standard vs. the fragmented, driver-heavy Windows/Intel hardware world); crash behavior (frequent GPFs on Windows 3.1x/WFW vs. Windows NT's protected-memory isolation); and disk access speed (Macintosh trailing Windows platforms in raw disk I/O). A "Windows Recommendations" section closes with concrete guidance: Windows NT Workstation (ideally with the then-upcoming "NewShell" Windows-95-like interface) for development and 4D Server hosting, a minimum 75MHz Pentium / 100MHz PowerMac processor, and practical hard-disk sizing and SCSI-vs-IDE tradeoffs for 1996-era hardware. Featured technology is squarely the operating system landscape itself — Mac OS, Windows 3.1x/WFW/95/NT — as it relates to running and deploying 4D and 4D Server in that era.
