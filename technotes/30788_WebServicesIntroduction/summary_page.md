## Overview
An introductory Tech Note explaining the fundamentals of Web Services, SOAP, and WSDL, and how 4D 2003's new native support for them lets 4D applications communicate with other systems over the network.

## Key Points
- Defines Web Services, SOAP, and WSDL for a 4D developer audience new to the concepts.
- Frames Web Services support as a major new 4D 2003 capability for application-to-application integration.
- Positioned as an introductory/beginner-level session rather than an advanced technical recipe.

## Featured Technology
- SOAP
- WSDL
- Web Services (4D 2003)

## Historical Context
Web Services (SOAP/WSDL) were the dominant application-to-application integration paradigm of the early-2000s pre-REST era, and 4D 2003's support for them was a major marketing point; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Superseded

The SOAP/WSDL paradigm this note introduces has been broadly superseded industry-wide by simpler REST/JSON-based web APIs, and 4D itself later added native JSON and REST-friendly HTTP commands, so the specific technology emphasis is now dated even though the general concept of machine-to-machine integration remains as important as ever.
