Authored by Frank Chang (Technical Support, 4D, Inc.) as Technical Note 03-53, this note is an introductory, beginner-oriented primer on Web Services in general and on 4th Dimension 2003's brand-new native support for them. It opens with conceptual grounding: what a Web Service is, its interoperability/platform-independence/reduced-cost benefits (citing real public examples like FedEx tracking, Amazon search, and BabelFish translation), possible use cases (flight lookups, reservations, blogging, auctions, mapping), and the two core specifications — SOAP (an XML messaging envelope with Header and Body, transport-agnostic but almost always carried over HTTP) and WSDL (a machine-readable description of a service's operations and parameters used to auto-generate 4D proxy code) — along with the distinction between synchronous, tightly-coupled RPC-style SOAP and asynchronous, document-driven DOC-style SOAP. It then turns practical, showing how to publish a 4D method (a book-reservation example) as a server-side Web service by enabling "Allow Web Service Request" in Preferences and checking "Offered as a Web Service"/"Published in WSDL" in Method Properties, and how to consume an external Web service as a client using the Web Services Wizard, which generates a proxy method built on `SET WEB SERVICE PARAMETER`, `CALL WEB SERVICE`, and `GET WEB SERVICE RESULT`. It documents the supported SOAP data types (Boolean, Blob, Date, Integer, Long Integer, Real, String, Text, Time, and arrays of several of these) and shows two ways to declare parameters — Compiler commands (single output only) or the more flexible `SOAP DECLARATION` command (multiple named inputs/outputs, requiring companion declarations in the Compiler_Web method). It closes with a security section covering HTTP Authentication (via 4D's built-in password system or a custom `On Web Authentication` method checking `Is SOAP request`) and SSL/HTTPS encryption for protecting sensitive data such as credit card numbers in transit.
