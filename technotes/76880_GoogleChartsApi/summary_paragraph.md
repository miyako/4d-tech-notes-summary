This first part of a two-part Tech Note by Jean-Jacques Bleu lays the theoretical groundwork for embedding Google's free Charts API into 4D web applications, using 4D's built-in Web Server, HTML/JavaScript, AJAX requests, and JSON responses, illustrated through the concrete example of drawing an interactive pie chart. It surveys the Google Charts documentation, notes that Charts are built on HTML5/SVG (making them broadly cross-browser and cross-device) and center around the `DataTable` class, and walks through the "Quick Start" flow of loading Google's JavaScript library, preparing data, optionally customizing options, and drawing the chart. The bulk of the note is a deliberately slow, educational walkthrough of a small demonstration website (served by 4D Web Server) built in four incremental steps: constructing an AJAX request in JavaScript, receiving and handling that request inside a 4D method, hand-building a JSON response text variable piece by piece and sending it back with `WEB SEND RAW DATA`, and finally parsing/consuming that JSON response in the browser. Debugging is demonstrated using the Firebug Firefox extension's console and DOM inspector to compare the JSON object 4D actually returned against a reference object copied verbatim from Google's own documentation, confirming the two are structurally equivalent. The note closes by noting that a companion second part will extend this foundation to render charts using live data from a 4D database, and to display them inside 4D Web Area objects (not just an external browser), removing the dependency on 4D Web Server entirely.
