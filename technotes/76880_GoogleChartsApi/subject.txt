Tech Note: 4D and Google Charts API (TN 13-10, 4D v13.3, September 2013) — part one of a two-part series by Jean-Jacques Bleu, laying the theoretical and technical groundwork for integrating Google's free Charts API into 4D web applications: hosting a small site with 4D Web Server, building AJAX requests in JavaScript, handling them in 4D, hand-building JSON responses, and rendering the returned data as an interactive pie chart using Google's DataTable class.
