This Tech Note describes a simple, PDA-inspired interface for quickly entering a date or time value, built by combining and adapting methods from two existing community example databases: the 4D Web Calendar (by Steve Hussey) and the 4D Calendar (by Dave Batton). The goal is a fast, touch/click-driven entry pattern rather than requiring the user to type a full date or time string by hand — a usability concern that predates modern date-picker widgets. Only the short on-page teaser text could be recovered here, so the exact implementation details of the combined interface are not available, but the note is a good example of the 2002-2003 4D developer community's practice of building on and crediting each other's shared example databases.
