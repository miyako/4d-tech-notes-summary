## Overview
A short Tech Note describing a quick PDA-style date/time entry interface for 4D, built by combining techniques from two existing community calendar example databases.

## Key Points
- Combines methods from two well-known community example databases: 4D Web Calendar (Steve Hussey) and 4D Calendar (Dave Batton).
- Aims to provide quick, PDA-style date/time entry rather than manual typing.
- An example of cross-pollination between community-contributed 4D example databases.

## Featured Technology
- Date/Time form objects
- Custom UI widgets

## Historical Context
Predates the ubiquitous native date-picker controls found in modern GUI toolkits and web frameworks; in 2003, such quick-entry UI had to be hand-assembled from custom form objects and community example code, as only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Historical Interest Only

The specific PDA-style hand-built date/time entry widget described here has been made largely unnecessary by the native date/time picker controls now standard in modern GUI toolkits, browsers, and current 4D form objects, so this note is chiefly of historical interest as a snapshot of pre-native-widget UI engineering in the 4D community.
