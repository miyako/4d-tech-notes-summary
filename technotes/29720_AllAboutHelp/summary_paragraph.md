Jamras Komoncharoensiri of 4D Inc. Technical Support surveys the complete set of help features available in 4th Dimension 6.8 and 2003, aimed at developers who want to both use and provide in-application assistance. The note covers seven distinct mechanisms: 4D Explorer Help (a 4D Help.rsr file, placed in the platform-specific active 4D folder, that surfaces command syntax when pressing Tab or F1 in the Method editor or browsing 4D Explorer); 4D Help in Microsoft Help (.HLP) format, containing over 500 command references plus a Quick Start guide, installable per-database via the Win4DX/Mac4DX folders so multiple help files appear together under the Help menu, including for 4D Client sessions; 4D Help in Apple Viewer format for Mac OS 9.x/X, requiring manual placement of a decompressed help folder inside the application package's Contents/Resources; 4D Contextual On-line Help, customized per database to provide database-specific 'How to' guidance; 4D's on-line HTML documentation; and the lighter-weight Help Tip and Dynamic Help Message object properties for in-form guidance. Throughout, the note is careful to spell out exact platform-specific installation folders (e.g. distinct paths for Windows 98/NT/2000/XP and Mac OS 9.x/X active-4D folders) and version compatibility caveats, such as the Microsoft Help application needing separate installation on Mac OS 9.
