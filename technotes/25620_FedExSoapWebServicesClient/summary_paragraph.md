This Tech Note showcases one of 4D 2003's headline new features — the ability to act as a SOAP web services client — by building a package-tracking application against a public FedEx SOAP server. It explains SOAP as a lightweight, XML-based, HTTP-transported protocol for cross-language application-to-application communication, and WSDL as the XML grammar used to describe a service's location and callable operations. The walkthrough uses 4D's Web Services Wizard (Tools menu, Design Mode) to point at the FedEx WSDL URL (http://www.xmethods.net/sd/2001/FedExTrackerService.wsdl), discover the getStatus operation, and auto-generate an RPC project method that becomes the client-side driver — after which the developer only needs to add error handling. The example database itself is built around two related tables, Shipments and Shipment History, so each tracking-number lookup appends a new status record over time, and it can optionally email the user updates via SMTP. This note is a concrete, practical demonstration of 4D 2003's brand-new Web Services client capability at the moment of its introduction.
