## Overview
This note introduces User Defined Forms, a 4D 2004 feature that allows end users of a deployed application — including compiled, merged, double-clickable standalone applications — to create or modify their own customized forms at runtime.

## Key Points (from available teaser)
- Targets the common vertical-market pain point of users repeatedly requesting form/layout tweaks.
- Lets end users tailor the look and feel of forms to their own industry, company, or workflow needs.
- Works even in compiled and merged deployed applications, not just in Design Mode.
- Framed as reducing developer support burden while increasing user satisfaction and flexibility.

## Featured Technology
- User Defined Forms (new in 4D 2004)
- Runtime, end-user-driven form customization
- Compiled/merged application compatibility
