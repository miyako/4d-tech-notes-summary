Demonstrating 4D Ajax Framework's interoperability with third-party services, this note integrates the Google AJAX Feed API — a now-defunct Google service for fetching and parsing RSS/Atom feeds client-side — into a 4DAF web application using the newer Data Grid 2.0 object, with a full example database provided to show feed data flowing into a live web page. Published February 6, 2008 as Technical Note 08-05 for 4D Web 2.0 Pack v11 (Mac & Win), written by a 4D Technical Services team member. Both halves of this integration are now defunct: Google shut down its AJAX APIs (including the Feed API) years ago, and the 4D Ajax Framework it's wired into has also been discontinued, making this note a snapshot of a specific, now-unreachable mashup pattern from the late-2000s AJAX/'Web 2.0' era rather than a usable how-to.
