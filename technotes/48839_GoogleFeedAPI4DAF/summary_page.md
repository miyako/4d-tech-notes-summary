# Integrating the Google Feed API with 4DAF

## Overview
Demonstrating 4D Ajax Framework's interoperability with third-party services, this note integrates the Google AJAX Feed API — a now-defunct Google service for fetching and parsing RSS/Atom feeds client-side — into a 4DAF web application using the newer Data Grid 2.0 object, with a full example database provided to show feed data flowing into a live web page.

## Key Points
- Published February 6, 2008 as Technical Note 08-05.
- Targets 4D Web 2.0 Pack v11 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Data Grid 2.0
- Google AJAX Feed API
- RSS/Atom feed parsing
- Client-side AJAX integration

## Historical Context
Both halves of this integration are now defunct: Google shut down its AJAX APIs (including the Feed API) years ago, and the 4D Ajax Framework it's wired into has also been discontinued, making this note a snapshot of a specific, now-unreachable mashup pattern from the late-2000s AJAX/'Web 2.0' era rather than a usable how-to.

**Status:** obsolete

**Related updates:**
- Google deprecated and shut down its AJAX Feed API years ago; the integration described is no longer functional as written
- 4D Ajax Framework (4DAF) has also been fully discontinued
