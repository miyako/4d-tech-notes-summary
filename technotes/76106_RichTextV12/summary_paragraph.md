This Tech Note introduces Rich Text, a new feature in 4D v12 that allows individual characters within a single text object to carry different style attributes — font, size, weight, alignment, color, and (Windows-only) background color — rather than requiring one uniform style for the whole object as in earlier 4D versions. It explains that Rich Text is available on any Text or Alpha-typed field, variable (including arrays), or list box cell, and that styled content is stored inline as HTML using `<SPAN STYLE="...">` tags wrapped around the styled portion, meaning the underlying field/variable content itself changes to include this markup (with an important caution about the 255-character limit on Alpha fields being at risk of truncation/data loss). The note documents the full set of supported STYLE attributes and their valid values, how Rich Text interacts with querying, sorting, and indexing (important since query/sort must operate on the semantic text, not the markup), how to enable it via the "multi-style" form object property and other display/entry settings, and how it behaves with drag-and-drop, copy/paste, entry/display filters, and Quick Report/Labels. A demo database covers practical scenarios like generating an advertising document, creating custom styles, and highlighting found text. The note targets developers wanting more sophisticated in-place text styling in forms without adopting a full word-processing area.
