This note demonstrates a practical application of 4D View Pro's underlying SpreadJS engine beyond the native VP command set: a user-facing wizard that walks through selecting a chart type, choosing a table and mapping its fields to categories/values/series via drag-and-drop, and customizing chart title, axis labels, legend, data labels, and gridlines, before generating a finished chart. Internally, user selections accumulate into a Form.data.js text variable containing raw JavaScript that calls the SpreadJS Charts API directly — activeSheet.suspendPaint(), activeSheet.setArray(...) to load a prepared 2D data array, sheet.charts.add('chart_pie', GC.Spread.Sheets.Charts.ChartType.pie, ...) to create the chart, then chart.title(), chart.axes(), chart.legend(), and chart.dataLabels() to configure appearance, finishing with activeSheet.resumePaint(). This generated JS is executed against the View Pro area via WA Evaluate JavaScript. Before rendering, the display area is stripped of scroll bars, headers, and other chrome using VP Export to object / VP IMPORT FROM OBJECT to toggle spreadJS properties and VP SET FROZEN PANES to disable scrolling, then the chart is exported as a picture with VP EXPORT DOCUMENT — natively producing a PDF on macOS, which on Windows must be converted to PNG via the third-party Xpdf command-line tool invoked through LAUNCH EXTERNAL PROCESS, since 4D's PDF encoding/decoding was at the time macOS-only.
