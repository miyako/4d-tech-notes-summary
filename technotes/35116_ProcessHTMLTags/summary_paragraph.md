Julien Feasson, a Software Engineer at 4D Inc., champions the new 4D 2004 command PROCESS HTML TAGS as, in his words, one of the most powerful additions to the language, because it brings the classic 4D web-server tag system (4DVAR, 4DHTMLVAR, 4DSCRIPT, 4DINCLUDE, 4DIF/4DELSE/4DENDIF, 4DLOOP/4DENDLOOP) to any text or blob, independent of whether the 4D Web Server is even running. The note walks through three concrete examples: generating a quick personalized email from a text template embedding tags like `<!--#4DVAR [People]Name-->` and conditional phone-number blocks; mail-merging with Microsoft Word 2003's then-new XML file format by embedding 4D tags directly inside a saved .xml template so PROCESS HTML TAGS produces a populated Word document; and running externally-stored "4D Scripts" -- plain text files containing 4D tags including 4DSCRIPT calls and 4DIF/4DLOOP logic -- to perform maintenance routines or hot-patch a compiled, running server without shutting it down or recompiling. It closes with a security discussion, noting that 4DSCRIPT only invokes methods flagged "Available through 4DACTION, 4DMETHOD and 4DSCRIPT" and checked via the On Web Authentication method, but warns that any 4D command (including QUIT 4D) can appear in a script, and recommends checksums or ENCRYPT BLOB/DECRYPT BLOB to protect externally stored scripts from tampering.
