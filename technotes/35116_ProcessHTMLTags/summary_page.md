# Tech Note 04-49: Process HTML Tags and more!

**Author:** Not specified in source
**Published:** December 9, 2004 | **Product/Version:** 4D v2004 | **Platform:** Mac & Win

## Overview
This note spotlights the Process HTML Tags command, which the author predicts will become one of the most powerful commands in the 4D 2004 language, thanks to its versatility across tasks as different as Microsoft Word mail merging and running maintenance routines.

## Key Points (from available teaser)
- Frames Process HTML Tags as a general tag-substitution engine, not limited to serving web pages.
- Cites mail merging with Word as one illustrative use case.
- Cites running maintenance routines as another illustrative use case.
- States the note's goal is to demonstrate the command's full power and invite readers to judge its significance themselves.

## Featured Technology
- Process HTML Tags command
- 4D's tag/template substitution mechanism
- 4D built-in Web Server (implied dynamic content context)
