This Technical Note is a beginner's introduction to SQL as newly natively supported inside 4D v11 SQL, aimed at 4D developers with little or no prior SQL experience. It explains SQL's purpose (accessing and manipulating relational databases) and maps its vocabulary onto 4D's existing concepts — a SQL row corresponds to a 4D record, a SQL column to a 4D field, and a SQL table to a 4D table — using an included sample database, BeginnerSQL.4dbase, that lets readers follow along and view SQL code plus its results in a list box. It documents the three principal ways to invoke SQL from 4D code: QUERY BY SQL, which runs a SQL SELECT while still producing a standard 4D Current Selection (and can be combined with SET QUERY DESTINATION); Begin SQL/End SQL blocks, which allow full multi-statement SQL scripts (semicolon-separated) storing results into 4D variables, fields, arrays, or list boxes without creating a Current Selection; and EXECUTE IMMEDIATE, used inside a Begin SQL/End SQL block to run a dynamically constructed SQL string built up from 4D variables at runtime. Practical syntax notes cover commenting conventions (`/* */` inside Begin SQL/End SQL versus the standard 4D back-quote comment elsewhere), and the fact that SQL statements are case-insensitive and whitespace-agnostic. The note proceeds into the SELECT statement itself, its structure, and how it compares to (but is not identical to) 4D's native QUERY command. As an introductory document tied to 4D v11's brand-new integrated SQL engine, it represents one of the first developer-facing explanations of what was, at the time, the single biggest architectural change to the 4D language in years — up to that point 4D had relied purely on its procedural/set-based language plus optional ODBC access to external databases.
