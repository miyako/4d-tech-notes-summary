This Tech Note introduces the concept of weighted lists — also called "lists with relevance" — as seen in web search engines, Apple Spotlight, and tag clouds, where results are ordered by a calculated relevance score rather than simple alphabetical or chronological order. It explains the underlying data structure: a data array (or reference to records/documents) paired with a parallel weights array, both sorted together so the most relevant items surface first. The note surveys several real-world weighted-list styles (tag clouds, the 4D Doc Center, Google search results) to highlight differing display strategies for different kinds of data. A sample database then demonstrates two concrete search algorithms in 4D: one that finds search terms across multiple fields of a table and its related records, weighting each match location, and another aimed at searching within one large text field, covering search-term extraction, keyword filtering, keyword frequency counting, and finding distinct keyword values. The note targets developers who want to add relevance-ranked search or "most popular" style features to a 4D application.
