This Technical Note (26-04, published April 23, 2026 for 4D v21HF2) shows how to replace brittle keyword-based icon search with semantic search, using a demo application built on the Material Design Icons set. Each icon's textual tags are converted into a vector embedding via OpenAI's embedding API (accessed through the 4D AI Kit component) and stored directly on the entity using the native 4D.Vector data type. At query time, the user's search text is embedded the same way and compared against stored vectors with a single ORDA `.query()` call using cosine similarity, ranking results by relevance rather than exact word matches. A hybrid strategy is demonstrated: dynamic embedding generation for free-text queries, plus precomputed vectors for a few predefined "quick search" buttons, reducing OpenAI API calls while keeping search fast. The note frames this as a broadly reusable pattern — document repositories, knowledge bases, media libraries, and product catalogs — and highlights 4D's native vector storage/query support and the AI Kit's OpenAI key-management helpers as the key enabling technologies.
