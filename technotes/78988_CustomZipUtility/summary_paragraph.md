This note documents a reusable ZIP compression utility built entirely on 4D's native ZIP Create archive and ZIP Read archive commands, available since 4D v18, wrapped in both an interactive drag-and-drop window and a headless programmatic API. The Compress utility, opened via zipItWindow, lets a user drag files/folders onto the window (or pick them via a Select button); a single item compresses to a same-named ZIP next to the original, while multiple items compress into a combined Archive.zip, with an optional password field defaulting to AES 256-bit encryption (configurable to other methods from a dropdown). Programmatically, zipItems(parameter : Object) -> zipPath : Text takes an object with a files collection of system paths plus optional password/encryption attributes (e.g. ZIP Encryption AES256) and returns the resulting archive path. The companion Uncompress utility previews a ZIP's contents in a list box, supports per-item or 'Extract All' extraction (defaulting to the ZIP's own folder), and validates a password field for protected archives; its programmatic counterpart, unzipItem(parameter : Object) -> $result : Integer, takes srcPath/desPath/optional password attributes. The note positions this as a convenience layer over already-available native commands rather than a new capability, aimed at giving developers a ready-to-drop compression feature for any 4D solution without external tooling.
