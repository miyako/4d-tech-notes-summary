## Overview
This note examines ideas for using 4th Dimension V6's new Drag and Drop capability with arrays and hierarchical lists, including scenarios involving grouped arrays or arrays whose ordering must remain synchronized with additional hidden arrays. ## Key Points
- The Drag and Drop command supports dragging one item to another location, or reordering within an array/hierarchical list.
- Drag and Drop can affect more than one object at once, such as elements within a grouped array.
- It also addresses arrays whose reordering must stay synchronized with other arrays not directly visible to the user, to keep the operation valid.
