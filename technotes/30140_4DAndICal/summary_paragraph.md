This Tech Note by Dave Dell'Aquila, Senior 4D Evangelist at 4D, Inc., explores integrating 4D applications with Apple's then-new iCal calendaring app on Mac OS X, built around the standard iCalendar (.ics) file format defined in RFC 2445. It surveys the practical options for publishing an iCal calendar so others can subscribe to it: a .Mac account (simplest, one-click 'Publish' from the Calendar menu), a third-party WebDAV service like iCal Exchange, or self-hosting via 4D WebSTAR V configured as a WebDAV server (with a step-by-step realm/folder/authentication setup), and mentions 4D WebMail as an open-source 4D application that already supports publishing iCal calendars. On the 4D coding side, the note walks through the Contacts sample database written by 4D Technical Support: it opens a local or downloaded .ics document and reads it line-by-line in a loop using RECEIVE PACKET($DocRef;$data;Char(10)), passing each line to iCal_Data_To_Arrays, which watches for BEGIN:VEVENT/END:VEVENT markers and, between them, extracts SUMMARY, DESCRIPTION, DTSTAMP, UID, and parses DTSTART/DTEND date-time strings (YYYYMMDD'T'HHMMSS) into 4D dates and times by substring-slicing year/month/day and reformatting with colons. The reverse direction — writing a .ics file from 4D Event records by concatenating BEGIN:VCALENDAR/BEGIN:VEVENT/...END:VEVENT/END:VCALENDAR blocks and uploading via WebDAV — is described at a higher level. The note closes by suggesting more ambitious uses, such as triggering 4D actions (like 4D BACKUP or printing a report) from specially-named iCal events.
