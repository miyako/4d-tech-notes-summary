This Tech Note describes how to automatically dial a telephone number from within a 4D application using a connected Hayes-compatible modem and the 4D commands SET CHANNEL and SEND PACKET. The technique allowed users to click a phone number in their database and have the modem dial it automatically, saving time and preventing misdialed numbers. SET CHANNEL was used to open a serial port connection to the modem, and SEND PACKET sent Hayes AT commands (the standard modem command language) to initiate the dial. The note assumes a Hayes-compatible modem and advises consulting modem documentation for non-standard hardware. This was a practical CRM-style feature in the late 1990s when external modems connected via serial ports were standard office equipment. The concept of using 4D's serial communication commands for hardware integration was common in this era. Only the teaser text survives; the full PDF with implementation code could not be recovered.
