This Tech Note addresses a common consultant's dilemma: a prospective customer demands proof that an application performs well with dozens or hundreds of concurrent users, but the developer only has a handful of test machines available. It proposes solving this with Amazon's Elastic Compute Cloud (EC2), which lets developers rent virtual machines by the hour at low cost to simulate large numbers of concurrent 4D Server clients. After introducing cloud computing and EC2's pricing/instance-size model circa 2009, the note explains how to use the POST KEY command to drive automated, keyboard-based emulation of real user interactions — a simple, low-cost alternative to expensive dedicated UI-testing software. It stresses the importance of first defining a realistic stress-test plan with the customer (identifying which parts of the application see heavy concurrent use, and at what per-user speed) before any technical setup begins. The bulk of the note is a detailed, step-by-step walkthrough of preparing an EC2 "client" instance (setting up a security group, choosing an Amazon Machine Image, launching and connecting to the instance, preparing it with 4D and bundling/saving it as a reusable image) and a separate "server" instance, followed by running the actual multi-client test and cleaning up EC2 resources afterward to avoid ongoing charges.
