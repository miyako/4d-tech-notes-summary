This Tech Note by Herve Le Marchand presents an ambitious, deeply technical example of building an interactive multi-view scheduling planner (similar to a Gantt chart) entirely from an SVG document manipulated live by 4D code, made practical since 4D v12 because individual SVG element attributes can be changed without rebuilding the entire ~3000-line XML tree. It frames the SVG Component's commands around the classic CRUD paradigm — `SVG_SET_VISIBILITY` to create/delete, `SVG GET ATTRIBUTE` to retrieve, and `SVG SET ATTRIBUTE` to update — with each SVG object addressed via a unique ID set through `SVG_SET_ID`. The note then applies an MVC (Model-View-Controller) architecture to the planner's 4D form and methods, covering the form's On Load, On Timer, and On Outside Call events, before tackling the harder interactive problems: detecting and resolving simple collisions between scheduled items, managing overlapping/covering items so nothing is visually lost, implementing a zoomable viewport with an optimally positioned viewbox so the planner looks correct at any scale, applying SVG gradients for visual polish, and wiring up keyboard shortcuts for navigating and editing the schedule. A bundled example database implements the complete feature and is intended either as a learning reference or as a starting point to be turned into a reusable component for other projects.
