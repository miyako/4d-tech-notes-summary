Hugo Fournier, a Technical Support Engineer at 4D Inc., presents a small utility database that lists and previews Quick Report (.4qr) files in a chosen folder, then uses it as the vehicle to survey every output format the Quick Report Editor supports. The interface's M_Update_List method populates a scrollable list via DOCUMENT LIST, filtering by the .4qr extension on Windows but, recognizing that Mac files could instead carry a 4DQR or 4DSE file type depending on their origin, falling back to Document type checks on Mac OS via the <>Platform interprocess variable. Clicking a report in the list runs M_Update_QR_Data, which loads the file into an offscreen Quick Report area with DOCUMENT TO BLOB and QR BLOB TO REPORT, then reports its kind (List or Cross-tab) via QR Get report kind and its configured output destination (Printer, Text file, 4D View, 4D Chart, or HTML File) via QR GET DESTINATION. The note then walks through each of the five destinations concretely: tab-delimited disk-file text output, 4D View grid output (one cell per report cell), 2D graphs (requiring a list report with category/value columns) and 3D graphs (requiring a cross-tab report with two categories and one value), and finally HTML file output, which is described as a tag-driven export mechanism controlled by an HTML template set via QR SET HTML TEMPLATE -- and shown to be flexible enough to produce a compatible 4D XML export file simply by substituting an XML template and renaming the resulting file's extension.
