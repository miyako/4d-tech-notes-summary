4D 2003 had a completely brand new Quick Report editor. Also provided were a complete set of new commands and functions that you could use to create your own. This has proven to be an overwhelming task for some. This tech-note's goal is to provide a slightly modified version of the existing 4D Quick Report editor. It includes some small enhancements that make the editor a little more flexible to the end user. This 2005-era Tech Note (TN 05-13) was published for 4D version 2004 on Mac & Win, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). This note provides source code for a modestly enhanced version of 4D 2003's newly rewritten Quick Report editor, aimed at developers who found the new Quick Report command set daunting to use directly. The classic Quick Report editor architecture it customizes belongs to the pre-SQL, pre-ORDA Design Mode era and has since been superseded by List Box-based reporting and 4D Write Pro in modern 4D applications.
