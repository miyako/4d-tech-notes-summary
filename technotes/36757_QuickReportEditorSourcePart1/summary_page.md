## Overview
4D 2003 had a completely brand new Quick Report editor. Also provided were a complete set of new commands and functions that you could use to create your own. This has proven to be an overwhelming task for some. This tech-note's goal is to provide a slightly modified version of the existing 4D Quick Report editor. It includes some small enhancements that make the editor a little more flexible to the end user.
