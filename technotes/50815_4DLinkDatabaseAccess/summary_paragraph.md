This Technical Note introduces 4D v11 SQL's new 4DLINK file format, an XML-based database access file that consolidates and replaces the functionality of earlier Path Documents (.PTH) files and the command-line interface (CLI) for database launching and connection. 4DLINK files are small, text-based XML files that contain parameters intended to automate and simplify opening or connecting to 4D databases, supporting both local database launching and 4D Server remote connections. The format offers significantly more power and flexibility than previous methods: developers can encode the structure file path (or 4D Server address), data file path, automatic login credentials (username and password, optionally MD5-encrypted), database opening mode (normal, interpreted, or compiled), connection parameters, and remote 4D Server database name. A 4DLINK file can be used in three ways: via double-click or drag-and-drop onto the 4D application, via selection in the 4D Open dialog box, or via the Open Recent Databases submenu (when stored in the system's local preferences folder). The note provides the formal XML Document Type Definition (DTD) describing all valid elements and attributes, includes sample 4DLINK file examples, and explains attribute meanings (is_remote for distinguishing local vs. remote databases, user_name and password for credentials, md5_password for encrypted authentication, structure_opening_mode for compilation mode, server_database_name and server_path for 4D Server connections, open_login_dialog to control login behavior). For remote 4DLINK files, the format supports server address (IP or DNS name) and can optionally prompt for login credentials. For local 4DLINK files, file:/// URLs specify structure and data file locations; local files may require path modification when moved between machines.
