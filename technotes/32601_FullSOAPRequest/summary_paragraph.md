Written by David Adams as a companion to the note on reading full SOAP responses, this technical note explains how to recover the complete, unmodified incoming SOAP request received by a 4th Dimension Web Service method, useful for debugging, logging, or reading inputs not declared via SOAP DECLARATION. It exploits an undocumented behavior of GET WEB FORM VARIABLES: when called inside a process handling a SOAP request, the command splits the incoming message into name/value pairs at the first equals sign, so concatenating the first name, an equals sign, and the first value reconstitutes the entire original SOAP XML body, which can then be re-parsed with Parse XML variable. The note walks through the anatomy of a sample SOAP request (an HTTP header block readable via GET HTTP HEADER, followed by a SOAP-ENV:Envelope/Body XML payload), contrasts this with 4D's normal automatic binding of inputs to method parameters and SOAP-declared process variables, and provides a full worked example, a soap_LogRequest method invoked from the On Web Authentication database method, that captures the client IP, server IP, username, User-Agent header, and the requested method name (parsed by walking two levels into the reassembled SOAP XML tree) into a log record. A further example shows reading an "undeclared" input (inRoundTo) added to a request without updating the method's SOAP DECLARATION calls, illustrating how manual parsing can support evolving parameter lists that the automatic binding system cannot easily accommodate.
