## Overview
A Tech Note demonstrating how to add hyperlink-style navigation and internal anchors to documents built with 4D Write.

## Key Points
- Demonstrates adding jump-to-top / jump-to-end navigation methods to a 4D Write document.
- Shows how to create internal anchors (hyperlink targets) within a 4D Write document.

## Featured Technology
- 4D Write
- Hyperlinks/anchors in documents

## Historical Commentary
**Status:** Obsolete

The classic 4D Write plug-in has been succeeded by 4D Write Pro, which has its own, generally richer navigation and hyperlink/anchor capabilities, making this note's specific classic-4D-Write commands obsolete for current document development, though the general concept of in-document navigation anchors remains a standard feature expectation.
