This Tech Note demonstrates how to add navigation capabilities to 4D Write documents, such as an object method that jumps the user to the end or the top of a document, making it easier to create hyperlink-style navigation for the user. It also shows how to create anchors within a document — described as another word for an internal hyperlink target — enabling structured, clickable navigation within long 4D Write documents, similar to how anchors work in HTML or word processing documents.
