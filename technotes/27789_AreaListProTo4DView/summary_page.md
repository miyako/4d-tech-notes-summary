## Overview
A migration-report Tech Note describing how one developer replaced Area List Pro (ALP) with 4D View in existing 4D 6.8 applications, with side-by-side method comparisons for common use cases.

## Key Points
- A practical account of migrating from the third-party Area List Pro (ALP) plug-in to 4D View.
- Covers two main use cases: record-selection display (like an output form) and included-form replacement for related records.
- Provides side-by-side ALP and 4D View methods for a representative (not exhaustive) subset of commands.

## Featured Technology
- 4D View
- Area List Pro (ALP) migration

## Historical Context
Area List Pro was a third-party 4D plug-in of the era; this note reflects the natural plug-in consolidation/migration pressures developers faced as 4D's own components (like 4D View) matured.

## Historical Commentary
**Status:** Obsolete

Both Area List Pro and 4D View are long-discontinued products with no direct modern equivalents, so this note's specific migration mappings are obsolete; the broader lesson — planning and executing a plug-in-to-plug-in migration by mapping common usage patterns — remains a useful, generally applicable approach whenever developers must migrate off a deprecated dependency.
