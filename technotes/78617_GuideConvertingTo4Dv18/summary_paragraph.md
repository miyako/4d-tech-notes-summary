This Tech Note is a practical migration guide written as 4D v18 dropped 32-bit support entirely, coinciding with the industry-wide move to 64-bit-only operating systems (macOS Catalina/Big Sur and newer). It stresses the first, non-negotiable step of backing up the entire database (structure `.4DB`, data `.4DD`, indexes, plugins, components, resources) because conversion is one-way and older versions can never reopen a converted structure or data file. The bulk of the guide walks through issues that surface immediately after opening an old database in v18: a Primary Key assistant prompt appears because ORDA requires every table to have a primary key; a Unicode-mode prompt appears, which the guide clarifies is mainly about preserving accented characters for non-English-coded databases and is safe to enable; and the "Use object notation to access object properties" compatibility setting must be turned on for ORDA's dot-notation syntax to work. It also walks through eliminating deprecated constructs: subtables (obsolete since v11) must be replaced with standard related tables and their `_O_CREATE SUBRECORD`-style commands removed; any command prefixed `_O_` is flagged as obsolete and should be replaced by consulting its F1 documentation; and PICT-format images (unsupported since v14) must be converted to PNG using a provided `UTIL_ConvertPICTs` utility method run against the older 32-bit database, then manually dragged into the new database's picture library. Because 4D View and 4D Write are 32-bit-only technologies with no direct command-for-command replacement, the guide points developers to Summit 2020 session recordings on migrating to 4D View Pro and 4D Write Pro, warning that most such code will need to be rewritten rather than mechanically translated. It closes with a naming-convention recommendation (avoid spaces/dots in table, field, form, and method names) to prevent ORDA dot-notation syntax errors, offering the bracket-notation workaround (`ds["Table 1"]`) where renaming isn't possible, and notes that 4D also offers professional services to assist with complex conversions.
