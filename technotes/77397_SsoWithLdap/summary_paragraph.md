This Tech Note by Tai Bui introduces the four new LDAP commands added in 4D v15 (LDAP LOGIN, LDAP LOGOUT, LDAP Search, LDAP SEARCH ALL) and explains how they can be used to build Single Sign On (SSO) functionality into a 4D application. It starts with LDAP fundamentals — directory entries, attributes, Distinguished Names (DN), and Relative Distinguished Names (RDN) — using a sample corporate directory tree to illustrate the concepts before covering each command's parameters, including connection URLs, credential formats (DN, CN, email, SAM-Account-Name), search filters, scope, and result formatting options. The note then explains SSO conceptually as reducing "password fatigue" and describes two general implementation patterns: SSO with locally installed software applications (auto-launching and logging into apps like Skype or FileZilla using credentials pulled from LDAP) and SSO with online/cloud services (via stored certificates). A detailed sample database and setup walkthrough uses Apache Directory Studio to stand up a local LDAP test server, load a custom schema and user entry via .ldif files, and then demonstrates connecting from 4D and using LDAP Search to retrieve stored credentials, which are fed into LAUNCH EXTERNAL PROCESS to auto-launch and log into the target applications. The author is candid that the sample is a simplified proof-of-concept that does not address encrypting stored credentials or generating launch scripts robustly, framing it as a foundation developers should expand and harden for production use. The conclusion reiterates that SSO, while requiring real implementation effort, is a valued convenience feature that 4D's new LDAP theme makes newly accessible without third-party plugins.
