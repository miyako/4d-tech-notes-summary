This extensive Tech Note by Vance Villanueva addresses the steep learning curve of 4D v17's Dynamic Forms feature, which lets developers build forms entirely from a JSON definition instead of using the form editor, but whose official documentation at the time covered only a simple starter example. The note methodically breaks down the JSON structure for nearly every 4D form object: a form is a `New object("pages"; New collection(Null; $page))` with a `$page` object containing an `"objects"` property, rendered either via `Open form window($form)` (which triggers screen updates through `DIALOG`) or via `OBJECT SET SUBFORM` for embedding inside a parent form (avoiding the need for `DIALOG`). It then documents, object-by-object, the JSON properties needed for text/group boxes, fields/variables, hierarchical lists and list boxes (covering array-based, selection-based, collection-based, and entity-selection-based variants), combo boxes/pop-ups/hierarchical and picture pop-up menus, buttons (standard, 3D, invisible, picture, button grid), radio buttons (standard, 3D, picture), check boxes (standard, 3D), progress indicators and rulers, drawing shapes (rectangle, line, rounded rectangle, oval), splitters and tab controls, and finally container-style objects — subforms, web areas, 4D Write Pro areas, and 4D View Pro areas — each shown with a minimal JSON snippet (e.g., `New object("type";"webArea";"text";"webArea";"top";$top;"left";$left;...)`). The note requires 4D v17 HF3/R2 or later and culminates in a bundled sample database, the "JSON Definition Tool," a UI for visually building and inspecting form-object JSON definitions, rendered live via `OBJECT SET SUBFORM`, intended to let developers experiment with and copy working JSON without memorizing the full schema. This positions the note as a comprehensive reference companion to 4D's terse official Dynamic Forms documentation, valuable to any developer building forms programmatically (e.g., generic/metadata-driven UIs, plugin-generated forms, or forms assembled at runtime from configuration).
