This Tech Note by Jay H. Burgherr addresses the challenge of configuring and maintaining a stable Macintosh system for running 4D, 4D Server, and 4D Client as Apple's newer, faster PCI-based Power Macintosh hardware became common in the mid-1990s. It introduces Open Transport, Apple's then-modern replacement for the older "Classic Networking" (MacTCP-based) stack, explaining that it lets a Mac communicate over multiple protocols simultaneously (e.g., AppleTalk for network printers alongside TCP/IP for connecting to a 4D Server), supports saved/switchable network configurations without restart, runs on Power PC/68030/68040 Macs, and is mandatory on any PCI-bus Mac, while being notably faster than the older MacTCP. The note's central troubleshooting topic is "Type 11" crashes/freezes that ACI's Technical Support team was fielding as its single most frequent complaint after customers upgraded to PCI Macs or switched from Classic Networking to Open Transport; it explains that 4D, 4D Server, and 4D Client were among the first commercially available applications built to be Open Transport-native, and recommends a specific tested combination of minimum versions to resolve these issues: 4th Dimension 3.5.3+, 4D Server/Client 1.5.3+, 4D Network components 1.5.3+, Mac OS 7.5.3 Revision 2+, and Open Transport 1.1.1+, while cautioning against blindly adopting "the latest" OS release without similar verification. It then walks through two supported approaches for getting to a clean, stable System 7.5.3 install — a full hard-drive reformat-and-fresh-install (using a compatible disk driver, e.g., the PDT Primer PE bundled with Power Computing machines) versus a lower-risk "Verify and Repair" approach using Disk First Aid and Apple Drive Setup — followed by a step-by-step Open Transport 1.1.1 installation procedure covering backup, reading the Open Transport ReadMe, recording existing TCP/IP settings from the MacTCP control panel, running the installer, selecting Open Transport via the Network Software Selector (on non-PCI Macs), and reconfiguring the AppleTalk, TCP/IP, and (if used) MacIPX control panels afterward. As a hardware/OS compatibility and networking-stack configuration guide entirely specific to classic Mac OS, PCI-era Power Macintosh hardware, and Apple's now-defunct Open Transport/MacTCP networking stacks, this note's specific guidance no longer applies to any currently supported 4D or macOS environment, though its broader caution about verifying software compatibility before adopting new OS releases remains sound general advice.
