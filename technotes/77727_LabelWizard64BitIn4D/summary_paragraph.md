Written by Vance Villanueva of 4D Inc. in February 2017 for 4D v16, this tech note tours the reworked 64-bit Label Wizard, contrasting its new streamlined UI and contextual-click design tools with the legacy 32-bit version. It explains backward compatibility rules for opening older ".4lb" label files — noting that Mac-created files import across platforms with minor dimensional differences, while Windows-created legacy files cannot be opened at all in the new wizard — and walks through the new contextual menus available on the editor, on generic objects, on field objects, and on level objects, alongside a simplified top-level menu and print preview capability. The note's more substantial technical content covers programmatic label generation: creating label files entirely offscreen (headless, without the UI), generating a generic label file and populating it with field and other objects entirely via 4D code, and manipulating the resulting labels.json settings file to control per-table form and method access restrictions for deployed applications. A companion demo database shows opening a label file from the drop-down, building a new label file and its objects in code, customizing form/method access through JSON, and running fully offscreen batch label printing — useful for automated document generation in deployed, unattended contexts. Because the 64-bit Label Wizard remains part of 4D's toolset today largely unchanged in its fundamentals, the guide's programmatic and JSON-driven techniques hold up well as a reference, even though many teams building modern reporting pipelines might now lean on 4D Write Pro or external PDF-generation tooling for more visually flexible output. Overall it's a durable, mid-relevance note documenting a still-supported native 4D feature.
