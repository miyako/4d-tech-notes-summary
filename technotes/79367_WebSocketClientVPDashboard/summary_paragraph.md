This technical note demonstrates how to combine 4D's WebSocket client capability, introduced with the "4D.WebSocket" class in v20 R3, with 4D View Pro to build a live financial data dashboard. The core problem addressed is consuming and visualizing continuously streaming external data — here, real-time Bitcoin ticker updates from Coinbase's free, unauthenticated public feed ("wss://ws-feed.exchange.coinbase.com") — inside a 4D application. The implementation defines a "WSConnectionHandler" class instantiated alongside "4D.WebSocket.new()", whose "onOpen" function sends a JSON subscribe message for the BTC-USD ticker channel, and whose "onMessage" function parses incoming JSON payloads with "JSON Parse" and updates a Form-level data object, maintaining a rolling collection of the ten most recent prices via ".shift()"/".push()". That data is then pushed into a View Pro spreadsheet area cell-by-cell using "VP Cell" and "VP SET VALUE", refreshed on a recurring "On Timer" event (e.g., every 15 seconds via "SET TIMER"). To turn the spreadsheet into a dashboard, the note shows executing raw JavaScript through "WA Evaluate JavaScript" to call the underlying Mescius SpreadJS API directly (creating a line chart bound to the price row and setting its title), then applying dashboard styling with "VP SET DEFAULT STYLE" and "VP SET CELL STYLE", and cleaning up UI chrome (scrollbars, tab strip) by exporting/re-importing the View Pro area's configuration object via "VP Export to object"/"VP IMPORT FROM OBJECT". The accompanying sample application walks through these steps interactively, culminating in a fully live BTC price dashboard, illustrating a general pattern for wiring any external real-time data source into a 4D View Pro-based visualization.
