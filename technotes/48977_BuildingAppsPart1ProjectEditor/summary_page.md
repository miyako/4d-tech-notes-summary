# Building Applications Examples – Part 1 XML Keys Editor

## Overview
The opening installment of a five-part series on 4D 2004's 80+ Build Application XML keys, this note introduces a custom-built 4D application that provides a graphical editor for every key in the XML project file used to configure application builds, aiming to make an otherwise dense, example-poor XML key reference approachable for developers building and customizing their own 4D executables on both Mac OS X and Windows.

## Key Points
- Published February 20, 2008 as Technical Note 08-07.
- Targets 4D v2004.7 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D 2004 Build Application XML keys
- Custom GUI project-file editor
- Cross-platform (Mac OS X & Windows) build configuration

## Historical Context
The foundational note of a well-regarded five-part XML-keys tutorial series; its practical GUI editor tool is tied to the specific XML project-file format used in the 4D 2004/early v11 era, since substantially reworked by later 4D versions and especially by the Project Mode (2018) shift to a fully text-based project structure.

**Status:** superseded

**Related updates:**
- 4D's build/compile configuration format has changed considerably since the 4D 2004 era described here
- Project Mode (2018+) introduced a git-friendly, fully text-based project structure that changed how build settings and XML-key-equivalent configuration are stored
