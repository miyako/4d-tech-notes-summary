The opening installment of a five-part series on 4D 2004's 80+ Build Application XML keys, this note introduces a custom-built 4D application that provides a graphical editor for every key in the XML project file used to configure application builds, aiming to make an otherwise dense, example-poor XML key reference approachable for developers building and customizing their own 4D executables on both Mac OS X and Windows. Published February 20, 2008 as Technical Note 08-07 for 4D v2004.7 (Mac & Win), written by a 4D Technical Services team member. The foundational note of a well-regarded five-part XML-keys tutorial series; its practical GUI editor tool is tied to the specific XML project-file format used in the 4D 2004/early v11 era, since substantially reworked by later 4D versions and especially by the Project Mode (2018) shift to a fully text-based project structure.
