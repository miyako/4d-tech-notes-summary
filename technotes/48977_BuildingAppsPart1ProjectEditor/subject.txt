Tech Note: Building Applications Examples – Part 1 XML Keys Editor (TN 08-07, 4D v2004.7, February 20, 2008) — The opening installment of a five-part series on 4D 2004's 80+ Build Application XML keys, this note introduces a custom-built 4D application that provides a graphical editor for every key in the XML project file used to configure application builds, aiming to make an otherwise dense, example-poor XML key reference approachable for developers building and customizing their own 4D executables on both Mac OS X and Windows.
