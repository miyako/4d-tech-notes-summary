This Tech Note (TN 01-47, 4D v6.7, Mac & Win, published October 30, 2001) by Jonathan Baltazar of 4D, Inc. walks through the ButtonMaker example database, originally created by Jeremy Sullivan of HD Industries, which generates custom HTML button graphics on demand. When a web visitor submits desired attributes -- width, height, font, bevel depth, button color, label text, text color, and style -- through an HTML form, the database's CGI4D_ButtonMaker and CGI4D_ButtonCreateButton methods use 4D Chart's offscreen-drawing commands (CT New offscreen area, CT Draw rectangle, CT Array to polygon, CT Draw text) to render a beveled 3D-style button with highlight and shadow polygons, convert the offscreen area to a picture, and stream it back to the browser as a GIF via SEND HTML BLOB. Supporting methods also pre-generate static style and color reference charts (stylechart.gif and colorchart.gif) the first time the database starts, so users can pick valid font-style and 256-color-palette values from a visual reference. The note documents each method in the chain -- from On Startup and On Web Connection through parameter parsing (GEN4D_ParseParams) and platform-specific path handling (Gen4D_GetPlatformDeliminator) -- as a complete worked example of server-side dynamic image generation purely within 4D. It is a clever dot-com-era technique for producing custom web graphics without a graphic designer, built entirely on 4D Chart's now-discontinued drawing API.
