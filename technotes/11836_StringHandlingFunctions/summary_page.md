## Overview
A reusable library of cross-platform string handling functions for 4D v6, covering capitalization, space trimming, keyword indexing, and other common text operations.

## Key Points
- Library of string handling functions written in native 4D code
- Covers capitalization, space removal, keyword index building, and more
- Cross-platform: works on both Mac OS and Windows
- Designed to be reusable across different 4D databases

## Featured Technology
- 4D v6
- String Functions
- Text Processing
- Keyword Indexing

## Historical Context
**Status:** Superseded

String handling utilities were essential in 4D v6 where built-in string functions were limited. Modern 4D has significantly expanded its string handling with built-in commands, regular expression support, and collection methods. Many of the specific utility methods described in this note would now be one-liners using modern 4D commands.

### Related Updates
- Modern 4D includes extensive built-in string manipulation commands
- Regular expression support via MATCH REGEX and related commands
- Collection and object methods provide additional text processing capabilities
