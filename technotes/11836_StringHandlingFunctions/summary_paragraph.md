This Tech Note provides a library of cross-platform string handling functions, all written in native 4D code. Almost any 4D application requires string manipulation for tasks such as capitalizing words, removing unnecessary spaces during data entry, or building keyword indexes from text. The note collects these commonly needed functions into a reusable library that developers can incorporate into their own databases.
