# Tech Note: Adding a Styles Palette to 4D Write

**Author:** Not specified
**Published:** October 1, 1999 | **Product/Version:** 4D Write v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11858

## Overview
This Tech Note creates a custom mouse-driven styles palette for 4D Write, replacing the built-in Styles pop-up menu with a more efficient button-based interface that includes dynamic help tips.

## Key Points
- Addresses the tedium of applying styles via 4D Write's pop-up menu for large documents
- Creates a palette with buttons for each style in the 4D Write template
- Each button triggers a 4D method that applies the corresponding style
- Dynamically manages help tips for the palette buttons
- Provides a "mouse-based" alternative to keyboard equivalents

## Featured Technology
- 4D Write (word processing plug-in)
- Custom palette/toolbar creation
- Dynamic help tip management
- Style application via 4D methods
