This Tech Note introduces Core Image Pack, a Mac-only 4D plugin that exposes Apple's Core Image framework — introduced with Mac OS X 10.4 — for high-quality, GPU-accelerated image manipulation directly from 4D. It requires 4D v11 SQL or higher and Mac OS 10.5 or higher, and supports operations ranging from color adjustments, blurring, denoising, and sharpening to complex blends between two images, all rendered quickly by taking advantage of the graphics card. The plugin exposes five commands — CI_SetImage, CI_GetImage, CI_GetFilterList, CI_GetFilterAttributes, and CI_ApplyFilter — plus a dedicated external area, CI_Preview, which displays filtered results directly from graphics-card memory for near-instant previewing before the final image is retrieved back into a 4D picture variable. An example database demonstrates an automatic slideshow of image manipulations followed by an interactive dialog for browsing filters, adjusting their parameters (sliders for numeric values, load buttons for supplementary images), and loading custom images from disk. The note targets Mac-only 4D developers who want to add professional-grade image effects to their applications without implementing image processing algorithms themselves.
