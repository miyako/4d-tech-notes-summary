# Tech Note: Converting a Database from Version 3 Macintosh to Version 6 Windows

**Author:** Not specified
**Published:** May 1, 1998 | **Product/Version:** 4D Transporter v6.0.x | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11785

## Overview
This Tech Note provides step-by-step instructions for converting a Version 3 Macintosh 4D database to Version 6 on Windows, using the 4D Transporter utility.

## Key Points
- **Migration path:** Version 3 (Mac-only) → Version 6 (cross-platform, targeting Windows).
- **Tool:** 4D Transporter — a dedicated utility for cross-version and cross-platform database migration.
- **Dual challenge:** Crosses both a major version boundary (v3→v6 with significant structural changes) and a platform boundary (classic Mac OS→Windows).
- **Target audience:** Long-time Mac-based 4D developers moving to Windows.

## Featured Technology
- 4D Transporter utility
- 4th Dimension v3 database format (Mac-only)
- 4th Dimension / 4D Server v6 database format (cross-platform)
- Cross-platform database migration

## Historical Context
**Status:** Historical interest only

4D Transporter was a standalone utility that facilitated database migration across major version and platform boundaries — a concept that no longer exists in modern 4D, where database upgrades are handled internally when opening a database in a newer version. The v3 database format is ancient history, and direct migration from such early versions has not been supported for many generations of 4D. The note is a reminder of 4D's transition from a Mac-only product (4th Dimension, originally by ACIUS/ACI) to the cross-platform development environment it became with v6 in the late 1990s.
