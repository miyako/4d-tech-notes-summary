This Tech Note provides a step-by-step guide for converting a Version 3 Macintosh-based 4th Dimension application to 4th Dimension or 4D Server Version 6 on Windows. The migration path crossed both version boundaries (v3 to v6) and platform boundaries (Mac to Windows), making it one of the more complex conversion scenarios. 4D Transporter was the dedicated utility tool used for this process, handling the structural differences between the old Mac-only v3 format and the new cross-platform v6 format. This was a critical need in the late 1990s as many long-time 4D developers on Macintosh needed to move their applications to Windows to serve a broader market or respond to organizational platform changes. The note reflects the era when 4D was transitioning from a Mac-only product to a fully cross-platform development environment. Only the teaser text survives; the full step-by-step instructions could not be recovered.
