This Technical Note by Timothy Aaron Penner introduces the GET LIST ITEM PARAMETER ARRAYS command, new in 4D v13, which makes it substantially easier to retrieve the metadata ("parameters") attached to items in a 4D hierarchical list. Since 4D v11 SQL, list items could carry String, Boolean, or Long Integer parameters via SET LIST ITEM PARAMETER and GET LIST ITEM PARAMETER, but developers previously had to already know a parameter's name to retrieve its value — there was no way to enumerate all parameter names for an item. The new command solves this by returning all parameter names (and optionally their values) for a given list item in a single call, with the note detailing its five-parameter syntax (the object-name-vs-reference selector, the list, the item reference, and output arrays for names and values). A comprehensive sample database demonstrates the command across multiple real-world scenarios: a generic List Editor, a Countries demo showing parameterized country data, a Countries Maps demo, a Countries Smart Searches demo for parameter-driven filtering, a Settings demo, Test Routines, and a Web Searches demo. Through these varied examples, the note illustrates practical patterns for using list item parameters as flexible per-item metadata in hierarchical lists throughout a 4D application.
