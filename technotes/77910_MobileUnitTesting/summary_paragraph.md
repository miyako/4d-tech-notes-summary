This revised Tech Note explains how to leverage Wakanda's built-in unit testing support — based on the Mocha and Chai JavaScript testing frameworks, introduced in Wakanda 2.1 — to validate 4D Mobile applications. It starts with a general introduction to Wakanda unit testing: writing individual test cases, grouping them, executing them via a "Test" button newly added in Wakanda Studio, and reviewing detailed results exported as JSON. It then applies this framework specifically to 4D Mobile, where 4D tables, attributes, and methods are exposed to the Wakanda/JavaScript layer, showing how to test the existence of exposed tables, attributes, and methods, and separately how to test CRUD and query operations against them (e.g., a raiseSalaries method call verified with Chai's `expect(...).to.equal(...)` assertions against expected salary values). The goal is to give 4D Mobile developers confidence that their exposed data model and business logic behave correctly and to catch regressions automatically rather than manually, running tests hands-free on the server and reviewing results in Wakanda Studio's dedicated test tab. The note candidly notes a limitation: at the time, Wakanda's testing feature only covered server-side logic, so separate frameworks would be needed for front-end and UI testing of the 4D Mobile client, and hints at future work extending testing to the front-end.
