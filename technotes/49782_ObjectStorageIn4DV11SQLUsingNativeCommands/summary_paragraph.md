4D v11 SQL has extended the capabilities of hierarchical list items to allow storage of Object-like structures. The same hierarchical list item may have values of different types; i.e. numerical, string or boolean. In other words, you can associate a dictionary with each list item. Using the commands SET LIST ITEM PARAMETER and GET LIST ITEM PARAMETER, you can store Objects using native 4D v11 SQL Commands. Published May 14, 2008 as Technical Note 08-18 for 4D v11 (Mac &amp; Win), this note was written by Luis Pineiros Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
