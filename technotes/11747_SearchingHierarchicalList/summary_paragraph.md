This Tech Note explains how to search a hierarchical list in 4D, noting that this functionality is straightforward to implement using 4D's built-in commands. Hierarchical lists differ from other 4D objects in how they store data: they hold "items" and the parent/child relationships between those items, where any item can be a parent to multiple children and any item can have one parent. This tree structure requires a recursive or iterative traversal approach for searching, unlike flat arrays or selections that can be searched linearly. The note positions hierarchical lists as a fundamental but distinct data structure within 4th Dimension, requiring specific techniques to search effectively. Hierarchical lists were commonly used for category browsers, file system views, organizational charts, and other tree-structured data displays in 4D applications.
