This Technical Note is an introductory-level explanation of Ajax aimed at 4D developers with no web development background, structured around dispelling common misconceptions (Ajax is not a new technology, not a new language, and not a proprietary product like Flash) before defining what Ajax actually is: a technique that combines existing open technologies — JavaScript, XML, HTML, and CSS — to build interactive web applications without full-page reloads. It recounts Ajax's brief history, crediting Jesse James Garrett's February 2005 essay "Ajax: A New Approach to Web Applications" for coining the term amid buzz generated by early Ajax-style Google products like Google Maps and Google Suggest, and lists browser compatibility of the era (IE 5.0+, Mozilla 1.0+, Firefox 1.0+, Netscape 7.0+, Safari 1.2+). It characterizes Ajax applications as interactive and free of disruptive page reloads, contrasting old-style form submission with modern asynchronous updates, and briefly touches on the underlying mechanics of how Ajax achieves this. The note's second half pivots to introduce the 4D Ajax Framework (4DAF) as 4D's turnkey and customizable solution for bringing this interactivity to existing 4D databases, describing its layered architecture (4DAF Client for plug-and-play use, 4DAF Libraries for custom embedding, and Data Services/Server layers handling browser-to-database communication) and showcasing prebuilt UI objects like the Image Matrix and Calendar that can visually and asynchronously represent 4D table data. It highlights ease of integration — often just a line or two of JavaScript, or none at all via the point-and-click "4D Ajax for Dreamweaver" extension — and points to further resources such as Daxipedia.com and other Technical Notes (e.g., 07-24, "4DAF Video Player") for advanced 4DAF development. As a conceptual on-ramp published just before 4D v11 SQL's SQL-focused notes, it captures 4D's broader 2007 strategy of pairing its classic desktop database engine with contemporary web interactivity.
