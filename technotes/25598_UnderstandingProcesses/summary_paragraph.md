This Tech Note aims to help developers understand processes in 4th Dimension, noting that processes have been part of 4D since version 3.0. It makes the important clarification that 4D processes are not like processes/threads in other languages — they are not real OS-level threads — but are instead emulated by 4D's single underlying execution thread, which the note frames around the main process being the User/Custom menu process (the User Interface, Client Manager, and Cache Manager processes on 4D Server, respectively). This is foundational conceptual material for any 4D developer needing to reason correctly about concurrency, semaphores, and inter-process communication in classic 4D applications.
