This 2001 Tech Note by Christian Cypert, the 4D & WebSTAR Plug-in Evangelist, teaches 4D plug-in developers how to construct database queries programmatically from compiled C/C++ code using the classic 4D Plug-in API, as an alternative to simply displaying 4D's built-in Query Editor. It first shows the easiest path, PA_QueryDialog, which pops up the native Query Editor pre-set to a given default table. It then covers the three-stage API for building queries without a dialog: PA_OpenQuery(TableNumber) to initialize, one or more PA_QueryXxx calls (where Xxx is a field type such as String, Longint, Date, Boolean, Real, or Time) to define search criteria, and PA_CloseQuery to execute. It explains the Query Operators (eQO_LogicalAND, eQO_LogicalOR, eQO_Except, and eQO_NoOperator for the mandatory first line) and Comparison Operators (eQC_IsEqual, eQC_IsDifferent, eQC_IsGreater, eQC_IsGreaterOrEqual, eQC_IsLess, eQC_IsLessOrEqual, eQC_Contains, eQC_NotContains), mapping each to its equivalent 4D QUERY command syntax. Three progressively complex worked examples in C show: a single-criterion string query (TN_QueryString, equivalent to QUERY([People];[People]LastName="Smith")), a two-criterion AND query (TN_QueryMultipleStrings), and a three-criterion query mixing string, longint, and date fields (TN_QueryComplex), the latter introducing the PA_Date structure and its fDay/fMonth/fYear members accessed via PA_GetDateParameter. The note concludes that despite a few extra parameters, building a query via the API closely mirrors writing one directly in 4D.
