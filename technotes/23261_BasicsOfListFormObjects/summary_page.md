## Overview
An introductory Tech Note explaining the basics of programmatically using 4D's four list-based form object types: scrollable areas, drop-down lists, combo boxes, and hierarchical lists.

## Key Points
- Introduces the four list-based form object types in classic 4D: scrollable areas, drop-down lists, combo boxes, hierarchical lists.
- Covers the basics of programmatically using each type.
- Serves as foundational material for more advanced hierarchical list notes.

## Featured Technology
- Scrollable areas
- Drop-down lists
- Combo boxes
- Hierarchical lists

## Historical Context
