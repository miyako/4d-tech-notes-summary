## Overview
This note introduces Select Document, a command new to 4D 2004 that gives developers greater power in handling file selections than any command available before it, illustrated through several worked examples.

## Key Points (from available teaser)
- Select Document is presented as a new, more capable command for handling file selection in 4D 2004.
- The note takes an example-driven approach, presenting several different scenarios/examples.
- Goal is to give developers a concrete, practical understanding of the command's expanded capabilities.

## Featured Technology
- Select Document command (new in 4D 2004)
- File/document selection dialog handling

## Historical Context
**Note:** Only the on-page teaser paragraph was recoverable for this Tech Note; the full PDF and example database were not accessible (old archive format not retrievable in this environment), so the specific worked examples cannot be reproduced here. Select Document has remained part of the current 4D classic language largely unchanged in concept, continuing to serve as the standard way to prompt for a file in current 4D databases, so the core technique this note teaches is still directly applicable today, even as the underlying OS file picker dialogs have visually evolved over the past two decades.
