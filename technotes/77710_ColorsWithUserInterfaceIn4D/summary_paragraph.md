Written by Tai Bui of 4D Inc. in January 2017 for 4D v16, this tech note is a design-theory-meets-implementation piece that surveys color's role in effective user interface design and then provides 4D code to apply that theory programmatically. It opens with an accessible discussion of how color affects mood and visual perception, contrasting Microsoft's and Apple's default OS color schemes as real-world examples, before moving into two more rigorous concepts: contrast ratios (citing ISO/ANSI/HFES's 3:1 minimum and the W3C's WCAG 2.0 Success Criterion 1.4.3, which sets 4.5:1/3:1 for Level AA and 7:1/4.5:1 for Level AAA) and color harmonies based on the color wheel, starting with simple complementary-color pairs and extending to more complex three- and four-color combination schemes. Having established the theory, the note then shows 4D implementation techniques: a method to programmatically generate a color that contrasts sufficiently against a given background color, methods to calculate color harmonies (complementary, and more complex multi-color schemes) from a base color, and a method to generate monochromatic color variations of a single hue. A sample database demonstrates the techniques in a working 4D form context. Because the underlying color science and WCAG accessibility standards are essentially timeless (with only incremental updates since, e.g., WCAG 2.1/2.2), and the 4D-side RGB/HSL manipulation code still executes on current 4D, this note remains useful reference material nearly a decade later — though a developer building modern web-facing 4D UIs today would more likely apply the same color theory via CSS custom properties or a design-system tool rather than through 4D method code.
