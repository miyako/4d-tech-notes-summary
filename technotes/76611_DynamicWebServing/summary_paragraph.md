This Technical Note by Darrell Draper is the second installment in a multi-part series on 4D v13's built-in Web Server, following an earlier note on static web serving, and focuses on generating dynamic content and handling incoming form data. It surveys the different ways 4D can produce "semi-dynamic" HTML pages — 4D Tags (HTML comments 4D expands on the fly), 4DScript, and 4DAction — comparing their pros, cons and typical use cases, before moving to fully dynamic pages generated via 4DCGI and the On Web Connection database method, including how to inspect On Web Connection's parameters. A "Which Method to Choose" section helps developers pick the right approach for their scenario, followed by guidance on serving web content generally. The second half of the note addresses the reverse direction: receiving data submitted from a web browser, covering how to build input forms and validate submitted input before storing it in the 4D database. Overall the note aims to equip developers with a practical toolkit for building 4D-based websites that go beyond static HTML, setting up later notes in the series that promised to cover more advanced Web Server topics like session management and security.
