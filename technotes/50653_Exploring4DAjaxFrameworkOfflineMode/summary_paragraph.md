With the new offline web browser technologies available, users can enter and save data in their browser while not connected to the internet, then automatically synchronize that data when they reconnect. This Technical Note will give a quick overview of the capabilities of Offline Mode, outline the new browser technologies behind the feature, and offer troubleshooting tips for developers implementing Offline Mode in a 4D Ajax Framework application. Published August 6, 2008 as Technical Note 08-28 for 4D Web 2.0 Pack v11.2 (Mac &amp; Win), this note was written by Thomas Fitch, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
