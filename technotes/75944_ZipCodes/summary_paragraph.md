This Tech Note tackles a common address-entry problem: automatically filling in City and State from a ZIP Code so users don't have to type — and re-verify — redundant information. It offers two alternatives bundled in a sample database: a local table of over 80,000 US ZIP codes (with city, state, area code, time zone, latitude and longitude) for fast offline lookups, and a call to a free third-party SOAP web service at webservicex.net for always-current information without local maintenance. The demo lets the developer toggle between "ZIP Code Database," "ZIP Code Service," or "None" as the lookup source, and shows sample code (`proxy_GetInfoByZIP`) that builds a SOAP request via `DOM Create XML Ref`/`CALL WEB SERVICE` and parses the XML response with `DOM Find XML element`. Beyond basic address completion, the sample also supports reverse lookups (finding all ZIP codes for a given City, State, or Area Code) and an approximate great-circle-style distance calculation between two ZIP codes' latitude/longitude using simplified trigonometry. The note frames this as a productivity and data-quality tool for any address-entry form, with the developer choosing between the reliability of a local (but staleness-prone) database and the freshness of an internet-dependent service.
