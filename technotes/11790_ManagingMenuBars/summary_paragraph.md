This Tech Note addresses the challenge of dynamically managing menu bars in 4D v6, specifically the limitation that procedurally added menu items do not have their menu structure created in memory and lack associated methods. This means that dynamically added items cannot be automatically executed through a form-associated menu bar in the same way as statically defined items. The note demonstrates techniques for dynamically adding and deleting menu items at runtime while working around these limitations. This was a practical concern for developers building applications that needed context-sensitive or user-configurable menus — a common requirement in data-driven applications. The procedural menu management approach described here reflects the v6 architecture where menus were primarily defined in the Design Mode Menu Bar Editor.
