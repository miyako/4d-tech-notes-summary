Only the readme/setup instructions for this Tech Note's demo database were available, rather than an extended narrative PDF body, so this summary is based on that readme and the referenced method/file names. Targeting 4D v17 beta and above (and Wakanda Enterprise 2.6.0+, tested against Safari 11.1.1/Chrome 67+), the demo requires a 4D Mobile Server Expansion for server-based testing, or can be run uncompelled in 4D standalone otherwise. It demonstrates the fundamentals of moving data as ORDA collections between 4D and a Wakanda Enterprise JavaScript backend acting as the 4D Mobile client layer: a Wakanda script `returnCollectionFrom4D.js` shows retrieving a collection produced on the 4D side, while `sendCollectionTo4D.js` shows sending a collection from Wakanda back into 4D, with the resulting JSON collection displayed in a 4D form named "CollectionFromMobile". Two further 4D methods, `convertArrayToCollection` and `convertCollectionToArray`, demonstrate basic type conversion between 4D's classic array types and the newer collection object, with results surfaced via alerts or inspectable in the debugger. As one of the earliest Tech Notes in the "4D Mobile Exchange ... using Collection" series (predating the more advanced entity-selection and locking scenarios covered in TN 18-17), this note serves as an introductory primer on collections as a mobile-data-interchange format, aimed at developers just getting started building 4D Mobile/Wakanda Enterprise-backed client applications during 4D v16R/v17's early ORDA-collection era.
