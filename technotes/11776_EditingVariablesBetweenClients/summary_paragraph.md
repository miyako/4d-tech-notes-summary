This Tech Note demonstrates a feature introduced in 4D V6 that allows developers to view and modify the contents of variables among multiple 4D Clients without resorting to traditional synchronization methods such as fields, semaphores, or documents written to disk. This capability enabled a form of inter-client communication where one client could inspect or change variable values held by another client connected to the same 4D Server. The note shows how to take advantage of this feature, which was a novel approach to multi-user data sharing in the client/server architecture of the time. This was particularly useful for scenarios like broadcasting notifications, sharing state information, or implementing lightweight messaging between connected users. The ability to bypass the overhead of field-based or file-based synchronization was a significant productivity advantage.
