# Tech Note 04-03: Complex Form Resizing

**Author:** Not specified in source teaser
**Published:** January 31, 2004 | **Product/Version:** 4D v2003 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31179

## Overview
This Tech Note describes a method for computing form object placement and size together when a 4D entry form is resized, combining move and resize logic into a single, coherent computation via the 4D language.

## Key Points
- Motivates resizable forms as useful both for showing more information and for adapting to user preferences.
- Notes that 4D's basic built-in resize/move behaviors are sometimes insufficient, requiring custom language-based logic.
- Describes a method that combines moving **and** resizing objects into one simple, logical operation.

## Featured Technology
- 4D form object model (Design Mode-era forms)
- Language-based object move/resize computation

## Historical Context
Only the on-page teaser paragraph for this asset could be recovered (the full archived PDF was not accessible in this environment), so this summary reflects the note's stated purpose rather than its exact method/code. This note predates 4D's later additions of more built-in form object anchoring and auto-resize options, so while its specific implementation is dated, the underlying challenge of precisely controlling object placement/size during form resize remains a recognizable and still relevant concern for 4D form design today.
