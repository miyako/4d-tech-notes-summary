This Tech Note demonstrates how to integrate FullCalendar (v4.3.1), a popular open-source JavaScript calendar framework, into a 4D application to provide interactive month/week/day/list calendar views without building the UI natively. The framework's js/packages folders are placed in the database's Resources folder (ensuring distribution to 4D Remote clients), and an HTML template hosts a #calendar div along with JavaScript glue functions (change, getTitle, updateEventData) that instantiate a FullCalendar.Calendar object with interaction, dayGrid, timeGrid, and list plugins. The HTML is loaded into a 4D Web Area, and dynamic values (like the default date) are injected via #4DTEXT tags processed with PROCESS 4D TAGS before load. 4D calls into the JavaScript side using WA EXECUTE JAVASCRIPT FUNCTION to switch views or dates, while the JavaScript calls back into 4D through a $4d bridge object (waCallBackEventEdit, waCallBackEventUpdate) whenever a user clicks, drags, or resizes a calendar event; these callbacks use ORDA (ds.Events.query(), entity.save()) to fetch and persist changes. The demo application layers a multi-user sharing/permission system on top, using project methods like openCalendarMainWindow, openCalendarPermission, and a hook method (setupUserListForCalendar) to integrate with any user/password system. The note positions this as a broader illustration of 4D's extensibility: developers can pull in any mature open-source JS library to fill functionality gaps rather than building everything natively, cutting development time significantly.
