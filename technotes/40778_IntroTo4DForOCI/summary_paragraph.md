This Technical Note by Yvan Ayaay introduces the 4D for OCI plug-in, which lets 4th Dimension and 4D Server applications communicate directly with Oracle 8i, 9i, and 10g database servers as native Oracle clients via the Oracle Call Interface (OCI), an API providing a dynamic runtime library of database access and retrieval functions plus handles for context, connection, bind, data, and error information. The note walks through installing the Oracle Database Client software required for the plug-in to function: on Windows, running the Oracle Universal Installer from the downloaded client package and then configuring a tnsnames.ora network configuration file (either via the Net Configuration Assistant or by hand) to define the connection's protocol, host address, and port for a named Oracle service. On Mac OS X 10.3.x, it documents a detailed, terminal-driven installation of the Oracle 10g Instant Client, including creating a root-owned "/Oracle" directory, copying the required libclntsh.dylib library into /usr/lib with appropriate permissions, and creating a user-level environment.plist property list file to configure the runtime environment needed by the plug-in. Positioned as a foundational setup guide, this note lays the groundwork for the more advanced companion Technical Note 05-45 on 4D for OCI error handling, and reflects a period when 4D was actively extending its database connectivity options beyond its native engine toward direct enterprise Oracle integration.
