This Tech Note by Tai Bui documents 4D Write Pro during its early rollout as the 64-bit replacement for the legacy 32-bit 4D Write plug-in, explaining why the architectural shift was necessary (32-bit plug-ins are incompatible with 64-bit application builds) and what changed as a result: 4D Write Pro is integrated into 4D as a native form object rather than a separate plug-in tool, available since v15R3, and is described as not a simple drop-in upgrade from old 4D Write but a genuinely new technology with different capabilities. The note walks through adding a 4D Write Pro object to a form, then surveys its default user interface controls and default contextual menu, noting that some of 4D's own design choices for these defaults may not suit every deployed application's end users. It covers the 4D Write Pro user experience baseline before diving into customization: adding new standard actions, tracking text selection state and interacting with the 4D Write Pro object programmatically, and then several concrete tailoring mechanisms — customizing control bars, using the 4D Write Pro Interface Component, modifying contextual menus, and customizing menu bars. A sample database (recommended to be opened with v16R4) demonstrates these techniques hands-on, giving developers a template for rolling out a customized 4D Write Pro experience tailored to their application's needs, as well as some guidance on transitioning existing 4D Write-based applications toward 4D Write Pro. As one of the earlier 4D Write Pro tech notes, it captures the product close to its initial release, before many of the richer features (styles, advanced page setup, mail merge, and more) that arrived in subsequent 4D versions.
