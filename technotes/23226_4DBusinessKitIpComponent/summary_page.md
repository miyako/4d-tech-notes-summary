## Overview
A Tech Note explaining how the 4DBK IP Component allows developers to extend and customize the otherwise closed-source 4D Business Kit e-commerce application.

## Key Points
- Clarifies that although 4D Business Kit's own source is closed, the IP Component opens it to developer extension.
- Describes 4D Business Kit as a stand-alone e-commerce application built using 4D 6.7.3.
- Foundational note preceding the later, expanded 4DBK v2.x IP Component note also in this batch.

## Featured Technology
- 4D Business Kit
- IP Component (extensibility)

## Historical Context
4D Business Kit was 4D's turnkey e-commerce platform of the early 2000s, built on 4D 6.7.3; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

4D Business Kit has been discontinued for many years, making the specific IP Component extensibility mechanism obsolete; any modern e-commerce solution built with 4D today would use current web/ORDA/REST tooling rather than this legacy closed-source-with-plugin-extension architecture.
