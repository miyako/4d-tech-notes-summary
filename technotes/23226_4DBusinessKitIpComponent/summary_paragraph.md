This Tech Note describes 4D Business Kit as a stand-alone, double-clickable e-commerce application built using 4D 6.7.3, whose source code is not available to the public — which might suggest it is a closed product, but the note argues this is far from true, because the 4DBK IP Component makes the platform wide open to any 4D developer for extension and customization. This is the foundational version of the IP Component note, with a later note in this batch ("The 4D Business Kit v2.x IP Component") documenting a subsequent, expanded 19-method version for 4DBK v2.0. Only the short on-page teaser text could be recovered here, so the specific methods available in this earlier version are not detailed.
