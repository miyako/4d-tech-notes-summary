This 2002 Tech Note by Sebastian Frey, 4D Evangelist at 4D, Inc., documents the 4DBK IP Component, a small (ten-method) 4D code component that lets any 4D 6.7+ application integrate with the 4D Business Kit (4DBK), a closed-source, stand-alone e-commerce server product built on 4D 6.7.3. Rather than exposing 4DBK's source, the IP Component works by leveraging the 4D Business Kit Tag Language over the network, relying on the 4D Internet Commands plug-in plus a small Business Kit Plug-in for BLOB text parsing, and can be cleanly added to or removed from a host application at any time. The note walks through configuring a demo application (with Local Web Port, SMTP mail server, and store code "DEMO") alongside a running 4DBK store, then demonstrates the core API: 4DBKC_SessionNew/4DBKC_SessionOpen to obtain a Business Kit session ID, and the central 4DBKC_Execute method, which sends a command string and returns a BLOB result. It highlights the demo's APP_BKExecute wrapper, which auto-inserts the mandatory "4DBKStoreSet/XXXX" prefix and simplifies success/failure checking, and walks through real workflows -- adding/updating a Customer record with 4DBKCustomerExists and 4DBKRecordNew/CUS, sending dynamic HTML email via the 4DBKMail tag, uploading product data (including pictures) as a BLOB with 4DBKC_ItemUpdateBuild/4DBKC_ItemUpdateSend, adding items to a shopping cart with APP_BKItemToCart, and validating/checking out an order with 4DBKOrderValidate. It is a practical guide to scripting a discontinued but historically significant 4D vertical e-commerce product.
