Written by Steve Hussey, CEO of Alto Stratus LLC, this Tech Note builds a system that lets 4D monitor a folder chosen by the user and periodically import its contents, using nothing more than a handful of standard commands and 4D's cooperative process model. A Locator dialog backed by the [Util_Preference_Application] table lets the user pick the folder to watch via Select folder("Select the watch folder."), storing the chosen path in a field. Choosing Demo > Run launches the Import_Mgr process, which loops with DELAY PROCESS/RESUME PROCESS to pause for roughly sixty seconds between iterations (configurable, and capped at five iterations for the demo) before launching a fresh Import process each cycle. The Import method lists the watched folder's contents with DOCUMENT LIST into an array, filters out the Mac OS invisible icon file by searching for "Icon@", then for each remaining file opens it in read-only mode with Open document, reads its contents with RECEIVE PACKET, parses the tab-delimited values into an array using the STR_Txt2AryPrs helper method, creates one [Imported_Value] record per value (storing the source document name, a sequence number, and the value), and finally closes and permanently deletes the source document with CLOSE DOCUMENT/DELETE DOCUMENT. The note closes by suggesting the Import_Mgr pattern could be extended to watch multiple folders in parallel or to reverse the flow and export 4D records to other systems.
