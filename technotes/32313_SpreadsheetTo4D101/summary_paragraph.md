This introductory Tech Note targets new 4D developers who want more functionality out of their spreadsheet data than Excel offers, but who don't want the tedium of manually re-entering that data into a 4D database. It walks through 4D's built-in import dialog, which supports a multitude of source file formats and can convert them seamlessly into a 4D database structure, while acknowledging that the range of options can feel overwhelming to newcomers. The tech note and its accompanying example database are explicitly designed to streamline and demystify this process, highlighting two complementary import paths: first, the Import Dialog itself along with the corresponding 4D language commands that let a developer automate the import programmatically rather than performing it manually each time; second, ODBC (Open Database Connectivity), Microsoft's cross-vendor protocol for connecting to external data sources, which 4D can use to pull data from any ODBC-compliant source essentially at the push of a button. The note positions the example database as a foundation developers can either build directly upon or mine for reusable import techniques to apply to their own existing databases. As a "101"-level note, its featured technology is squarely 4D's import subsystem and ODBC connectivity rather than any advanced or niche feature, reflecting the practical, everyday nature of moving business data from spreadsheets into a proper relational 4D application during the pre-SQL-engine era of the product.
