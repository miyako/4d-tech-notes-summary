# Tech Note 04-16: Spreadsheet to 4D 101

**Author:** Not specified in source teaser

## Overview
An introductory Tech Note aimed at developers who want to move data out of Excel spreadsheets and into a proper 4D database, without manually re-keying records, by using 4D's built-in import tooling and ODBC connectivity.

## Key Points
- Positions 4D's Import Dialog as a powerful, multi-format import tool that can feel overwhelming to first-time users.
- Covers both **manual** import (via the Import Dialog) and **programmatic** import (via corresponding 4D language commands).
- Covers **ODBC** as a second import path, allowing 4D to pull data from any ODBC-compliant external data source.
- Provides an example database intended as a reusable foundation for further import work.

## Featured Technology
- 4D Import Dialog and import-related language commands
- ODBC (Open Database Connectivity)

## Historical Context
Only the on-page teaser text for this asset was available (the full archived PDF could not be retrieved in this environment), so this summary reflects the stated scope and intent of the note rather than its exact walkthrough steps or code. As a 101-level onboarding note from 2004, it reflects an era when ODBC was 4D's primary bridge to external/spreadsheet-style data before 4D's own SQL engine (v11 SQL, ~2007) existed.
