Written by Hugo Fournier of 4D, Inc. Technical Support, this Tech Note revisits the data-driven web publishing example from the earlier TN 00-36 and reimplements it using new HTML tags added in 4D v6.7, dramatically simplifying the code required. Where TN 00-36 had to duplicate placeholder strings in HTML and manually replace them via 4D string-handling code for every record, this note's approach uses a static source HTML document (static.shtml, stored in the Web Folder and set as the HTML root) containing <!--4DLOOP [Table]-->/<!--4DENDLOOP--> tags to repeat blocks of markup per record, <!--4DVAR Field--> and <!--4DHTMLVAR Variable--> tags to insert field or computed values, and a <!--4DSCRIPT/MethodName--> tag to run a 4D method (such as Set_Space, which replaces spaces with %20) at each iteration of the loop. The Welcome method manages the record selection (querying either all chapters or a specific one based on whether a parameter was passed) before calling SEND HTML FILE("static.shtml") to trigger the parsing and delivery of the populated page. The note demonstrates that the exact same published content as TN 00-36 can be produced with substantially less string-replacement code thanks to these new tags.
