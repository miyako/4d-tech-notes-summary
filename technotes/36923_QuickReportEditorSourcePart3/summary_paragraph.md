Kent Wilbur closes his three-part Quick Report editor source-code series with the wizard itself, the most elaborate part of the editor, assuming familiarity with the structure-loading code from Part 1 and the manual-mode code from Part 2. He explains that the wizard is built as a series of form pages, one per step, with the very first page letting the user choose the type of report (list-style or cross-tab) and every subsequent page's content depending on that choice. A shared navigation system, implemented on form page 0 so it can overlay every wizard page, handles moving forward and backward through the sequence. The bulk of the note is then split into two long sections walking through the list-style wizard pages (covering table/field selection, sorting, and formatting choices) and the shorter cross-tab-style wizard pages, each reusing hierarchical list and synchronization techniques introduced earlier in the series. A closing section candidly discusses the wizard's graphics — over a hundred images combining simple pictures, resource-referenced pictures, and objects that grow, move, or stay fixed on resize — with Wilbur recommending developers not attempt to modify them but instead build their own forms and reuse only the underlying active objects and project methods. The technical note ends by inviting readers who build their own report editors from this source to submit write-ups back to 4D for a possible follow-up 'Variations on the Quick Report editor' series.
