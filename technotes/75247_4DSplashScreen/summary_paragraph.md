This Tech Note presents the 4DSplash component, a reusable compiled (or interpreted) component database that lets developers add a custom splash screen to any 4D database by simply copying the component into the database's Components folder and calling `4DSP_SplashScreen` from the On Startup method. The splash screen's appearance — background color, header/sub-header/description text and colors, and a square-icon or banner-style logo template — can be configured three ways: through an interactive Chooser Wizard form with a live preview, by passing nine parameters directly to `4DSP_SplashScreen`, or by hand-editing the component's `demoinfo.xml` preferences file. The note walks through the component's source code, showing how it opens a pop-up form window, applies colors with `SET COLOR`, auto-dismisses after ten seconds via `SET TIMER`, and reads/writes its XML preferences using the 4D DOM (`DOM Create XML Ref`, `DOM Find XML element`, `DOM SET/GET XML ELEMENT VALUE`, `DOM EXPORT TO FILE`) command set. The intended audience is 4D developers who want a single, drop-in component they can reuse and customize across multiple client databases without rewriting splash-screen logic each time. The Technical Note is a practical, code-focused walkthrough rather than a conceptual discussion, aimed at developers already comfortable installing 4D v11 SQL components.
