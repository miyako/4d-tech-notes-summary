Written during the remote-work surge of the Covid-19 pandemic, this Tech Note (a follow-up to an earlier note on 'Implementing a Remote Datastore') demonstrates a practical multi-site data-consolidation scenario using ORDA remote datastores. Two independently hosted 4D Server databases with identical structures ('Spain' and 'France') expose their data as REST resources; a third, empty local project database ('Europe') — whose Companies table has one extra 'Country' field — connects to each remote server via the Open datastore command (requiring a 4D REST license and both servers' HTTP Server running and the relevant tables/fields flagged 'Expose as REST resource'). The core merge logic loops over `$Remote_DS1.Companies.all()`, creates a new local entity per remote record with `$Local_DS.Companies.new()`, copies each field across explicitly, stamps the Country value, and calls `.save()`, repeating for the second remote datastore. Once merged, the Europe database's local Reporting form lets users filter merged companies by economic-sector Category, and the note shows using 4D View Pro to chart and compare sales figures (before/after Covid) across the combined dataset from both remote sources. The note frames this as proof that ORDA + REST can securely and efficiently pull and reconcile data across geographically distributed 4D Server instances without heavy server-side overhead.
