## Historical Context

Published July 2001 for 4D v6.7, this note dates from the "4D 2001"/"4D 2000-2001" product era (the v6.5/v6.7/v6.8 lineage),
running on classic Mac OS 9 (with Mac OS X newly released in 2001) and Windows 98/2000/NT. This was years before Project Mode
(introduced 4D v17, 2018), ORDA (2018+), and 4D's own SQL engine (introduced 4D v11 SQL, ~2007) existed — development happened entirely
in binary Design Mode (.4DB/.4DC structure files) using the classic procedural/set-based 4D language.

**Status: Obsolete**

This note explains how 4D of that era handled foreign-language systems specifically under Windows NT. Windows NT itself has been obsolete for decades (superseded by subsequent Windows releases and ultimately Windows 10/11), and 4D's Unicode and localization support has been completely overhauled since (full Unicode text handling was introduced around 4D v11 SQL), making both the OS context and the specific localization techniques described purely of historical interest today.

**What has changed since:**

- 4D introduced full native Unicode text support around 4D v11 SQL (~2007), superseding the older code-page/localization approach
- Windows NT is long obsolete, superseded by many subsequent Windows releases
