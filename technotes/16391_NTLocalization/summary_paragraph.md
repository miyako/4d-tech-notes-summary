This Tech Note (TN 01-34, 4D v6.7, Mac & Win, published July 31, 2001) presents an explanation of how 4D of that era handled foreign-language systems under Windows NT. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_31-35_(JUL)/01-34_NT_Localization.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This technical note explains how 4D handles foreign language systems. Its featured technology centers on Windows NT localization, 4D foreign-language system support, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note explains how 4D of that era handled foreign-language systems specifically under Windows NT. Windows NT itself has been obsolete for decades (superseded by subsequent Windows releases and ultimately Windows 10/11), and 4D's Unicode and localization support has been completely overhauled since (full Unicode text handling was introduced around 4D v11 SQL), making both the OS context and the specific localization techniques described purely of historical interest today.
