This Tech Note presents a technique for preventing web browsers from displaying cached versions of pages served by a 4D V6 web server. The solution uses ACI Pack's AP SET WEB FILTERS command to filter outgoing HTML from 4D, inserting an EXPIRES meta-tag into the header of the HTML stream. This instructs the browser that the page has already expired, forcing it to request a fresh copy from the server rather than displaying a cached version. The note acknowledges that effectiveness depends on browser support for the EXPIRES meta-tag. ACI Pack was a productivity plug-in for 4D that provided additional commands not available in the core product, including web-related utilities. This technique was relevant for dynamic database-driven web applications where stale data in cached pages could mislead users.
