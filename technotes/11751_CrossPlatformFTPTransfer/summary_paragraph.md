This Tech Note addresses a real business scenario of the mid-1990s: as corporations standardized their desktop computing strategy onto a single platform, 4D developers and database administrators were sometimes required to migrate a 4D Server application from one platform (e.g. Macintosh) to another (e.g. Windows), or vice versa. The note reassures readers that 4D's well-known cross-platform capability makes such a transition straightforward in principle, but flags the real practical challenge: many production 4D databases had grown into very large structure and data files, and simply getting those large files moved to the new target computer quickly was non-trivial. Its proposed solution leverages the fact that TCP/IP — a networking protocol common to both Macintosh and Windows computers via Ethernet — could be paired with FTP server software and a standard web browser to transfer the large structure and data files across the network to the new machine. This reflects a period when FTP plus a browser was a practical, broadly available cross-platform file transfer method, well before more specialized migration tools, cloud storage, or today's far higher network throughput existed to make such transfers routine.
