# Tech Note: Cross Platform File Transfer Via FTP and Web Browser

## Overview

This Tech Note explains how to use TCP/IP-based FTP together with a web browser to transfer large 4D Server structure and data files between Macintosh and Windows machines, in support of a corporate platform migration.

## Key Points

- Motivated by companies standardizing on a single desktop platform and needing to move 4D Server applications accordingly.
- Notes that 4D's cross-platform capability makes the underlying application transition straightforward.
- Identifies the real challenge as quickly transferring very large structure and data files to the new machine.
- Proposes using TCP/IP (via Ethernet) with FTP server software and a standard web browser as the transfer mechanism.

## Featured Technology

- TCP/IP networking
- FTP server software
- Web browser-based file retrieval
- 4D Server structure/data file migration

## Historical Context

Written in early 1997, this note reflects a period when TCP/IP was emerging as an alternative to classic AppleTalk networking for 4D Server, and when FTP plus a web browser represented a practical, cross-platform way to move very large files between systems — well before the network speeds, cloud storage, and dedicated migration tooling available today.

## Historical Commentary
**Status:** Historical interest only

This note describes using TCP/IP-based FTP and a web browser to migrate large 4D Server structure and data files between Macintosh and Windows during a corporate platform consolidation; while cross-platform file transfer over TCP/IP remains conceptually standard practice, the specific FTP/browser-based transfer mechanics described are a dated, narrow solution superseded by today's far faster networking, cloud storage, and dedicated migration tooling.
