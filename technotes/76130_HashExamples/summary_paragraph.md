Timothy Aaron Penner's Tech Note introduces hash functions as a foundational security and data-integrity tool for 4D developers. It explains what a hash function is, why 'salt' should be added before hashing (particularly for passwords), and surveys common uses: storing password hashes instead of plaintext passwords, verifying file integrity, and quickly disseminating/fingerprinting files via checksums like MD5. An included sample database puts these concepts into practice with four components: a File Browser, a File Hasher (including converting HFS paths to POSIX paths), a Find Duplicate Files tool that uses hashes to detect identical files regardless of filename, and a Password Hasher demonstrating salted password storage. The note is a practical primer aimed at developers who need to add basic security or file-integrity capabilities to a 4D application without deep cryptography background.
