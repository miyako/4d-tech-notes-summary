Written by Larry Sharpe, this Technical Note updates his earlier 2002 Tech Note 02-45 ("User Definable Views Using 4D View") to add straightforward "click-and-print" functionality for 4D View plug-in output areas, responding to client requests to print exactly what is shown on screen rather than relying on 4D's separate Reports engine. The sample database reuses most of the original 02-45 code (with `updated 02/15/07` comments marking every change) and documents one important intervening change to the 4D View plug-in itself: column sorting is now handled by a dedicated PV SORT COLUMN command rather than being bundled into PV SET COLUMN HEADER, allowing sort column/order to be changed independently of the column headers. The new printing feature adds a Print List menu item and a Print button, both routed through a single xOutput_Print4DView method that checks whether the Alt (Windows) / Option (Mac) key is held to choose between two underlying implementations: Views_4DV_Print_UserDefined, which hides the row header and then lets the user interactively set 4D View's native print options, page setup, and (optionally) print-preview via PV EXECUTE COMMAND and PV PRINT; and Views_4DV_Print_CodeDefined, a more extensive ~3-page method that sets font/size/color for printed rows/columns via an optional third parameter on the existing x4DView_Fields method, automatically computes and applies Portrait vs. Landscape page orientation based on column widths (to avoid the alignment problems of multi-page-wide printouts), and includes commented-out code showing how the same logic could instead print to a PDF document on either Mac or Windows. The note also notes that PV EXECUTE COMMAND's printing-options dialog remembers its settings for the life of the process, useful for combining code-defined defaults with optional user tweaks. Featured technology is squarely the 4D View plug-in's printing and layout commands (PV PRINT, PV EXECUTE COMMAND, PV SORT COLUMN, PV SET AREA PROPERTY), demonstrating a practical grid-printing workflow built on 4D View version updates current as of 4D 2004.5.
