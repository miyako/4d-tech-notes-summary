Thang Nguyen, of 4D's Quality Assurance team, explains how to use the spell-checking feature integrated into 4th Dimension 2004, which can validate Alpha and Text type variables and fields as well as 4D Write documents against 4D's bundled dictionaries (French, English, German, Spanish). He shows two ways to enable spell-checking: declaratively, by checking "Auto Spellcheck" in a field/variable's property list (or "Checking as you type" in 4D Write preferences), or programmatically, by calling the SPELL CHECKING command from form events such as On Losing Focus or On Validate, and by calling WR SET AREA PROPERTY with the wr on the fly spellchecking option for 4D Write areas. The note then documents the SET DICTIONARY command and its longint constants for switching among the four core languages and their many regional variants (e.g. English American, French Canadian, German Austrian), noting that variants beyond the four primary constants aren't yet actively supported by the spell-checker despite being loadable. Because the shipped dictionaries are encrypted and cannot be edited, Nguyen explains that user-added words are instead stored in a personal dictionary file named persoxxxxx.dic (created in the 4D Active/Application Support folder, locatable via Get 4D folder), which can be edited directly with a text editor or added to through the spell-check's "Add" button. Since 4D only supports one active personal dictionary at a time, the note closes with sample 4D code using SEND PACKET/RECEIVE PACKET to merge two personal dictionary files together (e.g. combining an English and a French personal dictionary) so a user working across languages doesn't lose custom words when switching.
