This technical note explains how to integrate the MD5 (Message Digest 5) cryptographic hash algorithm into 4D v11 SQL Release 2+ applications by leveraging the Web Area form object and JavaScript execution. MD5 is a cryptographic hash function that produces a fixed-size 128-bit (32-hex-character) fingerprint or message digest from an arbitrary-length input; it is designed to be fast on 32-bit machines and useful for applications where large files must be compressed securely before encryption (e.g., file integrity verification, non-security checksums). The note provides the complete mathematical theory (padding, state variables, four rounds of operations with auxiliary functions F/G/H/I, T-table, output generation) and a full JavaScript implementation translated from PHP. Two practical usage patterns are demonstrated: (1) an on-screen example where a Web Area displays an HTML/JavaScript UI allowing users to enter text and click "MD5" to see the hash result, and (2) an offscreen example where the Web Area is invisible, acting purely as a JavaScript execution engine, with input coming from a 4D form field and output returned to the form via the WA EXECUTE JAVASCRIPT FUNCTION command with a result variable. The HTML/JavaScript files are loaded via WA OPEN URL, using file:// URLs and path formatting utilities. The note emphasizes that this pattern generalizes beyond MD5: any JavaScript algorithm available on the internet can be injected into 4D without third-party plug-ins, providing access to a vast library of ready-made cryptographic and utility functions.
