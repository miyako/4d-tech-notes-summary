# Building and Embedding Dashboards/Charts

## Overview
Building on new Dashboard functionality introduced in 4D Ajax Framework v11, this note explains Dashboards as widget-like mini-applications that surface real-time information and performance metrics on a web page, then walks through building and embedding one Dashboard widget and one Chart widget onto an existing custom web page, illustrating the framework's approach to modular, reusable visual components.

## Key Points
- Published January 23, 2008 as Technical Note 08-03.
- Targets 4D Web 2.0 Pack v11 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Dashboards
- Widget-based UI composition
- Real-time metrics display
- Chart widgets

## Historical Context
Dashboards and live metrics widgets remain a common and relevant UI pattern, but the specific 4DAF Dashboard/widget object model documented here no longer exists, since the entire 4D Ajax Framework has been discontinued in favor of modern web component approaches.

**Status:** obsolete

**Related updates:**
- 4D Ajax Framework (4DAF), including its Dashboard widget system, has been fully discontinued
- Modern 4D dashboards are typically built with Qodly Studio (2021+) components, 4D View Pro (2018+) charting, or embedded third-party JS dashboard libraries
