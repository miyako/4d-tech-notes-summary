Building on new Dashboard functionality introduced in 4D Ajax Framework v11, this note explains Dashboards as widget-like mini-applications that surface real-time information and performance metrics on a web page, then walks through building and embedding one Dashboard widget and one Chart widget onto an existing custom web page, illustrating the framework's approach to modular, reusable visual components. Published January 23, 2008 as Technical Note 08-03 for 4D Web 2.0 Pack v11 (Mac & Win), written by a 4D Technical Services team member. Dashboards and live metrics widgets remain a common and relevant UI pattern, but the specific 4DAF Dashboard/widget object model documented here no longer exists, since the entire 4D Ajax Framework has been discontinued in favor of modern web component approaches.
