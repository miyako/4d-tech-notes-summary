Tech Note: Building and Embedding Dashboards/Charts (TN 08-03, 4D Web 2.0 Pack v11, January 23, 2008) — Building on new Dashboard functionality introduced in 4D Ajax Framework v11, this note explains Dashboards as widget-like mini-applications that surface real-time information and performance metrics on a web page, then walks through building and embedding one Dashboard widget and one Chart widget onto an existing custom web page, illustrating the framework's approach to modular, reusable visual components.
