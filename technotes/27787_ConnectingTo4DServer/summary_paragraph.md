Christian Cypert, 4D & WebSTAR Plug-in Evangelist, walks through the complete lifecycle of connecting to a 4D Server using the 4D Open plug-in, which lets a 4D Client or standalone 4th Dimension application connect to a specific 4D Server programmatically rather than through the standard connection dialog. The note breaks the process into three clearly separated steps, each tied to a demo button. First, OP Count network components and a loop calling OP Get network component info enumerate the available network protocols/components on the local machine, populating parallel arrays of component IDs and names for the user to choose from in a scrollable list. Second, connecting uses OP Set option to suppress error dialogs, OP Load network component to activate the chosen network component, OP Select 4D Server (or, alternatively, OP Find 4D Server if the target database name is already known) to locate a server and obtain its server ID, and finally OP Open connection, which takes the server ID, a display name for the 4D Server's process window, a username and password (validated against the server's 4D Users and Groups), and a process name, returning a connection ID. Third, disconnecting calls OP Close connection, OP Delete 4D Server to free the server-reference memory, and OP Unload network component to release the loaded network component -- in that order -- to fully and cleanly tear down the session.
