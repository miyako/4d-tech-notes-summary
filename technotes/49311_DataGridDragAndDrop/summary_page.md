# Data Grid Drag-and-Drop

## Overview
This note documents the built-in drag-and-drop functionality of the newer, more capable Data Grid shipped with 4D Ajax Framework v11 Release 1 (11.1), which gives developers finer control over grid data than the previous generation of Data Grid. It walks through the specific commands needed to enable drag-and-drop row/cell interactions and builds a complete example web page exercising these new options, with a sample database provided.

## Key Points
- Published April 2, 2008 as Technical Note 08-12.
- Targets 4D Web 2.0 Pack v11.1 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Data Grid v11.1
- Drag-and-drop UI interaction
- JavaScript grid API

## Historical Context
A hands-on tutorial for a specific interactive UI feature (drag-and-drop) of the now-discontinued 4DAF Data Grid; drag-and-drop as a UX pattern remains relevant, but the exact API and object model described no longer exist in any supported 4D product.

**Status:** obsolete

**Related updates:**
- 4D Ajax Framework (4DAF), including this Data Grid generation, has been fully discontinued
- Modern drag-and-drop web interactions in 4D applications are implemented via standard JavaScript/HTML5 drag-and-drop APIs or through Qodly Studio's web components (2021+), not the 4DAF Data Grid object
