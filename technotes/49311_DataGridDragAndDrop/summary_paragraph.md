This note documents the built-in drag-and-drop functionality of the newer, more capable Data Grid shipped with 4D Ajax Framework v11 Release 1 (11.1), which gives developers finer control over grid data than the previous generation of Data Grid. It walks through the specific commands needed to enable drag-and-drop row/cell interactions and builds a complete example web page exercising these new options, with a sample database provided. Published April 2, 2008 as Technical Note 08-12 for 4D Web 2.0 Pack v11.1 (Mac & Win), written by a 4D Technical Services team member. A hands-on tutorial for a specific interactive UI feature (drag-and-drop) of the now-discontinued 4DAF Data Grid; drag-and-drop as a UX pattern remains relevant, but the exact API and object model described no longer exist in any supported 4D product.
