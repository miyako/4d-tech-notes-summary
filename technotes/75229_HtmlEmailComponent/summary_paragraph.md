This Tech Note introduces an HTML Email Component that lets a 4D v11.3 database display, create/edit, and send HTML-formatted emails, targeting developers who want email-client-like functionality inside their applications. Displaying mail uses a Web Area to render HTML content, with options to hide externally-linked images by default (a common spam-tracking mitigation) and later reveal them on user request via JavaScript manipulation of the loaded DOM, plus helper commands to enumerate and save file enclosures that were expanded into a temporary folder. Creating and editing HTML mail embeds the open-source TinyMCE 3.2.1 JavaScript editor inside a Web Area, driven through 4D commands like `WA EXECUTE JAVASCRIPT FUNCTION` and a documented sequence of form/object events (`On Load`, `On Resize`, `On Timer`, `On End URL Loading`) because JavaScript cannot safely run before the page finishes loading. Sending is handled by `EMail_Send`, which embeds local images as email attachments and communicates with an SMTP server (with optional authentication) via the 4D Internet Commands plug-in. The note also covers customization points — swapping or updating the TinyMCE version, adding new UI languages, editing an HTML template that bridges 4D and the JavaScript editor, and localizing the component's own header text via XLIFF files — plus a "Unicode Wrapper" component that lets the library be used from 4D host databases still running in non-Unicode mode. TinyMCE's LGPL licensing terms and the requirement to ship its source are noted for compliance.
