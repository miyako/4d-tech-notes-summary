This Tech Note tackles a very common support burden for 4D developers: the constant stream of requests for new or modified data exports from deployed applications, which traditionally meant writing a new 4D Project Method using SEND PACKET in a loop for each report, then recompiling and redeploying the whole structure just to make a report change available. Written by 4D Germany's VP of Strategy and available since 4D v14 R5, Smart Templates propose breaking this cycle: report content, format, and formulas live in an externally editable template rather than hard-coded 4D method logic, and a single generic application entry point executes whatever template is supplied, meaning new or revised reports can potentially be delivered without a new structure deployment. The note walks through a progression of increasingly sophisticated template examples: a simple text-only tab-delimited file, a tab-delimited file with calculated values, an HTML export with calculated values, an HTML export embedding images, an HTML export with an embedded table, a Microsoft Excel document using conditional formatting, and a Microsoft Word document generating personalized gift cards — each demonstrating that the templating engine can drive substantially different output formats from the same underlying execution model. An examples database accompanies the note. Smart Templates represent a genuinely forward-looking idea for its time: separating report definition from application code so that business users or support staff (not just developers) can adjust exports is a durable, still-valuable architectural pattern, and the specific output formats targeted (tab-delimited, HTML, Excel, Word) remain exactly the formats developers still need to produce today. The one caveat is that this is a 4D-Germany-authored template engine/technique rather than a built-in 4D feature, so its continued relevance in any specific project depends on whether that particular template engine or an equivalent was actually adopted and maintained; the concept itself, however, has not dated at all.
