Written by Daniel Do, a 4D Technical Support Engineer, this Tech Note is a comprehensive practical guide for upgrading old 4D databases — as far back as version 2 or 3, running on Mac OS 8.6 — forward to 4D 2003 or 2004. It lays out general upgrade principles: go straight to the latest workable version rather than stepping through every intermediate release unless problems arise, perform any Mac-to-Windows platform change as late as possible in the process, never run very old 4D versions on newer operating systems (citing real risk of irreparable database damage), and always work from a compressed backup copy rather than a plain folder copy to avoid accidentally modifying the original data file. It details the tooling required for pre-3.2-era databases that used "externals" (the predecessor term for plug-ins): ResEdit (a Mac OS 9 resource editor) and the External Mover utility, explaining exactly which Mac resource types (4BND, 4BNX, 4Dte, STR#, THM#, FON#, CURS, etc.) constitute an external routine or plug-in's footprint and must be carefully deleted without disturbing unrelated resources, plus 4D Transporter for moving pre-2004 databases from Mac to Windows. It also documents a full worked example of upgrading a corrupted version 2 database: changing its Mac file creator/type codes (via a documented mapping table from version 2.2 through 2004) so a newer 4D can recognize it, opening it in successive demo-mode 4D versions (trying 6.7, then 6.5) to convert the structure and data files, and using 4D Tools' "recover by tag" feature (selecting all data segments) to repair record-level corruption encountered along the way, before finally converting all the way to 4D 2004. A closing section catalogs the most common upgrade-related problems — data corruption (recover by tag), structure corruption (repairing via 4D Tools, or isolating data vs. structure issues by testing with a fresh data file), and form/object corruption (fixed by resaving or copy-pasting affected form objects) — giving developers a troubleshooting playbook for the upgrade process as a whole.
