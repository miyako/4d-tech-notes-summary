In September 2007 the first Technical Note on this topic was released, number 0738, New List Box Features in 4D v11 SQL. Part 2 of the topic, covered in this Technical Note, delves into manipulating the new features of List Boxes in code rather than via the Form Editor. The new data sources available for List Boxes in 4D v11 SQL, as well as changes to the commands used to manage List Box’s in code, provide powerful tools for the 4D developer to create dynamic List Box-based content. A sample database is included. Introduction ------------------------------------------------------------------------------------------------------------------------------------------------------------------ This Technical Note expands on how to use List Boxes in 4D v11 SQL. The first part of the Technical Note is an overview of the commands and features used to manage List Box form objects programmatically through 4D code. The second part of the Technical Note documents the sample database and the code it uses.
