This Technical Note addresses the practical challenge of creating dynamic web subforms within the 4D Ajax Framework when a one-to-many relationship exists between tables (e.g., Department parent records with Employee child records). Rather than relying entirely on the Data Grid's built-in capabilities, the example combines the Data Grid for list display with the Bridge object—the central communication conduit of the 4DAF—to orchestrate parent-child interactions, record manipulation, and metadata queries via JavaScript. Eight progressive examples build up a working implementation: from plain grids, to event-driven row selection, to inline editing and multi-record persistence, demonstrating how to use Bridge methods like dax_bridge.addRecord(), dax_bridge.modifyRecord(), and dax_bridge.getRecord() alongside grid event handlers (onDataRowClick, onDataRowDblClick) to maintain consistency between the web UI and the backend 4D database. The note assumes intermediate JavaScript knowledge and provides access to both interpreted and compiled sample databases, with the core pattern relying on careful coordination of grid queries (queryAllRecords for parent, targeted queries for child filtered by parent ID) and Bridge calls to synchronize the displayed subform state with database writes.
