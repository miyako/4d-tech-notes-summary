# Tech Note: Passport for the Euro with 4D

**Author:** Not specified
**Published:** June 1, 1999 | **Product/Version:** 4D v6.0.6 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11794

## Overview
This Tech Note provides guidance on supporting the Euro — the new European monetary unit introduced across the EU — within 4D applications. It explains Euro conversion logic and how to manipulate 4D's internal "4DK#" and "euro" resources using BLOBs.

## Key Points
- **Euro currency conversion:** Explains the fixed conversion rates between European national currencies and the Euro.
- **4DK# resources:** Shows how to manipulate 4D's internal formatting resources via BLOB operations to support Euro display.
- **"euro" resources:** Demonstrates reading and modifying Euro-specific resource data.
- **Practical business need:** Aimed at developers building financial applications for European markets during the 1999-2002 Euro transition.

## Featured Technology
- Euro currency conversion logic
- 4DK# and "euro" resource manipulation
- BLOB operations for resource editing
- Currency formatting in 4D v6

## Historical Context
**Status:** Historical interest only

The Euro transition was a one-time event completed by 2002 when Euro banknotes and coins fully replaced national currencies in participating EU countries. The specific currency conversion logic described here is no longer needed. The resource-based approach (manipulating 4DK# resources via BLOBs) reflects the classic Mac OS resource-fork architecture that 4D used extensively in this era — an approach that has been entirely replaced by modern settings, JSON configuration, and built-in internationalization support in current 4D versions. The note is a vivid snapshot of how 4D developers responded to a major real-world economic transition.
