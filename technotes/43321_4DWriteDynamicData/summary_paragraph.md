This Tech Note by Daniel Do covers how to use dynamic data within 4D Write 2004, the word-processing and document-management plug-in for 4D that lets Word Processing documents be attached to database records and merge live data from those records into reports and letters. It begins with the basics of getting started — installing the 4D Write plug-in, adding a 4D Write area to an input form in Design mode, and expanding the working area via the "Goto Full Menu" button for easier editing — before covering how to insert 4D fields and expressions into a document via the Insert menu's "4D Expression…" command (or the equivalent contextual menu item), which opens a hierarchical table/field picker along with a matching list of applicable display formats. The note explains that inserted fields and expressions can be shown either as literal references (displayed with a grey background and surrounded by << >> marker symbols) or as their computed values, and that reference-based values are automatically recalculated whenever the current record changes — but only when explicitly refreshed via the "Compute References Now" command in the 4D Write Tools menu, or when the document is subsequently reopened. It distinguishes standard dynamic references (like the current date/time or page number, which are computed at the moment of insertion) from database-driven references (4D fields and expressions, which reflect the record currently displayed in the form or open in an external window, and appear blank if there is no current record). This lets developers build personalized form letters or reports — for example, a mail-merge style letter that recalculates a person's name, address, or the letter's date for whichever record is current — using either plain field references or arbitrary 4D expressions (e.g., computing an annual salary via multiplication). The note also promises coverage of creating tables within a 4D Write area as part of its broader treatment of dynamic content. As a document targeting 4D Write 2004 specifically, its instructions apply to the original 4D Write product and its Design-mode/Insert-menu workflow rather than any of 4D's later document tools.
