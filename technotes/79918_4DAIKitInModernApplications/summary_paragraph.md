This Technical Note (26-01, published January 29, 2026) is a foundational introduction to 4D AIKit, the built-in component (introduced in 4D 20 R9, requiring separate installation from 4D 21 onward) that connects 4D applications to OpenAI-compatible large language and vision models through the `cs.AIKit` namespace. It covers the component's three core class families — `cs.AIKit.OpenAI` (client/authentication entry point), `OpenAIChatCompletionsAPI` (multi-turn text generation via message collections with `system`/`user`/`assistant` roles), `OpenAIVision`/`OpenAIVisionHelper` (image analysis, OCR, document extraction), and `OpenAIImagesAPI` (text-to-image generation) — along with the structured `OpenAIError` object returned on API failure. Architectural guidance recommends class-based organization (dedicated classes per AI domain), a centralized singleton `AIConfig` class for credentials/model/parameter management loaded at `On Startup`, and asynchronous processing via worker processes (`CALL WORKER`/`CALL FORM`) for multi-process cases, since AIKit's native callback-based async pattern only works within the calling process. The bulk of the note walks through Demo-AIKit, an intelligent business-document assistant combining `DocumentAnalyzer` (GPT-4o vision-based structured data extraction from invoices/receipts/contracts), `SummaryGenerator` (multiple summary types via the more cost-effective GPT-4o-mini), and `ConversationManager` (context-aware document chat), backed by a Document/ExtractedData/Summaries/Conversation database schema. Deployment guidance covers token economics and cost-optimization strategies (model selection, prompt trimming, `maxTokens` caps), security practices (never embedding API keys in code/version control, environment-specific keys, GDPR/HIPAA-aware data handling since data leaves the local environment), a 10MB file-size cap for vision processing, and a troubleshooting table for common failure modes (auth errors, token-limit exceeded, slow processing, PDF conversion issues, unpredictable AI output). The note positions itself as the entry point for a broader family of 2026 AI Kit-focused Tech Notes (tool calling, semantic search) built on this same foundation.
