This Tech Note discusses integration opportunities opened up by Microsoft Office 2003's new support for industry-standard Extensible Markup Language (XML), contrasted with earlier Office versions that were positioned more as standalone productivity tools than as an integrated, XML-capable system. It notes that 4th Dimension 2003 had, in parallel, gained its own native XML support, making it more feasible for 4D applications to exchange structured data with Office 2003 documents. The note also points out that XML document exchange is not the only integration path — Web Services (SOAP/WSDL), another headline 4D 2003 feature, can equally be used to connect 4D and Office applications. Only the on-page teaser text for this note could be recovered, so the specific integration recipe or example database details are not available here; the note is best understood as a high-level positioning piece for two of 4D 2003's most significant new capabilities (XML and Web Services) applied to a topical integration scenario at the time.
