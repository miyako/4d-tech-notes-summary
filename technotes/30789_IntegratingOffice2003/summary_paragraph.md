Written by Julien Feasson (4D, Inc.) as Technical Note 03-54, this note explores how 4th Dimension 2003 could integrate with Microsoft Office 2003's newly added native XML support, framed around a running scenario of "Robert," a sales rep who otherwise has to retype the same weekly data into Word, a CRM system, and an Excel expense report. It introduces InfoPath 2003 as an offline-capable XML form front-end that can talk to a 4D database via Web services, then digs into the mechanics of Word 2003's WordprocessingML XML format (showing the DocumentProperties, fonts, styles, and body elements) and demonstrates parsing a saved-as-XML Word document from 4D using `Open document`, `DOCUMENT TO BLOB`, `Parse XML variable`, and repeated `Get First/Next XML element` calls to pull out field values. It covers generating new Word XML documents from 4D either from scratch or, more practically, by populating a pre-designed XML template (illustrated with a student-grades report example that duplicates a table row per student), and shows using 4D's data export tool to produce an XML file that Excel can directly import as a spreadsheet. The most technically involved section demonstrates a live, real-time alternative to file-based exchange: publishing a 4D-hosted SOAP Web service (on port 8080) that an auto-starting Visual Basic macro in Excel — built using Microsoft's Web Service References Tool and a generated proxy class — calls directly (`MyCall.wsm_ExportToXL(...)`) to pull the latest 4D data straight into a spreadsheet, eliminating the export/import round trip. The note closes by framing this Office/4D XML and Web-services integration as a productivity and data-accuracy win for business users, while noting 4D's next major release would make such integration even easier.
