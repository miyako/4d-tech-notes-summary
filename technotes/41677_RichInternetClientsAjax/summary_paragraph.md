This Tech Note, the first from 4D on the subject of Ajax, introduces "Rich Internet Client" techniques for building desktop-like, asynchronous web applications with 4D as the backend, citing contemporary examples like Google Mail, Google Suggest, and Flickr. It defines Ajax per Wikipedia as a combination of XHTML/CSS, DOM manipulation via JavaScript, and the XMLHttpRequest object for asynchronous server communication, and walks through a bundled demo database (based on the "Video Library" sample) featuring a Type Ahead actor-name autocomplete search and a scrollable "Live Grid" that fetches data incrementally, both without ever reloading the page or changing the URL, and both recommended for observation using the Firefox "Live HTTP Headers" extension. A dedicated JavaScript primer explains DOM element IDs and event handlers (contrasting an `onChange` HTML attribute with 4D's own "On Data Change" object-method event) using a simple, non-Ajax "Simple HTML" example before introducing the XMLHttpRequest object's history (Microsoft, then Mozilla, Safari, Opera) and a minimal cross-browser detection pattern. The "Simple Ajax" example then shows the identical HTML wired to a JavaScript ContentLoader helper object that calls a 4D method via a `/4DAction/` URL and updates the DOM when the response arrives, with the corresponding 4D method reading `$1` as the request parameter and replying via `SEND HTML TEXT`. The note flags a real gotcha — browser caching of GET-style Ajax requests can silently return stale data — and shows two fixes: sending the request as an HTML form POST (read via `GET WEB FORM VARIABLES`) which bypasses caching, or modifying HTTP response headers to set an expiry date (used in the more advanced Actor Suggest and Live Grid examples). It closes by beginning a deeper walkthrough of a "Double Combo Box" example requiring more JavaScript, illustrating how generic client-side code can be reused across multiple Ajax-driven widgets. Overall the note frames Ajax as a genuinely emerging technique 4D developers needed to learn from scratch in 2006, well ahead of any built-in 4D framework for it.
