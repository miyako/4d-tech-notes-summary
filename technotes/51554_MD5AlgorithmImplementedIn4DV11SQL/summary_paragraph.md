Nowadays more and more businesses are conducted over the internet, and security for changing information is becoming a problem. This is the time when encryption algorithms come in handy. 4D developers also want to implement some of the well known encryption algorithms in their databases. Some of these algorithms are already written in JavaScript code. 4D v11 SQL release 2 offers tools for developers to implement JavaScript code in a 4D database. This Technical Note explains how easy it is to implement JavaScript code in 4D. In our examples we use an MD5 encryption algorithm. The hash function of this algorithm is written in JavaScript and we will implement this function in 4D. There are two examples, and they show the algorithm in a 4D Web area and a 4D form. Published November 12, 2008 as Technical Note 08-39 for 4D v11 (Mac &amp; Win), this note was written by Atanas Atanassov, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
