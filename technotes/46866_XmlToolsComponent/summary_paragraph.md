This Technical Note by David Adams introduces the XML Tools component, a packaged collection of roughly 70 public methods (out of over 120 total in the source) that simplify reading and writing XML in 4th Dimension by wrapping native DOM commands with higher-level, error-safe utilities, organized into themed groups: XmlNode Utilities (node information, attributes, relatives), XmlTreeWalker (generic tree walk with callback, detailed further in Technical Note 07-27), XmlPath Utilities, XmlTree Utilities, XmlTreeList Utilities (detailed further in Technical Note 07-26), XmlFind Utilities, general XML Tools utilities, and XmlError component error information. The note explains the rationale for packaging this code as a component rather than plain source: it reduces the surface area developers must understand (about 70 exposed methods versus 120+ internal ones), simplifies keeping the logic up-to-date across the multiple Technical Notes and databases that reuse it, and improves error-testing efficiency by having low-level private methods skip redundant parameter validation while protected "gateway" methods perform comprehensive checks before delegating to them. It recommends compiling the component for best performance, noting that internal tree-scanning routines use recursion and can exhaust process stack space on deep trees if uncompiled, though compilation greatly increases usable recursion depth. Each exposed method includes Explorer comments documenting parameters and behavior, supplemented by a public "XML Tools Read Me" method and an internal "XML Tools Read Me Private" method listing every routine. The note also flags an important gotcha: 4D's language and database engine compare values case-insensitively by default, but XML element and attribute names are case-sensitive, so the XML Tools routines always compare element names, paths, and attribute names case-sensitively internally (cross-referencing the earlier Technical Note 05-41 on case-sensitive operations). Detailed reference documentation follows for the XmlNode Utilities: Node Information group, covering routines like XmlNode_GetName, XmlNode_GetValue, XmlNode_PutValueInPointer, XmlNode_GetCDATA, XmlNode_GetFullPath, XmlNode_GetLevel, and XmlNode_MatchesConditions, each shown as an error-safe, function-style alternative to native DOM commands such as DOM GET XML ELEMENT NAME, with worked code examples against a sample contacts XML document. The Technical Note package bundles the component itself, its source code database, and an example database demonstrating many of its features, and is a prerequisite companion to the more focused Technical Notes on XmlTreeWalker and XmlTreeList.
