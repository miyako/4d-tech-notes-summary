This 2002 Tech Note by Julien Feasson, a Software Engineer at 4D, Inc., walks through building a working HTTP client entirely on top of the 4D Internet Commands plug-in, at a time when 4D had no native HTTP client support. It opens with a concise primer on the Hypertext Transfer Protocol itself: how a URL like http://www.4D.com:80/ is decomposed into protocol, hostname, port, and document path; the structure of a raw HTTP request (method line plus General, Request, and Entity headers such as Accept-Language, User-Agent, Host, Connection, and Authorization); and the full set of HTTP 1.1 methods (GET, HEAD, POST, PUT, DELETE, TRACE, OPTIONS, CONNECT). It then documents the most common headers in detail, including how HTTP Basic Authentication encodes a "username:password" string in Base 64 for the Authorization header, and how the Transfer-Encoding: chunked scheme works for streamed responses. The accompanying demo database implements a two-form 4D HTTP Client -- a browser-style window for typing a URL and viewing the response, and supporting logic that parses the URL, builds and sends the request via the 4D Internet Commands, and interprets the returned headers and (optionally Base 16-decoded, chunked) body. The note is a hands-on protocol-level tutorial rather than a wrapper around a built-in high-level API, reflecting how HTTP integration had to be built manually in 4D's earliest internet-enabled era.
