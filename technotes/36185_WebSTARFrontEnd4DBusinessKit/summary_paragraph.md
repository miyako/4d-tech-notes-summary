The purpose of this technical note is to describe how to set up 4D WebSTAR as a front end Web interface for 4D Business Kit. The following examples use 4D WebSTAR 5.3.3 and 4D Business Kit 2.2.2. This 2005-era Tech Note (TN 05-07) was published for 4D Business Kit version n/a on Mac OS X, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). Only the short on-page teaser paragraph for this note could be recovered in this archive pass — the full PDF/example download was not accessible — so the summary here reflects only that teaser text rather than the complete technical content of the original note. Featured technology associated with this note includes: 4D WebSTAR 5.3.3 web server, 4D Business Kit 2.2.2, Mac OS X web front-end configuration. This note describes configuring the 4D WebSTAR web server as a front-end for 4D Business Kit, an e-commerce/business application product from the mid-2000s Mac OS X era. Both 4D WebSTAR and 4D Business Kit have long been discontinued and are not part of any current 4D product line, making this note obsolete as a practical guide; 4D's own built-in Web Server has since become the standard way to expose 4D applications over HTTP.
