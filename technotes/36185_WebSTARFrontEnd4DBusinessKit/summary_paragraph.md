Steve Hartman, of 4D's Information Systems team, provides a configuration walkthrough for placing 4D WebSTAR 5.3.3 in front of 4D Business Kit 2.2.2 as its front-end web server on Mac OS X (with the Admin Client also available on Windows). The core mechanism is 4D WebSTAR's Web ReWrite plug-in, configured as a reverse proxy: the note has readers open the supplied Rewrite proxy rules.txt template from Business Kit's "Files to import" folder, find and replace every occurrence of the generic www.4dbkstore.com placeholder with their real Business Kit server address (in the example, 127.0.0.1:8080, running Business Kit on the same machine but a different port), then import that edited rules file into the Admin Client's Web ReWrite Proxy rules page and save. Hartman notes the rules assume a store folder named in the default "XXXX_Site" convention and that all served pages use .htm/.html extensions, pointing to WebSTAR's own Technical Reference manual chapter on Regular Expressions for anyone needing custom rules. On the Business Kit side, the corresponding configuration is a single Preferences change: selecting the '4D WebSTAR/Apache' page, checking the option to use Business Kit as a secondary server behind WebSTAR/Apache/IIS, and entering the WebSTAR server's IP address and optional port (with a separate toggle for handling HTTPS as well as HTTP). The result is a setup where an ordinary HTML link served by WebSTAR (e.g. to /Test_Site/WebPagesUS/home.htm) transparently proxies through to the Business Kit storefront running behind it.
