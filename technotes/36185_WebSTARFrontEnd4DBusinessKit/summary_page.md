# Tech Note 05-07: WebSTAR: Front End for 4D Business Kit

**Published:** February 17, 2005 | **Product/Version:** 4D Business Kit vn/a | **Platform:** Mac OS X
**Page:** https://kb.4d.com/assetid=36185

## Overview
The purpose of this technical note is to describe how to set up 4D WebSTAR as a front end Web interface for 4D Business Kit. The following examples use 4D WebSTAR 5.3.3 and 4D Business Kit 2.2.2.
