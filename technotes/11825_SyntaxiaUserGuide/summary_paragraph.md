This Tech Note by Bart Scott, Manager of Analysis, serves as the user guide for Syntaxia, a 4D database containing five key pieces of information about each language element in 4D v6: command name, syntax, chapter reference, wildcard shortcut, and command number or constant value. With over 500 commands in 4D v6 plus constants and plug-in commands (4D Calc, 4D Chart, 4D Draw, 4D Write), totaling some 1,500 entries, the database provided developers with a lightweight, searchable reference tool. The interface uses five tab controls for filtering by letter, selecting sources (4D commands, individual plug-ins, constants), choosing display forms with or without syntax, and controlling sort order and direction — all with keyboard equivalents. The note explains the practical value of command numbers (for future-proofing code against name changes like SEARCH→QUERY), constant values, and the wildcard shortcut system that allows typing abbreviated commands with @ for tokenization. Syntaxia was designed to run in very little memory as a desk accessory in the background.
