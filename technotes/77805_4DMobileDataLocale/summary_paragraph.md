This Tech Note, delivered largely as an installation and development Read Me, documents how to set up and customize locale-based data display (date, time, and number formatting) in a 4D Mobile application, which at the time required 4D v16 paired with a separately licensed Wakanda Enterprise server (2.0.0+) and Wakanda Studio for the frontend tooling. It lists explicit system requirements (4D v16+, Wakanda Enterprise 2.0.0+, a supported OS and browser) and notes that Wakanda Enterprise requires its own 4D Mobile license registered on the Wakanda side, obtainable via the 4D Store or a sales representative. The installation guide walks through opening the demo's .4dbase file in 4D, starting the 4D Web server, opening the corresponding .waSolution file in Wakanda Studio, and running it to launch a connected demo web page in the browser, with troubleshooting notes about port conflicts and license/service activation issues. The development guide section explains how to access the 4D Mobile data model from within Wakanda Studio (surfaced under a RemoteModel folder), where server-side methods, calculated attributes, and events (including the locale customization logic) are defined in a model.js file. It also identifies where the actual Angular-based mobile app source code lives (an app.component.html/.ts pair) so a developer can find and adapt the specific date/time/number locale customization code demonstrated in the note. The note closes by pointing to further 4D Mobile, Angular, and Wakanda documentation and tutorials for readers wanting deeper background. As a Wakanda/4D Mobile-specific technical guide, its practical instructions are tied to a product stack that 4D has since retired.
