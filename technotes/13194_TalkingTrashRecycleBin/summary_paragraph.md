This Tech Note by Steve Hussey (CEO, Alto Stratus LLC) addresses a common 4D pattern -- processing external documents and then permanently removing them with `DELETE DOCUMENT` -- by showing how to move the file to the Mac OS Trash or Windows Recycle Bin instead, so it can still be recovered later. The `TRSH_Find` function uses `PLATFORM PROPERTIES` to branch by OS, then derives the volume name from `System folder(0)` and appends `"Trash:"` (Mac OS, colon-delimited) or `"Recycled\"` (Windows, backslash-delimited, since Windows 98 truncated the folder to fit DOS 8.3 naming as RECYCLED). A `HFS_FileNameFromPath` utility extracts just the file name from a full path by splitting on the platform's directory delimiter and returning the last array element. On Mac OS, moving a file into the Trash requires first checking for a name collision with `Test path name` and deleting any existing file of the same name (since Mac OS would otherwise refuse the move), whereas on Windows no such check is needed because Windows renames files entering the Recycle Bin to sequential names like DC0, DC1. The accompanying demo database lets a user pick a file, delete it outright, move it to the Trash/Recycle Bin, or list the Trash/Recycle Bin's contents using `DOCUMENT LIST`.
