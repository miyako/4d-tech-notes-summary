Written by Jonathan Le of 4D Technical Support, this technical note documents 4th Dimension 2004's improvements to the Method Editor's macro system, which lets developers generate frequently used code snippets, such as comment headers or field-assignment boilerplate, without retyping them. Two new features headline the release: macros can now be distributed across multiple XML files stored in a dedicated "Macros" folder next to the original Macros.xml (rather than being confined to a single file), and a new double tag, <method></method>, lets a macro invoke an actual 4D project method rather than simply insert static text. The note walks through the full macro tag vocabulary, including single-value tags like <selection>, <caret>, <user_os>, <time>, and <clipboard>, and demonstrates building macros step by step, from a simple text-insertion macro to one that calls a project method (FirstTable) to auto-generate field-assignment code for the database's first table. A more advanced example shows a macro calling a TouchTable method that creates a record, populates it with parameters passed from the macro call, and opens an output form to display the result, illustrating the special _action, _blobReplace, _textReplace, and related process variables 4D uses to manage text/BLOB substitution and method invocation. The note positions macros as a productivity tool for enforcing coding conventions and reducing repetitive typing in the classic 4D Method Editor.
