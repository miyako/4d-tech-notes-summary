This Tech Note by Jesse Pina addresses how to make a 4D application multilingual, a capability that became significantly easier with 4D v12 and 4D v11 SQL. It explains the resource storage model behind 4D localization, focusing on the XLIFF (XML Localization Interchange File Format) standard as the modern replacement for 'old style' 4D resources, and documents the syntax for both XLIFF-based and legacy MyTitle-style resource references. The note walks through the localization roadmap for a project — from setting up resource files to deploying a localized database — including a worked deployment example. It also covers two techniques for giving developers finer control over which language is displayed at runtime: using the new v12 command SET DATABASE LOCALIZATION, and using an interprocess variable, each demonstrated with a custom method in an included demo database. The note closes by contrasting these two control mechanisms and summarizing best practices for building and shipping a localized 4D application.
