## Overview
This note is an introductory primer covering both the general architecture of ODBC and the specific new native ODBC features introduced in 4D 2004, aimed at readers who are new to ODBC as well as those familiar with ODBC generally but not with using it inside 4th Dimension.

## Key Points (from available teaser)
- Covers the basic architecture of ODBC as a general database connectivity standard.
- Explains the new ODBC features integrated natively into 4D 2004.
- Written for both ODBC beginners and ODBC-familiar-but-4D-inexperienced readers.
- Positioned as foundational reading alongside other ODBC-focused notes from the same release cycle (Native ODBC, Advanced ODBC, MySQL/PostgreSQL connectivity).

## Featured Technology
- ODBC architecture and standard
- 4D 2004 native ODBC integration

## Historical Context
**Note:** Only the on-page teaser paragraph was recoverable for this Tech Note; the full PDF and example database were not accessible (old archive format not retrievable in this environment), so specific diagrams and explanations cannot be reproduced here. ODBC remains a broadly used database connectivity standard today, but the specific 4D 2004 native ODBC feature set this primer introduces has been superseded by 4D's later native SQL engine (v11 SQL) and ORDA, making the note primarily of historical interest for understanding 4D's data-access evolution.
