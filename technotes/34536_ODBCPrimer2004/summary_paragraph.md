This Technical Note serves as an introductory primer on Open Database Connectivity (ODBC), covering both the general architecture of ODBC as a standard and the specific new ODBC features that had just been integrated natively into 4D 2004. It is explicitly written for two audiences: those learning about ODBC for the first time, and those already familiar with ODBC generally but who had never used or implemented ODBC functionality specifically within 4th Dimension before. As a primer, the note's stated aim is foundational rather than advanced, laying groundwork that companion notes from the same release cycle (covering native ODBC, advanced ODBC commands, and dedicated MySQL/PostgreSQL connectivity) could build upon. The precise architectural diagrams, terminology, and step-by-step explanations used are not recoverable here since only the brief on-page teaser (not the full PDF/example archive) was available for this entry. Read alongside its sibling notes from the same period, this primer illustrates how central ODBC connectivity was to 4D's late-2004 release messaging, well before 4D had its own built-in SQL engine.
