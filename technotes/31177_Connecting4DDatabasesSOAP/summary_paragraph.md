This Tech Note introduces one of the marquee new features of 4th Dimension 2003: native support for SOAP (Simple Object Access Protocol), positioning it as a great new capability that lets 4D perform SOAP requests as a client or serve SOAP-based services as a provider. As an early, foundational note on this technology, it discusses the general advantages of using SOAP to interact with web services — likely covering standardized, cross-platform interoperability, the ability to expose 4D business logic to non-4D clients, and the reverse scenario of 4D calling out to external SOAP services — before narrowing its focus specifically to how one 4D database can connect to another 4D database using SOAP as the communication protocol. The note describes, at a conceptual and practical level, how to perform a Web service based on SOAP, likely walking through the basic setup required (enabling the native 4D Web server, configuring the relevant preferences, and marking methods as offered as Web Services) alongside the client-side mechanics of issuing a SOAP request from one database to another. Given its position as Tech Note 04-02, very early in the 2004 numbering sequence, this note functions as an on-ramp for developers just getting acquainted with SOAP in 4D, likely paired with (and building toward) the more detailed technical notes on returning data and pictures through SOAP that followed later that same year. The featured technology is squarely 4D's new SOAP Web Services capability, framed here specifically through the lens of 4D-to-4D database connectivity.
