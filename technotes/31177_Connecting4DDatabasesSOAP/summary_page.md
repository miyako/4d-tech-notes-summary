# Tech Note 04-02: Connecting 4D Databases through SOAP

**Author:** Not specified in source teaser
**Published:** January 31, 2004 | **Product/Version:** 4D v2003 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31177
**Download:** https://kb.4d.com/DLTN/TN/2004/Windows/TN_2004_01-04_(JAN)/04-02_Connecting_4D_w_SOAP.exe

## Overview
An introductory Tech Note on 4th Dimension 2003's new native SOAP support, covering the advantages of using SOAP to interact with web services and how to perform a SOAP-based Web service specifically to connect one 4D database to another.

## Key Points
- Introduces SOAP support as "a great new feature" of 4th Dimension 2003.
- Notes that 4D can both **perform** SOAP requests (as a client) and **serve** SOAP services (as a provider).
- Discusses general advantages of SOAP for web service interaction.
- Focuses specifically on the scenario of connecting two 4D databases via SOAP.

## Featured Technology
- 4D Web Services (SOAP), both client and server roles
- 4D-to-4D database connectivity over SOAP

## Historical Context
Only the on-page teaser paragraph for this asset could be recovered (the full archived PDF was not accessible in this environment), so this summary reflects only the note's stated introductory framing, not its full walkthrough. As one of the earliest notes covering 4D's brand-new SOAP feature, it is a foundational, historical artifact of 4D's Web Services rollout. SOAP itself has since been superseded by REST/JSON approaches in 4D development, and later features (such as remote datastores/ORDA from 4D v16, 2018) provide more modern mechanisms for connecting 4D databases, making this note's specific SOAP-based approach of historical interest only.
