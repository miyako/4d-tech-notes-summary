# Tech Note: Tricks and Tips for Using the Form Wizard - Part 1

**Author:** Not specified in source document

## Overview

Part 1 of a two-part Tech Note sharing tricks and tips for getting more out of 4D v6's new Form Wizard, illustrated using the bundled MusicPro example database.

## Key Points

- Assumes basic familiarity with the V6 Form Wizard and goes beyond introductory usage.
- Covers using group boxes to organize form objects.
- Covers applying styles to active objects for a more polished appearance.
- Covers adding text to buttons.
- Uses the MusicPro sample database (bundled with 4D) as a worked example.
- Part 2 (separate note) covers controlling alpha field width in output forms.

## Featured Technology

- 4D V6 Form Wizard
- Group boxes
- Active object styles
- Button text
- MusicPro example database

## Historical Context

Written soon after 4D v6 introduced the Form Wizard as a major new form design tool; both the Form Wizard's specific options and the MusicPro sample database referenced here reflect that initial V6-era implementation, which has since been substantially reworked and extended across later 4D versions.

## Historical Commentary
**Status:** Superseded

This note teaches specific tricks for the 4D v6 Form Wizard (group boxes for organizing form objects, styling active objects, adding button text, and controlling output-form field widths) using the bundled MusicPro example; the Form Wizard itself and its options have been substantially redesigned in later 4D versions (and eventually joined by newer form design paradigms), making these exact UI steps superseded, though the underlying form-layout concepts (grouping, styling, field sizing) remain conceptually relevant.
