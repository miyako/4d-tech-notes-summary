Written by Jean-Yves Fock-Hoon, 4D, Inc. Quality Assurance Manager, this Tech Note documents a 4D v6.7 improvement that lets the MOVE OBJECT and GET OBJECT RECT commands run during printing — specifically inside PRINT SELECTION, PRINT FORM, and PRINT RECORD (but not PRINT LABEL) — using the same relative/absolute coordinate parameters available in display mode, plus the ability to resize objects while printing. The accompanying example database models a family tree with [People] and [Children] tables and demonstrates three printing routines: a Print Selection report that indents each person's name according to generation depth and moves a spouse-name variable into place only for married males (using MOVE OBJECT in the On Printing Detail event with relative coordinates, reading back positions via GET OBJECT RECT so the next record's shift is computed correctly); a Print Record example that prints the current record's in-memory, unsaved values by modifying field variables on an On Timer event before calling PRINT RECORD; and a Print Form example that builds a full columnar report from scratch, computing exact absolute coordinates for header, body, and footer lines and drawing borders/columns with a loop over PRINT FORM. The note concludes that with these enhanced print-time object commands, developers now have the tools to build their own quick, dynamic report layouts without pre-designing a fixed print form for every possible column configuration.
