salesforce merges Sales, Service, Marketing, Contracts, Document Management, and Analytics into a single suite of Customer Relationship Management (CRM) solutions.

salesforce has a unique way of looking at CRM. There is no prepackaged software with salesforce; instead, there is a fully customizable API for building software based on open standards. This note demonstrates integrating a 4D 2004 application with salesforce.com's CRM API, reflecting the early-2000s SOAP/XML web-services era of 4D-to-cloud-service integration. Salesforce's API has evolved enormously since 2005 (moving through many SOAP and REST API versions), so the specific integration approach shown is certainly obsolete, though the underlying idea of connecting 4D to a CRM platform via its published API remains a common, still-relevant integration pattern today, now typically done via 4D's HTTP Client commands and REST/JSON.
