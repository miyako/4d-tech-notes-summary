This Tech Note by Jonathan Le of 4D Technical Support demonstrates how a 4D 2004 database can integrate with salesforce.com's CRM platform through its sforce Web Services API, which is built on SOAP, WSDL, and XML. It explains how 4D's Web Services Wizard generates proxy-stub methods from a WSDL file and shows the four core commands used to drive a SOAP exchange -- SET WEB SERVICE PARAMETER, CALL WEB SERVICE, SET WEB SERVICE OPTION, and GET WEB SERVICE RESULT -- alongside the DOM XML commands used to build and parse SOAP payloads. A complete worked example walks through the sforce "login" call, showing the raw SOAP request and response and the 4D code that constructs the request XML and extracts the returned Server URL, Session ID, and User ID. The note then introduces the accompanying 4D-eBay-style sforce Toolkit, which bundles a Template, a Component, and an Object Library so developers can either build a new eBay-integrated database from scratch or drag-and-drop pre-built buttons (Download, Add, Update) into an existing database after binding local table fields to sforce object fields with a Bind Tool. The goal throughout is to show 4D developers how the 2003-2004 additions to the command library eliminated the need for the older Internet Toolkit plug-in when talking to standards-based Web Services.
