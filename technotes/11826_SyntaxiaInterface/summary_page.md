# Tech Note: The Syntaxia Interface

**Author:** Not specified
**Published:** February 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11826

## Overview
This Tech Note explains the interface design of the Syntaxia database (companion to TN 99-03), which uses multiple tab control objects to provide dynamic, user-driven filtering, sorting, and form selection.

## Key Points
- Companion to Technical Note 99-03 (Syntaxia user guide).
- Uses tab control objects for on-the-fly changes to selection criteria, sort order, and display form.
- Demonstrates dynamic UI patterns possible with 4D v6 tab controls.
- Interface allows filtering, source selection, form switching, and sort control without mouse interaction.

## Featured Technology
- 4D v6.0
- Tab control objects
- Dynamic form/selection management
- Syntaxia language reference database

## Historical Context
**Status:** Historical interest only

Tab control objects remain available in modern 4D, though the List Box widget now provides built-in sorting and filtering that reduces the need for the manual tab-based approach demonstrated here. The Syntaxia database itself is a historical artifact, but the UI design patterns it illustrates are still conceptually relevant.
