This Tech Note explains the inner workings of the interface for the Syntaxia database, which was documented in Technical Note 99-03. The Syntaxia interface takes advantage of tab control objects to allow users to make on-the-fly changes to selection criteria, sort order, and even the form being used to display data. By using multiple tab controls in the footer of the database, the interface provides an intuitive way to filter commands by letter, select data sources (4D commands, plug-ins, constants), choose display forms with or without syntax details, and control sort order and direction. The design demonstrates sophisticated use of 4D v6's tab control objects to create a highly interactive data browsing experience. This companion note to the Syntaxia user guide illustrates practical UI design patterns that were possible with 4D's form objects in the late 1990s.
