This Tech Note addresses a specific constraint of 4th Dimension 2003's SOAP Web Services support: while SOAP responses could automatically carry virtually every native 4D data type, pictures were a notable exception and could not be returned directly. The note explains that this limitation can be worked around because BLOBs (Binary Large Objects) are supported in SOAP responses, so a picture can first be converted into a BLOB using the `PICTURE TO BLOB` command and then transmitted successfully as part of a SOAP/XML response. It frames returning pictures over SOAP as broadly useful — for example, serving images to remote clients or other systems integrating with a 4D-based Web Service — and walks through the mechanics of converting and packaging images for transport within SOAP messages. An accompanying example database demonstrates a working, simple SOAP-based image-serving system, giving developers a concrete starting point rather than only abstract guidance. Throughout, the note offers suggestions for extending the basic example toward more sophisticated image-serving functionality, such as handling multiple images or more complex response structures. The featured technology is squarely 4D's early Web Services (SOAP) stack combined with its native BLOB and picture-handling commands, reflecting the broader 2003-2004 push within 4D to make its native Web server and Web Services support a first-class integration mechanism for exchanging rich data types, including binary image content, with external SOAP clients.
