Written by a third-party developer (Larry Sharpe of InfoService) rather than a 4D employee, this Tech Note is an orientation guide for developers new to Web 2.0 concepts and the 4D Ajax Framework (4DAF), part of the 4D Web 2.0 Pack alongside 4D Live Window and the 4D Ajax for Dreamweaver plug-in. It frames the 4DAF as a 4D Component plus HTML/CSS/JavaScript/image assets, distinguishing the low-level "4DAF Libraries" from the ready-made "4DAF Client" front end, and contrasts the older Web 1.0 full-page-reload model with the Ajax-style partial-page-update philosophy the 4DAF enables. It surveys the available learning resources (the 4DAF Installation Guide, Admin Reference, Developer Guide, the Daxipedia wiki, and community Tech Notes/Tech Tips) and walks through installing the 4DAF component, plug-in, DAX folder, and DAX_??? method hooks, then logging into the web-based or standalone Admin Client "Control Panel." It details the Control Panel's five tabs — About, General Prefs, Access Control, Query Manager, and DDW Manager — explaining how to configure View styles (Grid, Calendar, Data Tree, Data/Image Matrix), link output Views to input Sheets, and set up Developer Defined Windows and preset queries. It also enumerates the eight categories of 4DAF back-end Project Methods available to developers (Preferences, Authentication/Sessions, Data Modifications, Developer Created Selections, DDWs, Callbacks, Queries, and Lists) for extending or overriding default 4DAF behavior, and briefly points toward building fully custom HTML/JavaScript pages using 4DAF objects directly, referencing a companion Tech Note (07-21, 4DAF Custom Data Grid) for that deeper topic. As a beginner's map of the 4DAF ecosystem circa version 1.1, it is squarely a product of the now-retired 4D Web 2.0 Pack line.
