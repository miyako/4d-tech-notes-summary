This note is a practical guide to 4D View Pro's table and pivot-table features, aimed at helping developers turn raw record sets into organized, sortable, and summarized spreadsheet views inside a 4D application. It opens with an overview of 4D View Pro itself — a spreadsheet component powered by SpreadJS from GrapeCity, embedded in a 4D form as a View Pro area (with an On VP Ready event to detect when the underlying JS engine has finished loading) or run headless via VP Run offscreen area for server-side document processing. It then walks through creating tables both via the interface (Toolbar or Ribbon UI modes) and procedurally with the VP CREATE TABLE command (new in 4D v19 R6), which can target a specific VP Cells range and populate it from 4D data via VP SET DATA CONTEXT. A large section is devoted to pivot tables — first through the user interface, covering interaction and the Ribbon bar, then procedurally by constructing a pivot configuration object with attributes such as name, sourceData, row/column, layout, theme, and options, plus per-field settings like sourceName, displayName, area, subtotal, and index to control how source columns map into the pivot's rows, columns, and values. A bundled sample database demonstrates both a plain table and a pivot table built from the same underlying data, giving developers a working reference to adapt for their own reporting needs.
