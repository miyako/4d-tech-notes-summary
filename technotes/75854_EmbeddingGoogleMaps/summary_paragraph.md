This Tech Note explains how to embed interactive maps based on the Google Maps API into a 4D v11 SQL application using the Web Area form object. It starts with the simplest approach — constructing a Google Maps URL and assigning it to a Web Area's URL variable — before moving to the full Google Maps JavaScript API, which requires an API key and offers full control over zoom, layers, and markers. The note walks through geocoding an address into coordinates and reverse-geocoding coordinates back into an address (the latter requiring a JavaScript round-trip captured via the Web Area's On URL Filtering event), then shows how to generate an on-the-fly local HTML document containing the map and markers, complete with clickable tips and custom URLs that can trigger 4D actions. It concludes with a section on two-way integration with Google Earth, including launching Google Earth with a specific KML document and maintaining a live connection between 4D and a running Google Earth instance. The included demo database and custom methods (the "Geo_" method family) give developers reusable building blocks for adding location-based features — store/customer locators, GPS-tagged photo displays, and similar mapping use cases — to their 4D applications.
