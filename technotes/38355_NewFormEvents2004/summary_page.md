## Overview
A short Tech Note documenting new form events introduced in 4D 2004 specifically for 3D button form objects.

## Key Points
- Covers form events newly added for 3D-style (raised/beveled) buttons in the 4D 2004 release.
- Part of a broader set of UI-related additions accompanying 4D 2004's form system overhaul.

## Featured Technology
- 4D 2004 form event system
- 3D button form objects

## Historical Context
**Status:** Historical interest only

3D-style buttons were a common desktop GUI convention in the early-to-mid 2000s but have since fallen out of favor in modern interface design, including in 4D's own form object conventions, which now lean toward native OS-styled or flat controls. The underlying form-event mechanism in 4D has continued to evolve since and still applies to both Design Mode and Project Mode forms, but this note's narrow focus on 3D-button-specific events makes it primarily of historical interest today.
