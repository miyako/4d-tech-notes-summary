Written by Jean-Yves Fock-Hoon, QA Manager at 4D, Inc., this Tech Note explains the new form events added in 4D 2004 for 3D buttons and picture buttons: On Mouse Enter, On Mouse Move, On Mouse Leave, and On Long Click, plus On Arrow Click for 3D buttons with an attached pop-up arrow. Prior to 4D 2004, achieving rollover effects required manual polling via ON EVENT CALL or the On Timer event; the new events fire automatically for visible objects in the frontmost (or floating) window's process. The example database demonstrates two dialogs showing a clickable map of the United States. In Example 1, moving the mouse over the map uses On Mouse Move to look up the state and capital under the cursor via a precomputed pixel mask, while On Mouse Enter and On Mouse Leave toggle the visibility of the information fields. Example 2 upgrades the state name display to a 3D picture button with an attached pop-up arrow: On Clicked opens a new process showing full state details, On Long Click (timed to the system's double-click interval) opens a separate process displaying the state's flag, and On Arrow Click opens a pop-up menu (built from `Pop up menu`) letting the user jump directly to another state. The note contrasts On Long Click with On Double Clicked to clarify their distinct behavior and timing.
