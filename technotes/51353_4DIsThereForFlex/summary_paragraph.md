If you have 4D v11 SQL and want to connect a Flex application to 4D, you can take advantage of the latest addition to the 4D Web 2.0 Pack: 4D for Flex. This technical note includes a sample Flex application using SQL-oriented classes provided by 4D for Flex. The write-up explains the workings of the application code in detail. It provides an example of how to get started with the cornerstone 4D for Flex objects. Some basic background in Flex is helpful to understand the sample code. Published October 23, 2008 as Technical Note 08-37 for 4D Web 2.0 Pack v11.2 (Mac &amp; Win), this note was written by Tim Kaufman, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
