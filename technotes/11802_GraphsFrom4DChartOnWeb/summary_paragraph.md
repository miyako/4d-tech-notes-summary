This Tech Note discusses techniques for displaying graphs created with 4D Chart in a web browser, exploring the nuances of various approaches. 4D Chart, previously sold as a separate module, was integrated into 4D V6, providing versatile graphing capabilities that supplemented the more basic built-in GRAPH and GRAPH FILE commands. The note examines different methods for rendering chart output as web-compatible content, addressing challenges such as image format conversion, dynamic generation, and proper HTML embedding. An example database was provided to help developers explore which techniques best suited their needs. This was part of the broader trend of 4D developers adopting web publishing in the late 1990s, leveraging 4D's built-in web server to serve dynamic content to browsers. The techniques described bridge 4D's desktop graphing capabilities with the emerging web delivery medium.
