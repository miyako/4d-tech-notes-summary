# Tech Note 98-19: Displaying Graphs from 4D Chart on the Web

**Author:** Not specified in source document
**Published:** April 1, 1998 | **Product/Version:** 4D Chart v6.0 | **Platform:** Mac &amp; Win
**Page:** https://kb.4d.com/assetid=11802
**Download:** Not available

## Proposition
This Tech Note explores various techniques for displaying 4D Chart graphs in a web browser through 4D's built-in web server, with an accompanying example database.

## Key Points
- 4D Chart was integrated into 4D V6 (previously sold separately)
- Compares multiple techniques for rendering charts in web browsers
- Addresses image format, dynamic generation, and HTML embedding challenges
- Includes an example database for hands-on exploration
- Supplements the more basic built-in GRAPH and GRAPH FILE commands

## Featured Technology
- 4D Chart
- 4D Web Server
- GRAPH Command
- Web Publishing
- HTML

## Context / Positioning
The integration of 4D Chart into v6 was a significant product change. Web publishing was a major growth area for 4D in the late 1990s as developers sought to deliver database-driven content to browsers.

## Historical Commentary
**Status:** Obsolete

This note reflects the exciting early days of web publishing with 4D, when developers were figuring out how to serve dynamic graphical content to browsers. 4D Chart's integration into v6 was a significant enhancement. The specific techniques for serving chart images to browsers have been superseded by modern web charting libraries and 4D's evolved web server capabilities.
