Written by Frank Chang of 4D Technical Support, this Tech Note is an introductory primer on XML aimed at 4D developers who had not yet worked with the format, positioned as a 'crash course' rather than exhaustive reference. It explains XML's lineage from SGML, contrasts it with HTML (XML describes data; HTML only describes display), and walks through core grammar: processing instructions like the mandatory `<?xml version="1.0" encoding="UTF-8" standalone="yes"?>` prologue, DOCTYPE declarative statements, and the open/close tag structure of markup elements. A worked example shows a minimal XML document ('helloworld') styled directly with a linked CSS style sheet (`<?xml-stylesheet type="text/css" href="helloworld.css"?>`), rendered in a browser exactly like styled HTML. The note then introduces XSLT as the mechanism for transforming one XML document into another document type — typically XHTML — via an `<xsl:stylesheet>`/`<xsl:template>` document that walks the source tree with `<xsl:for-each select="people/name">` and emits values with `<xsl:value-of select="first"/>`, illustrated end-to-end with a 'names.xml'/'names.xsl' pair that renders a sortable-looking HTML table of people's names. The Tech Note closes by pointing readers to further reading (books on XML and XSLT) and to a companion, more code-focused Tech Note (KB #26844, 'Parsing XML Documents') for actually working with XML from 4D code.
