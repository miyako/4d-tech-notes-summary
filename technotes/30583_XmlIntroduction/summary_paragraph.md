This Tech Note is a foundational, standards-history-oriented introduction to Extensible Markup Language (XML), describing it as a simple, flexible, W3C-standardized text format derived from SGML (Standard Generalized Markup Language), originally designed for large-scale electronic publishing but now central to exchanging data on the Web and across applications. It frames XML's rise as the latest chapter in programmers' long-running quest to find universally interchangeable data formats, tracing the lineage back to SGML's attempt to combine universal interchange with rich information storage.
