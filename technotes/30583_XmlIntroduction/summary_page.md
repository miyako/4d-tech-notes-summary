## Overview
An introductory Tech Note on Extensible Markup Language (XML) — its SGML lineage, W3C standardization, and growing role in data exchange — positioned as background for 4D 2003's new native XML support.

## Key Points
- Explains XML's W3C standardization and its origins in SGML.
- Frames XML as a general solution to the long-standing programmer challenge of interchangeable data formats.
- Serves as a conceptual primer alongside other 2003 Tech Notes on XML parsing and Web Services.

## Featured Technology
- XML
- SGML lineage
- 4D 2003 XML support

## Historical Commentary
**Status:** Still Relevant

XML itself remains a widely used, still-relevant data format (particularly in enterprise, document, and some legacy web-service contexts), and 4D still supports native XML parsing and generation commands today, so the fundamentals covered by this primer remain accurate. However, XML's dominance as the default data-interchange format has been substantially eclipsed by JSON for most modern web/API use cases since this note was written.
