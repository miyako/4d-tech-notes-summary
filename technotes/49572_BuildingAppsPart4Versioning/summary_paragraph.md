Part 4 of a five-part XML-keys tutorial series, this note focuses on the versioning-related XML keys available in the 4D 2004-era Build Application dialog's underlying project file — covering how build numbers, version strings, and related metadata are expressed as XML keys and edited through the companion GUI project-file editor introduced earlier in the series, so a shipped application correctly reports its version to end users and update mechanisms. Published April 23, 2008 as Technical Note 08-15 for 4D v2004.7r3 (Mac & Win), written by Josh Fletcher, Technical Services Team Member, 4D Inc.. Part of a well-documented five-part series on 4D's XML-based build configuration system from the mid-2000s; while the specific 80+ key XML format described here (4D 2004 era) has been superseded, the general idea of declarative, versioned build configuration persists in modern 4D's build/compile settings.
