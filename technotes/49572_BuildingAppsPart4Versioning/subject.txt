Tech Note: Building Applications Examples – Part 4 Versioning (TN 08-15, 4D v2004.7r3, April 23, 2008) — Part 4 of a five-part XML-keys tutorial series, this note focuses on the versioning-related XML keys available in the 4D 2004-era Build Application dialog's underlying project file — covering how build numbers, version strings, and related metadata are expressed as XML keys and edited through the companion GUI project-file editor introduced earlier in the series, so a shipped application correctly reports its version to end users and update mechanisms.
