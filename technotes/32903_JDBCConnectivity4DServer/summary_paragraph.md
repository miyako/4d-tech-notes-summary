Written by Yvan Ayaay of 4D Technical Support, this technical note explains how to use 4D's JDBC driver (jdbc4d.jar, class com.fourd.jdbc.DriverImpl) to connect Java programs and JDBC-compliant applications to 4D Server. The first half walks through a complete Java example: adding the driver JAR to the CLASSPATH, loading the driver class with Class.forName, establishing a connection via DriverManager.getConnection with a jdbc:4d:<ip address> URL, and then executing SQL SELECT, INSERT, UPDATE, and DELETE statements against a 4D database (illustrated with a sample "student" table), including the mapping between 4D data types (Alpha, Text, Real, Integer, Long Integer, Date, Time, Boolean, BLOB) and their Java equivalents. The note documents the specific subset of SQL syntax the 4D JDBC driver supports at the time, including SELECT with LEFT JOIN and ORDER BY, and basic INSERT/UPDATE/DELETE grammar. The second half demonstrates connecting the open-source iSQL-Viewer application to 4D Server purely through configuration (no code required), by adding the driver to its classpath and defining a connection with the driver class name, JDBC URL, and credentials, then using its SQL editor to query, insert, and export data. The note concludes that the JDBC driver requires no custom programming from the end user and enables straightforward interoperability between 4D Server and the broader Java/JDBC ecosystem.
