This Tech Note serves as a getting-started guide for 4D's productivity modules — 4D Write (word processing), 4D Calc (spreadsheet), and 4D Draw (vector drawing) — along with ACI Pack, a utility plug-in. It includes an example database demonstrating how to use all the plug-ins together in a single 4D application. The productivity plug-ins were key components of the 4D v6 ecosystem, allowing developers to embed rich document editing, spreadsheet, and drawing capabilities directly into their database applications without external dependencies. ACI Pack complemented these with additional utility routines for file I/O, picture handling, and other common tasks. This note was aimed at developers new to the plug-in ecosystem, providing a practical starting point with working code. The plug-in architecture itself — compiled native code extensions loaded at startup — was the standard extensibility mechanism in this era. Only the teaser text survives; the full PDF and example database could not be recovered.
