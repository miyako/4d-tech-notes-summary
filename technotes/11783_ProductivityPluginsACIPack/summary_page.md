# Tech Note: Getting Started with Productivity Plug-ins and ACI PACK

**Author:** Not specified
**Published:** September 1, 1998 | **Product/Version:** 4D Write v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11783

## Overview
This Tech Note introduces developers to 4D's productivity plug-in ecosystem — 4D Write, 4D Calc, 4D Draw, and ACI Pack — with an example database showing how to use them all together in a single application.

## Key Points
- **4D Write:** Word processing plug-in for embedding rich text editing in 4D forms.
- **4D Calc:** Spreadsheet plug-in for embedding spreadsheet functionality.
- **4D Draw:** Vector drawing plug-in for embedded graphics editing.
- **ACI Pack:** Utility plug-in providing file I/O, picture handling, and other productivity routines.
- **Integrated example:** Demonstrates using all four plug-ins together in one database.
- **Getting-started focus:** Aimed at developers new to the plug-in ecosystem.

## Featured Technology
- 4D Write, 4D Calc, 4D Draw (productivity plug-ins)
- ACI Pack (utility plug-in)
- 4D v6 plug-in architecture (compiled native code extensions)

## Historical Context
**Status:** Obsolete

The productivity plug-in landscape described here has changed dramatically. 4D Write was eventually replaced by 4D Write Pro (a modern rich-text component). 4D Calc was superseded by 4D View Pro (a spreadsheet component based on SpreadJS). 4D Draw was discontinued without a direct replacement. ACI Pack was discontinued entirely, with its utility functions absorbed into 4D's built-in command set over successive versions. The plug-in architecture itself has evolved toward components and built-in features rather than compiled native extensions.
