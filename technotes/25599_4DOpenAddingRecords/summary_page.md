# Tech Note 02-58: 4D Open: Adding records

## Overview
A Tech Note explaining a simple way to add records remotely to a 4D Server using the 4D Open plug-in.

## Key Points
- States that 4D Open supports Add, Modify, and Delete operations on a 4D Server's records.
- Focuses specifically on a simple technique for adding records remotely.

## Featured Technology
- 4D Open plug-in
- Remote record creation

## Historical Context
4D Open was the classic plug-in mechanism for cross-database connectivity before native remote datastore/ORDA capabilities existed; only the short teaser text for this note could be recovered here.

*Note: only the on-page teaser paragraph for this Tech Note could be recovered in this environment; the full PDF/example database is no longer accessible (old format/archive not reachable here), so this summary is necessarily based only on that short teaser text.*

## Historical Commentary
**Status:** Obsolete

4D Open as a distinct plug-in is obsolete; modern 4D applications would use ORDA remote datastores or REST APIs to add records to a remote 4D Server rather than this legacy plug-in mechanism.
