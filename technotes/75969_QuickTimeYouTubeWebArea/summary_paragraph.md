This Tech Note refines a series of earlier Web Area technical notes (covering web mashups, extending the Web Area as a 4D form, and JavaScript injection) by showing how to control embedded QuickTime and YouTube videos from within a 4D form using each service's public JavaScript API together with the Web Area's JavaScript injection functions. It is organized into three sections: The Database, which explains the 4D-side structure, methods, and form used by the demo; QuickTime, which shows how to get a reference to an embedded QuickTime movie and drive Play, Pause, and Volume buttons via its JavaScript API; and YouTube, which explains how the Flash-based SWFObject embed works, how to get a reference to the embedded video, and how to wire up equivalent play/pause/volume controls, noting that a running 4D web server is required to serve the demo page (and that some browsers report harmless errors when loading the QuickTime page). The note closes with practical tips and caveats encountered while implementing the solution. It targets 4D developers who want to build custom video-playback controls around embedded third-party video content inside a 4D application.
