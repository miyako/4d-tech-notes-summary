Jean-Yves Fock-Hoon, QA Manager at 4D, demonstrates a generic technique for drawing a user's attention back to a field whose value fails an entry rule, by making its label visually "blink" between red and white rather than only popping a modal Alert. The technique overlays each standard field label with a picture button that precisely covers it; on the form's On Load event, 4D Chart's offscreen-area commands (CT New offscreen area, CT Draw text, CT SET TEXT ATTRIBUTES, CT Area to picture) render the label text once in red and once in white, and the two pictures are concatenated (ppbN := pictRed/pictWhite) into a single alternating-frame picture button, whose Animation properties are configured to cycle the two frames automatically. The Validate button's object method then checks each entry rule (a required Name field, a minimum guest count, valid reservation date and time) and, for any field that fails, hides the static label and shows the corresponding animated picture button in its place using SET VISIBLE, before issuing REJECT and REDRAW WINDOW to keep the record open for correction.
