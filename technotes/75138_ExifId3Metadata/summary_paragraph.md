This Tech Note introduces a 4D component that wraps ExifTool, Phil Harvey's well-known open-source (GPL/Artistic License) Perl-based command-line application for reading, writing, and editing image/audio/video metadata (EXIF, GPS, IPTC, XMP, and many camera-specific maker notes, plus ID3 tags for MP3), giving 4D databases the ability to inspect and modify a wide range of file metadata without implementing any format parsing themselves. The component exposes two primary commands: `Exif_ReadAllTags`, which returns all tags found in a file as two parallel text arrays (names and values), and `Exif_WriteTags`, which adds, modifies, or removes specified tags (each with a corresponding numeric Action code) and optionally skips creating a backup copy of the original file. Special handling is documented for date/time tags — `AllDates`, `DateTimeOriginal`, `CreateDate`, and `ModifyDate` — where the Action parameter takes on a shifting meaning (add time, set a new value, or subtract time), useful for correcting time-zone or clock-drift discrepancies between a camera and other devices like a GPS unit. The note documents error codes returned by both commands, notes that ExifTool at the time supported read/write for images but read-only for MP3 ID3 tags, and includes a caution specific to Mac OS: if a database package is unzipped on Windows and then copied to a Mac, the bundled `exiftool` binary can lose its Unix-executable permission bit, breaking the component until it's restored (e.g. via `chmod` or re-extracting the archive natively on the Mac). The component ships with a test dialog for exploring a file's tags during development, which the note explicitly advises against including in a final deployed application. This note targets developers who need to read or manipulate photo/media metadata from 4D without building EXIF/ID3 parsers themselves.
