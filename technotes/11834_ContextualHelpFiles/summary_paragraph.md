This Tech Note describes how to create and use an online help system or complete documentation set for a 4th Dimension version 6.5 database using HTML (HyperText Markup Language). The note addresses the common developer need to provide in-application help that users can access directly while working in the database. By leveraging HTML as the documentation format, developers could take advantage of hyperlinks, formatting, and browser-like navigation within their 4D applications. The approach utilized 4D v6.5's capabilities to render or display HTML content, making it possible to build a self-contained help system embedded in the application. This was a practical solution in an era before standardized in-app help frameworks were widely available. The technique reflects the late-1990s trend of adopting web technologies (HTML) for desktop application documentation.
