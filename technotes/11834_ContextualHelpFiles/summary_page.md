# Tech Note 99-09: Creating and Using Contextual Help Files

**Author:** Not specified
**Published:** May 1, 1999 | **Product/Version:** 4D v6.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11834

## Overview
This Tech Note describes how to create an HTML-based online help system for a 4th Dimension version 6.5 database, enabling users to view documentation and help content directly within the application.

## Key Points
- Uses HTML (HyperText Markup Language) as the format for creating help files.
- Enables in-application viewing of a complete documentation or help system.
- Targets 4D v6.5, which introduced capabilities for working with HTML content.
- Provides a practical solution for embedding user-accessible help in a 4D database.

## Featured Technology
- 4D v6.5
- HTML for documentation/help
- Online help system design

## Historical Context
**Status:** Obsolete

This note reflects the late-1990s trend of adopting web technologies like HTML for desktop application purposes. Building a custom HTML-based help system was a creative solution for its time, but modern 4D versions provide Web Area objects and other integrated mechanisms for displaying help content.
