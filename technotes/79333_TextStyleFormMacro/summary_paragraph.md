This technical note tackles a small but persistent usability gap in 4D's Form Editor: the Properties List window's Font dropdown only shows font names as plain text, so developers must repeatedly click each font just to see its actual appearance, with no live preview while navigating via keyboard. The provided solution is the Text Style Editor, a form editor macro (built using 4D's class feature, which requires the target database to be in project mode) that adds an "Open Text Style Editor" option to the form canvas's right-click Macros menu. When invoked, it inspects the current form-element selection and adapts accordingly: with zero elements selected it only allows exporting a style as JSON; with one element selected it loads that element's existing text style and enables direct Apply; with multiple elements selected it resets to sensible defaults (first font, size 10, black, no styles) and applies any new style to all of them at once. The modal dialog itself has four sections — a live sample-text preview (with a dark-background toggle to check contrast), a fonts list box that renders each font name in its own actual typeface and updates the preview on arrow-key navigation, font style options (size, color, bold/italic/underline), and application options offering an "Apply" button (which the `openTextStyleDialog` class uses to directly rewrite the form definition for the selected elements) or a "Copy as JSON" button that places a JSON string of style properties (fontFamily, fontSize, stroke, fontWeight, fontStyle, textDecoration) on the clipboard for reuse in .4DForm files, CSS stylesheets, or 4D code via `Get text from pasteboard`. Because it operates as a standard form macro, any changes it makes are fully undoable through the form editor's normal undo mechanism. The technote also ships the underlying "matrix" database used to build the component, heavily commented, so developers can customize or extend the macro and rebuild it as an installable component following 4D's standard component build process.
