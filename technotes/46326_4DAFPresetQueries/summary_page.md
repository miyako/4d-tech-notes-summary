# Tech Note 07-17: 4D Ajax Framework: Preset Queries

**Author:** Not specified in source document

**Page:** https://kb.4d.com/assetid=46326

## Overview
This Tech Note revamps an example Invoicing database by adding "Preset Queries" within the 4D Ajax Framework (4DAF), showing how these predefined, one-click searches are both practical and beneficial for end users and easy for developers to implement.

## Key Points
- Uses an existing Invoicing demo database as the working example.
- Positions Preset Queries as a foundational, high-value 4DAF feature for developers new to the framework.
- Emphasizes ease of implementation as much as end-user benefit.
- A complete example database (~60MB) was distributed separately for Windows and Mac alongside the Tech Note PDF.

## Featured Technology
- 4D Ajax Framework (4DAF)
- 4D Web 2.0 Pack
- Preset Queries feature
- Invoicing demo data model

## Historical Context
Only a short teaser abstract for this note survives in this archive; the full PDF and its ~60MB accompanying example database could not be recovered in this environment (old download format/link not accessible), so the specific implementation steps and code are not available here. The 4D Ajax Framework and 4D Web 2.0 Pack were a subscription-based, then-modern approach to building AJAX-driven web front ends for 4D, since fully discontinued and replaced by 4D's built-in Web Server and modern web tooling (including Qodly). The general concept — offering end users predefined, one-click "canned" queries rather than requiring them to build searches manually — remains a common and still-useful UI pattern in any database application today.

## Historical Commentary
**Status:** Obsolete

The 4D Ajax Framework and its Preset Queries feature are tied to a discontinued 4D Web 2.0 Pack product; the underlying UX idea of offering saved/preset searches to end users is timeless, but the specific 4DAF implementation described here has no direct current-day equivalent within 4D's tooling.
