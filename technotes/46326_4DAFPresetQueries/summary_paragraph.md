This Technical Note, published as part of the May 2007 batch, uses an example Invoicing database to demonstrate how to add "Preset Queries" to a 4D Ajax Framework (4DAF) web application, revamping the demo so that end users can run predefined, canned searches rather than building queries from scratch. The stated goal is to show 4D developers who are new to the 4D Ajax Framework how practical and beneficial Preset Queries can be for end users, while also illustrating how straightforward they are for a developer to create within the framework. Only a short teaser abstract survives for this note in the archive; the full PDF and its accompanying ~60MB example database (offered separately for Windows and Mac) could not be recovered in this environment, so the specific implementation steps, screenshots, and code used to wire up the preset queries are not available here. The 4D Ajax Framework was a subscription-based component of 4D's Web 2.0 Pack aimed at building rich, AJAX-driven web front ends on top of a 4D database, and Preset Queries were positioned as one of its more valuable end-user-facing features at the time. As a subscription product expected to receive incremental updates, the framework (and by extension notes describing it) was explicitly acknowledged even at the time as likely to become outdated quickly. The featured technology is squarely the 4D Ajax Framework and its Preset Query mechanism, applied to a simple Invoicing table structure as a teaching example. No code samples, command names, or configuration screens are preserved in the available teaser text, limiting this summary to the note's stated purpose and scope rather than its technical execution.
