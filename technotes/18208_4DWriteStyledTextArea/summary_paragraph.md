This Tech Note (TN 01-45, 4D Write v6.7, Mac & Win, published September 30, 2001) presents a technique for embedding a 4D Write area on a form so it behaves like a plain Alpha/Text field while accepting styled text. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4d.com/aci_technical_notes/2001/windows/tn_2001_41-45_(sep)/01-45_stylized_text_areas.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This tech note shows how to can use a 4D Write area on an input form so that it looks like a standard Alpha or Text field. The advantage is that you can use the 4D Write area to accept styled text. Its featured technology centers on 4D Write (classic plug-in), Styled text form areas, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note shows how to embed a classic 4D Write area on a form so it visually behaves like a plain Alpha/Text field while still accepting rich styled text. Classic 4D Write (the plug-in-based rich text editor of this era) has since been replaced by 4D Write Pro, an entirely HTML/CSS-based document engine introduced around 4D v14, so the specific plug-in and API this note relies on are obsolete, even though the underlying goal — an inline styled-text input area — is still achievable with modern tooling.
