This Technical Note details the enhanced picture management capabilities in 4D v11.2, which introduced native support for current Mac OS X and Windows picture formats, eliminating the need for intermediate format conversion that would previously degrade image quality by stripping transparency, gradients, antialiasing, and other native format characteristics. The release added powerful picture transformation commands (SCALE for resizing, CROP for rectangular area extraction, FLIP HORIZONTALLY and FLIP VERTICALLY for mirroring, FADE TO GREY SCALE for desaturation, and COMBINE PICTURES for compositing), along with user interface enhancements including drag-and-drop picture import to fields and variables, contextual menu options (Cut, Copy, Paste, Clear, Import, Save As, display format control), and optional scrollbars for truncated pictures. The note provides extensive technical reference including the complete list of supported picture codecs and formats (4D picture .4pct, JPEG .jpg/.jif/.jpeg/.jpe, PNG .png, BMP/Paint Brush .bmp/.dib/.rle, GIF .gif, Radiance, PDF Mac OS X only, TIFF .tif/.tiff, EMF Windows only, PICT .pic/.pct/.pict, SVG .svg, SGI .sgi/.rgb, Photoshop .psd, Mac Paint .pntg/.pnt/.mac, TGA .targa/.tga, JPEG 2000 .jp2, QuickTime .qtif/.qti) and their codec IDs returned by PICTURE CODEC LIST command in three forms (extension, MIME type, 4-character QuickTime code). The note also explains picture storage locations (picture fields, picture variables, Resources folder, static image objects in forms, Pictures Library) and demonstrates that despite multiple storage methods, 4D v11.2 now preserves the original format characteristics uniformly across all storage types via native codec support.
