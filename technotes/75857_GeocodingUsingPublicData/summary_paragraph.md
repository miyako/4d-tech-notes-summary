This Tech Note is a follow-up to TN 09-29 ("Embedding Maps in 4D Using Google Maps") that instead demonstrates geocoding — converting between addresses/place names and geographic coordinates — using free, Creative Commons-licensed data sources: Geonames.org (Attribution license) and OpenStreetMap (Share-Alike license). It explains how to query the `ws.geonames.org` XML web service directly via browser-style URLs (with parameters like `name`, `country`, `lang`, `featureClass`, and `style`) for forward search, postal-code lookup, reverse geocoding by coordinates, US street-level reverse address lookup, "nearby" place search, and even geo-tagged Wikipedia article search. A companion example demonstrates similar lookups against OpenStreetMap's node-based data. The accompanying demo database uses the existing `HTTP_Download` helper method (from TN 05-31) to fetch each service's raw XML response, then parses it with DOM XML commands via a generic `GN_ExtractSearchResult` method that extracts whichever XML elements/attributes are requested into arrays for display in a list box, with a dispatcher method (`DemoOpenSource_FormPage`) selecting the right URL/parsing logic per form page. The note closes by noting the pattern is easily extended to other geocoding services or additional returned fields.
