Written by Sebastian Frey, Web Developer Tools Evangelist at 4D, Inc., this Tech Note is the seventh in a series on the Beta 1 DataGrid application, and focuses specifically on 'Videos2000,' the sample video-rental-store application built to showcase the Enterprise Data Module (EDM). Unlike the original single-backend 'Videos' connectivity demos, Videos2000 can point its Customers, Videos, and Tracking tables at the local 4D database, a remote 4D Server, an Oracle database, or an ODBC source, all from one code base, with the Launcher UI exposing Administration options (Create/Drop Tables, Enable/Disable Constraints, Import & Export Data, SQL Templates) alongside per-source data views. The note walks through APP_VideoTablesCreateDrop, which opens a connection via EDM_ConnectionForType and issues canned SQL stored in [APP_VideoSQL] through EDM_OdbSqlExecute or EDM_OraSqlExecute to create or drop remote tables; APP_VideoConstraintsOnOff, which is Oracle-specific and queries the USER_CONSTRAINTS data dictionary; and APP_VideoImportExport, a generalized replication method that swaps data between the local database and any remote source across four EDM Models (Videos uses two Models to split off its 'fat' MoviePoster picture column into a one-row Model) by creating and paging through an EDM_QueryCreate/EDM_QueryRowsAllSelect query, checking for existing rows on the target with row-select-by-key methods, and saving each row with EDM_ModelRowSave. It closes by tracing how the DataGrid/GRD_ 4D Calc grid modules implement the classic list-detail 'drill down' UI pattern on top of EDM's Model/Query abstraction, since EDM itself has no built-in list-detail presentation layer.
