This Tech Note is the seventh in a series documenting the Beta 1 release of the Enterprise Data Module (EDM), also referred to as the DataGrid application. Where the preceding six notes in the series had explored DataGrid's individual modules and the various 4D Plug-Ins that composed it, this entry shifts perspective to focus on a complete, real sample application built with the platform: 'Videos2000.' A full, working version of the Videos2000 database is included alongside the Tech Note itself, giving developers a concrete end-to-end example of what an application built on the still-beta Enterprise Data Module could look like in practice, rather than another module-by-module technical breakdown. The featured technology is therefore the Enterprise Data Module/DataGrid framework and its constituent plug-ins, showcased through a complete sample application aimed at developers evaluating or already building on this then-emerging (and ultimately not long-lived) 4D data platform.
