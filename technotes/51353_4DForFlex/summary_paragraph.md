This technical note demonstrates how to build Rich Internet Applications (RIAs) using Adobe Flex—a Flash-based framework for declarative UI development—connected to 4D Server v11.2+ via direct SQL queries. The 4D Web 2.0 Pack provides three Flex SWC (Shockwave Component) libraries with SQL-oriented classes: Flex4D_SQL.swc (core, required) provides SQLService and SQLResultSet for SQL connectivity and data manipulation; additional components support more specialized features. The sample application (FlexPlanner) is a form-building and task-management tool with a ComboBox for filtering Category, a DataGrid displaying filtered Tasks, and a detail form for editing individual Task records. It demonstrates two UI states: Form View (side-by-side layout with category ComboBox and task detail form) and Grid View (two-column layout with separate category and task grids). The note provides detailed setup instructions: 4D configuration (enable SQL Server, create Flash security policy XML file in Preferences/SQL/Flash), Flex Builder project configuration (source/output folders, pointing output to the 4D Webfolder for deployment), and library path configuration (adding Flex4D_SQL.swc). The development guide covers key 4D for Flex classes and programming patterns: SQLService (declares connection with host, userName, password, and event handlers for connect/disconnect/result/fault), SQLResultSet (data structure representing a 4D selection, bindable to Flex display objects), AsyncToken (for tracking asynchronous query results), data binding (linking SQLResultSet to DataGrid and ComboBox), and event handling for interactive features (filtering on ComboBox selection change, loading detail form on DataGrid row selection, CRUD operations via Save/New/Delete buttons). Deployment options include running the compiled SWF directly in Flash Player or serving via 4D Web Server (http://localhost:8080/FlexPlanner.html). The sample includes MXML markup and ActionScript 3 code demonstrating SQL SELECT queries, event-driven data loading, and form synchronization patterns.
