Tech Note: Advanced Cropping in 4D (TN 14-01, 4D v14, January 2014) — a follow-up to an earlier basic cropping note by Charles "Charlie" Vass, describing how to build a full drag-handle cropping tool resembling those found in popular graphics applications, using 4D's TRANSFORM PICTURE command combined with carefully arranged static picture objects and mouse-event tracking to simulate a resizable cropping rectangle.
