This Tech Note by Charles "Charlie" Vass builds on an earlier, more basic cropping Tech Note by describing an advanced image-cropping tool in 4D that mimics the corner-handle cropping UI found in popular graphics applications like Photoshop. It centers on 4D's `TRANSFORM PICTURE` command — distinct from a picture form object's mere display formatting — which supports Reset, Scale, Translate, Flip, Crop, and grayscale-fade operations on the actual picture data. The bulk of the note documents the engineering required to fake a smooth, resizable cropping rectangle purely from 4D form objects: four thin static "rect_" picture objects are precisely positioned edge-to-edge around the crop area so they appear as one continuous frame with a resizable hole in the middle, with a `RepositionToolAssets` method keeping everything aligned on load and after each crop operation. Mouse-drag events are dispatched from a central `HandleMouseEvents` method to one of five handle-tracking methods (`TrackTopLeftHandle`, `TrackTopRightHandle`, `TrackBottomLeftHandle`, `TrackBottomRightHandle`, `TrackInCropRect`) depending on which handle or region the user grabs, and `OBJECT MOVE` repositions the picture and tool assets as the crop area changes, also accounting for images larger than the display object, scrolled images, and 4D's screen-update behavior. Finally, the tool gives users three ways to persist the cropped result: saving to the Picture Library under a new name/ID, saving to a file on disk via a save dialog, or committing the crop back into the original form's picture object. A complete sample database implements the entire tool and can be dropped into any 4D application.
