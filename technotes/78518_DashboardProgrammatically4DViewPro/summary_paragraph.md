This Tech Note highlights an underused capability of 4D View Pro (4DVP) beyond ordinary spreadsheets and formulas: transforming continuously-updated data into a live, non-interactive dashboard display, built through a mostly programmatic workflow. The process begins by loading live data into the VP area using `VP SET VALUE`/`VP SET VALUES`, with the note recommending pre-consolidating large datasets into a few significant, dashboard-appropriate data points before deciding on cell layout. Because a 4D View Pro area is internally a Web Area running GrapeCity's SpreadJS JavaScript spreadsheet engine, charts are added by dropping down to the SpreadJS API directly via `WA Evaluate JavaScript`: the note shows obtaining the active sheet (`spread.getActiveSheet()`), wrapping modifications in `suspendPaint()`/`resumePaint()` for performance, and calling `sheet.charts.add()` with parameters for chart name, type (e.g. `columnClustered`), pixel position, size, and source data range, followed by further SpreadJS customization of chart appearance. Visual styling of the underlying data uses native 4D VP commands instead — `VP SET DEFAULT STYLE` for an overall theme (background/font colors) and `VP SET CELL STYLE` for per-cell overrides such as a distinct font. The final and most distinctive step "primes" the VP area to behave like a dashboard rather than a spreadsheet: exporting the area to an object with `VP Export to object`, then setting nested `spreadJS` properties to hide scrollbars, tab strips, row/column headers, and gridlines, and enabling `isProtected` to lock the sheet from user edits, before reimporting with `VP IMPORT FROM OBJECT`; scrolling is separately disabled via `VP SET FROZEN PANES`. The completed dashboard configuration (with live data still loaded separately at runtime) can be serialized to a `dashboard.json` file and later re-imported into its own window. The accompanying demo database provides "Simulate Live Data," "Create Dashboard," "Export Dashboard," and "View Dashboard" actions to walk through the full pipeline.
