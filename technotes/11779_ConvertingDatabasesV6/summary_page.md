## Overview
This note explains how to convert 4th Dimension databases from version 3.x to version 6, noting that while most databases converted successfully, some databases that appeared to work fine under 3.x could encounter conversion problems. ## Historical Context
Published October 1997 alongside the V6 release, this note reflects V6's notable terminology overhaul — Phases were renamed Events and Procedures were renamed Methods — which was a source of confusion for developers migrating older 3.x databases. The archive of the full technical content could not be recovered (no working download link exists for the original page). As guidance for a one-time historical database-conversion path (3.x binary structure files to the V6 binary structure format) that closed decades ago, and long predating the modern structure file format and Project Mode (introduced v17, 2018), this note is of historical interest only today.
