This Tech Note introduces `WA Run offscreen area`, a new command in 4D v18 R3 that creates an in-memory Web Area — without any visible form or dialog — letting developers tap into 4D's embedded web rendering engine to load pages, run JavaScript, and extract data even on a headless server with no display. The command takes a single object parameter supporting an optional `url` (or File object) to load, an `area` name, an `onEvent` callback (either a Formula object or a class's onEvent function), an `autoQuit` flag controlling whether the command auto-terminates on load-finish/error, a `timeout` (default 60 seconds, 0 for unlimited), a `result` value automatically mapped to the command's return value, and any number of arbitrary custom properties the developer wants accessible inside the callback. The callback fires at four lifecycle points — `On Load`, `On End URL Loading`, `On URL Loading Error`, and `On Unload` — and inside it, the developer can use commands like `WA Evaluate JavaScript`, `WA EXECUTE JAVASCRIPT FUNCTION`, `WA Get Page Content`, `WA Get Page Title`, `WA OPEN URL`, `WA REFRESH CURRENT URL`, and `WA STOP LOADING URL`, or call 4D methods from JavaScript running in the page. After execution, a `timeoutReached` boolean is automatically added to the parameters object if the operation timed out. Error handling uses `WA GET LAST URL ERROR` inside the `On URL Loading Error` case of the callback to capture the failing URL, description, and error code into a custom `error` property on the parameters object, which the calling method can then inspect with `OB Is defined` after `WA Run offscreen area` returns. Three worked examples in the sample database show the pattern in action, including one that loads `https://blog.4d.com`, waits for it to finish loading, and evaluates a JavaScript expression (`document.getElementsByTagName('h2')[1]...innerHTML`) to scrape the title of the most recent 4D blog post — timed using `Milliseconds` deltas captured across the On Load/On End URL Loading/On Unload events.
