This Tech Note builds a reusable "WPNP" (Write Pro Navigation Panel) component that gives multi-page 4D Write Pro documents a navigational subform (similar to a PDF thumbnail sidebar) plus a full-screen presentation mode, similar in spirit to slide-show software. It leverages the fact that a 4D Write Pro area is an object that can be copied, zoomed, and manipulated independently of the "live" document, so a read-only, low-zoom copy can serve as a page browser. The implementation is split into two form components: a "WPForm" containing a non-enterable, 25%-zoomed Write Pro object embedded in a subform, and a "FullScreenFormWP" that displays a single page at a time in presentation mode. Synchronization between the subform and the live document is handled by a family of WPNP_* methods (WPNP_updateSubform, WPNP_pointToPage, WPNP_loadWPForm, WPNP_createBookMark, WPNP_updateCurrPages, WPNP_storeRangePages, WPNP_getCurrentPageNum, WPNP_getFocusedScr, WPNP_openPreviewForm), using CALL SUBFORM CONTAINER to report click events up from the subform and the Storage object to persist page bookmarks and ranges across the presentation form. Page navigation in full-screen mode uses `WP New` combined with `OB Get` to reload the correct page object, and left/right arrow key presses step through pages tracked in Storage. The note targets 4D v17 and later, since it depends on Write Pro object-notation commands for determining page position that were new at that time. It's intended as a practical, drop-in add-on for any 4D Write Pro-based database needing quick document browsing or presentation capability.
