This Tech Note (TN 01-43, 4D v6.7, Mac & Win, published September 30, 2001) by Thomas Maul of 4D Germany presents a generic 4D component, delivered under the TMXML_ method prefix, for exporting and reimporting entire 4D databases as XML text files. Maul frames the tool around several real business needs: long-term legal data archiving (some countries require invoice records to be retained 7-10 years, and XML text is far more likely to remain readable decades later than a proprietary binary format), database defragmentation (a text-only export/reimport cycle rebuilds address tables and indexes from scratch, eliminating fragmentation and hidden data-file damage), controlled repair of suspect databases (an export-with-errors approach reports exactly which records and tables fail, unlike 4D Tools' silent tag-based repair), and a clean drop-field/drop-table migration path when a structure evolves over years of development. TMXML_ExportAll and TMXML_ImportAll drive the core process, iterating all tables and fields generically (including one-level subtables via TMXML_AddSubTable/TMXML_AddSubField), while TMXML_AddPictToConvert and TMXML_AddBlobToRTF let a developer opt individual picture and 4D Write blob fields into JPG/RTF conversion for future-proof readability. The note is explicit that the code should be installed as a compiled component rather than copied inline, both to protect the shared implementation from drift across a developer's databases and to make future updates easy to apply via 4D Insider.
