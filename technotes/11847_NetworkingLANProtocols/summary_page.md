## Historical Context
**Status:** Obsolete

This networking primer was written when AppleTalk and IPX/SPX were still common LAN protocols alongside TCP/IP. Today TCP/IP is universal, and concepts like media access methods and bus/ring topologies are mostly academic. The note is part of an educational series for 4D developers who needed to understand networking fundamentals for deploying 4D Server — knowledge now assumed as baseline IT literacy.

### Related Updates
- TCP/IP has become the universal standard, replacing AppleTalk, IPX/SPX, and other legacy protocols
- Modern 4D Server operates exclusively over TCP/IP
