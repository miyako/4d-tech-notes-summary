This 2002 Tech Note by Roland Lannuzel, a 4D Developer at 4D S.A., demonstrates the MOVE OBJECT command in conjunction with the On Timer, On Load, and On Resize form events, using an animated analog clock as its centerpiece example. It explains that MOVE OBJECT works on both static objects (text, pictures, lines, circles) and dynamic objects (fields, variables, buttons), supporting relative or absolute coordinates and homothetic resizing, and stresses that every object's true coordinates are those of its bounding rectangle -- so to invert a line's slope you must swap the rectangle's x1/x2 or y1/y2 rather than trying to move the "line" itself. The clock demo uses GET OBJECT RECT to read the dial's bounding rectangle, then Sine and Cosine to compute hour/minute/second hand positions, implemented in the appendix methods DrawAnalogClock (which repositions three "Pin" hand objects based on Current time) and DrawClockSpots (which places twelve dot markers around the dial). SET TIMER(60) in the On Load event triggers an On Timer handler that, every ten seconds, randomizes the clock window's position and size via SET WINDOW RECT, which in turn fires On Resize to redraw the dial's dot markers so the "Grow" sizing option keeps the dial itself proportional to the new window size. A second, simpler demo shows moving and resetting line objects to fixed coordinate sets via labeled buttons. The note closes by emphasizing that time-consuming redraw logic was deliberately deferred to On Timer rather than On Load, so the form's initial appearance is not delayed.
