# Tech Note 02-01: Moving Objects

**Author:** Not specified in source document
**Published:** January 31, 2002 | **Product/Version:** 4D v6.8 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=23220

## Overview
A Tech Note demonstrating how to use the MOVE OBJECT command together with the On Timer, On Load, and On Resize form events to dynamically reposition objects on a 4D form.

## Key Points
- Demonstrates the MOVE OBJECT command for dynamically repositioning form objects.
- Shows usage triggered by three form events: On Timer, On Load, and On Resize.

## Featured Technology
- MOVE OBJECT command
- On Timer / On Load / On Resize events

## Historical Context
Reflects classic 4D's manual, code-driven approach to responsive form layout, before more automatic object anchoring/resizing properties existed in later 4D versions.

## Historical Commentary
**Status:** Superseded

The MOVE OBJECT command and the On Timer/On Load/On Resize events remain part of current 4D, so this note's core technique remains applicable, though later 4D versions introduced more automatic object anchoring and resizing properties that reduce how often developers need to hand-code dynamic repositioning logic like that shown here.
