This Tech Note describes the installation and update procedures for 4D Server in scenarios involving hardware upgrades, machine migrations, and license recovery. The discussion centers around three key components: the 4D Server application itself, the hardware dongle (a physical device connected to the computer for copy protection and license validation), and the Expansion Pack Diskette (a floppy disk used to expand server capabilities). The note covers upgrading 4D Server, moving the application to another machine, and recovering lost licenses — all common administrative tasks that required specific procedures due to the hardware-based licensing system. The dongle and Expansion Pack were physical components that had to be managed carefully during any server infrastructure change, as losing or damaging them could prevent the server from running.
