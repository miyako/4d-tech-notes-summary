## Proposition
This Tech Note provides instructions for managing 4D Server installations involving the hardware dongle and Expansion Pack diskette, covering upgrades, machine migrations, and license recovery.

## Key Points
- Covers three components: 4D Server application, dongle, and Expansion Pack Diskette
- Upgrade procedures for 4D Server
- Instructions for moving 4D Server to another machine
- License recovery procedures
- Dongle is a physical copy-protection device
- Expansion Pack Diskette expands server capabilities

## Featured Technology
- 4D Server
- Dongle
- Expansion Pack
- Licensing

## Context / Positioning
Hardware dongles and floppy-disk-based expansion packs were standard software protection and distribution mechanisms in the late 1990s. Managing these physical components was a routine but critical part of server administration.

## Historical Commentary
**Status:** Obsolete

Hardware dongles for software licensing were common in the late 1990s but have been entirely replaced by software-based licensing systems. The Expansion Pack concept and dongle-based licensing reflect an era of physical copy protection. 4D has long since moved to software-based license management.
