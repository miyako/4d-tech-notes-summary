This Technical Note covers the new keyword features in 4D v11 SQL. 4D v11 SQL adds support for keywords in the form of three new features: keyword indexes, the “contains keyword” comparison operator, and support for regular expressions (regex). These powerful tools allow 4D Developers to perform fast, efficient keyword-based searches. Published January 9, 2008 as Technical Note 01-08 for 4D Developer v11 (Mac &amp; Win), this note was written by Josh Fletcher, Technical Support Engineer, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
