This Tech Note demonstrates how to build a generic SQL client for 4D Server using SQL Pass-through, enabling simultaneous connections to multiple 4D Server (v11.2+) databases from a single application. It explains the prerequisites — a 4D Server with SQL Server enabled and a known publishing port (default 19812), an available client or unlimited SQL license, and valid SQL credentials — and describes how the included sample database opens a new process per SQL Query Browser window so a user can connect to several 4D Servers concurrently via the SQL LOGIN command. The note walks through the connection flow (collecting username, password, and server IP), browsing the connected server's schema once logged in, and then using the resulting 4D SQL Query Browser interface to explore and query the data. It is positioned as both a teaching example of SQL Pass-through mechanics and a genuinely reusable utility for developers who regularly need to inspect multiple 4D Server databases without building bespoke tooling each time.
