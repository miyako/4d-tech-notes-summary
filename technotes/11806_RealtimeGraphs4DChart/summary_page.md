## Proposition
This Tech Note demonstrates how to build real-time, live-updating moving graphs using 4D Chart in 4D V6, with an example database showing data flowing in as it's acquired.

## Key Points
- Uses 4D Chart module for real-time moving graph display
- Shows new data flowing in as it is acquired
- Makes fluctuations, cycles, and trends visible in real time
- Includes an accompanying example database
- Applicable to data acquisition, monitoring, and live-feed scenarios

## Featured Technology
- 4D Chart
- Real-time Data Visualization
- Data Acquisition

## Context / Positioning
Real-time data visualization within a database application was an advanced technique in the late 1990s. 4D Chart's ability to do live-updating graphs demonstrated the platform's versatility beyond standard business application use cases.

## Historical Commentary
**Status:** Obsolete

Real-time data visualization within a desktop database application was an innovative technique for the late 1990s. While 4D Chart has been discontinued, the concept of live-updating graphs remains relevant. Modern implementations would use web-based charting libraries with WebSocket or polling-based data feeds.
