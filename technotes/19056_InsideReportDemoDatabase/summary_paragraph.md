This 2001 Tech Note by Jonathan Baltazar, an Inside Sales Representative at 4D, Inc., tours the "Report Demo" example database -- an intermediate-level, three-table (Departments, Employees, Donations) hierarchical database originally created by Tad Michael Wheeler of DataCraft -- to teach 4D's classic reporting commands. It walks through the On Startup database method, which simply calls Shell_Startup to load a shared "Simple Shell" UI framework, then focuses on the ReportDemo_SpecialReport project method: it sets SET PRINT PREVIEW(True), selects ALL RECORDS from the Donations table, sorts them with a compound ORDER BY (Department Name, Quarter of Date, Donation Date), inserts a BREAK LEVEL(2;1) after each quarter, uses ACCUMULATE to subtotal Donation Amount within each break, and switches OUTPUT FORM between a "R.Quarter" and "Output" form around a PRINT SELECTION call to render the grouped, subtotaled report. The note also documents three object methods on the Employee input form's salutation, first-name, and middle-initial fields, which all call a shared ReportDemo_FormatName utility method; that method uses Case-of logic and Substring to correctly abbreviate a middle initial and assemble a properly formatted "Emp Formal Name" (handling combinations of salutation, first, middle, and last name being present or blank). The note is a straightforward, code-level explanation of a widely distributed 4D example database's reporting and formatting logic.
