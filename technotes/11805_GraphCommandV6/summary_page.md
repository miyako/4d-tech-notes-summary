# Tech Note 98-22: The GRAPH Command in 4D V6

**Author:** Not specified in source document
**Published:** July 1, 1998 | **Product/Version:** 4D Chart v6.0.x | **Platform:** Mac &amp; Win
**Page:** https://kb.4d.com/assetid=11805
**Download:** Not available

## Proposition
This Tech Note documents the changes made to 4D's GRAPH commands in V6 and provides migration guidance for developers converting applications from V3.

## Key Points
- Significant changes were made to GRAPH commands in 4D V6
- Affects applications converted from 4D V3 (all 3.x.x and Server 1.x.x)
- Explains the reasons behind the command changes
- Provides specific code changes needed for compatibility
- Important migration resource for the V3-to-V6 transition

## Featured Technology
- GRAPH Command
- 4th Dimension V6
- 4D V3 Migration
- Charting

## Context / Positioning
The V3 to V6 migration was one of the most significant upgrade paths in 4D history, with many commands and behaviors changing substantially.

## Historical Commentary
**Status:** Obsolete

The GRAPH command changes in v6 reflect a broader pattern of breaking changes during major 4D version transitions. While the GRAPH command itself has been further modified and partially superseded by more modern charting approaches in later 4D versions, the migration concerns described here are of historical interest.
