# Tech Note 99-01: Classification and Resources of External Routines (Plug-ins)

**Author:** Not specified
**Published:** February 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11827

## Overview
This Tech Note examines the classification, resource structure, and conversion handling of external routines (plug-ins) in 4th Dimension, including guidance on removing them during database conversion to v6.

## Key Points
- 4D supports compiled native code extensions to enhance its standard features.
- These were called "external routines" before v3.5, renamed "plug-ins" thereafter.
- Documents the classification system and resource structure of plug-ins.
- Explains how to properly remove or handle plug-ins during database conversion to v6.
- Relevant to developers managing v3/v3.5-to-v6 migration.

## Featured Technology
- 4D v6.0
- Plug-in (external routine) architecture
- Resource management
- Database conversion

## Historical Context
**Status:** Obsolete

The plug-in architecture has evolved significantly since 4D v6. Many classic plug-ins (4D Calc, 4D Chart, 4D Draw) have been discontinued, and the component architecture introduced in later 4D versions provides an alternative extension mechanism.
