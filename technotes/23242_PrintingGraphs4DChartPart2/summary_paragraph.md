Written by Tim Tonooka, a 4D Solution Partner, this is Part II of a two-part Tech Note on printing graphs from 4D Chart, following Part I's survey of available printing interfaces with the concrete coding details for handling tricky print-size issues, illustrated by the "ChartPrint" example database. It demonstrates four printing techniques via buttons on a 4D Chart Form demo: "Print As Is" prints the graph via a single CT DO COMMAND call at its exact on-screen pixel dimensions (which can split a large graph across pages or waste space on a small one); "Print Resized Graph" copies the document into an offscreen 4D Chart area with CT AREA TO AREA, finds the graph object's ID via CT Get ID, and uses CT MOVE/CT SIZE to resize the actual graph object to fill a page before printing -- noting this redraws the graph with different gridline granularity as it resizes; "Print Picture" instead uses CT Area to picture to convert the whole document into a picture variable placed on a form and printed via PRINT FORM, preserving the exact on-screen level of graph detail when stretched; and "Print Resized Picture" (used by the CHT_Print project method) computes proportional width/height ratios against a 540x720-point page and uses CT Place picture plus CT SIZE to scale the picture without distortion before printing from an offscreen area. The note also shows intercepting 4D Chart's own File > Print command via a CT ON MENU-installed CHT_MenuHandler that offers Custom vs. Standard printing, plus separate examples of building a graph entirely in an offscreen area and printing it directly (DEM_PrintOffscreen), printing it via a picture variable with PRINT FORM (DEM_PrintFormReport), and printing per-record graphs with PRINT SELECTION and PRINT RECORD (including from an unsaved "dummy" record), noting PRINT FORM alone cannot print 4D Chart plug-in areas directly.
