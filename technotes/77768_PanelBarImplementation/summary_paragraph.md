This Tech Note by Tai Bui responds to a design trend it identifies in modern computing: as monitors have grown wider (higher horizontal-to-vertical aspect ratios) over time, horizontal toolbars and menu bars have become comparatively less space-efficient than vertical navigation elements, making a vertical "panel bar" a more modern UI choice for many applications. It briefly surveys functional bars in modern technology and contrasts horizontal versus vertical bar designs before settling on the panel bar as the focus, presenting an approach to implementing one based on parsing a menu structure into a navigable panel. The technical implementation is built around a list box acting as the panel bar's visual and interactive backbone: the note covers the panel bar's graphical structure and intended functionality, then walks through building it in 4D — creating the panel bar form, parsing an existing menu into panel bar entries, building the panel bar list box, writing a form initialization method, and applying functionality (e.g., handling clicks/selection to trigger navigation actions). Additional technical details cover list box sizing considerations and display formatting choices needed to make the panel bar look and behave like a polished navigation control rather than a plain list box. A sample database accompanies the note, letting developers see the finished panel bar in action and adapt the pattern to their own menu structures. As a UI pattern note, it offers a concrete, list-box-based recipe for a common navigation need, reflecting design sensibilities and 4D form-building techniques typical of the mid-2010s classic 4D era.
