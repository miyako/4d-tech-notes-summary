This Tech Note introduces the Three-State checkbox, one of many new features shipped in 4D 2004, which extends the traditional two-state (checked/unchecked) checkbox with a third, indeterminate or 'mixed' state useful for representing ambiguous or partially-applicable boolean values in a user interface. The note frames this as opening new possibilities for building more expressive user-interactive dialogs, and walks through how to configure and use three-state checkboxes in a 4D form, backed by a downloadable example database demonstrating the feature in practice. This kind of UI form-object addition was typical of 4D's steady incremental improvements to its native Design Mode form editor during the mid-2000s, well before 4D's later web-based form rendering or Project Mode (2018) fundamentally changed how forms were built and stored. As a concise feature-introduction note with an example, it is aimed at 4D developers who want to adopt the newly available three-state checkbox in their own application dialogs.
