The 4D Internet Commands plug-in supports transferring individual files over FTP but has no built-in command for transferring a whole directory tree, a gap this Tech Note addresses with a hand-built strategy. For downloads, the approach determines the target FTP directory path, picks a local destination path, recursively walks the remote directory to build parallel arrays of all sub-directory and file paths, recreates the directory structure locally, and then downloads every file at every sub-level. The note works through a concrete example directory tree (an HTML folder with an images sub-folder, plus a documents folder) to show how the atDirectoryList and atFileList arrays are populated and used to drive the recreation and transfer steps. This is a practical engineering-recipe note aimed at developers needing FTP directory sync behavior that the plug-in doesn't provide out of the box, mirroring what most stand-alone FTP client applications offer natively.
