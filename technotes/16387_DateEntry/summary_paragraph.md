This Tech Note by Elaine Smith (Technical Support Engineer) demonstrates the Date Entry example database, which lets users tab into a date field and set its value with special function keys rather than typing a full date. It explains 4D's Form event model — the distinction between Form-method-oriented events (e.g., On Load) and Object-method-oriented events (e.g., On Clicked), and how disabling events at the Form vs. Object level affects which methods actually receive them — before focusing on `On Before Keystroke` and `On After Keystroke`, which fire before and after a typed character is applied to a field. The `FILTER KEYSTROKE` command, called during `On Before Keystroke`, replaces the just-typed character with a supplied string (or cancels it entirely if passed an empty string), while the `Keystroke` command returns the character the user actually typed. The note supplies Tom Dillon's (DataCraft) `HandleDate` and `StringToDate` example methods, which trap single-letter shortcuts — T (today), M (first of month), H (last of month), Y (first of year), R (last of year), + (add a day), - (subtract a day) — and also parse flexible delimiter-free date strings like "070476" or "07041976", resolving two-digit years per the `SET DEFAULT CENTURY` command.
