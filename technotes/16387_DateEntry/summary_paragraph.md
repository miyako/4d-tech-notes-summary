This Tech Note (TN 01-31, 4D v6.7, Mac & Win, published July 31, 2001) presents a walkthrough of the Date Entry example database's function-key-driven flexible date input. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_31-35_(JUL)/01-31_Date_Entry.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: The Date Entry example database demonstrates how, by using a set of routines, the Date entry field can be more flexible for the end user. By tabbing into a field, a User can set the date using the special function keys. Its featured technology centers on Custom date-entry form routines, Function-key input handling, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note presents the Date Entry example database, which uses a set of custom routines and special function keys to make date-field entry more flexible for end users tabbing into a field. This specific function-key-driven UI trick reflects a 2001-era UI paradigm; modern 4D applications typically use built-in date pickers, calendar pop-ups, or List Box date columns for more discoverable and accessible date entry, making the exact technique shown here obsolete even though flexible date entry remains a valid usability goal.
