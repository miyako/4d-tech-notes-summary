This Technical Note by Timothy Aaron Penner explains how to serve multiple 4D Web Servers from a single operating system by assigning multiple static IP addresses to one network interface card, since each 4D Web Server instance requires exclusive access to a distinct IP. It walks through the OS-level configuration steps for both Windows (via the Network Connections control panel and TCP/IP Advanced settings) and Mac OS X (via the Network preference panel's "Duplicate Service" feature), noting that DHCP cannot be used and static IPs are required. The note then covers how to make the 4D database aware of which IP to listen on, presenting two approaches: using DNS with a Fully Qualified Domain Name, or hard-coding/reading a specific IP address, either directly in the database structure or from an external configuration file (ListenIP.txt) placed next to the structure. Sample 4D project methods (SET_SPECIFIC_IP_OR_HOST, SET_WEB_LISTEN_IP, GET_IP_FROM_EXTERNAL_FILE) demonstrate parsing the IP, converting it to a Long Integer, and calling WEB SET OPTION to bind the Web Server to the correct address before restarting it. The note closes with simple usage examples showing all three configuration approaches in practice.
