This Tech Note demonstrates how to use 4D's BLOB (Binary Large Object) data type, introduced in 4D v6, to store files such as documents, pictures, or even application binaries within a 4D database. BLOBs allow storage of up to 2 GB of arbitrary binary data per field. The note describes methods for importing single or multiple files into a BLOB field and extracting them when required. It covers the fundamentals of how BLOBs work and how documents and applications are stored on disk, providing the foundation needed to implement a file-storage system within 4D. Example files could include Microsoft Word documents, application executables, or even 4D databases themselves. Only the teaser text survives; the full PDF could not be recovered.
