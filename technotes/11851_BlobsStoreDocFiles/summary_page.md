## Overview
A practical guide to importing, storing, and extracting document and application files using 4D's BLOB data type, demonstrating binary file management within a 4D database.

## Key Points
- BLOBs in 4D v6 allow storing up to 2 GB of arbitrary binary data
- Demonstrates importing single and multiple files into BLOB fields
- Covers extraction/export of stored files back to disk
- Files can include documents, pictures, applications, or even 4D databases

## Featured Technology
- 4D v6
- BLOBs
- Document Storage
- File Import/Export

## Historical Context
**Status:** Superseded

Storing files as BLOBs was a cutting-edge technique in 4D v6. Modern 4D provides object fields, built-in picture/document handling, and 4D.File/4D.Blob classes that make binary file storage and retrieval far more straightforward. The concept of embedding documents within a database remains valid, though the approach has evolved significantly.

### Related Updates
- 4D.Blob and 4D.File classes provide modern file handling
- Object fields and entity storage have largely replaced raw BLOB manipulation for document storage
