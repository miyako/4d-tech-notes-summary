## Overview
A Tech Note describing "4D for Keynote," a tool that imports Keynote presentation chart data into 4D for editing and exports the modified data back to the Keynote file.

## Key Points
- Imports chart data from an Apple Keynote presentation file into 4D for editing.
- Allows the user to modify the imported chart data using 4D's data-entry capabilities.
- Exports the modified data back into the Keynote presentation file, updating its charts.

## Featured Technology
- Apple Keynote file format
- Presentation data import/export

## Historical Context
Published the same year Apple introduced Keynote (2003) as part of the original iWork suite, this note reflects an early, creative integration between 4D and a brand-new Apple productivity application.
