This Tech Note describes "4D for Keynote," which imports a Keynote presentation file, displays the chart data it contains inside 4D, and allows the user to modify that data from within the 4D application. After editing, 4D for Keynote can export the modified data back into the Keynote presentation file, effectively letting 4D serve as a structured data-editing front end while Keynote remains the presentation/visual layer for the data. This is a creative cross-application integration example that reflects Apple's then-new Keynote presentation software (part of the original iWork suite, launched in 2003) being paired with 4D's classic strengths in structured data entry and editing.
