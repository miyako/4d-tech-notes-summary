Jean-Yves Fock-Hoon, QA Manager at 4D Inc., demonstrates several techniques for representing data through color and shape rather than plain figures, arguing that visual encoding communicates magnitude and pattern more effectively than numbers alone. The first example computes sales totals or averages per area, then dynamically maps each value onto an RGB color gradient (dividing the value range into 20 levels and scaling each into a 100-255 color-component range with SET RGB COLORS) to shade six areas on a form -- with a second variant generating the same data via 4D 2003's new Quick Report XML export (QR SET HTML TEMPLATE with an inline XML template and QR RUN) instead of a manual loop. A second dialog applies the same idea to a fixed, hard-coded green-to-yellow-to-red color scale representing phone-queue load per line. A third example moves beyond rectangles into 4D Chart, loading a polygon-based map document (map.4CT) and applying a graph-coloring algorithm so that no two countries sharing a border receive the same color, comparing a minimal-color-set approach against a more colorful randomized approach. Throughout, the note also notes practical trade-offs, such as interpreted vs. compiled performance for the manual computation loop (compiling matters for the loop but not for the Quick Report engine, which is already compiled internally).
