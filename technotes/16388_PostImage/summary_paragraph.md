This Tech Note by Chiheb Nasr (Technical Support Engineer, 4D S.A.) demonstrates a beginner-friendly technique for posting a picture from a web browser to a 4D Server and storing it in a Picture field, noting that Windows clients needed QuickTime 4.0 for the feature to work. The technique starts with a static HTML page whose form uses `Enctype="multipart/form-data"` and an `<INPUT Type="file" Name="vBlobImage">` field, posting to a `/4daction/WebH_Reception` action; 4D's Web server calls `WEB_COMPILER` and `On Web Authentication`, filling matching 4D variables — provided the uploaded BLOB variable name (`vBlobImage`) is declared with `C_BLOB` in the `Compiler_Web` method, since without that declaration only the file's path or name would be retrieved. On the server side, the received BLOB is split by locating the `CR+LF+CR+LF` delimiter (`2*(Char(13)+Char(10))` in 4D), with the header portion parsed by `WebH_BlobImageHeaderProc`, `WebH_ExtractPictureName`, and `WebH_ExtractPictureType` to determine the file's name and type, and `WebH_ExtracErrorType` reporting back if the uploaded file isn't actually a picture. If it is a picture, `WebH_Reception` stores it in the `[Pictures]` table's picture field and confirms the upload to the browser.
