This Tech Note (TN 01-32, 4D v6.7, Mac & Win, published July 31, 2001) presents a technique for uploading pictures from a web browser and storing them in a 4D database. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_31-35_(JUL)/01-32_PostImage.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This technical note demonstrates a technique for uploading pictures from a Web browser and storing them in the database. That technique can easily be integrated in existing database even by beginners. Its featured technology centers on Web picture upload, 4D built-in Web Server, Browser-to-database file transfer, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note demonstrates uploading pictures from a web browser and storing them directly in a 4D database, described as an approachable technique even for beginners. The general goal — accepting image uploads from a web client into 4D — remains a common requirement, but the specific 2001-era web-server upload mechanism has been superseded by modern 4D REST/ORDA endpoints and richer built-in support for handling multipart form uploads and BLOB/picture fields.
