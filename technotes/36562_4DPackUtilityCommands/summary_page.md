## Overview
There are 4 new utility commands in 4D Pack 2004.1. Three of those commands are implemented to give 4D developers flexibility in managing the database structure (tables, fields, relations and default objects). This technical note will discuss about these new utility commands as well as provide a few demonstrations on how to use them.
