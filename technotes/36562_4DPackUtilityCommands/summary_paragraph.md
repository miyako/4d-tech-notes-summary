Jamras Komoncharoensiri, a 4D Evangelist, introduces three utility commands newly added in 4D Pack 2004.1 that let developers build a database structure programmatically instead of manually from the Design-mode structure window. AP Add table and fields(tableName; fieldNamesArray; fieldTypesArray; fieldLengthsArray{; listFormTemplate{; detailFormTemplate}}) creates a new table with fields defined by parallel arrays and returns the new table number (originally built to let the 4D ODBC Pro plug-in's Assimilator tool clone a table read from an ODBC source), optionally applying named list/detail form templates pre-created through the New Form Wizard; it supports every field type except Subtable. AP Create relation(sourceTableNum; sourceFieldNum; destTableNum; destFieldNum) draws a one-to-many relation between two tables equivalent to a manually drawn relation line, applying standard default relation properties that can be adjusted afterward with 4D's relation-management commands. AP Get templates(templateNameArray) populates an array with the available detail form template names, useful for offering the user a template choice in a custom UI. The note demonstrates all three commands together in a two-part example database: an "HR Manager" database that exports its table/field/relation structure to an XML file using plain 4D commands, and a "New DB" database whose cln_ImportStructure method reads that XML and recreates the entire structure — tables, fields, and relations — using the new 4D Pack commands, illustrating a practical structure-cloning/migration workflow.
