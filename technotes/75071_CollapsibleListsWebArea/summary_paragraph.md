This Technical Note by Joe Resuello shows how to use the 4D Web Area (new-ish in 4D v11 SQL) to build interactive collapsible lists that go beyond what a standard 4D hierarchical list control can display. Using a Contacts/Appointments demo database, it walks through creating a Web Area on a compositing-mode form, loading a local HTML template file containing 4D TAGS (processed via PROCESS HTML TAGS) plus JavaScript and CSS, and displaying the result with WA OPEN URL. A short JavaScript toggledisplay() function handles the expand/collapse interaction, while 4D TAGS (#4DSCRIPT, #4DLOOP, #4DVAR) dynamically populate grouped Appointment records under clickable category headers. The note concludes that combining HTML/CSS/JavaScript with 4D TAGS in a Web Area effectively extends the 4D form with visual interactivity not otherwise available.
