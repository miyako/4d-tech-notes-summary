This Tech Note by Walt Nelson is a practical reference library of common array, string, and date manipulation routines intended to save 4D developers from "reinventing the wheel," accompanied by an example database demonstrating each routine and an appendix with representative source code. The array routines include ArrayDelete and ArrayInsert (both using "parameter indirection" — pointer-based generic procedures that can operate on up to 23 arrays passed by position without knowing their names in advance, with a performance note recommending bulk resizing over repeated insert/delete for 3+ elements), ArrayUp/ArrayDown (for cycling a list highlight with wraparound, typically bound to arrow-key buttons), ArraySum (summing numeric array elements), and Arr_Find_in_List/ArrFindMeaning (looking up the "meaning" text associated with a code in a choice-list-derived array). The date routines include Date1stofMonth and DateLastOfMonth (computing month boundaries, with logic adaptable to different date formats/locales such as U.S. and Korean), DateBlank (indirection-based blanking of up to 25 date fields/variables at once), DateDayofWeek (finding a specific weekday within the week containing a given date), DateFormatCalc (detecting the OS date format/locale at startup for use by the other date routines), DateGet (getting a date offset by a number of months, handling variable month lengths), and DateParse/DateValidate (splitting a date into year/month/day string parts, and validating user-entered dates with configurable beep/reset behavior). The string routines include StringBlank and StringNmbrZero (indirection-based blanking/zeroing of up to 25 fields/variables), StringConcat (joining two strings with a space, handling blank operands gracefully), StringFmDollars (converting a dollar amount into its check-writing text representation, requiring the ACI PACK plugin and an installed string resource), and StringPadSpaces/StringPadZeros/StringUpprLower (fixed-length padding and name-case formatting utilities). Each category has an interactive test screen in the example database (Array Manipulation, Date Manipulation, String Manipulation menu items), and the appendix supplies full commented source code for the array routines (ArrayDelete, plus explanatory notes on the pointer-indirection technique) as representative examples of the coding style used throughout. As a utility-library-style note built around the general-purpose, reusable-routine philosophy that has always been central to 4D development, most of its individual algorithms and its parameter-indirection technique remain conceptually valid today, though the specific implementations shown would now typically be supplemented or replaced by newer built-in 4D language commands, object/collection methods, or the ORDA layer where applicable, and the classic 4D Insider tool it references for porting code between databases has long since been absorbed into the modern 4D IDE's project management features.
