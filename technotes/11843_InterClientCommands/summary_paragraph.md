This Tech Note examines four new commands in 4D v6.5 that enable enhanced communication between clients and between clients and the server. These commands allow sending messages, updating variables, and performing actions on remote clients with a single command call. The note provides several examples and helpful hints for using these inter-client communication features, and includes an example database implementing an inter-client messaging system that can be easily incorporated into existing databases. This reflected 4D v6.5's growing support for collaborative, multi-user workflows. Only the teaser text survives; the full PDF could not be recovered.
