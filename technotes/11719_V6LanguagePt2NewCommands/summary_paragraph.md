This Tech Note is Part 2 of a two-part series cataloging the new and enhanced commands introduced by 4D Version 6, described as the most significant upgrade to the product since the release of 4D Server, delivering many long-requested items from developers' "wish lists" since Version 3. Having introduced new V6 concepts and initial commands in Part 1, this installment works through the remaining categories: 4D Environment Commands (e.g., ACI folder, Application file/type/version, Compiled, Data file, DATA SEGMENT LIST, Structure file, Version type — all returning information about the running 4D application/environment), System Environment Commands (Count Screens, Current Machine/Owner, FONTLIST, Gestalt, Menu bar height, SCREEN COORDINATES, Screen depth/height/width, SET SCREEN DEPTH, System/Temporary folder, Test path name — for querying the host OS and hardware), a Transaction command, Document commands, User Interface commands, Clipboard commands, Math/Date/Time commands, Drag and Drop commands, Entry Control and Form Event commands, Hierarchical List commands, Language commands (including RESOLVE POINTER, which resolves a pointer back to a variable name, or a table/field number, or an array name and element index, plus a note on building dynamic command names via constants like kDEFAULT_TABLE), Message commands (ALERT, CONFIRM, and REQUEST all gain the ability to customize OK/Cancel button text), Process commands, Resource commands (a full new suite — ARRAY TO STRING LIST, CLOSE/OPEN/CREATE RESOURCE FILE, DELETE RESOURCE, GET/SET ICON/PICTURE/TEXT/STRING RESOURCE, GET/SET RESOURCE NAME/PROPERTIES, RESOURCE LIST, RESOURCE TYPE LIST, STRING LIST TO ARRAY — for cross-platform Mac/Windows resource manipulation), Set commands (adding COPY SET), String/ASCII Conversion commands (ISO TO MAC, MAC TO ISO, WIN TO MAC, MAC TO WIN — for converting text between character-set encodings), Window commands (a Window-ID-based suite including DRAG WINDOW, ERASE/REDRAW WINDOW, Find window, Get/SET WINDOW RECT, Get window title, Next window, Window kind, WINDOW LIST, Window process — noting some syntax was still unfinalized at publication), and Password System (Users & Groups) commands (DELETE USER, Is user deleted, GET/SET GROUP/USER PROPERTIES, GET GROUP/USER LIST — built around unique User IDs and Group IDs). It also flags that a suite of Menu manipulation commands existed at the time only in an external "Menuset" package pending finalization. The note closes by reiterating that, across both parts, V6 represents the most significant language upgrade since 4D Server's release, adding new objects, operators, and commands requested by the developer community. As a comprehensive but pre-release command catalog for a major, decades-old 4D version, most of its specific commands (particularly the classic resource-file suite, the ASCII cross-platform conversion commands, and the era's Users & Groups password model) are now legacy or superseded by newer 4D capabilities, though the Window-ID and RESOLVE POINTER-style introspection concepts, along with the Events/Methods terminology V6 introduced, remain recognizable parts of the 4D language today.
