# Tech Note: Converting Version 3 Lists into Version 6 Hierarchical Lists

**Author:** Not specified
**Published:** December 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11861

## Overview
This Tech Note provides methods for converting 4D Version 3 lists into the hierarchical list format introduced in Version 6, addressing a common migration challenge of the v3-to-v6 transition era.

## Key Points
- Conversion works for single-level lists only
- Linked lists from v3 cannot be automatically retrieved during the v6 upgrade
- Provides 4D methods to perform the conversion
- Addresses a specific v3-to-v6 migration pain point

## Featured Technology
- 4D v3 list system
- 4D v6 hierarchical lists
- List conversion methods
