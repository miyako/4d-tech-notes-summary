This Tech Note explores a new command available in 4D 2003, BEST OBJECT SIZE, which provides valuable information about how much space a form object will need whether displayed on screen or printed on a page, letting a developer better adjust form size or the amount of content that fits on a printed page. It builds directly on the author's earlier Tech Note #02-37, "Enhanced Print form Capabilities in 6.8.1" (published August 2002, also covered in this batch), recommending readers review that earlier note first since some of its material is reused here, with this note covering only the new BEST OBJECT SIZE-specific information. This close cross-referencing between notes shows how 4D's printing capabilities were iteratively expanded across the 6.8.1-to-2003 versions.
