## Overview
A Tech Note exploring 4D 2003's new BEST OBJECT SIZE command, which calculates how much screen or print space a form object will need, building on an earlier 2002 note about enhanced print form capabilities.

## Key Points
- Introduces the new BEST OBJECT SIZE command in 4D 2003 for calculating an object's needed display/print space.
- Explicitly builds on and cross-references the earlier TN 02-37, "Enhanced Print form Capabilities in 6.8.1".
- Aimed at helping developers better adjust form size or print page content based on object size calculations.

## Featured Technology
- BEST OBJECT SIZE command
- Form/print layout sizing

## Historical Context
Reflects the iterative expansion of 4D's printing/layout command set between 4D 6.8.1 (2002) and 4D 2003, a period of active investment in procedural print control covered by several notes in this batch.
