This Tech Note is a companion piece to TN 22-02 (Computed Attributes in 4D), applying the same computed-attributes concept inside 4D's now-discontinued 4D for Android mobile app generator. Using 4D v19R3 and the Mobile Project editor (File > New > Mobile Project), it builds a schoolDB app with Teachers and Students tables, where an 'exposed' keyword on class getter functions (e.g., `exposed Function get fullName -> $result : Text` combining firstName+lastName, or `exposed Function get GPA -> $result : Real` averaging a JSON-stored grades object) makes computed attributes selectable as publishable fields in the Structure section of the Mobile Project editor. It demonstrates building list/detail forms via drag-and-drop templates (Simple Collection, Profile, Visual Contact, Left Cut Header), creating custom data formatters via a manifest.json (mapping integer grade values to letter-grade icon images through a 'choiceList'), and implementing per-role data filtering and authentication through an On Mobile App Authentication database method that queries Students/Teachers by email and returns userInfo used in ORDA filter-query strings (e.g., `email = :userEmail`) so students see only their own data while teachers see everyone's. The app is then tested via the Android SDK/Android Studio simulator integration built into the Mobile Project editor. While the specific ORDA/computed-attribute mechanics remain accurate 4D concepts, the entire delivery vehicle — the native Android app generator inside 4D — no longer exists as a current 4D product.
