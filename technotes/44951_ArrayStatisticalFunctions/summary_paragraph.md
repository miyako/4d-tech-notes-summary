This Technical Note by David Adams addresses a limitation of 4th Dimension's seven built-in statistical functions (Sum, Average, Min, Max, Std deviation, Variance, Sum squares): they only operate on table fields and are often restricted to specific phases of a PRINT SELECTION report, making them unusable in many other situations such as working with numeric arrays. The accompanying sample database implements a full ArrayStats_* library of statistical routines that work on Real, Integer, and LongInt arrays via pointer parameters, going beyond simple replacements for the native functions to add weighted averages, range, mode, and frequency-count calculations, plus support for computing variance/standard deviation from either a sample or a full population. Each routine (ArrayStats_GetMean, GetMedian, GetMin, GetMax, GetMode, GetFrequencyCounts, GetRange, GetStandardDeviation, GetSum, GetSumSquares, GetSumSquaresAlt, GetVariance, GetWeightedMean) carefully validates its incoming pointer parameter (checking for nil pointers, non-numeric array types, and empty arrays) before running its core calculation, recording any problems through a companion ArrayStatsError_Set/Get/GetDefinition error-code system with 14 documented error codes. The note explains the mathematical background behind several routines, such as why sum-of-squares (summing squared distances from the mean) is used instead of a raw distance sum (which always totals zero), and the difference between the standard "sum of squared deviations" method and an alternate "computational method" formula for sum squares. GetMode and GetFrequencyCounts work together to identify one or more modal values (and their frequency counts) in a dataset, sorted by value, while GetWeightedMean computes weighted averages useful for scenarios like combining differently-weighted grade components. All variables and parameters are explicitly typed for compiler compatibility, and the note recommends compiling with "All variables are typed" preference enabled. The featured technology is 4D's classic array/pointer-based programming model applied to build a reusable, generically-typed statistical function library, a style of code characteristic of pre-collection, pre-ORDA 4D development.
