This Tech Note explains the concept of a "bind" in 4D Open, the plug-in used to connect one copy of 4D (or 4D Client) to a separate 4D Server, describing it as a way to connect data from one 4D system to another — for example, linking several fields from a 4D Server to fields or variables in a different 4D database. By binding two data sources together, data can flow back and forth between the two systems, and the note walks through the basics of setting up such a bind.
