Written by Gilles Mellot of 4D S.A., this Tech Note delivers a small, portable development utility for a genuine 4D v6.5-era limitation: the language had no built-in way to display the contents of a BLOB field on a form. The accompanying sample database provides a single Wood_Blob project method plus one form that any 4D structure (v6.5 or later) can adopt to browse BLOB fields directly, using a hierarchical pop-up menu (built at On Load by scanning every table and field for Is BLOB type) to choose which BLOB field to inspect. The tool displays the selected BLOB's contents in decimal, hexadecimal, and binary simultaneously, supports navigating through the BLOB in 720-byte pages via next/previous/first/last-segment buttons, lets the user jump to a specific byte offset, includes a search dialog for locating ASCII or hexadecimal byte sequences, and offers a general-purpose base-conversion dialog (binary, base 3, 5, 8, 10, hex) built on the same F_Dec2Base/F_Base2Dec conversion routines used internally. An On Timer form event continuously updates the hex/decimal/binary displays as the user highlights different byte ranges in the hex text area, and a print button outputs the current BLOB view.
