This March 1996 Tech Note by David Adams serves as an overview for a series of Internet-focused Tech Notes published that month (TN 96-12 on 4D as a CGI, TN 96-13 on HTML construction, and TN 96-14 on converting arrays to HTML tables), framing 4D's place in the rapidly growing Internet/Web ecosystem for developers and consultants. It surveys several categories of 4D-Internet integration: adding interactivity to a static web site (via an off-the-shelf server like WebSTAR handling standard HTTP, with 4D providing custom search/data-collection features through AppleEvent-based CGI bridges like NetLink/4D or System 7 Pack, positioned as faster and more capable than AppleScript-based alternatives); managing and producing web pages from 4D's relational data and file-system access (illustrated with ACI's own Webster database, which the note says produced the entire ACI web site from a database in about ten minutes); database publishing on the web (treating HTML generation as a kind of structured export, ranging from simple static page generation to full dynamic search-serving); connecting to mail, FTP, and the web as an Internet client via commercial toolkits like PDM Internet Tools; running a full Web, FTP, or mail server written entirely in 4D using low-level TCP/IP toolkits (ITK, TCP ToolKit) or complete server products (NetWings, Web Server 4D); and serving 4D Server data directly over the Internet via its native TCP/IP support, recommending 4D Open for reduced-bandwidth remote client access over slow connections. It closes with a product-contact directory of contemporaneous third-party Internet add-ons for 4D, a short recommended-reading list (including O'Reilly's Internet/TCP-IP references), and a jargon glossary defining CGI, HTML, HTTP, POP3, and SMTP for readers new to the space. As a fully readable full-PDF Tech Note, this summary reflects the complete document.
