This Tech Note introduces a component that recreates the classic "User Mode" familiar to long-time 4D developers — a generic maintenance interface that lets an administrator or designer create, modify, or delete records for any table, sort/order/query data, and use import, export, and the report editor, without being constrained by the application's normal business logic. Crucially, because it is delivered as a component rather than relying on 4D's Design-mode-only User Mode, this functionality remains available even in a built (compiled) application. The component displays a list box for the currently selected table (with a toolbar popup to switch tables), supports long-click-to-edit, and exposes fully functional Delete, Order, Query, Show All/Show Selection, Report, Export/Import, and Execute (formula editor, respecting SET ALLOWED METHODS) actions. The note documents the component's three exposed methods: UserMode_Show (opens the maintenance window, optionally targeting a specific table), UserMode_Access (a per-table, per-feature Boolean array to enable/disable Show, Modify, New, Delete, Report, Import, Export, and Execute), and UserMode_Forms (assigns dedicated maintenance-purpose input forms per table, since normal application forms may enforce business rules unsuitable for raw data maintenance). Installation is a simple drag of the component into the structure's component folder.
