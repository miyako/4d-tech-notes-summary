This Tech Note demonstrates how to modernize a legacy 4D application — using the venerable 4D Invoice demo (based on 4D 16) as its subject — into a single-window, Microsoft Outlook-style interface without a full rewrite, addressing the performance and UX drawbacks of classic double-click-to-open-a-new-process workflows, which increase network/process load especially over slower home-office connections. The approach is delivered in three composable, class-based pieces requiring only project mode and 4D 20 R2–R5 language features (with an older-4D-compatible toolbar class available separately on GitHub): a resizable, end-user-customizable ribbon Toolbar built from two classes (cs.Toolbar and cs.Toolbar_Button) that automatically shrinks buttons to icon-only or grouped-menu forms as window width changes, backed by user-editable Buttons.json/Default.json/User.json settings files; a generic ORDA_Listbox class that dynamically assigns the displayed table and column expressions at runtime, letting end users add/remove/reorder/resize columns and persist that layout; and a Preview Mode pattern that replaces double-click-to-edit-in-a-new-window with an Outlook-like single click into an inline preview area, driven by an On Selection Change handler that checks the previously selected entity for unsaved touched attributes, offers to save via entity.save(dk auto merge), and handles optimistic-locking conflicts. A generic-with-override pattern (e.g., a per-table useAll() or quickSearch() class function checked via `If ($class.useAll#Null)`) lets developers override default list/search behavior per table without a large centralized case statement. The note closes with an ORDA network-traffic case study comparing classic double-click navigation (11KB out/14KB in, 124 packets) versus the single-window ORDA approach (92KB out/6KB in, 50 packets), explaining ORDA's upfront batching/caching strategy and showing how the ORDARequests.json log and "local" class functions can further reduce server round-trips — positioning the whole exercise as a low-risk, incremental path to modernize classic 4D UIs while reducing server load and network latency impact, especially for remote users.
