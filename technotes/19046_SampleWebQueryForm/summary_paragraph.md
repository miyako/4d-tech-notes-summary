This Tech Note (TN 01-48, 4D v6.7, Mac & Win, published October 30, 2001) by Eric Saltzen of 4D, Inc. demonstrates building a web-based query form against a stock-symbol database using 4D 6.7's new semi-dynamic HTML tag set. Two HTML forms are provided: a simple single-field symbol search (findStockSymbol.shtm) and an advanced form (findStockGeneral.shtm) that partially emulates 4D's built-in Query Editor by letting the user choose a field, a comparator (equal to, greater than, etc.), and a conjunction (AND/OR/Except) for each of several search rows. Both forms are populated dynamically via a 4DSCRIPT call to WEB_QueryFormFill, which fills parallel field-name and value arrays consumed by a 4DLOOP tag to render an HTML table of inputs, while 4DVAR tags echo back previously entered values if the form must be redisplayed after a validation error. On submission, the WEB_QueryFormHandle method uses the 6.7 command GET WEB FORM VARIABLES to retrieve posted values, builds a multi-line QUERY command string conditioned on which fields were filled in, and executes it with the EXECUTE command, then reports zero-match or too-many-match conditions back to the user before sending the results page. The note closes by showing how the results page uses a 4DSCRIPT call to substitute a stock's ticker symbol into an exchange-specific lookup URL, illustrating a complete pattern for building parameterized, dynamically-assembled search queries for a web audience with 4D 6.7's tag-based publishing model.
