This Tech Note (TN 01-48, 4D v6.7, Mac & Win, published October 30, 2001) presents an example of building simple and advanced HTML web query forms against a 4D database. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_46-49_(OCT)/01-48_Web_Query_Form.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This Tech Note examines a web-based query form for 4th Dimension 6.7 based on a stock symbol database. Two sample HTML forms are given, a simple one with a single text field and an advanced form that partially emulates 4D's built in Query editor. The techniques illustrated can be expanded upon and easily adapted for use in your own databases. Its featured technology centers on 4D Tags, HTML web forms, 4D built-in Web Server query emulation, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note builds a web-based search form against a stock-symbol database, offering both a simple single-field HTML form and a more advanced one that partially emulates 4D's native Query Editor, all served through 4D's tag-based web publishing. The underlying idea of a web search form against 4D data remains universally relevant, but the specific 4D Tags/HTML-embedded implementation shown is a legacy technique that has been superseded by REST/ORDA-backed APIs consumed by modern JavaScript search UIs.
