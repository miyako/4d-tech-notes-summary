This Tech Note documents the Contact Manager module (a "portlet" in 4D Portal terminology), which lets a user store the kind of information typically kept in a Palm or Windows CE hand-held device, cell phone, or other PIM (Personal Information Management) software, and access it anywhere on the Web through 4D Portal. The Contact Manager was deliberately designed to be very small, making it easy to understand, adapt to custom needs, or move into a developer's own custom web application. The note explains that almost all of the portlet's logic lives in a single method, CGI_ContactStart, since the Contact Manager is "event driven" and responds to different events passed to it as URLs — meaning much of the note is effectively a close study of that one method.
