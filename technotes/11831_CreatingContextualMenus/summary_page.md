# Tech Note 99-06: Creating Contextual Menus

**Author:** Not specified
**Published:** April 1, 1999 | **Product/Version:** 4D v6.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11831

## Overview
This Tech Note explains how to create contextual (right-click) menus on both Macintosh and Windows platforms in 4th Dimension, covering menu creation and customization options.

## Key Points
- Contextual menus were already established on Windows; Mac OS 8.x introduced them to the Macintosh.
- The note covers cross-platform contextual menu implementation in 4D.
- Customization options include font styles, separation lines, checkmarks, icons, and shortcut keys.
- Menu items can be shown as disabled/grayed out.
- Provides techniques for building platform-native UI interactions.

## Featured Technology
- 4D v6.5
- Pop-up/contextual menus
- Cross-platform UI development
- Mac OS 8.x contextual menu support

## Historical Context
**Status:** Obsolete

Modern 4D provides built-in support for contextual menus through form events like On Alternative Click and commands like Dynamic Pop up menu, making the manual techniques described in this note largely unnecessary.
