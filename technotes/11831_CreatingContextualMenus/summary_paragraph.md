This Tech Note discusses how to create contextual (right-click) menus on both Macintosh and Windows platforms within 4th Dimension. With the introduction of Mac OS 8.x, contextual menus became popular on the Macintosh, complementing the existing Windows convention. The note explains the mechanics of creating contextual menus and documents the available customization options including font styles, separation lines, checkmarks, icons, shortcut keys, and the ability to show disabled menu items. It covers cross-platform considerations for implementing contextual menus consistently on both Mac and Windows. The techniques described provided 4D developers with the tools to create more intuitive, platform-native user interfaces that matched user expectations on both operating systems. This was particularly important during the late 1990s when cross-platform consistency was a key selling point of 4D applications.
