This Tech Note presents a versatile, text-based progress display system that is easy to add to a database and easy to drive from application code. The progress window can show multiple lines of text that can each be updated independently, displaying whatever status information the developer chooses, making it well suited to monitoring a complex sequence of events and troubleshooting complicated code by providing a live, updating summary of conditions as they occur. Notably, the final results of a monitored activity can even be redisplayed after the process itself has already finished. The technique demonstrates a practical use of a two-dimensional array to store the progress state, and shows how interprocess communication can be streamlined to support this kind of real-time status reporting across 4D processes.
