This Tech Note is the first in a two-part series implementing a UDDI (Universal Description, Discovery, and Integration) client using 4D 2003's built-in Web Services feature. UDDI is described as a protocol built on top of SOAP, used for discovering and describing available web services in a registry, and the note assumes the reader already understands SOAP, Web Services, and XML fundamentals. It promises to detail the process of using 4D's Web Service Client commands together with the new XML parsing commands to build a working UDDI inquiry client. Only the short on-page teaser text could be recovered here, so the specific UDDI query implementation is not available, but this note is a good, advanced follow-on to the more introductory Web Services notes covered elsewhere in this batch.
