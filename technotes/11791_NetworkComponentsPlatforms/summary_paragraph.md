This Tech Note provides a reference table documenting 4D's network components, describing how they install and function on various platforms. In the late 1990s, 4D operated in a complex networking environment where both AppleTalk (the native Mac networking protocol) and TCP/IP had to be supported across Mac OS and Windows platforms. The network components governed how 4D Client connected to 4D Server, how database files were shared, and how network services were discovered on the local network. This information was critical for system administrators deploying 4D Client/Server in mixed-platform environments — a common scenario when businesses ran both Macintosh and Windows machines. The table format suggests a quick-reference document covering component names, supported platforms, and installation notes.
