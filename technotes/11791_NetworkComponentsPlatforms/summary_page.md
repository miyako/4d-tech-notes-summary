# Tech Note: Network Components on Various Platforms

**Author:** Not specified
**Published:** January 1, 1998 | **Product/Version:** Network Components | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11791

## Overview
This Tech Note provides a reference table documenting how 4D's network components install and function across Mac and Windows platforms. It served as a quick-reference for administrators deploying 4D in mixed-platform networking environments.

## Key Points
- **Reference table format:** Documents network component names, installation behavior, and platform compatibility.
- **Cross-platform focus:** Covers both Mac OS (AppleTalk and TCP/IP) and Windows (TCP/IP) networking.
- **Deployment guide:** Aimed at system administrators configuring 4D Client/Server networking.

## Featured Technology
- 4D network components (client/server connectivity layer)
- AppleTalk and TCP/IP protocol support
- Cross-platform Mac/Windows networking

## Historical Context
**Status:** Obsolete

The networking landscape described in this 1998 note has fundamentally changed. AppleTalk was deprecated by Apple and removed from macOS entirely; all modern networking is TCP/IP-based. 4D's client/server networking layer has been rewritten multiple times, and the concept of separately installable "network components" no longer applies. Modern 4D Server uses a proprietary TCP-based protocol that is configured through the application's preferences rather than through separate component installation. The note is a useful artifact for understanding the cross-platform networking complexity of late-1990s computing.
