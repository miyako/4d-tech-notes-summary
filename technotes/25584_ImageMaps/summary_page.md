## Overview
A Tech Note explaining client-side and server-side HTML image maps, and how they can be implemented for a web site, including one driven by a 4D web application.

## Key Points
- Explains image maps: a single image linking to multiple destination addresses based on click location.
- Distinguishes client-side image maps (handled entirely in the browser via HTML) from server-side image maps (coordinates sent to the server).

## Featured Technology
- HTML image maps
- Client-side vs. server-side image maps

## Historical Context
Image maps were a common web design technique in the late 1990s/early 2000s, before CSS-based navigation and richer client-side scripting largely replaced their common use cases; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Historical Interest Only

Image maps (especially server-side ones) are a largely obsolete web design pattern today, replaced by CSS/JavaScript-based interactive UI and, where region-based image interactivity is still needed, by SVG or canvas-based click regions; the note remains useful mainly as a historical snapshot of early-2000s web UI techniques applied to 4D-driven web sites.
