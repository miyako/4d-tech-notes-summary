This Tech Note explains image maps, a common web design tool that lets a single image link to multiple destination addresses depending on where within the image a user clicks. It distinguishes the two main types: client-side image maps, where HTML embedded in the page directs the browser to a new address based on click coordinates without a server round-trip, and server-side image maps, which look the same to the end user but instead send the click coordinates to the server, which then determines the destination address.
