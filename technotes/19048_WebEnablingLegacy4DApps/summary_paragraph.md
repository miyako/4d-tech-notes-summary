This Tech Note (TN 01-46, 4D v6.7, Mac & Win, published October 30, 2001) presents an overview of approaches for exposing client-server 4D databases to the internet, focused on 4D-Tags-based semi-dynamic pages. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4d.com/aci_technical_notes/2001/windows/tn_2001_46-49_(oct)/01-46_legacy_web-enabling.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This tech note is an provides an overview of what's involved in updating client-server 4D databases so they can be accessed via the internet. Although other approaches are discusssed, the use of semi-dynamic pages using 4D tags is covered most thoroughly. Its featured technology centers on 4D Tags, Semi-dynamic web pages, 4D built-in Web Server, Client-server web publishing, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note surveys approaches for exposing an existing client-server 4D database to the internet, focusing mainly on semi-dynamic HTML pages built with 4D Tags served by 4D's built-in Web Server. 4D Tags and the built-in web server still exist and function in current 4D versions, but 4D's web strategy has since shifted decisively toward REST APIs built on ORDA combined with modern JavaScript front ends (or low-code Qodly Studio apps), making tag-embedded HTML page generation a legacy pattern rather than the recommended approach for new web-enabling projects.
