This Tech Note describes the QuickTime Container plug-in, which lets a 4D developer open a window that plays a QuickTime-supported movie or audio file directly inside a 4D application, supporting every format QuickTime itself supported at the time. Using the plug-in's standard QuickTime controller requires only minimal coding effort, letting developers add movie/audio playback to a database with just a few lines of 4D code. For developers who need more control, the plug-in also exposes optional commands giving full programmatic access to playback state and behavior, enabling a fully custom user interface to be built around the underlying QuickTime engine rather than relying on the default controller widget. The plug-in fits into the broader category of 4D plug-ins that extend the base 4D language by wrapping a native OS/framework capability (in this case, Apple's QuickTime multimedia framework) as callable 4D commands. Its target technology is squarely QuickTime, meaning it depended on QuickTime being installed and licensed on both the Mac and Windows sides, since QuickTime was cross-platform at the time.
