This tech note documents 4D Write Pro's document-merging capability, centered on the WP INSERT DOCUMENT command, which lets a developer insert the entire body content of one Write Pro document into another (or into a specific range/element within it), enabling efficient template reuse for generated documents like contracts or reports. The core concept is the "Write Pro range," a start/end position anywhere in a document (a paragraph, header, table cell, or a text selection obtained via WP Selection range) that serves as the insertion target; three insertion modes are available via the wk append, wk prepend, and wk replace constants. The command intelligently merges body-scoped attributes like paragraph/character styles: if a style name doesn't exist in the target it's created, if an identical style already exists nothing happens, and if a same-named but differently-defined style exists it's copied in and renamed with an incrementing suffix (e.g. "Custom1") to avoid silently overwriting the original. Only the body and its supporting properties (styles, tab settings) are merged — headers, footers, and backgrounds are explicitly excluded and must be handled via separate per-element template documents inserted individually. To merge only a portion of a document (e.g., a highlighted selection) rather than the whole body, the note shows creating a temporary document scoped to a Write Pro range via WP New, then using that temporary document as the "second document" parameter to WP INSERT DOCUMENT. Five bundled demos incrementally build up these concepts: simple append, controllable insertion mode via a drop-down, style-conflict handling, omitted elements (headers/footers/backgrounds), and partial-selection merging.
