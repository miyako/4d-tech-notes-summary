# Tech Note 99-05: Preflight Checklist

**Author:** Not specified
**Published:** April 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11830

## Overview
This Tech Note provides a comprehensive checklist for verifying every facet of a 4D-based application before delivering the final version to end users, intended for use by developers and QA teams.

## Key Points
- Addresses the problem of developers overlooking errors in applications they've worked on for a long time.
- Provides a structured checklist covering important pre-deployment verification items.
- Designed to be given to Software Quality Assurance teams.
- Covers most important issues for final application review.

## Featured Technology
- 4D v6.0
- Application deployment and QA
- Software testing methodology

## Historical Context
**Status:** Historical interest only

The concept of a preflight checklist before deployment is timeless and remains relevant to any software development process. However, modern 4D development benefits from automated testing, CI/CD pipelines, and significantly improved Build Application tools that complement manual checklists.
