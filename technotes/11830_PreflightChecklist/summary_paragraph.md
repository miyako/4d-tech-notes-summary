This Tech Note presents a preflight checklist for developers to use before delivering a completed 4D-based application to end users. The note acknowledges that when developers have worked with an application for a long time, it becomes easy to overlook even obvious errors. The checklist is designed to be given to a Software Quality Assurance team and covers the most important issues that need verification before deployment. It provides a systematic approach to final application review, covering the various facets of a 4D application that should be checked and rechecked. This kind of structured QA process was especially important in the 4D v6 era when automated testing tools were limited and manual review was the primary quality assurance method. The note represents solid software engineering practice applicable to any development platform.
