This Technical Note covers 4D 2004's newly introduced native ODBC support, which removed the previous requirement for a separate ODBC plug-in when pulling data from external ODBC-compliant data sources into a 4D database. The teaser highlights Microsoft Excel as a particularly compelling target: Excel was widely useful but had inherent limitations that 4D could help overcome, and the new native ODBC functionality made pulling Excel data into 4D easier than before. The note states its goal is to illustrate and describe this new native ODBC functionality end to end, including a practical example for beginning to bring external data into an existing 4D application, though the exact commands, dialogs, and step-by-step example are not recoverable since only the brief on-page teaser (not the full PDF/example archive) survived for this entry. As one of several ODBC-focused notes published around 4D 2004's release, it reflects a broader push that release cycle to reduce friction for developers integrating 4D applications with common external data sources like spreadsheets and other databases.
