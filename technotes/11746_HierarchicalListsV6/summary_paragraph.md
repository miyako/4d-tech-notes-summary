This Tech Note explains the differences between the "linked" list technique that 4D developers used in version 3.x of 4th Dimension and the native hierarchical list feature introduced in version 6, and it summarizes the steps for creating hierarchical lists in V6. Only the on-page teaser paragraph for this asset survives in this archive, so this summary is based solely on that description rather than the full technical content of the note. In the 3.x era, developers who wanted tree-like, expandable/collapsible list displays had to fake the effect using "linked" choice lists — a workaround approach — because 4D had no built-in hierarchical list object. Version 6 changed this by introducing genuine hierarchical lists as a first-class feature, letting developers build nested, expandable lists (of the kind used for pop-up menus, outline views, or navigation trees) without the older workaround. The featured technologies are therefore the older linked-list technique and the new native hierarchical list capability that replaced it. Because only the teaser is available, the specific numbered creation steps, the example database, and any accompanying language commands the full note likely covered cannot be described here.
