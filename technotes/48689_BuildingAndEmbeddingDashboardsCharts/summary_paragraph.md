A slew of new features have been introduced in the 4D Ajax Framework v11. Most notably, is the introduction of Dashboards. Dashboards are widget-like mini apps that provide visual depictions of real time information and performance metrics on your web page. This Technical Note will focus on building and embedding Dashboards to a custom page (already provided). One Dashboard and one Chart will be built and embedded. Published January 23, 2008 as Technical Note 03-08 for 4D Web 2.0 Pack v11 (Mac &amp; Win), this note was written by Joe Resuello, Technical Marketing Engineer, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
