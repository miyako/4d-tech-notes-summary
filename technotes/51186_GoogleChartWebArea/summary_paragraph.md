This Technical Note updates the earlier Google Chart API approach (TN 08-04) to use the new Web Area form object introduced in 4D v11 SQL Release 2, replacing the previous 4D Live Window plug-in integration method. The note explains how Google's Chart API works as a remote service—developers construct a parameterized URL with encoded data and chart options, send it to Google, and receive a rendered PNG image in response. A sample 4D database is included that demonstrates building a graphical chart configuration interface with five form pages: (1) Chart Title page for setting title text, font size (in points), and RGB color values (using hex notation and slider controls), (2) Data Import page for selecting tables and numeric fields to plot as Y-axis values, (3-4) Chart Styling pages for configuring appearance (series colors, background gradients, grid lines) using hex color codes and slider controls, and (5) a URL display page showing the complete parameterized Google Chart API call. The note details Google Chart API parameter syntax (cht for chart type, chs for size, chd for data encoding, chtt for title, chts for title styling, chco for series colors, chf for fills, chxt/chxl for axis labels), explains the CSV rules for data encoding, and walks developers through accessing 4D database fields to populate chart data dynamically, achieving live chart updates as users modify input on each form page.
