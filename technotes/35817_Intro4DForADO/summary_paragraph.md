ADO, short for ActiveX Data Objects is Microsoft's newest high level interface for data objects. 4D for ADO enables the execution of queries on most of the RDBMS that run on Windows, including MS SQL Server, Oracle 8i/9i, Sybase Adaptive Server Enterprise (ESA), MS Access and many others. Since ADO enables access to Active Directory Services, the 4D for ADO plug-in can also be used to interact with data sources that support ADO.Net back ends such as LDAP servers and other Internet data sources. 4D for ADO plug-in can be used with 4D 2004 on both Windows and Macintosh platforms. This 2005-era Tech Note (TN 05-04) was published for 4D version 2004 on Mac & Win, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). Featured technology associated with this note includes: 4D for ADO plug-in, Microsoft ActiveX Data Objects (ADO), MS SQL Server / Oracle / Sybase ASE / MS Access connectivity, LDAP/Active Directory access via ADO.Net. This note introduces the 4D for ADO plug-in, which let 4D 2004 developers query external RDBMSes (MS SQL Server, Oracle, Sybase ASE, MS Access) and directory services via Microsoft's ActiveX Data Objects interface, predating 4D's own SQL engine (v11 SQL, ~2007) and ODBC-first connectivity story. The specific ADO plug-in and Windows-centric ADO technology it relies on are now obsolete, since modern 4D applications connect to external databases via ODBC, dedicated SQL/JDBC plugins, or REST APIs rather than ADO.
