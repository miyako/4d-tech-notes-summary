## Overview
ADO, short for ActiveX Data Objects is Microsoft's newest high level interface for data objects. 4D for ADO enables the execution of queries on most of the RDBMS that run on Windows, including MS SQL Server, Oracle 8i/9i, Sybase Adaptive Server Enterprise (ESA), MS Access and many others. Since ADO enables access to Active Directory Services, the 4D for ADO plug-in can also be used to interact with data sources that support ADO.Net back ends such as LDAP servers and other Internet data sources. 4D for ADO plug-in can be used with 4D 2004 on both Windows and Macintosh platforms.
