Contributed by Thomas Maul of 4D Germany, this Tech Note documents PhotoAdjust, a cross-platform compiled plug-in that lets 4D developers adjust digital camera photos directly within a 4D application — exposure, brightness, contrast, saturation, sharpening, cropping, and resizing. It describes the plug-in's three core commands (Photo_SetImage, Photo_GetImage, Photo_Adjust) and explains how a bundled component provides a ready-to-use adjustment dialog that can be localized and further customized by developers. The note walks through using the example database and adjust dialog, and documents the plug-in's system requirements at the time: Mac OS 10.5+ or Windows 7, explicitly excluding Windows XP and Vista. It's a compact, practical reference for integrating third-party photo-adjustment functionality without building custom image-processing code from scratch.
