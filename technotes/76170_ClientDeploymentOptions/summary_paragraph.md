Josh Fletcher's Tech Note tackles a foundational 4D Client/Server architecture decision: whether to deploy the standard 4D software package and connect in Remote mode, or to build and deploy a Merged client application. It defines key terminology (Client Cache, Client Software, Merged, Automatic Client Update, Deployment Client, Upgrade Client) before giving an overview of both deployment techniques and the software involved in each. Separate sections enumerate the advantages and disadvantages of 4D Remote (arbitrary server access, server failover, interpreted mode, simplified development, but lacking automatic client update and customization) versus Merged clients (automatic client update, customization, but greater development overhead and deployment complexity). The note explicitly scopes its applicability to 4D v11 SQL and v12, noting that concepts may not translate cleanly to older 4D versions. It equips developers and consultants to make an informed, project-specific choice between the two deployment models.
