# Tech Note 98-25: Proportionally Resizing Groups of Objects on a Form

**Author:** Not specified in source document
**Published:** March 1, 1999 | **Product/Version:** 4D v6.5 | **Platform:** Mac &amp; Win
**Page:** https://kb.4d.com/assetid=11808
**Download:** Not available

## Proposition
This Tech Note demonstrates how to use the On Resize event and MOVE OBJECT command to automatically and proportionally resize groups of objects when a form is resized.

## Key Points
- Uses the On Resize form event (new in 4D V6)
- Employs MOVE OBJECT to reposition/resize objects programmatically
- Maintains proportional relationships between grouped objects
- Includes reusable code and an example database
- Full implementation instructions provided

## Featured Technology
- On Resize Event
- MOVE OBJECT
- Form Design
- 4th Dimension V6

## Context / Positioning
The On Resize form event was a significant new capability in V6, enabling responsive form behavior for the first time in 4D.

## Historical Commentary
**Status:** Superseded

Form object resizing remains a relevant UI concern in 4D, though the specific V6 approach using On Resize and MOVE OBJECT has been supplemented by more sophisticated form layout options in modern 4D, including automatic sizing properties, constraints, and responsive form design features.
