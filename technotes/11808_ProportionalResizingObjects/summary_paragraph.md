This Tech Note describes how to use the new On Resize form event and the MOVE OBJECT command in 4D V6 to proportionally resize groups of objects on a form automatically as the form window is resized. The technique ensures that all objects in a group maintain their relative proportions and positions when the user adjusts the form size, providing a more polished and professional user interface. The note includes an example database with reusable code and full implementation instructions that developers could adapt for their own projects. The On Resize form event was a new feature in 4D V6, enabling developers to respond programmatically to form size changes for the first time. This capability was important for creating flexible, user-friendly forms that adapted to different screen sizes and user preferences.
