This Tech Note demonstrates how to build a Gantt chart — a horizontal bar chart visualizing planned vs. actual progress of sub-projects within a main project — using the 4D SVG Component newly bundled with 4D v11 SQL Release 3. It opens with project-management background on Gantt charts (what they show, when to use them, how to construct one) before diving into the included `G_Chart.4dbase` component's implementation: the `Gantt_Start` method declares chart dimensions from a computed date range, draws a scaled grid of vertical day lines and month labels using `SVG_New_line`/`SVG_New_text`, then loops through sub-project arrays to draw named rows with diamond-shaped "polygon" markers for planned/actual start and end dates connected by gradient-filled duration rectangles, finally rendering everything to a form picture variable with `SVG_Export_to_picture`. A second method, `Gantt_Use`, implements interactivity: clicking a start/end polygon selects it (parsing its SVG element ID to determine sub-project number, planned/actual type, and position), then clicking a grid line deletes and redraws the corresponding line/polygon at the new date, persisting the updated dates back into the chart's data arrays and an XML file that records chart definitions (table/field bindings and boundary dates) for later reloading. Usage is wrapped in a six-step Wizard (name the chart, choose a table, choose the main-project name/label fields, choose sub-project name/date fields, set date boundaries, save) plus a Load Gantt Chart dialog for retrieving, deleting, or creating saved charts. A sample database (`TestGanttChart.4dbase`) with a single-table "Building a House" example ties the pieces together. The note closes by noting the component is illustrative rather than a full project-management product, aimed at developers who want to see how far 4D SVG Component commands can be pushed to build fully custom, dynamic graphics.
