This Tech Note explains how to create and customize a Windows Program Item (or Start Menu entry) that launches an executable database built with 4D Compiler Pro merged with 4D Engine. It starts by contrasting platforms: on the Macintosh, merging with 4D Engine produces a single stand-alone double-clickable application that appears automatically in the Finder, but on Windows the compiler generates three separate files — Customdb.EXE, Customdb.4DC, and Customdb.RSR — placed in a Distrib folder, with the executable defaulting to a generic application icon (Appendix B of the 4D Compiler Reference Manual is cited for creating a custom icon file). The note then gives detailed, screenshot-referenced, step-by-step instructions for Windows 95: adding the executable to the Start/Programs menu via Taskbar Properties → Start Menu Programs → Add → Browse, naming the shortcut, and then customizing its icon via Taskbar Properties → Advanced → selecting the shortcut's Properties → Shortcut tab → Change Icon. A parallel set of instructions covers Windows NT and Windows 3.1.x for Workgroups, which use Program Manager Groups and Program Items instead: creating a New Program Item, filling in its Description and Command Line (including the full path to the compiled EXE), and using the Change Icon dialog (pointing to a saved .ico file, or browsing PROGRAM.EXE/MOREICONS.DLL for additional built-in icons) to assign a custom icon. The summary reiterates that on Windows, because the compiled/merged output consists of multiple files rather than one, developers must take these extra manual steps to create the illusion of a single, polished, double-clickable application comparable to the Macintosh experience. The featured technology is entirely 4D Compiler Pro's Windows merge/deployment output combined with native Windows 95/NT/3.1 shell configuration tools of that era.
