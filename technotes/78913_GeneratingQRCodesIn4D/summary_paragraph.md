This Tech Note tackles a common line-of-business need — generating QR codes (for contact vCards, URLs, phone numbers, emails) — inside a 4D application without any native QR command. It uses a template.html file wired to the open-source 'QR Code Styling' JavaScript library (bundled locally for offline use) and 4D's PROCESS 4D TAGS command with embedded $4DTEXT tags to inject data (and an optional base64 logo image) into the page before it's rendered. Two output paths are demonstrated: displaying the generated QR code directly in a Web Area via WA OPEN URL, and converting the QR code to a static picture by using WA Run offscreen area plus an OffscreenArea class (with an onEvent handling On End URL Loading) to extract the canvas as base64 via WA EXECUTE JAVASCRIPT FUNCTION, then decoding it to a 4D picture with BASE64 DECODE and BLOB TO PICTURE. The note explains the vCard text format for contact-adding QR codes and shows how customizations like a center logo or dot styling are controlled purely through the JavaScript library's options object. A reusable project method, getQRPicture, is provided so developers can drop QR generation into any part of an application that needs a picture-typed QR output. This is a practical, code-complete example of bridging 4D's server-side logic with client-side JS rendering via the Web Area component, a pattern widely applicable beyond QR codes.
