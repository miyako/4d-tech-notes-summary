This Tech Note showcases a new feature introduced in 4D version 6.5: a significantly enhanced Picture Library that made it easy for developers to add animated graphics to their forms. Its core proposition is accessibility — achieving a bit of visual polish ("flash") on a form through animation, without requiring any third-party plug-in, using only 4D's built-in Picture Library tooling. The note walks through the step-by-step details of setting up this animation feature and includes an example database that demonstrates the resulting effect in practice. It explicitly notes that no code is required to get basic animation working, though developers could optionally add code for finer control over playback and timing, making the feature approachable for less code-centric form designers as well as advanced developers wanting programmatic control. The featured technology is the 4D v6.5 Picture Library itself and its new animation capability, sitting alongside other picture-related features of that release (such as picture operators, covered in a related Tech Note in this same batch). This kind of feature announcement/tutorial note was typical of how 4D communicated new version capabilities to its developer community upon each major release, pairing a plain-language explanation with a working sample database. For UI designers at the time, this represented a low-effort way to add liveliness to otherwise static forms — splash screens, status indicators, or decorative touches — squarely within the constraints of the classic Design Mode forms engine of 4D v6.5.
