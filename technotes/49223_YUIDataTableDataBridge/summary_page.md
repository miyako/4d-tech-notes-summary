# Integrating the YUI DataTable with the 4D Ajax Framework Data Bridge

## Overview
Demonstrating the flexibility of the 4D Ajax Framework to interoperate with other third-party JavaScript libraries, this note shows how to integrate Yahoo's YUI DataTable widget with a 4DAF web application using the framework's Data Bridge commands to feed server-side 4D data into the YUI-rendered table, with sample databases provided for both 4D 2004 and 4D v11 SQL.

## Key Points
- Published March 19, 2008 as Technical Note 08-10.
- Targets 4D Web 2.0 Pack v11 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Data Bridge
- YUI (Yahoo User Interface) Library
- YUI DataTable widget
- Cross-framework JS integration

## Historical Context
A snapshot of the late-2000s JavaScript ecosystem, when Yahoo's YUI library was a mainstream choice for rich web widgets; both YUI (discontinued by Yahoo in 2014) and the 4D Ajax Framework it integrates with here are long defunct, making this note interesting mainly as a historical record of that era's web-integration patterns.

**Status:** obsolete

**Related updates:**
- Yahoo officially discontinued the YUI Library in 2014
- 4D Ajax Framework (4DAF) has also been discontinued; modern 4D web integrations use REST/ORDA with any current JS framework, or Qodly Studio's built-in components
