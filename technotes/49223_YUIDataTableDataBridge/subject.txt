Tech Note: Integrating the YUI DataTable with the 4D Ajax Framework Data Bridge (TN 08-10, 4D Web 2.0 Pack v11, March 19, 2008) — Demonstrating the flexibility of the 4D Ajax Framework to interoperate with other third-party JavaScript libraries, this note shows how to integrate Yahoo's YUI DataTable widget with a 4DAF web application using the framework's Data Bridge commands to feed server-side 4D data into the YUI-rendered table, with sample databases provided for both 4D 2004 and 4D v11 SQL.
