# Tech Note 05-35: 4D Internet Commands - Net Commands

## Overview
**Note:** this entry's content_source is `teaser_only` — the full PDF/example archive could not be recovered in this environment, so the following is based solely on the short on-page teaser text.

Per the teaser, this note expands an earlier network "ping" utility (TN 00-43) with two additional network diagnostic capabilities: DNS/reverse-DNS lookup, and the classic UNIX "finger" command, implemented using the 4D Internet Commands plug-in.

## Key Points (from teaser)
- Builds on a prior ping utility introduced in Technical Note 00-43.
- Adds DNS and reverse-DNS lookup functionality.
- Adds support for the old UNIX finger command.
- Positioned as a tool to help developers isolate network-related problems while deploying 4D applications.
- Implemented using commands from the 4D Internet Commands plug-in.

## Featured Technology
- 4D Internet Commands plug-in
- Ping utility
- DNS / reverse DNS lookup
- UNIX finger command

## Historical Context
The full archive for this Tech Note could not be recovered (old-format download not accessible in this environment), so this summary is necessarily limited to the teaser. The finger protocol has been almost universally deprecated and disabled across networks for security reasons since the late 1990s/2000s, and the 4D Internet Commands plug-in's low-level networking utilities have since been superseded by native 4D language commands and modern OS-level diagnostic tools, making this utility of historical interest rather than practical use today.
