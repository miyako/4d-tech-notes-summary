This January 1996 Tech Note by Christopher Chapman documents ASIFONT.MAP, a plain-text font substitution lookup file used by 4D to map Macintosh font names and font families to appropriate Windows font names and families whenever a database is ported from the Macintosh environment to Windows. It shows the standard/default ASIFONT.MAP contents (e.g. mapping Macintosh "times" to Windows "Times New Roman (Roman)", "helvetica" to "Arial (Modern)", "geneva" to "MS Sans Serif (Swiss)", etc.) and explains that while the default mappings suffice for most applications, developers using custom fonts need to add their own entries. The note walks through a four-step process: first, verify the font is properly installed and printable on both platforms; second, gather the Macintosh font name and its FOND family resource ID number using ResEdit on a copy of the System file; third, gather the equivalent Windows font name and font family using a third-party utility or the Microsoft Windows SDK to inspect the .FNT file; and fourth, combine this information into a single ASIFONT.MAP line in the format "Macintosh Font Name(FOND ID):Windows Font Name(Family Name)", appended via Notepad, noting that the file must live in the same directory as 4D.EXE. The featured technology is entirely about this manual font-substitution file and the classic Mac OS ResEdit tool used to inspect FOND resources.
