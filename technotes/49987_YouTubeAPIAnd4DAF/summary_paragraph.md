YouTube is a service that allows users to upload their videos and publish it in the World Wide Web. The benefit of this service is that it can be used to entertain, advertise, and educate. This Technical Note will focus on downloading video feeds using the new YouTube API and how to utilize this service within a 4D Ajax Framework v11 web application. Published June 4, 2008 as Technical Note 08-21 for 4D Web 2.0 Pack v11.1 (Mac &amp; Win), this note was written by Robert Molina, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
