Written by Frank Chang, a 4D Evangelist, this Tech Note shows 4D developers how to integrate with eBay's marketplace using the eBay Developers Program's SOAP-based Web Services API, positioning 4D as a rapid front-end for either standalone "Individual Applications" or "Bridge Applications" that connect an existing product database to eBay listings. The centerpiece is the 4D - eBay Object Library, a set of nine drag-and-drop form objects -- including a Bind Tool that maps a table's fields to the 14 fields eBay's SOAP API requires, plus Add Item(s) to eBay, Download from eBay, Update eBay, and Update Locally buttons -- that call generic project methods such as AbstractAction_Startup and eBay_PostAdd to build and dispatch SOAP requests via proxy stub methods like proxy_AddItem. The note details the step-by-step setup flow: obtaining an eBay developer token through the Auth & Auth tool, binding local fields to eBay's schema once per database, then adding the pre-built objects to any output form so end users can push new items to eBay, pull down the seller's existing listings, or sync updates in either direction. It also walks through the internal AbstractAction_Startup dispatch pattern, which spawns a new process per action using New process so that any bound object can invoke the correct underlying eBay operation method by name.
