## Overview
An introduction to the Splitter form object in 4D v6.5, demonstrating how to create resizable, user-adjustable form layouts.

## Key Points
- Splitters divide forms into resizable areas the user can adjust
- 4D evaluates object properties to determine resize/move behavior
- Examples: resizing output forms, splitting input forms, grouped scrollable areas
- Custom graphics can be associated with splitter objects

## Historical Context
**Status:** Still Relevant

Splitter objects were a significant UI feature introduced in 4D v6.5, allowing resizable form layouts. Modern 4D forms still support splitters as standard form objects, though the property system and form editor have evolved considerably. The basic concept and usage of splitters remains current.

### Related Updates
- Splitter objects remain available in modern 4D forms
- The form editor and object property system have been modernized but splitter functionality is essentially the same
