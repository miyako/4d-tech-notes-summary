This Tech Note describes how to use the Splitter object in 4th Dimension v6.5, a UI component that divides a form into two or more areas that users can resize by dragging the splitter horizontally or vertically. When a splitter is moved, 4D evaluates each object's properties to determine whether it should be resized, moved, or remain unchanged. The included example database demonstrates splitter usage for resizing output forms, splitting input forms, resizing grouped scrollable areas, and associating custom graphics with a splitter.
