This Tech Note documents 4D Pop, a series of free, open-source Design-Mode "developer components" made possible by 4D v11 SQL's streamlined component architecture, and explains both how to install/extend the 4D Pop palette and how each first-party component works. Once installed via a Components folder and an On Startup call, the palette displays icons for compatible components, each defined by a small XML descriptor (4DPop.xml) specifying its name, icon, and the shared component methods to run on click, drag, or drop. The note walks through 4D-authored components including Bookmarks (URL/file/email shortcuts), Color Chart (an HSL/RGB color picker that generates SET RGB COLORS code by drag-and-drop), Commands (a searchable 4D command finder that can insert code or open documentation), Constants Editor, Image Buddy (a Resources-folder picture manager with basic transform tools), Migration tools (Shortcut editor, Constants/Macros migration assistants for moving to v11 SQL), Rulers (on-screen measurement guides with screen-resolution simulation), SqlSchemas (a GUI for managing SQL schemas, table assignments, and group rights), Window management tools, and an XLIFF editor for creating/editing the XML-based localization files 4D v11 SQL uses for string resources. It also lists several third-party 4D Pop-compatible components (barcode/button/icon generators, a color picker, a regex lab) contributed to the 4D Pop community forum, with a standard disclaimer that 4D does not support or guarantee third-party components. The note targets 4D developers looking to speed up their day-to-day Design Mode workflow and optionally build or extend palette tools themselves.
