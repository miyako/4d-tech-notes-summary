This Tech Note covers the basics of adding drag and drop functionality to a 4D database, introducing related concepts such as Form Events, pointers, and reusable code patterns. It highlights the advantages of drag and drop interfaces — easier data insertion, intuitive interaction, and keyboard-free operation. The note examines drag and drop between two variables, between two arrays, dragging from a hierarchical list, and drag and drop between two processes. It then provides examples of how generic (reusable) code simplifies implementing and maintaining drag and drop across a database.
