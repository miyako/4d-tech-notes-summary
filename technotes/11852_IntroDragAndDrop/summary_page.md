## Overview
A beginner-friendly introduction to implementing drag and drop interfaces in 4D databases, covering variables, arrays, hierarchical lists, inter-process communication, and reusable code patterns.

## Key Points
- Covers drag and drop between variables, arrays, hierarchical lists, and processes
- Introduces Form Events, pointers, and reusable/generic code patterns
- Emphasizes advantages: easier data entry, intuitive UI, keyboard-free interaction
- Provides examples of generic code for maintainable drag and drop implementations

## Featured Technology

## Historical Context
**Status:** Superseded

Drag and drop in 4D v6 required manual handling of form events and pointers. Modern 4D (v17+) still supports drag and drop via form events, but the underlying framework, object model, and event handling have been significantly modernized. The core concepts of reusable generic code and pointer-based abstraction remain sound programming principles.

### Related Updates
- 4D's form event model has been modernized but drag and drop still relies on form events
- Project Mode and ORDA have changed how developers structure reusable code
