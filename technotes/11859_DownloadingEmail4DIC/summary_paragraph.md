This Tech Note explains how to download email from within a 4D application using 4D Internet Commands, effectively building a custom email client. The note argues for building custom email solutions despite the availability of free clients like Claris Emailer Lite, Outlook Express, and Eudora, citing several compelling use cases: needing a custom interface for users, integrating email with database sales automation systems, receiving and processing orders from web sites, and programming scheduled downloads at preset times or triggered by conditions. These use cases reflect the late-1990s trend of bringing internet functionality into database applications. The 4D Internet Commands plug-in provided POP3 protocol support for retrieving email.
