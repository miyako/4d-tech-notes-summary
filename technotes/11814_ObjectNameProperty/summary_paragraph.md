This Tech Note explains the Object Name property, a new feature in 4D version 6 that provides an alternative way of referencing objects on a form. Previously, form objects could only be referenced by their field or variable name, but Object Names allow any form object — including fields, lines, static text, buttons, and other elements — to have an independent identifier. For example, a button variable named bAccept could have the Object Name 'button1', 'b1', or 'var(1)', decoupling the programming reference from the object's identity on the form. This was a significant enhancement for form management, enabling developers to reference objects in code without depending on potentially changing variable names. The feature improved code clarity and made it easier to manage complex forms with many objects.
