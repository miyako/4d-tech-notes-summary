# Tech Note 98-31: The Object Name Property

**Author:** Not specified in source document
**Published:** November 1, 1998 | **Product/Version:** 4D v6.0 | **Platform:** Mac &amp; Win
**Page:** https://kb.4d.com/assetid=11814
**Download:** Not available

## Proposition
This Tech Note introduces the Object Name property in 4D V6, which allows form objects to be referenced by a name independent of their field or variable name.

## Key Points
- New feature in 4D V6 — Object Name property for form objects
- Any form object (field, line, static text, button, etc.) can have an Object Name
- Object Name is independent of the object's variable or field name
- Enables cleaner code references to form objects
- Examples: a button named bAccept can be referenced as 'button1', 'b1', etc.

## Featured Technology
- Object Names
- Form Objects
- 4th Dimension V6
- Form Design

## Context / Positioning
The Object Name property became a foundational feature in 4D form programming and has been carried forward through all subsequent versions of the platform.

## Historical Commentary
**Status:** Still Relevant

Object Names proved to be a durable and important feature in 4D form design. The ability to reference objects independently from their variable names has been carried forward through all subsequent versions and remains a core part of form programming in modern 4D, including in the JSON-based form definitions used in Project Mode.
