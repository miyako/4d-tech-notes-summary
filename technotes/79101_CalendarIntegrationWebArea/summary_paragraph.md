This Tech Note showcases 4D v19R7's new Open URL action for 4D for Mobile, which lets developers link an HTML document to a mobile action so it renders inside a native web area — vastly expanding UI customization beyond 4D for Mobile's built-in view templates. The demonstration app, "PTOgo," is a manager-facing iOS tool for reviewing employee Paid Time Off requests (a single "Requests" table with Name, Date, Hours, and Status of Pending/Approved/Denied); since the app is inherently date-centric, the author adds a calendar view built from the free third-party FullCalendar JavaScript library (embedded via `index.global.js` in the project's WebFolder) instead of relying only on list/detail mobile templates. The implementation copies a `template.html` file containing FullCalendar initialization script and CSS, using 4D's server-side templating tags (`<!--#4DCODE-->`, `<!--#4DEACH-->`, `<!--#4DTEXT-->`) to inject a JSON-like array of calendar events; a "loadDataToCal" project method queries `ds.Requests.all()`, builds an event collection (color-coded orange for Pending, green for Approved, omitting Denied requests), merges it into the template via `PROCESS 4D TAGS`, and writes the result out as `calendar.html`, which is regenerated whenever a user authenticates (`On Mobile App Authentication`) or approves/denies a request (`On Mobile App Action`). On the 4D for Mobile project side, an "Open URL" preset action is configured to load `/calendar.html` into the web area, and a small `$4d.mobile.dismiss()` JavaScript call wired to a "CLOSE CALENDAR" button lets users return to the native UI. The note positions this Open URL + web area + third-party JS library pattern as a general technique — not calendar-specific — for injecting arbitrarily rich, custom HTML/CSS/JS-driven views into otherwise template-constrained 4D for Mobile applications.
