## Overview
A Tech Note introducing how to create and administer a 4D Portal instance using its web-based Portal Administration site.

## Key Points
- Explains how the Portal Administration site is used to create or update a 4D Portal instance.
- Accessed via a local HTTPS URL (https://127.0.0.1/portaladmin/).

## Featured Technology
- 4D Portal
- Portal Administration site

## Historical Context
4D Portal was a portal-building platform of the early 2000s with modular portlets, part of a broader family of 4D Portal Tech Notes covered in this batch; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

4D Portal as a distinct product is long discontinued, making the specific administration workflow described here obsolete; modern portal/dashboard applications would be built using current web frameworks or 4D's own modern web/REST capabilities rather than this legacy platform.
