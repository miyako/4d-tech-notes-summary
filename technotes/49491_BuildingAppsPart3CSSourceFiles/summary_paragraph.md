Part 3 of the XML-keys build-configuration series, this note covers the Component Source (CS) and SourcesFiles XML keys used to control which source files, components, and resources are bundled into a compiled 4D 2004 application, demonstrated through the same companion GUI project-file editor introduced in Part 1, so developers can manage exactly which files ship with a built application. Published April 16, 2008 as Technical Note 08-14 for 4D v2004.7r3 (Mac & Win), written by Josh Fletcher, Technical Services Team Member, 4D Inc.. This is a niche, build-configuration-specific note from the mid-2000s XML-keys series; the specific file-bundling mechanism it documents (CS/SourcesFiles XML keys) reflects 4D 2004's project-file format, since substantially reworked in later 4D versions and especially by the shift to Project Mode.
