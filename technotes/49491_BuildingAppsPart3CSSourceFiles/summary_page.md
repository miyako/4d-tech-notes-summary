# Building Applications Examples – Part 3 CS and SourcesFiles

## Overview
Part 3 of the XML-keys build-configuration series, this note covers the Component Source (CS) and SourcesFiles XML keys used to control which source files, components, and resources are bundled into a compiled 4D 2004 application, demonstrated through the same companion GUI project-file editor introduced in Part 1, so developers can manage exactly which files ship with a built application.

## Key Points
- Published April 16, 2008 as Technical Note 08-14.
- Targets 4D v2004.7r3 on Mac & Win.
- Author: Josh Fletcher, Technical Services Team Member, 4D Inc..

## Featured Technology
- 4D 2004 Build Application XML keys
- Component Source (CS) key
- SourcesFiles key
- XML project file editor

## Historical Context
This is a niche, build-configuration-specific note from the mid-2000s XML-keys series; the specific file-bundling mechanism it documents (CS/SourcesFiles XML keys) reflects 4D 2004's project-file format, since substantially reworked in later 4D versions and especially by the shift to Project Mode.

**Status:** superseded

**Related updates:**
- 4D's build/compile configuration model has evolved considerably since 4D 2004; component and source-file bundling is now managed differently in modern 4D versions
- Project Mode (introduced 2018) changed how source files and components are organized and referenced during a build
