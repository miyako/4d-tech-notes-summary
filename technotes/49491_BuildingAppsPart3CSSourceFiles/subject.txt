Tech Note: Building Applications Examples – Part 3 CS and SourcesFiles (TN 08-14, 4D v2004.7r3, April 16, 2008) — Part 3 of the XML-keys build-configuration series, this note covers the Component Source (CS) and SourcesFiles XML keys used to control which source files, components, and resources are bundled into a compiled 4D 2004 application, demonstrated through the same companion GUI project-file editor introduced in Part 1, so developers can manage exactly which files ship with a built application.
