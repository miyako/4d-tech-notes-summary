## Overview
A Tech Note explaining 4D 2003's new database template feature, which lets developers create new databases starting from existing structures via an enhanced Open Database dialog.

## Key Points
- Introduces 4D 2003's new database template mechanism for starting new databases from existing structures.
- Templates are surfaced through a modified Open Database dialog.

## Featured Technology
- 4D 2003 Open Database dialog
- Database structure templates

## Historical Context
Reflects classic 4D's binary Design Mode structure file workflow, where this templating mechanism was a meaningful productivity improvement for developers frequently starting new projects; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Superseded

The specific Open Database template dialog mechanism described here is tied to classic Design Mode; current 4D (with Project Mode, introduced in v17) offers different, more flexible ways to scaffold new projects (including project templates and version-control-friendly text-based structures), making this note's specific UI obsolete though the underlying goal of reusable starting-point structures remains a relevant workflow need.
