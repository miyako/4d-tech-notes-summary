This Tech Note explains a new mechanism introduced in 4th Dimension 2003 to simplify creating new databases based on existing structures: a modified Open Database dialog that displays a list of templates — pre-existing database structures a developer can use as the starting point for a new project, rather than building a structure entirely from scratch each time. This addressed a genuine productivity gap in classic 4D's binary Design Mode structure file workflow, where reusing a proven base structure across multiple projects previously required manual copying and adaptation.
