Dave Dell'Aquila, Senior Evangelist at 4D, Inc., documents 4th Dimension 2003's new database-template mechanism, which lets the Create a Database tab of the Open/Create Database dialog offer a list of pre-built starting-point structures (tables, methods, forms, menus, pictures, and even data) alongside the option to start from a blank database. Templates are simply structure files placed in a '4D Templates' folder next to the 4D application, but converting an ordinary database into a valid template requires several specific conditions: it cannot use plug-ins (since all templates share one directory with no way to route separate plug-in folders), it must ship with an accompanying datafile (.data on Mac, .4DD on Windows), and its structure file must contain four specific resources at ID 14000 -- an 'STR ' resource holding the template's display name, a 'TEXT' resource holding its description text shown when selected, a 'PICT' resource (ideally 171x256 pixels) shown as a preview image, and an 'STR#' resource listing the expected data-file names. The note walks through adding each of these using Apple's ResEdit tool, and separately proposes a workaround for the no-plug-ins restriction: naming a plug-in folder distinctively (e.g. 'Orders.Mac.4DX') inside the Templates folder and having the new database's startup method detect and copy it into place using commands like Test path name, FOLDER LIST, and COPY DOCUMENT.
