This Tech Note (TN 01-38, 4D v6.7, Mac & Win, published August 31, 2001) by Jonathan Baltazar, a 4D, Inc. Technical Support Engineer, explores the Loan Tool example database, written by Tad Michael Wheeler of DataCraft, which lets a user solve for whichever one of four loan variables (amount, payment, interest rate, or term length) they don't already know. A four-button grid on the main input form selects the calculation mode, and the LoanTool_RecalculateLoan method applies the corresponding amortization formula -- computing an effective periodic interest rate and discount factor, then solving for loan amount, payment, or term length algebraically; when the unknown is the interest rate itself, LoanTool_ClosestInterestRate instead runs an iterative Newton-style convergence loop (up to 10 iterations) to approximate it, since the amortization formula can't be inverted algebraically for rate. The note also documents a UI technique in the vSector object method: depending on which of the four buttons is selected, the corresponding input field is disabled and the MOVE OBJECT command repositions a shared result-display area directly over that field, so a single form layout serves all four calculation modes without needing four separate forms. A simpler "Quick Entry" form and its LoanTool_CalculatePayment method are also covered, offering a condensed payment-only calculator that reuses the same underlying math.
