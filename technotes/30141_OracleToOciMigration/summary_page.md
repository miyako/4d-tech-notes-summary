## Overview
A migration-focused Tech Note explaining how to move a 4D database from the legacy 4D for Oracle plug-in commands to the newer 4D for OCI commands, using the OCI Mapper 2003 framework.

## Key Points
- Targets developers migrating from the legacy 4D for Oracle plug-in to the newer 4D for OCI plug-in.
- Centers on the OCI Mapper 2003 framework, designed specifically to ease that migration.
- Compares 4D for Oracle vs. 4D for OCI in terms of similarities, differences, advantages, and disadvantages.

## Featured Technology
- 4D for Oracle
- 4D for OCI
- OCI Mapper 2003

## Historical Commentary
**Status:** Obsolete

Both the legacy 4D for Oracle plug-in and this specific OCI Mapper migration framework are long obsolete artifacts of 4D's early direct-database-plug-in era; modern 4D applications needing Oracle connectivity would instead typically use ODBC, or more likely today, 4D's native SQL engine together with standard database connectivity, making this note of historical interest only.
