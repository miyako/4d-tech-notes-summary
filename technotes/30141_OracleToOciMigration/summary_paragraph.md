This Tech Note is a migration guide aimed at 4D developers moving a database from the older 4D for Oracle plug-in's command set to the newer 4D for OCI (Oracle Call Interface) plug-in, centered on the new OCI Mapper 2003 framework built specifically to ease that transition. It promises to cover an overview of both 4D for Oracle and 4D for OCI, comparing their similarities and differences and weighing the advantages and disadvantages of each, positioning the migration as "painless" thanks to the mapper framework. Only the short on-page teaser text could be recovered here, so the concrete mapping details and code are not available, but the topic reflects 4D's ongoing effort in this era to modernize its Oracle connectivity plug-ins onto OCI, Oracle's lower-level, more standardized client interface.
