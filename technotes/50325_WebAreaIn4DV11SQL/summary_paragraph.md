------------------------------------------------------------------------------------------------------------------------------------------------------------ 4D v11 SQL Release 2 replaces the functionality of the 4D Live Window plug-in with a new type of form area: Web Area. Web Areas can display Web content such as HTML dynamic and static pages, files, pictures, Javascript, Flash, PDF files, etc. This Technical Note will refer to 4D v11 SQL Release 2 (11.2) or higher when it applies to Web Area implementation. Previous versions of 4D v11 SQL do not support Web Areas. Published July 2, 2008 as Technical Note 08-25 for 4D SQL v11.2 (Mac &amp; Win), this note was written by Luis Pineiros, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
