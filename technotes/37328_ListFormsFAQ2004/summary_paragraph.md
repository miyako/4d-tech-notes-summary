This Tech Note, published as an FAQ by 4D Technical Support, documents one of 4D 2004's most significant form-related architectural changes: the harmonization of three previously divergent ways of displaying record lists (Output form in User Mode, Output form driven by MODIFY/DISPLAY SELECTION, and Output form used as a subform) into one consistent underlying behavior, while still preserving minor differences for subform-specific use. It defines precise new terminology (included form, form displayed as a list, highlighted line) to disambiguate discussion of the new unified model, and walks through a compatibility table describing how older subform properties (Enterable, Enterable and double-clickable, Selectable, Non-modifiable) map onto version 2004's new Focusable/Enterable-in-list/Selection Mode/Double-click properties for databases converted from earlier versions. It explains a key behavioral shift: the current record is no longer automatically loaded in a list form under Single selection mode because window redraws now unload it, requiring explicit use of the new LOAD RECORD command, typically from the On Load event. The FAQ also documents three new selection modes (Single, Multiple, None) settable via MODIFY SELECTION/DISPLAY SELECTION or subform properties, the removal of empty clickable blank-area rows below the last record (with workarounds using buttons, menu items, or shortcuts tied to Add Subrecord/CREATE RECORD/ADD RECORD), the disappearance of the old focus-indicating blinking triangle (now handled via native OS focus indication or simulated with On getting focus/On losing focus), stricter object-containment rules within header/detail/break areas, and new form events (On Load Record for detecting record loads when switching a line to entry mode, and On Selection Change for detecting user record highlighting) alongside the new EDIT ITEM command and GET HIGHLIGHTED RECORDS/HIGHLIGHT RECORDS commands for programmatic highlight management under Multiple selection mode. Throughout, the note frames these changes as bringing 4D's list forms into closer alignment with native Mac and Windows OS GUI conventions of the time.
