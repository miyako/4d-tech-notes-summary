# Tech Note 03-24: New Printing Capabilities with 4D 2003

**Author:** Not specified in source document

## Overview
A Tech Note introducing 4D 2003's new procedural printing commands, which for the first time let developers control most default print dialog options in code, demonstrated across Print Form, Print Selection, and Print Record.

## Key Points
- Introduces new 4D 2003 commands for procedurally controlling print dialog options.
- Covers usage with Print Form, Print Selection, and Print Record.
- Uses an example database called "Print Options" to illustrate the new commands.

## Featured Technology
- 4D 2003 printing commands
- Print Form / Print Selection / Print Record

## Historical Context
Reflects a genuine feature upgrade in 4D 2003's printing subsystem, a notable improvement over prior versions where print behavior was largely limited to what the standard print dialog exposed.

## Historical Commentary
**Status:** Superseded

4D's printing command set introduced here has been maintained and further extended in subsequent 4D versions, so the core capability (procedural control over printing) remains relevant, though specific commands and options have evolved; developers today would consult current documentation rather than this 2003-era note for exact syntax.
