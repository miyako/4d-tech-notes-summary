This Tech Note introduces the new printing commands added in 4D 2003, highlighting that for the first time, developers can procedurally control most of the options previously only available through the default print dialog box. It demonstrates how to use these commands with Print Form, Print Selection, and Print Record, using an example database called "Print Options" as the guiding illustration. This was a meaningful capability upgrade for developers needing precise, code-driven control over print behavior (such as page ranges, printer selection, or paper settings) rather than relying on the user to configure a dialog manually each time.
