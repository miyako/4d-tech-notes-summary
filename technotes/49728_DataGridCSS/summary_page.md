# Data Grid CSS

## Overview
With the Data Grid introduced in 4D Ajax Framework v11 Release 1, this note documents the CSS-based styling API and class hooks exposed by the Data Grid object, letting developers reskin grid rows, columns, headers, and cell states using standard Cascading Style Sheets rather than hardcoded visual properties. Worked examples show applying custom CSS classes to grid elements via the framework's JavaScript API.

## Key Points
- Published May 7, 2008 as Technical Note 08-17.
- Targets 4D Web 2.0 Pack v11.1 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Data Grid
- CSS styling / class hooks
- HTML/CSS customization
- JavaScript API calls

## Historical Context
This is a pure web-UI styling technique tied entirely to the discontinued 4D Ajax Framework's Data Grid component; the specific API/class names no longer exist in any current 4D product. CSS styling itself remains a universal web skill, but the underlying grid object and its JS hooks are gone.

**Status:** obsolete

**Related updates:**
- 4D Ajax Framework (4DAF) has been fully discontinued; modern 4D web UIs are built with the 4D web server, REST/ORDA, and Qodly Studio (2021+) low-code web components
- Grid/table styling today is typically handled via modern JS frameworks or Qodly's built-in table component, not manual CSS hooks into a legacy Data Grid object
