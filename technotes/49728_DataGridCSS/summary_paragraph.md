Cascading Style Sheets (CSS) are an open standard for changing the appearance of any style element on an HTML page. The new Data Grid, introduced in 4D Ajax Framework v11 Release 1, is the framework’s most powerful object and it has API calls and classes that allow for easy CSS manipulation. This Technical Note exposes those commands and classes via easy-to-follow examples. A sample database is provided. Published May 7, 2008 as Technical Note 08-17 for 4D Web 2.0 Pack v11.1 (Mac &amp; Win), this note was written by Joe Resuello, Technical Marketing Engineer, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
