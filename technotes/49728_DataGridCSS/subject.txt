Tech Note: Data Grid CSS (TN 08-17, 4D Web 2.0 Pack v11.1, May 7, 2008) — With the Data Grid introduced in 4D Ajax Framework v11 Release 1, this note documents the CSS-based styling API and class hooks exposed by the Data Grid object, letting developers reskin grid rows, columns, headers, and cell states using standard Cascading Style Sheets rather than hardcoded visual properties.
