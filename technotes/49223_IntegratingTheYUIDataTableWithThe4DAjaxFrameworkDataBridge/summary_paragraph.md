The flexibility of the 4D Ajax Framework allows for it to interact and be integrated alongside other Ajax frameworks and API’s. This Technical Note will cover integrating the YUI DataTable with a 4D Ajax Framework web application using the Data Bridge commands. A sample database is included for both 4D 2004 and 4D v11 SQL. Published March 19, 2008 as Technical Note 08-10 for 4D Web 2.0 Pack v11 (Mac &amp; Win), this note was written by Tim Penner, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
