This Tech Note covers the Hierarchical List object, a long-standing 4th Dimension feature for displaying data in a well-organized, efficient, tree-like manner, focusing specifically on updates made to several of its controlling commands in 4D 2004. It explains what changed for each affected command and why those changes improve data manipulation and control compared to prior versions, and provides a handful of concrete examples showing what developers can now accomplish with hierarchical lists that was harder or impossible before. This is characteristic of 4D's steady, incremental refinement of its native classic-language commands during the mid-2000s, well before the object/collection-based data structures and modern List Box hierarchical display modes that would later supplement (and in some UI contexts replace) direct use of the Hierarchical List object. As a command-reference-style update note, it targets developers already using Hierarchical Lists who need to understand what changed in the 2004 release and how to take advantage of it.
