# Tech Note 04-36: Included Lists with 4D View

**Author:** Not specified in source
**Published:** September 9, 2004 | **Product/Version:** 4th Dimension v2004 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=33905

## Overview
This note covers the basic use of a 4D View area (available since 4D v6.8 via the 4D View plug-in) as a "subform-type" area, focusing specifically on its "included lists" feature as an alternative to using true subforms.

## Key Points (from available teaser)
- 4D View has provided an alternative to subforms since 4D version 6.8.
- The note focuses on "included lists" within a 4D View area.
- Purpose is to cover the basic use of a View area functioning like a subform-type area.

## Featured Technology
- 4D View plug-in
- 4D View area used as a subform substitute
- Included lists (tabular sub-display) within a View area

## Historical Context
**Note:** Only the on-page teaser paragraph was recoverable for this Tech Note; the full PDF and example database were not accessible (old archive format not retrievable in this environment), so the specific configuration steps and example cannot be reproduced here. The original 4D View plug-in has been discontinued, with its role superseded first by 4D's built-in List Box form object and later by the unrelated, modern 4D View Pro product (2018), making this note's specific technique of using a 4D View area as a subform substitute obsolete today, even though the general idea of embedding tabular sub-displays in a form persists conceptually.
