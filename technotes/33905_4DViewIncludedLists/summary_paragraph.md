The teaser identifies the note's specific focus as 'included lists,' a feature of the 4D View area that presumably let a developer embed one or more list-like tabular displays within a View area, mimicking some of the layout benefits of a genuine subform without using the subform mechanism itself. Because 4D View was a spreadsheet-oriented plug-in rather than a native form object, using it as a subform substitute required its own set of techniques distinct from working with real subforms, which this note apparently sets out to cover at a basic, introductory level. The exact configuration steps, list structure, and example database used to demonstrate included lists are not recoverable here since only the brief on-page teaser (not the full PDF/example archive) was available for this entry.
