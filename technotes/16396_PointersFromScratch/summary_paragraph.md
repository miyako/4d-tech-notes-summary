This Tech Note (TN 01-39, 4D v6.7, Mac & Win, published August 31, 2001) by Jamras Komoncharoensiri of 4D, Inc. Technical Support is a ground-up tutorial on the concept of pointers in 4D, aimed at developers unfamiliar with the idea. It starts from the basics of what a variable is (a named block of memory holding a value), then defines a pointer as itself a variable that holds the memory address of another variable, using an extended CD-player/roommate analogy to make the reference/dereference distinction concrete. It covers declaring pointers with C_POINTER, creating a reference with the -> operator or the Get pointer command, dereferencing to read or assign the pointed-to value, and 4D's departure from strongly-typed pointers in languages like C (a single C_POINTER variable can point to any variable type). The note then catalogs everything a 4D pointer can reference -- variables, objects (with a list of which object types can and cannot be pointed to), tables, fields, arrays, individual array elements, and even pointers-to-pointers -- with worked examples for each, including the Self command for referencing an object's own variable from within its object method. It closes with practical guidance: pointers can only reference fixed-address process or interprocess variables (not transient local $ variables on the stack), how passing a pointer as a parameter works, and when to use the flexible but slower Get pointer command versus a hard-coded -> reference.
