Written by Timothy Aaron Penner, this Tech Note is a practical, step-by-step guide to code-signing 4D-built applications, framed with a "tamper-evident seal" analogy: a signed binary proves it hasn't been altered since signing and comes from a trusted source, and on Windows removes the "Unknown Publisher" warning, at the cost of extra build-time signature verification and (for a real certificate) monetary cost. On Windows, it demonstrates creating a self-signed certificate for demonstration purposes via PowerShell's `New-SelfSignedCertificate -Type Custom -Subject "..." -KeyUsage DigitalSignature -FriendlyName "..." -CertStoreLocation "Cert:\LocalMachine\My"`, capturing the resulting certificate thumbprint, then exporting it to a password-protected PFX file using `ConvertTo-SecureString` and `Export-PfxCertificate`, while explicitly noting that production use should rely on a certificate from a trusted Certificate Authority rather than a self-signed one. On macOS, it covers obtaining a "Developer ID Application" certificate either via the Apple Developer website or directly within Xcode's account/certificate manager (requiring an active Apple Developer Program membership), then locating it in Keychain Access. The note then demonstrates two ways to actually sign the built application: invoking signing during 4D's `BUILD APPLICATION` process itself, and manually signing after the fact from Terminal using `codesign -s "Developer ID Application: xyz (123)" -fvvvv "path"`, including troubleshooting an "ambiguous" certificate-name error when multiple certificates share a similar name. The Windows equivalent covers installing `signtool` from the Windows SDK and signing from the Command Prompt, plus how to remove an existing signature if needed. This note captures a snapshot of 4D's distribution-hardening guidance at a time (2018) before Apple's notarization requirement became mandatory, focused purely on the signing step itself rather than the broader Gatekeeper/SmartScreen trust chain that developers must now also satisfy.
