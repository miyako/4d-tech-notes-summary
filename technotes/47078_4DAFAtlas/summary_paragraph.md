This Technical Note showcases two features introduced in 4D Ajax Framework (4DAF) version 1.1 — the Data Matrix (also called Image Browser), which displays records including Picture fields as a visual grid, and Data Driven Tabs, which auto-generate navigation tabs from the distinct values of a chosen field via preset queries — by combining them into a "mash-up" interactive atlas of countries and their flags. The sample database's single "Countries" table is switched from the default "Grid" View style to "DataMatrix" in the 4DAF Control Panel's Access Control tab, displaying each country as a flag-image tile alongside text fields; a Developer Defined Window named "Map It" (wired up via a helper Project Method) opens a separate window embedding the Google Maps API to show the selected country's map. Data Driven Tabs are configured in the Query Manager tab by creating a preset "dynamic query" on the "Continent" field, so tabs are auto-generated and refreshed periodically (by default every ~3 minutes) as new continent values appear in the data; an "All records" tab can optionally be shown first. The note walks through using the resulting 4DAF Client window — browsing, editing, creating, and deleting records; narrowing by tab or query type-ahead; and adjusting display density with "More"/"Less" zoom controls and a "Setup" toolbar controlling image/header/layout/sort options — then shows how the same Data Matrix can instead be embedded in a fully custom HTML page ("pictrix.html") via the 4DAF JavaScript `dataMatrix` constructor and its `customize()` method, documenting all constructor and customization parameters (target node, selection, header/content templates, image field, layout, margin, zoom level, scroll mode, forced rows/columns, and toolbar/dropdown visibility flags) in detail. It notes a known limitation that Data Matrix objects lacked auto-resize support in 4DAF 1.1, requiring a manual JavaScript workaround tied to the window's `onresize` event, and references a related Tech Note (07-17, "4D Ajax Framework: Preset Queries") for further preset-query background.
