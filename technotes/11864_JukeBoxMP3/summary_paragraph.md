This Tech Note demonstrates how to create an intelligent MP3 jukebox application using 4D v6.5 that plays MP3 files according to specific criteria such as music type, artist, and year. Beyond simple playback, it shows how to read and write ID3 tags—the metadata embedded in MP3 files that describes the track's title, artist, album, and other information. The database-driven approach allows users to organize and filter their music collection using 4D's query capabilities, making it more than a simple media player. Written at the height of the MP3 revolution in December 1999, this note showcases 4D's versatility beyond traditional business database applications.
