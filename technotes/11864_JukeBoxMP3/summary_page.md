# Tech Note: Juke-Box MP3 with 4D

**Author:** Not specified
**Published:** December 1, 1999 | **Product/Version:** 4D v6.5 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11864

## Overview
This Tech Note demonstrates building an "intelligent" MP3 jukebox application with 4D that plays music files based on database criteria and manages ID3 metadata tags.

## Key Points
- Plays MP3 files filtered by music type, artist, year, and other criteria
- Reads and writes ID3 tags (metadata embedded in MP3 files)
- Combines 4D's database querying with media playback
- Cross-platform (Mac & Windows)

## Featured Technology
- MP3 audio playback from within 4D
- ID3 tag reading and writing
- Criteria-based media selection using 4D queries
