This Tech Note by Vance Villanueva tackles a common deployment headache for 4D applications that use custom fonts: ensuring the same font renders consistently on every workstation an application is deployed to, across both Mac and Windows, without requiring an administrator to manually install fonts on each machine. The proposed solution places the custom font files inside a database's "Resources" folder, which 4D already automatically copies down to each 4D Client's local Resources folder in a Client/Server deployment, then pairs that with style sheets to consistently assign the custom font to form objects across platforms. To actually get the font registered with the operating system, the note provides platform-specific automation: on Mac, simply copying the font file with `COPY DOCUMENT` into the user- or system-level Fonts folder is sufficient; on Windows, because font installation additionally requires registering the font in the Windows registry, the note generates a small VBScript at runtime (via a `create_vb_script` method using the Shell Application's "Install" verb) and executes it with `LAUNCH EXTERNAL PROCESS`. The described "On Startup" method checks the machine's font directory against the fonts bundled in Resources and triggers installation (followed by a required 4D restart) only when needed. A bundled demo form visually confirms font installation status and disables the install button once fonts are already present.
