# Tech Note: Enhanced User Environment Wizards

**Author:** Not specified in source document
**Published:** April 1, 1997 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11758
**Download:** Not available (no working download link archived for this page)

## Overview

This Tech Note showcases the enhanced User Environment wizards that shipped with 4D v6 — Quick Report, Label, Query, Order by..., and Charting Wizards — demonstrating their improved speed, power, and flexibility using the MyMusic tutorial database.

## Key Points

- Notes that V6's BLOBs, Form Wizards, Web Services, and new commands had received attention, but the improved User Environment wizards had not.
- Covers five specific wizards: Quick Report, Label, Query, Order by..., and Charting.
- Uses the MyMusic tutorial database (bundled with 4D v6) as a hands-on demonstration vehicle.
- Targets both end users and developers working in 4D's User Mode.

## Featured Technology

- Quick Report Wizard
- Label Wizard
- Query Wizard
- Order by... Wizard
- Charting Wizard
- MyMusic tutorial database

## Historical Context

Written shortly after 4D v6's release, at a time when 4D's User Environment (Design Mode's end-user-facing counterpart) offered wizard-driven tools for non-programmers to build reports, labels, queries, and charts without writing code; these specific wizards and the MyMusic sample database have been substantially reworked in subsequent 4D versions.

## Historical Commentary
**Status:** Superseded

This note demonstrates the enhanced V6 User Environment wizards (Quick Report, Label, Query, Order by..., and Charting Wizards) using the MyMusic tutorial database; while the underlying goal of wizard-assisted end-user querying/reporting remains relevant, these specific classic User Mode wizards and the MyMusic tutorial database itself belong to a design-mode-only era that has been substantially reworked in look, feel, and capability across later 4D versions.
