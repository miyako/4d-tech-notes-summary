This Tech Note highlights an under-discussed side of the 4D v6 release: while BLOBs, Form Wizards, Web Services, and new language commands had received significant attention, relatively little had been said about the enhancements made to the Wizards and Editors within the V6 User Environment (4D's end-user, non-programmer-facing operating mode). Using the V6 tutorial database MyMusic as a working example, the note demonstrates the increased speed, power, and flexibility of five specific User Environment wizards: the Quick Report Wizard, the Label Wizard, the Query Wizard, the Order by... Wizard, and the Charting Wizard. These wizards existed to let end users — not just developers — perform common data tasks like building reports, designing mailing labels, constructing queries, sorting data, and creating charts, all without writing 4D code. By walking through MyMusic as a concrete, hands-on example, the note gives readers a tangible sense of how each wizard's V6 improvements manifested in practice, making it a practical orientation guide for anyone (developer or end user) needing to get up to speed on the refreshed User Environment tooling that shipped with 4D v6.
