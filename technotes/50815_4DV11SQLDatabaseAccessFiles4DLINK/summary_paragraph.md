This new file type allows 4D Developers to control the way in which 4D databases are launched, automatically log in users, automatically create a data file, etc. This feature goes beyond anything seen in both Path Documents and the CLI found in previous versions of 4D. This Technical Note outlines how these files can be created and used. A sample database for creating 4DLINK files is included. Published August 20, 2008 as Technical Note 08-30 for 4D v11.2 (Mac &amp; Win), this note was written by Timothy Penner, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
