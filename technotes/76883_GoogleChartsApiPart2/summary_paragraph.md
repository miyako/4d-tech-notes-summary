This second and concluding part of Jean-Jacques Bleu's Tech Note builds directly on Part 1's AJAX/JSON foundation to draw real Google Charts populated by data pulled from a 4D database, rather than the hardcoded example used earlier. It first demonstrates a pie chart of European country populations built from data stored in a `[Series_value]` table, letting the demo present the same underlying dataset as a top-5, top-10, or full country-list pie chart, and shows how an AJAX request can carry parameters so the correct slice of data is returned and rendered client-side. The most consequential shift in this part, however, is architectural: rather than requiring 4D Web Server to serve every page, the note shows how to render Google Charts directly inside a 4D Web Area form object, using the classic `PROCESS 4D TAGS` command together with `#4DHTML`, `#4DTEXT`, and `#4DIF` template tags to inject 4D-computed JSON data, chart type, title, and options straight into a cached HTML template loaded into the Web Area — meaning applications with no web server license or requirement can still benefit from rich, interactive charting. It walks through the JavaScript side of loading the three necessary Google libraries (JSAPI, the core Visualization library, and the specific chart-type package such as `corechart`, `gauge`, or `table`), invoking `drawChart` via `google.setOnLoadCallback`, and optionally rendering an accompanying data table alongside the chart. The note concludes the two-part series by summarizing the full technology stack assembled — HTML, JavaScript, 4D Web Server, AJAX/JSON, 4D Web Area objects, and `PROCESS 4D TAGS` — as a solid foundation for more advanced Google Charts usage.
