The 4D Ajax Framework's Offline Mode feature, introduced in Release 2 (v11.2), leveraged two emerging browser technologies to allow Data Grids to function without an internet connection: HTML5 (specifically its Web Applications 1.0 specification for browser-local storage) and Google Gears (an open-source SQLite-based browser extension by Google for offline application support). This technical note provides a comprehensive guide to configuring offline access at the framework level, enabling specific views/grids offline in the Control Panel, and troubleshooting browser compatibility issues. Developers must ensure all fields in offline-enabled views are set to input mode; otherwise, new record creation fails silently. When offline, users can add, edit, and delete records in cached grids; upon reconnection, toggling offline mode back to online triggers automatic synchronization. The note warns of session timeout edge cases (if a user's session expires while offline, records won't sync until the user logs back in and cycles offline/online again) and documents the JavaScript API (dax_goOffline(), dax_goOnline(), dax_purgeOfflineCache() functions; four corresponding success/fail event handlers) for developers using custom web pages instead of the framework's pre-built client. Extensive troubleshooting sections address the browser permission dialog required for Gears activation, detection of unsupported browsers (Internet Explorer 7, older Firefox), and the offline/online status indicator color behavior (green = online, yellow = transitioning, red = offline)."
