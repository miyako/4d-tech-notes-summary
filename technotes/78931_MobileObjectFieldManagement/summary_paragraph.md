Only the KB-page teaser abstract could be retrieved for this entry, but it describes a demonstration of using 4D's object attributes feature freely within 4D Mobile applications — the product line that generated native iOS and Android apps from a 4D data model. The bundled sample, a 'Nutrition coaching' application, models a diet-tracking use case where a user's attributes (age, gender, goals, weight, height, and similar) are stored as object fields and surfaced in the generated mobile app's UI, illustrating how flexible, schema-light object data can drive varied per-user attribute sets in a mobile context. Because only the teaser is available, the specific implementation steps for wiring object attributes into the iOS/Android project generation pipeline cannot be confirmed here. What can be said with confidence, based on the broader history of the 4D product line, is that the 4D Mobile / '4D for iOS' native app-generation technology this note is built on has since been discontinued as a 4D product offering, which limits the note's practical applicability for anyone building new mobile solutions today.
