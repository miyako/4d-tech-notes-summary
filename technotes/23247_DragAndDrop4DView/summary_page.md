## Overview
A Tech Note explaining how to implement customizable drag-and-drop cell operations within a 4D View area using its dedicated command set.

## Key Points
- Frames drag-and-drop as an essential spreadsheet-application capability.
- Describes 4D View's dedicated drag-and-drop command set for customizable cell-to-cell operations.

## Featured Technology
- 4D View
- Drag and drop commands

## Historical Commentary
**Status:** Obsolete

4D View has been discontinued, making the specific drag-and-drop commands described here obsolete for current development; drag-and-drop functionality in modern 4D applications is now typically implemented via list box form objects or, for web-based UIs, standard HTML5 drag-and-drop APIs.
