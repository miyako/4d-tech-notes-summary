# Tech Note 02-43: Connecting WebSTAR and 4D Business Kit using Rewrite

## Overview
A Tech Note explaining how to connect the WebSTAR V web server to 4D Business Kit storefronts using WebSTAR's URL Rewrite capability.

## Key Points
- Describes WebSTAR V as a Unix-rewritten, Mac OS X-optimized web server with a Java-based Admin Client.
- Focuses on using WebSTAR's Rewrite (URL rewriting) capability to connect it with 4D Business Kit.

## Featured Technology
- 4D WebSTAR V
- 4D Business Kit
- URL Rewrite

## Historical Context
Reflects the Mac OS 9-to-Mac OS X transition era, when WebSTAR V's move to a Unix-based architecture under Mac OS X was a significant technical milestone for the product; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

Both WebSTAR and 4D Business Kit have been discontinued for many years, making the specific Rewrite configuration described here obsolete; the general technique of using URL rewriting to connect a web server to an underlying application remains a standard, still-relevant web architecture pattern (now typically done with Apache/nginx rewrite rules or 4D's own built-in web server routing).
