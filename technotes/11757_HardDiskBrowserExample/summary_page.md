## Overview

This Tech Note introduces new 4D v6 commands for examining and manipulating files and directories on the hard disk, demonstrated through an accompanying HDBrowse (Hard Disk Browser) example database that also teaches hierarchical list construction and recursive method design.

## Key Points

- Showcases new V6 commands for hard disk file/directory examination and manipulation.
- The HDBrowse example database demonstrates these commands in a working context.
- Teaches creation and manipulation of hierarchical lists alongside other new V6 features.
- Includes an example of a recursive method (a method that calls itself), used to traverse the file/folder hierarchy.

## Featured Technology

- 4D V6 file/directory commands
- Hierarchical lists
- Recursive methods
- HDBrowse example database

## Historical Context

Written for 4D v6's newly expanded file-system command set, at a time when browsing and manipulating the local disk's folder hierarchy from within a 4D application was a relatively new capability; the specific commands and hierarchical list APIs demonstrated have since been superseded, though the recursive traversal technique taught remains generally applicable programming practice.

## Historical Commentary
**Status:** Superseded

This note showcases new 4D v6 commands for examining and manipulating hard disk files/directories via the HDBrowse example database, alongside hierarchical list creation and a recursive method example; while recursion and hierarchical list UI concepts remain evergreen programming techniques, the specific v6-era file-system commands and hierarchical list APIs demonstrated have been superseded by 4D's modern file-system and list-handling command sets.
