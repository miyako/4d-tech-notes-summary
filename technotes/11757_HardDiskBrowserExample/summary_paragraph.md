This Tech Note introduces some of 4D v6's new commands for examining and manipulating files and directories on the local hard disk, using an accompanying example database called HDBrowse (Hard Disk Browser) to demonstrate them in action. Beyond the file-system commands themselves, the note uses HDBrowse as a vehicle to teach the creation and manipulation of hierarchical lists — a UI element for displaying nested, expandable/collapsible data such as a folder tree — along with several other new 4D v6 features encountered along the way. Notably, the example database includes a recursive method (a method that calls itself), used here to walk a folder/file hierarchy of arbitrary depth, giving developers a concrete, runnable illustration of recursive technique applied to a real-world file-browsing task. As a hands-on, example-database-driven Tech Note, it served both as an introduction to new v6 file-system commands and as a practical teaching tool for hierarchical list construction and recursive method design, two techniques broadly useful well beyond the specific file-browsing use case demonstrated.
