This Tech Note by Charlie Vass explains and demonstrates how to generate CSS image sprites — combined "master images" used with the CSS `background-position` property to reduce HTTP requests and eliminate hover-state flicker on websites — directly from within 4D. It opens with a history of sprites from early video game graphics through Dave Shea's 2004 CSS-based sprite technique, explaining why combining many small icons/images into one master image and switching visibility via background-position was a significant web performance win over per-image JavaScript rollover techniques. The note then covers 4D's picture manipulation heritage: the original black-and-white-oriented Picture Operators versus the more capable COMBINE PICTURES and TRANSFORM PICTURE commands introduced in 4D v11, which better preserve full-color source image characteristics when assembling a composite. It walks through creating sprites with vertical, horizontal, and composite (grid) organization layouts, and documents a purpose-built "4D CSS SPRITES Maker" tool included with the technical note that automates sprite-sheet generation. Related bonus tools are also introduced: a Gradient Button Maker and a "4D SPRITES Date Widget," both apparently built using the same underlying picture-combination techniques, plus a set of web examples demonstrating the resulting sprites in action. The conclusion reiterates that 4D's picture commands, despite their age, remain powerful enough to handle modern web asset production tasks like sprite generation without needing external image-editing software such as Photoshop.
