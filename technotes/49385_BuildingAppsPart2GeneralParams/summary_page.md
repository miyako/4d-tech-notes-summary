# Building Applications Examples – Part 2 General Parameters and Licenses

## Overview
Part 2 of the five-part XML-keys build-configuration series, this note covers the General Parameters and Licenses XML keys used in 4D 2004's Build Application project file, showing how application-wide settings and license-related build options are expressed as XML keys and edited through the same companion GUI project-file editor introduced in Part 1, so developers building custom 4D executables can configure these settings without hand-editing raw XML.

## Key Points
- Published April 7, 2008 as Technical Note 08-13.
- Targets 4D v2004.7r3 on Mac & Win.
- Author: Josh Fletcher, Technical Services Team Member, 4D Inc..

## Featured Technology
- 4D 2004 Build Application XML keys
- General Parameters key
- Licenses key
- XML project file editor

## Historical Context
Another installment in the well-regarded mid-2000s XML-keys tutorial series; the specific General Parameters/Licenses XML key format documented here reflects 4D 2004's build-configuration model, since substantially reworked in later 4D versions and especially by the Project Mode (2018) shift to a git-friendly, fully text-based project structure.

**Status:** superseded

**Related updates:**
- 4D's build/compile configuration format has changed considerably since the 4D 2004 era described here
- Project Mode (2018+) changed how build settings, including general parameters and license configuration, are stored and edited
