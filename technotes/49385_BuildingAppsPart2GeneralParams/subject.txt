Tech Note: Building Applications Examples – Part 2 General Parameters and Licenses (TN 08-13, 4D v2004.7r3, April 7, 2008) — Part 2 of the five-part XML-keys build-configuration series, this note covers the General Parameters and Licenses XML keys used in 4D 2004's Build Application project file, showing how application-wide settings and license-related build options are expressed as XML keys and edited through the same companion GUI project-file editor introduced in Part 1, so developers building custom 4D executables can configure these settings without hand-editing raw XML.
