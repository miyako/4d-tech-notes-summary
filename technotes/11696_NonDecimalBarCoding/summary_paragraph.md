This March 1996 Tech Note by Kent Wilbur addresses situations where a number needs to be represented in a base other than decimal, most notably Code 39 bar coding, which encodes information using a 36-character alphabet (0-9 and A-Z), effectively base 36. It presents two custom 4D methods, BA_ToDecimal and BA_FromDecimal, that convert numbers between decimal and any base from binary (base 2) up through base 111, built around explicit digit-to-character mapping arrays rather than any built-in 4D numeric base support (since 4D itself had no native non-decimal number handling at the time). The note walks through how these routines are used to prepare a value for Code 39 bar code rendering: converting the source number to its base-36 representation, then mapping the resulting digits onto printable characters using the Adobe CodeThirtyNine bar code font so that ordinary text output renders as a scannable bar code. It includes a speed test comparing conversion performance across different target bases and rounds, giving developers a sense of the runtime cost of the custom conversion methods relative to how many values needed to be encoded. The techniques are framed as generically useful beyond bar coding for any application needing non-decimal numeric representations.
