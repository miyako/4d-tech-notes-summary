This Tech Note presents a straightforward technique for automatically quitting a 4D Client that is not in use, an important consideration for multi-user 4D Server environments where idle clients consume licenses. The approach uses the ON EVENT CALL command to detect mouse clicks and key presses, combined with a background process that periodically checks whether any user activity has occurred. A Boolean variable serves as the activity flag: the startup method and the ON EVENT CALL method set it to False (indicating recent activity), while the monitoring process sets it to True. If the process finds the variable already True on its next check, it means no user activity has occurred since the last check, and the process quits the client. This simple yet effective pattern leverages basic 4D process management and event handling. The concept of automatically disconnecting idle clients remains relevant for license management and security in modern client-server environments.
