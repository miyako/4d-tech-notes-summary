For all of the vast improvements that 4D v11 SQL provides over its predecessors with respect to performance and scalability, some of the more subtle aspects of this latest offering are worth spending some time with. Case in point is 4D’s support of NULL values. A NULL value is a value that exists, but its contents are unknown. This tech note covers the uses for NULL values, the language commands in 4D and SQL that developers can use to manipulate them and their behavior in 4D v11 SQL. Published October 30, 2008 as Technical Note 08-38 for 4D v11 (Mac &amp; Win), this note was written by Chris Visaya, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
