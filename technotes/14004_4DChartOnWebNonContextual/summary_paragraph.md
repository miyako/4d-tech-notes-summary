This Tech Note by Kent D. Wilbur (4D, Inc.) updates the 1998 Tim Tonooka note on serving 4D Chart graphs to the web, moving the technique from 4D v6's contextual-mode-only approach to the non-contextual web server introduced in 4D v6.7. It demonstrates two scenarios in the accompanying 4DChartOnTheWeb example database: displaying charts already saved as pictures in `[Charts]` records via a simple `SEND HTML FILE` call and a `.shtml` page with a `4DLOOP`/`4DVAR` tag, and building fully interactive charts on the fly from HTML form input using 4D Chart's offscreen-area commands (`CT New offscreen area`, `CT Chart arrays`, `CT Area to picture`). Because non-contextual mode has no guaranteed process state between requests, the live-chart path works around statelessness by saving the freshly rendered chart into a temporary `[Charts]` record, then a second request looks the record up by ID, converts the picture to a GIF BLOB with `PICTURE TO GIF`, deletes the temporary record, and streams the image back with `SEND HTML BLOB`. The `On Web Connection` database method manually parses the URL after `/4DCGI/` to dispatch to project methods like `Web_CreateChart`, `Web_Fields`, and `Web_ShowSavedChart`. The note closes by pointing to a bundled "Advanced Interactive 4D Chart Web Demo" that renders 3D charts with adjustable display settings using the same temporary-record/BLOB technique.</EOF
