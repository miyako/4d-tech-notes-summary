This Tech Note is the second part of a series (following "Creating a Quick Report Wizard", also covered in this batch) that shows how to build a cross-tab report from scratch using a custom Quick Report wizard. Cross-tab reports summarize data across two dimensions (rows and columns) rather than a simple linear list, and building a user-facing wizard to configure such a report procedurally was a valuable productivity tool for 4D developers working with the reworked 2003 Quick Report engine.
