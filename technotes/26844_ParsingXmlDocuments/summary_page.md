**Status:** Still Relevant

4D's native XML parsing commands introduced in this era remain part of the product today and continue to be a supported way to work with XML data, so the core capability discussed here is still relevant, even though modern 4D applications more often reach for JSON parsing/generation commands for typical web integration work.
