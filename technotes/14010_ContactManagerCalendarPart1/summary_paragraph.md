This Tech Note is the first of a planned two-part series examining the internals of 4D's Contact Manager example database, an application distributed to illustrate useful interface design and programming techniques. Part I focuses specifically on the Calendar interface: the forms and underlying method code that render and drive the calendar view within Contact Manager. The note is explicitly a code tour rather than a general-purpose technique guide — its value lies in exposing how a real, polished sample application handled a non-trivial UI component (a calendar) using period 4D tools. A planned second Tech Note (not part of this entry) was to cover how user interactions on that same Calendar form are managed. As a companion piece to a specific downloadable sample database rather than an independent technical topic, its featured technology is essentially "Contact Manager itself" — classic 4D form and method programming as applied to a calendar UI, offered to developers looking for concrete, real-world examples of interface construction from that era.
