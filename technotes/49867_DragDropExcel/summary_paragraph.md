This Tech Note (TN 08-19, published May 21, 2008 for 4D v11 SQL) demonstrates the platform's newly added native Drag and Drop mechanism and pasteboard (clipboard) access, which removed the prior need for third-party plug-ins to move data between a 4D Listbox and an external application such as Microsoft Excel. The sample covers both the "automatic" drag-and-drop mode enabled purely through form object properties, and the "manual" mode driven by database methods reacting to the `On Drop` and `On Drag Over` form events, parsing tab-delimited and carriage-return-separated text to reconstruct rows and columns exchanged with Excel. The underlying APIs and event model remain present in current 4D versions largely unchanged, though this capability is now considered a basic, well-established feature rather than cutting-edge, and richer options such as native XLSX file I/O and web-based integrations have since supplemented simple clipboard-based exchange for spreadsheet interoperability.
