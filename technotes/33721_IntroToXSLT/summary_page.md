## Overview
This Tech Note introduces XSLT (Extensible Stylesheet Language Transformations) as the most powerful tool of its era for converting XML data into other structured formats or human-friendly presentations, framed around new commands that 4th Dimension 2004 introduced for applying XSLT transformations directly to XML documents or XML held in 4D variables. It notes that XSLT transformations could also be triggered directly from 4D's Export dialogs, tying the feature into everyday data-export workflows rather than requiring custom code for every use case. The note covers what XSLT is, the fundamentals of the XSLT language, why a developer would choose it, and how to apply it within a 4D application, assuming the reader already understands basic XML and XML namespaces. This reflects the mid-2000s period when XML was rapidly becoming the standard medium for structured data storage and exchange, and 4D was actively building out native XML/XSLT tooling to keep pace with that industry shift, well before JSON displaced XML as the default lightweight data-interchange format. As an introductory conceptual guide plus command reference, its content bridges general XSLT knowledge with 4D-specific implementation details of the time.

## Historical Context
**Status:** superseded

This note captures 4D's mid-2000s investment in native XML/XSLT tooling at a time when XML was the dominant structured-data exchange format; 4D's XML and XSLT-related commands introduced in this era are still present in the current 4D language and technically functional. However, the broader industry has since largely superseded XML/XSLT with JSON for data interchange and web APIs, and 4D itself added native JSON parsing and manipulation commands (mid-2010s onward) that most modern 4D developers now reach for instead of XSLT transformations for everyday data conversion tasks.
