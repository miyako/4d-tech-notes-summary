This Tech Note by Timothy Tse introduces a 4D v14 enhancement allowing 4D expressions — fields, variables, commands, project methods, or any value-returning statement — to be embedded directly inside "Multi-style" styled text variables, which had previously only supported HTML-span-based text styling. It walks through the mechanics of the feature: creating styled text via the Multi-style property, inserting expression references with `ST INSERT EXPRESSION`, toggling between showing expression values versus their raw references with `ST SET OPTIONS`, refreshing dynamic values with `ST COMPUTE EXPRESSIONS`, and converting live references into permanently frozen static text with `ST FREEZE EXPRESSIONS`. It also covers reading styled text back out as plain text (`ST GET PLAIN TEXT`) or with its styling tags intact (`ST GET TEXT`). The practical value highlighted is mail-merge-style automation: instead of manually composing thousands of personalized letters or emails, a single template with embedded field expressions can be computed per-record. The note demonstrates this concretely with a bundled sample database containing a rich text editor and an Email form that lets users insert field/variable/URL/command expressions, toggle between value and reference display, load/save templates, and send the resulting styled text as an HTML email (cross-referencing the companion Tech Note on Sending HTML Emails).
