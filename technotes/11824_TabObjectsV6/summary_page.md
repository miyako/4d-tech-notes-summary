# Tech Note: 4D v6 Tab Objects

**Author:** Not specified
**Published:** January 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11824

## Overview
This Tech Note covers the new tab control objects introduced in 4D v6, explaining their advantages over the v3-era workaround of using graphic images with invisible buttons, and discussing implementation approaches for multi-page forms.

## Key Points
- Tab objects replaced the v3 technique of simulating tabs with graphics and invisible buttons.
- Significant improvements in memory usage, execution speed, and visual appearance.
- Highly useful for managing multi-page forms.
- Can be used on detail or list forms; list-based tabs offer the most flexibility.
- 4D uses tab objects in its own palettes, validating the UI pattern.
- The most difficult aspect is deciding which implementation approach to use.

## Featured Technology
- 4D v6.0
- Tab control objects
- Multi-page form design
- Detail and list form UI patterns

## Historical Context
**Status:** Historical interest only

Tab control objects remain a core UI element in modern 4D and are actively supported. However, modern 4D provides additional container and navigation objects, and the form editor has evolved significantly since the v6 era.
