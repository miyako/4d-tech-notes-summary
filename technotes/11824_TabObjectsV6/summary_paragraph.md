This Tech Note covers the tab control objects introduced in 4th Dimension version 6, which replaced the previous v3 technique of simulating tabs using graphic images with invisible buttons. The new tab objects provide significant advantages in terms of memory usage, execution speed, and visual appearance. The note explains that tab objects are highly useful for managing multi-page forms and are intuitive for users. It discusses the different implementation approaches available, noting that deciding which implementation method to use is the most challenging aspect. Tabs can be used on either detail or list forms, with the list-based tab offering the most flexibility. The note also points out that 4D itself uses tab objects within many of its own palettes, validating the approach as a first-class UI pattern. This was an important UI advancement for 4D developers transitioning from the v3 workaround approach.
