This Tech Note describes the basics of 4th Dimension's "inherited forms" feature, which lets objects placed on one form (Form A) be reused by another form (Form B), so that Form B "inherits" Form A's objects rather than requiring the developer to duplicate them. This is a form-design productivity and consistency feature — changes made to shared inherited objects propagate to every form that inherits them, similar in spirit to a lightweight template/base-class relationship for UI elements.
