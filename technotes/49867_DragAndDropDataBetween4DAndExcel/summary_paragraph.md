This Technical Note covers how to implement the new Drag and Drop mechanism as well as the pasteboard functionality in 4D v11 SQL to copy text data between a 4D Listbox and Excel spreadsheet. Published May 21, 2008 as Technical Note 08-19 for 4D v11 (Mac &amp; Win), this note was written by Atanas Atanassov, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
