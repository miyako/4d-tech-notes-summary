This Tech Note introduces Rich Text Area, a 4D component (originally beta in v12 Release 0, standard by the release version) that gives end users a dedicated sub-form interface for editing styled text, which can then be saved back to Text or Alpha variables and fields. It first explains 4D v12's new native rich text feature itself — the ability to apply styled text to Text/Alpha form objects and to list box cells — since understanding this underlying capability is necessary context for the component built on top of it. It then covers installing the Rich Text Area component on both Mac OS X and Windows, including removing source code after installation and verifying a successful install, followed by step-by-step instructions for adding Rich Text Areas to application forms. The note walks through end-user interaction with the area (contrasting plain rich-text-enabled fields/variables against the richer Rich Text Area sub-form UI), covers text manipulation capabilities, and explains populating and saving text to and from the area. A sample database demonstrates the complete implementation. The note targets developers wanting a polished, user-friendly rich text editing experience rather than relying solely on contextual-menu-driven styling of a plain variable.
