Written by Jamras Komoncharoensiri, this is the second of two Tech Notes on 4D Blogger, a demo blogging application whose WebLog Client and WebLog Server communicate over SOAP; this installment focuses on the client-side interface and the new features added in 4D Blogger v2. It details the construction of a custom WebLog calendar built from seven layered form-object types -- previous/next navigation buttons, a month/year label, a 7-column day-name header, a 6x7 grid of oval "has a post" indicators, a matching 6x7 grid of day-number variables, and an invisible 6x7 button grid for clicking a specific day -- coordinated by project methods like `GEN4D_CleanCalendar` and `GEN4D_UpdateVisibleLog`. A background process, `GEN4D_GetMostCurrentData`, polls the WebLog Server every 10 seconds via SOAP to refresh the list of days with posts, archived months, admin usernames, and categories, then calls the foreground "Client Panel" process via `CALL PROCESS` so an `On Outside Call` form event can redraw the calendar with fresh data. The note walks through the new multi-category feature, showing the SOAP-backed add/rename/delete/assign-admin operations for WebLog categories (`SOAP_AddCategoryName`, `SOAP_RenameCategory`, `SOAP_RemoveCategoryName`, `SOAP_SetCategoryAdmin`), each of which pauses the background poller during the SOAP call and resumes it afterward. It also covers the new self-service user signup flow (`SOAP_SaveNewUser`, with field-by-field validation and per-field error messages) and the new category-based and "my logs" search/display options (`SOAP_GetLogByCategory`, `SOAP_GetMyLogs`), rounding out the WebLog Client feature set introduced since Part I.
