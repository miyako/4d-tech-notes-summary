This Tech Note by Gou Yang, a Technical Support Engineer at 4D, Inc., is a focused guide to panes and splitters in the 4D View plug-in area. It first explains the underlying concept: a 4D View area starts as a single pane where all cells scroll together, and adding a horizontal or vertical splitter divides it into two panes that scroll independently — illustrated with a gradebook-style example where a 'Last Name' pane and an 'Average' pane stay fixed while individual assignment-score columns scroll, a pattern familiar as spreadsheet 'freeze panes.' It covers the manual, mouse-driven way to add or remove a splitter (dragging from a small handle at the top of the horizontal/vertical scrollbar), then documents the four programmatic commands for the same operations: PV ADD HOR SPLITTER / PV ADD VERT SPLITTER (each taking the area, a new splitter/pane number, a pixel position relative to the last separator, and a locked flag), with worked examples that first query the current pane count and row/column size via PV Get area property, PV Get row height, and PV Get column width before computing where to place the new splitter. It shows the mirror-image PV REMOVE HOR SPLITTER / PV REMOVE VERT SPLITTER commands, cautioning that removing the last remaining pane triggers an alert, so code should guard with a pane-count check first. Finally it documents PV SET HOR PANE PROPERTY / PV SET VERT PANE PROPERTY for configuring an individual pane once created — demonstrated locking a pane's scrollbar and splitter (so users can't accidentally scroll or remove a frozen column) and setting its relative-scroll position by multiplying a target column index by that column's pixel width, noting that 4D View treats the first column as index zero for this purpose.
