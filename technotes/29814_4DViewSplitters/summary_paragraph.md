This Tech Note introduces the concept of panes and splitters within 4D View, the spreadsheet-style area component, teaching developers how to divide a 4D View area into multiple independently scrollable panes using splitter bars, similar to the freeze-pane/split-window feature found in spreadsheet applications. It walks through the relevant command set: PV ADD HOR SPLITTER and PV ADD VERT SPLITTER to create horizontal and vertical splitters at a given position (optionally locked), PV SET HOR PANE PROPERTY and PV SET VERT PANE PROPERTY to configure pane behavior, and PV REMOVE HOR SPLITTER / PV REMOVE VERT SPLITTER to remove them. After reading the note, a developer should be able to programmatically add, configure, and remove splitters to organize a large 4D View area into more manageable, independently scrollable regions — useful for large tables with frozen header rows/columns or side-by-side comparison views.
