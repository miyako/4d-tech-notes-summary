## Overview
A command-reference-style Tech Note introducing panes and splitters in 4D View, covering the full set of PV commands used to add, configure, and remove horizontal and vertical splitters in a 4D View area.

## Key Points
- Introduces panes and splitters as a way to divide a 4D View area into independently scrollable regions.
- Documents PV ADD HOR SPLITTER / PV ADD VERT SPLITTER for creating splitters at a given position.
- Documents PV SET HOR PANE PROPERTY / PV SET VERT PANE PROPERTY for configuring pane behavior.
- Documents PV REMOVE HOR SPLITTER / PV REMOVE VERT SPLITTER for removing splitters.

## Featured Technology
- 4D View
- PV ADD HOR/VERT SPLITTER
- PV SET PANE PROPERTY commands

## Historical Context
4D View was 4D's classic spreadsheet-style plug-in/component; splitters and panes mirrored the freeze-pane concept familiar from spreadsheet applications of the time.

## Historical Commentary
**Status:** Obsolete

4D View as a distinct product has since been discontinued, and its PV-prefixed command set is not part of current 4D's standard toolkit, making the specific commands documented here obsolete for new development. The freeze-pane/splitter UI concept itself remains a common and still-useful pattern, now more often implemented via list box form objects or web-based grid components in modern 4D applications.
