This Tech Note, authored by Tim Tonooka of ACI Technical Support, is the first part of a multi-part series on creating interactive graphic interfaces with 4D Draw v6.5. It demonstrates how 4D can auto-trace bitmap images (specifically BMP files) and convert them into 4D Draw vector graphics suitable for interactive use—such as clickable USA maps color-coded by sales data or interactive real estate development diagrams. The note provides an extensive guided tour of the "v65Trace" example database, which features four functions: converting pictures to BMP format using ACI_Pack, examining BMP picture properties including pixel-level analysis in a 4D Draw area, tracing bitmap images to vector polygons with configurable line tolerance, and working with traced results in a 4D Draw window. A detailed primer on graphics file formats (TIFF, PICT, WMF, EPS, JPEG, GIF, BMP) explains why BMP was chosen for its simplicity and consistency. The note thoroughly compares 4D Draw with 4D Chart, documenting over a dozen reasons why 4D Draw is superior for interactive interfaces—including object locking, background layers, named objects, zoom control, and handle suppression. Multiple approaches to creating vector graphics are discussed, from manual drawing to commercial tracing utilities like Adobe Streamline and CorelTrace, to the 4D-native solution demonstrated here.
