Adding the 4D Ajax Framework to a basic database is very simple. The more customizations to the database, the more the default configuration of the 4D Ajax Framework must be changed. It is one of this tool’s greatest assets that it is easily customizable. The 4D Ajax Framework is configured by default to use the 4D Password System. This Technical Note shows how easy it can be to implement a custom password system with the 4D Ajax Framework instead of using the 4D Password System. A sample database is included. Published April 30, 2008 as Technical Note 08-16 for 4D Web 2.0 Pack v11.1 (Mac &amp; Win), this note was written by Thomas Fitch, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
