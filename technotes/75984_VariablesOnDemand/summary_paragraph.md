This Tech Note documents a 4D v11 SQL component, "Variables On Demand" (VOD), that lets a host database declare and manage 4D variables dynamically at runtime, even inside a compiled application where normal variables must be statically declared and typed at compile time. Building on a technique first introduced in an earlier note ("4D v11 SQL Assimilator," asset #75182), the component creates namespaced pools of "anonymous" variables accessed not by name but through pointers, and provides cooperative garbage collection so the variable pool isn't purely static after compilation. The API includes methods like DVar4D_Startup, DVar4D_New and DVar4D_New2D (for 1D and 2D variable creation), DVar4D_Get, DVar4D_IsDefined, DVar4D_Clear and DVar4D_ClearGroup, along with introspection methods like DVar4D_Declared and DVar4D_Array_Size. A demo database illustrates practical usage of the component. The note targets advanced 4D developers who need flexible, runtime-created variable storage without the rigidity of 4D's normally static, compile-time variable declarations — reducing developers' need to know the name of on-demand variables in the host structure.
