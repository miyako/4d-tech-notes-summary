This Tech Note covers the two major list box enhancements introduced in 4D v12: the ability to print list boxes, and the ability to build hierarchical (collapsible/expandable) list boxes using arrays. It traces the evolution of the list box object from its 2004 introduction (array-driven only) through 4D v11 SQL (table/named-selection support) to v12, where columns and headers become fully programmable and dynamically retitlable. It documents the new and modified commands — LISTBOX COLLAPSE, LISTBOX EXPAND, LISTBOX SET HIERARCHY, LISTBOX GET HIERARCHY, LISTBOX GET PRINT INFORMATION, LISTBOX SELECT BREAK, and an updated LISTBOX Get column width — and walks through building a list box object, exporting its format to XML, and importing that format back via a documented method. It also explains the printing workflow: OPEN PRINTING JOB, OPEN PRINTING FORM, and the Print object command, applied specifically to a previously-unprintable array-based list box. An example database demonstrates both the interface and the underlying print_lb_process method. The note is aimed at developers who need reporting-style, hierarchical, or printable grid displays and previously had to work around list boxes' historical limitations.
