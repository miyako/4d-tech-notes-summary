This Tech Note is the second in a two-part series on the SVG coordinate system as used by 4D's SVG component, focusing specifically on the "rotate" and "skew" values of the SVG transform attribute (the first part, referenced here, covered "translate" and "scale"). It re-establishes the foundational concepts — the infinite default user coordinate system, the viewport that constrains drawing to a finite rectangle, and the viewBox that maps user-space coordinates onto that viewport — before diving into how rotate and skew transformations act on SVG objects within that system. The note emphasizes that understanding the underlying mechanics of a transformation, rather than treating it as a black box, is essential to using it effectively, since SVG transform behavior is often less intuitive than developers expect. A demo database accompanies the explanation to let developers experiment directly with rotate and skew values. The note is aimed squarely at 4D developers already using the 4D SVG component who need precise, predictable control over object orientation and shape distortion in generated vector graphics.
