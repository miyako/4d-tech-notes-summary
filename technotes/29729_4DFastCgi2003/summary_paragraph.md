This Tech Note discusses the need for web sites to incorporate functionality from external applications, contrasting the two most common integration approaches of the time: CGI and server-specific APIs. It notes that CGI programs are flexible and language-independent but can become a performance bottleneck, since traditional CGI spawns a new process per request — motivating the use of FastCGI, a persistent-process protocol designed to avoid that overhead, for integrating 4D applications with web servers.
