This Tech Note reviews the fundamentals of object locking using semaphores in classic 4D — a mechanism for coordinating access to shared resources across cooperatively multitasked processes — and explains how to use wrapper methods to avoid common semaphore-related problems (gotchas), such as forgetting to release a semaphore, double-locking, or race conditions between check-and-set logic.
