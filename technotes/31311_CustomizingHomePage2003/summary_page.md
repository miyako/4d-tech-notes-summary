# Tech Note 04-06: Customizing the Home Page Automatically Created by 4th Dimension 2003

**Author:** Not specified in source teaser
**Published:** February 12, 2004 | **Product/Version:** 4th Dimension v2003 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31311
**Download:** https://kb.4d.com/DLTN/TN/2004/Windows//TN_2004_05-09_(FEB)/04-06_Customizing_Home.exe

## Overview
This Tech Note explains how to modify the HTML of the default "welcome" home page that 4th Dimension's built-in Web server automatically generates when no custom home page exists in the Web server folder.

## Key Points
- 4D's native Web server auto-generates a generic welcome page instead of a 404 error when no home page file is present.
- This default page, while better than an error, isn't tailored to any specific database's branding.
- The note explains how to modify the underlying HTML of this auto-generated page.
- Particularly useful for vertical-market developers who want a customized default home page shipped from nothing more than a bare structure file.

## Featured Technology
- 4th Dimension native Web server
- Default/auto-generated Web server home page HTML
- Vertical-market deployment customization

## Historical Context
Only the on-page teaser paragraph for this asset could be recovered (the full archived PDF was not accessible in this environment), so this summary reflects the note's stated purpose rather than the exact HTML/customization steps shown. 4D's built-in web server has been substantially rearchitected in later versions, and the specific default-page mechanism described here is dated; the general idea of tailoring a deployed database's default web presence remains relevant, but is now typically handled through fuller custom web content rather than editing the legacy auto-generated page.
