This Tech Note addresses a small but recurring detail of deploying 4th Dimension's built-in web server: when no home page file exists in the default Web server folder, 4D automatically generates a generic welcome page rather than returning a 404 - Page Not Found error to visitors. While this default page is a sensible fallback that avoids a broken-looking error response, the note observes that it is not as polished as a custom page specifically tuned to a given database's branding or purpose. The core proposition of the tech note is to explain exactly how to modify the HTML that makes up this default, automatically generated home page, giving developers a way to present a properly branded or informative landing page even before they have built out a full custom home page for their database. The note explicitly calls out its usefulness to vertical-market developers — those building and distributing 4D-based solutions for specific industries or clients — who want to ship a customized home page starting from nothing more than a bare structure file, without necessarily having designed a complete custom website around their database yet. This makes the technique especially relevant for solution providers who need a reasonable, professional default web presence out of the box for every deployment of their product, rather than relying on 4D's generic fallback page. The featured technology is squarely 4D's native Web server and its default content-generation behavior, an area of the product that was foundational to any database exposing a web presence in this era.
