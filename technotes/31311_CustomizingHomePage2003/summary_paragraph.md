Written by David Adams, this Tech Note explains how to customize the default welcome page that 4th Dimension 2003's built-in Web server automatically generates when a database's Web folder and home page are missing — a feature new to version 2003 aimed at showing something friendlier than a 404 error. It reveals that this default page's HTML is stored inside 4th Dimension itself as a resource of type "Html" with ID 1 (visible in the Resorcerer resource editor under OS X), and because 4D searches for matching resources starting with the most recently opened file (the structure) before falling back to the application itself, a developer can override the built-in page simply by saving their own HTML as an "Html" resource with ID 1 in the structure file — requiring no modification to 4D itself. Sample code shows using `TEXT TO BLOB` and `SET RESOURCE` to write the HTML resource, and `GET RESOURCE`/`BLOB to text` to read it back. The note extends the technique to serving linked assets from resources too: a custom home page can reference a stylesheet served from a TEXT resource (ID 16000) via a `WebGetStyles` method using `Get text resource` and `SEND HTML TEXT`, and a company logo served from a PICT resource via a `WebGetPictureResource` method that loads the image with `GET PICTURE RESOURCE`, converts it with `PICTURE TO GIF`, and returns it with `SEND HTML BLOB`, both exposed as 4DACTION URLs (e.g. `/4daction/WebGetStyles/`). It closes with practical development tips (editing index.html directly during development but pushing final HTML back into the structure resource before distribution), notes on how 4D Server and 4D Client synchronize resource changes, and a list of resource-editing tools (ResEdit, Resorcerer, Orchard Software's free editor, ResFool) and further reading for developers who want to go deeper into 4D's classic resource system.
