This Technical Note by Joe Resuello of 4D Inc. demonstrates how to embed 4D Ajax Framework (4DAF) objects into a custom HTML page with minimal JavaScript to build a highly customizable interface, using a video player that plays clips from 4D Tech Tips and 4D Web 2.0 Pack demos as its worked example. It opens with a standard caveat for the era: because 4D Web 2.0 Pack is a subscription-based product expected to ship frequent incremental releases, the note (based on 4DAF version 1.1) warns it may become outdated faster than typical 4D documentation, and points readers to the daxipedia.4d.com wiki for the latest information. The included sample ships as both a merged application (usable without a Web 2.0 Pack license) and an interpreted source database with the 4DAF itself stripped out, since only licensed developers may build with it. Structurally, the note frames the finished interface as a custom implementation built directly on the 4D Ajax Framework Libraries, with the 4DAF Client used only for configuration, and walks through the build in discrete steps: installing the 4DAF component into the source database (named "Movies.4DB"), creating a table-backed Selection and configuring it with the ImageMatrix style via the 4DAF Client's Access Control tab, authoring a custom HTML file (index_movies.html) that loads the framework's localization/compile scripts and a stylesheet, embedding a DataFiller to feed data into the page, and using an IFrame to play the videos themselves (with URLs sourced from the database). The note emphasizes that the required Database and Project methods from the 4DAF installation guide were pre-implemented in the sample so readers can focus on the HTML/JavaScript embedding technique rather than framework setup mechanics. As a component-level how-to for building custom 4DAF front ends, it is representative of the "rich internet application" ambitions of the 4D Web 2.0 Pack era.
