This Tech Note addresses a Mac OS X limitation of the era: unlike Windows, where 4D Server could be "Registered as a Service" for automatic startup and clean unattended shutdown, Mac OS X had no equivalent native mechanism. The note explains a "faux" service technique using Mac OS X User Accounts Login Items to auto-launch a small paired AppleScript application at login, which in turn starts 4D Server with a specific database; the same AppleScript application listens for the system "quit" event and signals 4D Server to shut down cleanly (without the "Delay" dialog) when the machine restarts or shuts down. Different pairing strategies are covered depending on whether the target is a built ("OEM"/VAR) server, a self-contained .4dbase bundle, or a structure/data pair requiring a .4DLink file. To simplify adoption, the note includes a utility database called PairingsMaker that generates the necessary AppleScript and Terminal scripts for the developer, requiring only a few clicks rather than manual scripting. The note targets 4D Server administrators who need reliable, unattended server availability on Mac OS X similar to what Windows services provide.
