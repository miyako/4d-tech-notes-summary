This Tech Note demonstrates the "catalog functions" of the ODBC Pro plug-in, a set of commands that describe the structure (catalog) of an external database — its tables, columns, statistics, primary/foreign keys, table and column privileges, stored procedures, and supported data types. It lists the full command set (ODBC_SQLTables, ODBC_SQLColumns, ODBC_SQLStatistics, ODBC_SQLSpecialColumns, ODBC_SQLPrimaryKeys, ODBC_SQLForeignKeys, ODBC_SQLTablePrivileges, ODBC_SQLColumnPrivileges, ODBC_SQLProcedures, ODBC_SQLProcedureColumns, and ODBC_SQLGetTypeInfo) and explains their two main practical uses: building dynamic SQL requests at runtime by discovering available tables and columns, and optimizing SQL requests by exploiting known relations, indexes, and primary/foreign key structure. It illustrates the primary/foreign key relationship using a simple Employee/Service table example. The general usage pattern for every catalog command is the same: allocate a statement handle via ODBC_SQLAllocStmt, call the desired catalog command (passing the statement handle plus command-specific filters like catalog/schema/table/column name), bind result columns to 4D variables or fields by position using ODBC_SQLBindCol, fetch rows in a loop with ODBC_SQLFetch until no data or an error occurs, and finally free the statement with ODBC_SQLFreeStmt. Two full code samples are given: one calling ODBC_SQLColumnPrivileges to retrieve column names, privilege assignees, and grantees for a table, and one calling ODBC_SQLColumns to retrieve a table's column names, types, and sizes. A companion test database demonstrates all catalog commands interactively, letting the developer connect to any configured ODBC data source and explore its catalog through a simple dialog. As a plug-in-level integration technique, this note reflects a pre-native-SQL era of 4D development focused on programmatic metadata discovery for external SQL data sources.
