This Tech Note by Steve Hussey (CEO, Alto Stratus LLC) is a concise reference on 4D's `OPEN WEB URL` command, which hands a URL string off to the user's configured default application for that URL type. For web sites, it shows both full (`"http://www.jumpstart-4d.com"`) and partial (`"www.jumpstart-4d.com"`) syntax, noting the URL can come from a variable or field and that 4D performs no validation of it. For e-mail, it demonstrates building a `mailto:` link with `?subject=` and `?body=` query parameters, and shows how to embed a line break in the body using the percent-encoded carriage return/line feed sequences `%0D` (Mac OS) or `%0D%0A` (Windows), since 4D's own CHAR(13)/CHAR(10) can't be passed directly. It briefly covers connecting to FTP sites (`OPEN WEB URL("ftp.4d.com")`) and closes with local HTML files via a `file:///` URL, explaining the triple-slash syntax (protocol separator plus root-level path) and suggesting this as a simple way to build a context-sensitive help system using ordinary web-browser-rendered HTML pages launched from buttons throughout a 4D application.
