This Tech Note presents "Resource Mover," a productivity tool developed with 4D for manipulating commonly used resources such as pictures, icons, string lists, constants, and sounds. The tool works on both MacOS and Windows, making it especially valuable on Windows where no equivalent to the Mac's ResEdit resource editor existed. The note covers two specific resource types in detail: button families used when creating forms, and the "clut" (color lookup table) resource used for defining colors in the Method editor. It also demonstrates how to change a form's background dynamically. The tool addresses a real gap in the Windows 4D development experience, where resource manipulation was otherwise difficult. The full PDF was not recoverable. The entire resource fork paradigm has been deprecated since Mac OS X.
