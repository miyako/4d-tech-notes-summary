# Tech Note: Resource Mover

**Author:** Not specified
**Published:** October 1, 1999 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11857

## Overview
This Tech Note presents "Resource Mover," a cross-platform 4D productivity tool for manipulating resources (pictures, icons, string lists, constants, sounds), with special coverage of button families and CLUT resources.

## Key Points
- Cross-platform resource manipulation tool built in 4D
- Especially useful on Windows where no ResEdit equivalent existed
- Handles pictures, icons, string lists, constants, and sounds
- Demonstrates editing button families for form creation
- Shows how to edit the "clut" resource for Method editor colors
- Demonstrates dynamic form background changes

## Featured Technology
- Classic Mac OS / Windows resource management
- ResEdit-style resource manipulation
- Button family resources
- CLUT (color lookup table) resources
- Dynamic form background modification

## Historical Context
**Status:** Obsolete

The full PDF could not be recovered (error: NO_DOWNLOAD_LINK_TEASER_ONLY). The entire resource fork paradigm this tool was built around has been deprecated since Mac OS X. Modern 4D stores pictures, icons, and other assets in the Resources folder, picture libraries, or as direct file references—not as typed resources in resource forks. The "clut" resource for Method editor colors and the concept of button family resources are relics of classic 4D that no longer apply. ResEdit itself was discontinued by Apple decades ago.
