This Tech Note explains JSON Web Tokens (JWTs) — a widely used standard for compactly and securely transferring identity/authentication data, commonly used by online APIs (Google, Apple, Adobe, and others) as well as 4D's own REST server — and shows how to generate and verify them using native 4D code, with no third-party library required. It breaks down the three-part JWT anatomy: a header JSON object specifying the signing algorithm (`alg`, e.g. HS256/RS256) and token type (`typ: "JWT"`); a payload JSON object carrying the actual claims/data being transferred; and a verify signature, computed by Base64URL-encoding the header and payload, concatenating them with a period, and hashing the result with the algorithm specified in the header, optionally combined with a shared secret key for tamper detection — the three encoded parts are joined with periods into the final token string. In 4D, the header and payload are built as ordinary 4D objects (`New object("alg"; ...; "typ"; "JWT")`), then encoded with `BASE64 ENCODE(JSON Stringify(...); ...; *)` for URL-safe Base64; the note documents four signature algorithm families in the bundled sample database — HS (HMAC), ES (ECDSA), RS (RSASSA-PKCS1), and PS (RSASSA-PSS) — combined with SHA-256/SHA-512 hashing, dispatched via custom `jwtHashHMAC` and `jwtHashSign` methods (the latter using 4D's built-in CryptoKey class for non-HMAC algorithms), with the final token assembled as `header + "." + payload + "." + signature`. Verification reverses the process: split the token on periods, Base64-decode and JSON-parse the header/payload, recompute the hash using the same algorithm and a shared secret, and compare it to the received signature to confirm validity. The example database (adapted from Thomas Maul's open-source JWT implementation) provides interactive demos to generate a JWT with a chosen algorithm/payload and to verify a pasted JWT/secret pair, cross-checkable against the public jwt.io tool, positioning JWTs as a natural fit for authenticating 4D's own REST API or communicating securely with external services.
