Print selection — printing a header, repeating detail rows, break groups, and a footer from a record selection — has traditionally relied on 4D's list-form printing engine, which is form-heavy and cumbersome to modify whenever a report layout changes. This note reimplements the same report structure using 4D Write Pro, 4D's HTML/CSS-based document editor, by inserting a table with WP Insert table, defining header cells via WP Table get cells and WP SET TEXT, and binding data rows to an ORDA entity selection through WP SET ATTRIBUTES(...; wk datasource; Formula(ds.People.query(...))) combined with WP INSERT FORMULA expressions like This.item.firstname — the This.item keyword triggers WP Write Pro to repeat the row once per entity in the selection when WP COMPUTE FORMULAS runs. Headers and footers are built with WP New header/WP New footer plus WP SET TEXT or formula-bound WP INSERT FORMULA (e.g. for a This.pageNumber page counter), and the finished document can be sent to a printer with WP PRINT or exported as PDF with WP EXPORT DOCUMENT. Beyond the manual walkthrough, the note packages this pattern into a small reusable API of three methods — apiWPPrintSelection(WPPointer; QueryDefinition; FieldDefinition), apiWPSetHeader, and apiWPSetFooter — driven entirely by declarative object/collection parameters (table name, ORDA query string, field/column definitions with optional break levels, sum/count aggregation, and styling attributes), so a developer only needs to describe what data and appearance they want rather than hand-build a print form for each report.
