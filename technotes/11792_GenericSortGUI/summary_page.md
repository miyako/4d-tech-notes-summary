# Tech Note: A Generic Sort GUI

**Author:** Not specified
**Published:** February 1, 1998 | **Product/Version:** 4D v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11792

## Overview
This Tech Note provides a reusable GUI design pattern for sorting columns on output forms using arrow keys. It includes generic code and an example database for 4D v6.

## Key Points
- **Problem addressed:** Users need an intuitive way to sort columns on output forms; poor GUI design frustrates data extraction.
- **Solution:** A simple, generic sort GUI using arrow key navigation.
- **Reusable code:** The provided code can be applied to any 4D v6 database without modification.
- **Includes:** Example database demonstrating the technique.

## Featured Technology
- 4D v6 output forms and form events
- Arrow key-based column sorting
- Generic/reusable code patterns for GUI

## Historical Context
**Status:** Obsolete

In the 4D v6 era, output forms did not have built-in column sorting capabilities, so developers had to implement sort interactions manually. Modern 4D list boxes include native sortable column headers (click-to-sort), making this kind of custom implementation entirely unnecessary. The broader lesson about thoughtful GUI design for data presentation remains valid, but the specific technique is obsolete.
