The flexibility of the 4D Ajax Framework allows for it to interact and be integrated alongside other frameworks and API’s. This Technical Note will cover integrating the Google AJAX Feed API into a 4D Ajax Framework web application using the new Data Grid 2.0 object. An example database is included. Published February 6, 2008 as Technical Note 08-05 for 4D Web 2.0 Pack v11 (Mac &amp; Win), this note was written by Robert Molina, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
