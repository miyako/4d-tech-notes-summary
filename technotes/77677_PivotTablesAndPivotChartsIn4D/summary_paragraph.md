Written by Tai Bui of 4D Inc. in November 2016 for 4D v16 64-bit, this tech note introduces 4D's then-new native pivot table and pivot chart capability, explaining the concept for developers who may be more familiar with the equivalent Microsoft Excel feature than with building it themselves. It walks through what a pivot table is — taking flat, row/column data and adding a third "value" axis with an aggregation type to summarize large record sets into digestible tables — using a sample clothing-company sales dataset shown first as an Excel pivot table example, then reproduced as a 4D-native equivalent, including a more complex filtered/multi-dimensional variant. Pivot charts are covered as a visual counterpart, generating charts from the same underlying pivot configuration to make trends (e.g., regional sales performance by product/gender) easier to spot than in tabular form. The note then documents the practical mechanics in 4D: the Pivot Table/Chart Design Editor for developers to define the feature at design time, and the end-user-facing interface that lets users pick fields for rows, columns, and values interactively at runtime, along with the output design flow from user input through to rendered table/chart. A sample database demonstrates using the feature against both provided tables and a newly added user table. As a fundamentally end-user data-analysis feature (not tied to a specific web/mobile stack), the pivot table/chart capability introduced in v16 has remained part of 4D's toolset in subsequent releases, so this note continues to serve as a reasonably accurate onboarding guide, even as some 4D shops now also route more advanced BI-style reporting needs to external tools or through 4D Write Pro for richer document output.
