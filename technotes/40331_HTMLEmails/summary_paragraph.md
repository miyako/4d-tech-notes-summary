This Technical Note by Thomas Maul shows how to send HTML-formatted emails with embedded pictures from 4D 2004, using the motivating example of an automatically generated daily or weekly sales report sent to a management group. It contrasts two ways emails can reference pictures — external URLs (common in advertising email, offering smaller transfer size but allowing read-tracking and increasingly blocked by privacy-conscious mail clients) versus embedding pictures as MIME enclosures referenced within the document (larger but reliably displayed by all mail clients, making it the more dependable choice for business reports) — and explains the multipart MIME structure needed to combine HTML text with embedded image parts. The sample database generates a report containing customer sales statistics and a pie chart grouped by ZIP code plus a product-code statistic and chart, using 4D Chart to produce pictures that are converted to GIF, and demonstrates two ways to build the HTML content: the easy, no-HTML-knowledge-required 4D Quick Report engine (including its wizard-driven "Build 4D Code" feature, new in 4D 2004, which generates ready-to-use report code), and a more flexible HTML-template approach processed with the new PROCESS HTML TAGS command for merging dynamic data into developer- or designer-authored templates. The final assembled report is sent using 4D Internet Commands, and the note includes detailed step-by-step customization instructions (adjusting Quick Report destination parameters, performing MIME-safe character replacements for the "=" character) for adapting the demo to a developer's own Invoices-style database and exposing the reporting feature to end customers.
