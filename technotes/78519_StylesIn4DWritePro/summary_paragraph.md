This Tech Note is a reference guide to how styling works in 4D Write Pro, 4D's procedurally-buildable word-processing feature set. It starts with the document object model: a 4D Write Pro document contains structural elements (headers, footers, bodies, tables, rows, paragraphs, pictures, sections, subsections, style sheets), each obtainable and creatable via commands like `WP Get header`/`WP New header`, and a more generic "Range" concept — with `owner`, `start`, `end`, and `type` properties — that can target arbitrary spans of text, even across multiple paragraphs, via commands such as `WP Text range`. Styles are then applied to any target object (element or range) using the twin commands `WP SET ATTRIBUTES`/`WP GET ATTRIBUTES`, which take an attribute selector (ideally referenced via a `wk`-prefixed constant like `wk font bold` rather than a raw string, for autocomplete and forward-compatibility) and a value, with support for setting/getting multiple attribute-value pairs in a single call; the note documents the specific 205 and 204 syntax errors triggered by incompatible attributes or invalid values. An object-notation alternative is also shown, treating attributes as direct properties of a range object, with a recommendation to use bracket notation with `wk` constants rather than hardcoded dot-notation property names for safety. The second half of the note covers 4D Write Pro Style Sheets — a document-scoped, uniquely-named collection of style configurations analogous to style sheets elsewhere in 4D (Design environment, 4D View Pro). Style sheets are created with `WP New style sheet`, choosing between "character" type (applies only to the exact selected range) and "paragraph" type (applies to every paragraph touched by the range), attempting to reuse a name throws a 208 error, and once created a style sheet is styled just like a range via `WP SET ATTRIBUTES` and then applied to text using the `wk style sheet` attribute. The note notes that created style sheets automatically populate the 4D Write Pro toolbar's paragraph/character style dropdowns (with "Normal" as the default paragraph style), and the accompanying six-demo sample database walks through each concept hands-on.
