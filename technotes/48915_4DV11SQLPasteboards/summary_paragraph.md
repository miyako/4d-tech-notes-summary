This Technical Note covers the new Pasteboard theme of 4D v11 SQL. This new theme encompasses the functionality of the previous Clipboard theme and adds new functionality. One of the more significant additions is the ability to now access drag-and-drop data from outside of 4D. This Technical Note will cover the different pasteboards available in 4D, what new functionality has been added, and what data types are supported. A sample database is included. Published February 13, 2008 as Technical Note 08-06 for 4D Developer v11 (Mac &amp; Win), this note was written by Jesse Piña, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
