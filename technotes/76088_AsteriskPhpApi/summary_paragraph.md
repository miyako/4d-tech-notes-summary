This Tech Note covers how to integrate 4D v12 with Asterisk, the popular open-source PBX/VoIP telephony platform, using 4D v12's newly introduced PHP scripting support as the bridge. It first explains the architecture of 4D's PHP integration — the PHP EXECUTE command (calling into PHP over FastCGI), PHP SET OPTION/PHP GET OPTION for interpreter configuration, and PHP GET FULL RESPONSE for retrieving stdout, error, and HTTP header details — before introducing Asterisk itself, its Asterisk Management Interface (AMI) for external control, and how to enable AMI and provision users in `managers.conf`. It then introduces the Asterisk-PHP-API, a PEAR-distributed (BSD-licensed) PHP library by Doug Bromley that wraps AMI calls, and walks through practical examples: listing all queues, adding/removing a handset from a queue, listing SIP and IAX peers, listing parked calls, originating a call, running arbitrary Asterisk CLI commands, and listing/inspecting channel status. A companion example database exposes each of these operations through a demo form. The note closes with full license text for both Asterisk-PHP-API and Asterisk itself. It targets 4D developers wanting to integrate telephony/PBX control (call center queues, click-to-dial, call monitoring) into a 4D application.
