This Tech Note explains the basics of getting started with the ODBC Driver for 4D Server and 4th Dimension, covering setup and configuration on both Windows and Macintosh platforms. On Windows, it describes using the 32-bit ODBC administrator application to configure the driver, while on Macintosh it covers Intersolve's ODBC Data Source Administrator. The note also lists common problems encountered when using the ODBC driver or ODBC plug-in, providing troubleshooting guidance. ODBC connectivity was important for allowing external applications like spreadsheets, reporting tools, and other databases to access data stored in 4D Server. This was before 4D had its own built-in SQL engine, so ODBC provided the primary standardized data access path for third-party tools. The note reflects the late-1990s state of database connectivity technology.
