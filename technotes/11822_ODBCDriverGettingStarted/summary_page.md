# Tech Note 98-19: Getting Started with ODBC Driver for 4D Server

**Author:** Not specified
**Published:** December 1, 1998 | **Product/Version:** 4D Server v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11822

## Overview
This Tech Note covers the basics of setting up and configuring the ODBC Driver for 4D Server on both Windows (using the 32-bit ODBC administrator) and Macintosh (using Intersolve's ODBC Data Source Administrator).

## Key Points
- Covers ODBC driver setup on both Windows and Macintosh platforms.
- Uses the Windows 32-bit ODBC administrator for Windows configuration.
- Uses Intersolve's ODBC Data Source Administrator for Macintosh configuration.
- Lists common problems and troubleshooting for ODBC driver/plug-in usage.
- Enables external application access to 4D Server data via ODBC.

## Featured Technology
- 4D Server v6.0
- ODBC Driver for 4D
- ODBC Plug-in
- Intersolve ODBC tools
- Windows ODBC Administrator

## Historical Context
**Status:** Obsolete

This note predates 4D's built-in SQL engine (introduced in v11 SQL, ~2007). The ODBC Driver for 4D has been significantly updated for modern operating systems, and Intersolve's tools are no longer used. Modern 4D provides native SQL support and updated ODBC connectivity that supersede this early configuration approach.
