This tech note addresses changes and new additions in the GDIPlus plug-in, version 1.1

- The GDIPlus plug-in now uses the new 4D 2004 Plug-In Architecture but remains compatible with 4D 2003
- A stub for Mac OS X was created.
- Scrollbar support in plug-in area
- Mouse Wheel support in both the plug-in areas and external windows has been added
- The command Get Picture as blob was added
- Much faster redraw for very large pictures
- Bug fixes - Some issues of bad redraw or scrollbar calculation This 2005-era Tech Note (TN 05-06) was published for 4D version 2004 on Mac & Win, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). Featured technology associated with this note includes: GDIPlus plug-in v1.1, 4D 2004 Plug-In Architecture, Mac OS X plug-in stub, Get Picture as blob command. This addendum documents version 1.1 improvements to the GDIPlus plug-in, including adoption of the new 4D 2004 Plug-In Architecture, a Mac OS X stub, scrollbar/mouse-wheel support, and a new Get Picture as blob command. The GDIPlus plug-in itself is a discontinued third-party/legacy plug-in tied to the pre-Unicode, pre-Universal Binary 4D 2003/2004 plug-in API, so this specific plug-in and its API generation are now obsolete, though 4D still supports compiled plug-ins built on later, Unicode-aware API generations.
