Thomas Maul, General Manager of 4D Germany, provides an addendum documenting the changes in version 1.1 of the GDIPlus plug-in, a Windows-focused plug-in wrapping Microsoft's GDI+ picture-rendering technology for use inside 4D. The headline change is adoption of 4D 2004's new bundle-based Plug-In Architecture while remaining compatible with 4D 2003, shipping as a folder-like bundle on Windows plus a Mac OS X stub that makes the plug-in visible (though non-functional, since GDI+ is Windows-only) on that platform; installation instructions cover both placing the bundle in the new PlugIns folder for 4D 2004 and manually copying its Windows/Mac4DX contents for use with 4D 2003. Functionally, the plug-in area now automatically displays scrollbars when a picture exceeds the visible area (only under 4D 2003+), controllable via two new optional parameters (HorScrollbar, VerScrollbar) added to GDI_SetDisplayMode, alongside newly automatic mouse wheel support in both plug-in areas and external windows. The most substantive addition is the new command GDI_GetPictureBlob(Area; Format) → theBlob, intended for efficiently building a grid of thumbnails: by loading a picture into an offscreen area (GDI_LoadPictureFile), reducing it (GDI_ConvertToThumbnail), and extracting it as a blob for use with 4D Pack's AP Read Picture Blob (avoiding the need for QuickTime if a BMP format blob is used), developers can generate and hold many thumbnails in 4D without keeping large source pictures fully loaded in memory. The addendum closes with a note on faster redraw performance for very large pictures and general bug fixes for redraw and scrollbar-calculation issues.
