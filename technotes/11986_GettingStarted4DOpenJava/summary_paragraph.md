Written by Jamras Komoncharoensiri of 4D, Inc. Technical Support, this Tech Note introduces 4D Open for Java, a pure-Java package of twenty-three classes (distributed as a single jar file) that lets a Java program — applet or standalone — connect to a 4D Server and exchange data with it, running on any Java Virtual Machine (Windows, Unix, Linux, Mac OS) under Internet Explorer or Netscape Communicator. It lays out the three steps every 4D Open for Java program must follow: creating a connection via `opDriverManager.getConnection(ipAddress)` returning an `opConnection`, starting a 4D process on that connection with `connection.startProcess(workstation, user, password, processName)` (up to six simultaneous processes per client connection), and then issuing read/write requests as methods of the resulting `opProcess` object, before finally calling `stopProcess` and `CloseConnection`. The bulk of the note walks through a complete example applet class, `Employee`, which implements `ActionListener` and `opConstants`, initializing its UI in the constructor and routing all user interaction through a single `actionPerformed` event handler that dispatches to dedicated methods for connecting (`doConnect`, hardcoding a target IP and calling `RecordsInTable`), displaying all records (`doPrint` via `process.AllRecords(table)`), and searching, adding, deleting, and modifying records through similarly structured request/response method pairs. The note positions this pattern as the on-ramp for any Java developer building a custom client interface against a 4D Server database over a web connection.
