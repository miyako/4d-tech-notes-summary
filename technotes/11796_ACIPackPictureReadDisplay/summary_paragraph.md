This Tech Note details how to manage pictures using the ACI_PACK plug-in alongside native 4D routines, with code extracted from an accompanying Pixys example database. It covers a set of ACI_PACK commands including AP Get Picture Type, AP Read Picture Blob, AP Set Picture Mode, AP Read Picture File, AP Save BMP 8 Bits, and AP Save GIF, as well as 4D's own SAVE PICTURE TO FILE and COMPRESS PICTURE routines. Using these combined commands, developers could export pictures in PICT, BMP, JPEG, and GIF formats, and read PICT, JPEG, GIF, BMP, and (on Windows) WMF and EMF formats. The note also mentions that sound file types (.snd and .wav) could be interpreted on the Windows platform. This was a practical guide for developers needing cross-platform image handling in an era when 4D's built-in picture support was limited. The ACI_PACK plug-in filled critical gaps in 4D's picture I/O capabilities before native commands were expanded in later versions. Only teaser text survives; the full PDF and accompanying example database could not be recovered.
