This Tech Note by Timothy Tse documents a 4D v15-introduced list box capability that lets a single column display multiple different data types per row by backing that column with an array of 4D objects rather than a traditionally-typed array. It starts by explaining 4D's object type as a property/value data structure similar to JSON, capable of holding text, numeric, boolean, array, and nested-object values, and walks through defining such an object in 4D code. The note then explains how to use these objects as the source for a list box column array, noting that unlike a traditional single-type column (e.g. all-text or all-integer), an object-backed column lets each row display a different type — one row a checkbox (boolean), another a numeric spinner, another free text — driven entirely by what each row's object defines. It documents a color value type option and event handling specific to object columns, then works through the relevant object properties that control cell rendering and behavior: value, min/max, behavior, dropdowns, unit lists, and an alternate button configuration. A use-case section demonstrates parsing an object structure and building the corresponding list box arrays in practice, followed by a demo showing all the documented properties in action and displaying 4D objects as a functioning list box. Notably, the note flags that this feature requires a 4D View Pro license to use, tying it to 4D's premium grid/reporting product line even though the mechanism operates through the standard list box object. As a fairly narrow, feature-specific technical note, its content maps directly onto a still-supported 4D capability.
