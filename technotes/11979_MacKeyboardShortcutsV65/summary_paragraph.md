This Tech Note is a reference document compiling every keyboard shortcut available across 4D's Macintosh application family circa v6.5: 4th Dimension and 4D Server themselves, plus the companion utilities 4D Tools, 4D Transporter, and Customizer Plus. It is organized into clearly delineated sections covering shortcuts available while opening a structure file (such as holding OPTION to choose a different data file, or SHIFT to force the password dialog), shortcuts usable in all environments, shortcuts specific to the Design environment (window management, the Explorer, object renaming), shortcuts for the Debugger (including a process-switching pop-up triggered by CONTROL+OPTION+COMMAND+click during execution), shortcuts for the User and Custom Menus environments, and shortcuts for the standalone 4D utility applications. Its proposition is purely reference-oriented, giving developers and power users a single authoritative listing of productivity shortcuts rather than teaching any particular technique or API. The featured technology is the classic Mac OS-era 4D Design/Debug/User environment UI as a whole, reflecting how deeply integrated keyboard-driven workflows were in 4D's development experience at the time.
