This Tech Note describes the 4th Dimension Form Wizard as a powerful tool for creating forms and rules-based form templates, noting that although the Form Wizard has literally hundreds of built-in options, a developer may still want to customize the "look and feel" of generated templates by substituting their own resources for the graphics the Form Wizard uses by default. The note's purpose is to show developers how, and where, to place custom graphics so they override the Form Wizard's default graphics. As an example, it uses the MusicPro database, one of the sample applications included in the standard 4D and 4D Pro installation, to walk through the technique. A notable caveat given in the teaser: 4D supports Mac OS-based resources on both Macintosh and Windows, but because the Windows environment does not provide utilities for editing Mac OS-based resources, developers must follow this particular example on a Macintosh. No further specifics of the actual resource file locations, naming conventions, or step-by-step replacement procedure are present in the recovered teaser text; the concrete guidance from the original PDF could not be recovered for this summary.
