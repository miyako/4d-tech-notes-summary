# Tech Note: Customizing the 4D Form Wizard

## Overview
This note explains how to customize the "look and feel" of templates generated by the 4th Dimension Form Wizard, by substituting custom graphics resources for the Wizard's built-in defaults, demonstrated with the MusicPro example database.

## Key Points
- The Form Wizard has hundreds of built-in options for creating forms and rules-based templates.
- Developers can override the Wizard's default graphics by placing their own custom resources in the correct location.
- The MusicPro sample database (bundled with standard 4D and 4D Pro installations) is used as the worked example.
- Important caveat: 4D supports Mac OS-based resources on both platforms, but only Macintosh provides utilities for editing them — so this specific example must be followed on a Mac.
- Specific resource file locations, naming conventions, or a step-by-step replacement procedure are not present in the recovered teaser text.

## Featured Technology
- 4D V6 Form Wizard
- Mac OS-based resource files (custom graphics)
- MusicPro example database

## Historical Context
Published August 1997, shortly after the V6-era Form Wizard's introduction, this note reflects the cross-platform resource-file quirks of the classic Mac OS/Windows 3.1/95 era, where Mac-style resources could be used on Windows but only edited on a Macintosh. The archive of the full technical content could not be recovered (no working download link exists for the original page). Both the Form Wizard's template-customization approach and the classic Mac OS resource-fork model referenced here are obsolete: the Form Wizard has been superseded by later 4D form design tools, and classic Mac OS resources became irrelevant once Mac OS X moved away from the resource fork model.
