This Tech Note dissects the classic "Spinners" demo database, which implements up/down spinner controls that increment or decrement a field's value while the mouse button is held down, with optional acceleration after a configurable delay. It walks through the Compiler_Spin method that declares the shared variables and speed/wait lookup arrays, the M_ShowDemo method that opens the single dialog form, and the bOnLoad object method that detects whether the database is running on Mac or Windows to show the correct platform-specific buttons. The heart of the technique is the Spin_Control project method, triggered from On Clicked and On Timer form events, which reads the mouse state with GET MOUSE, decides whether to accelerate based on elapsed time, and then updates the pointed-to field differently depending on whether it is a Time, Date, or plain numeric type (handling US vs. non-US date ordering for month/day highlighting). The note credits the original method to Tom Dillon of DataCraft, with a later "Under the Hood" revision by Raymond Manley for 4D, Inc. It is a good illustration of using On Timer, pointers, and SET TIMER together to build a responsive custom UI widget in classic 4D.
