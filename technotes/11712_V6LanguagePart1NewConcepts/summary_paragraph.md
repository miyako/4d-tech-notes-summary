This Tech Note is Part 1 of a multi-part series previewing the substantial language and conceptual changes introduced in 4th Dimension Version 6, aimed at developers moving up from earlier 4D releases. It opens with a terminology shift: what were previously called "Files" and "Procedures" are now officially "Tables" and "Methods" (aligning 4D's vocabulary with standard relational database terminology), and object names (tables, fields, methods, variables) can now be up to 31 characters long instead of the previous short limit, giving developers far more descriptive naming freedom. The note then walks through a series of new language capabilities: built-in system constants (replacing hardcoded numeric literals with named values for readability), new hexadecimal and bitwise operators for low-level numeric manipulation, and the BLOB (Binary Large Object) data type for storing arbitrary binary data directly in fields/variables. A significant section covers object properties and events — a new mechanism letting developers query and respond to the state and interactions of form objects programmatically, described as a step toward more dynamic, event-driven form behavior. Query-related enhancements are also detailed: expanded query destinations and result-set limiting options giving developers finer control over search operations. The note covers new password-management commands for enhancing 4D's built-in access-privilege system, and stored procedures, a mechanism for running server-side 4D code independent of client connections. It closes with an introduction to 4D's then-brand-new built-in Web Server capability — describing how 4D could now natively serve web pages and interact with browser requests without requiring a separate web server product, a significant early step in 4D's Internet strategy. Featured technology spans the full breadth of 4D v6.0's new language surface: terminology/naming changes, constants, hex/bitwise operators, BLOBs, object properties/events, query enhancements, password/stored-procedure commands, and the built-in Web Server.
