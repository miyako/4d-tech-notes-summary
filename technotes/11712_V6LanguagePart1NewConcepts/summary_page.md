# Tech Note 96-45: The 4D Language, Part 1: New Concepts in Version 6

**Author:** Walt Nelson
**Published:** September 1, 1996 | **Product/Version:** 4th Dimension v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11712
**Download:** https://kb.4d.com/DLTN/TN/1996/Windows/TN_1996_42-45_(SEP)/96-45_V6_Language_Part1.exe

## Overview
Part 1 of a multi-part series, this Tech Note is a comprehensive preview of the language and conceptual changes introduced in 4th Dimension Version 6, covering new terminology, longer object names, constants, new operators, BLOBs, object properties/events, query enhancements, password commands, stored procedures, and 4D's first built-in Web Server.

## Key Points
- **Terminology shift:** "File" and "Procedure" become "Table" and "Method," aligning 4D's vocabulary with standard relational database terms.
- **Longer names:** table, field, method, and variable names can now be up to 31 characters.
- **New language features:** built-in system constants, hexadecimal/bitwise operators, and the BLOB (Binary Large Object) data type.
- **Object properties and events:** a new mechanism for querying and responding to form object state and interactions programmatically.
- **Query enhancements:** expanded query destinations and result-set limiting options.
- **Password commands and stored procedures:** enhancements to the access-privilege system and server-side code execution independent of client connections.
- **Built-in Web Server:** 4D's first native capability to serve web pages and handle browser requests without a separate web server product.

## Featured Technology
- 4D v6.0 language enhancements (longer names, constants, object properties, events)
- 4D as Web Server (early built-in web server feature)
- BLOB data type
- Password / stored procedure commands

## Historical Context
This note is a snapshot of the significant v6.0 transition, but nearly every specific feature it describes has since been superseded many times over: object naming limits now far exceed 31 characters, the early built-in Web Server bears no resemblance to 4D's modern web server/web services/ORDA stack, and password commands and stored procedures have been substantially reworked across two decades of subsequent releases. The "File"→"Table" and "Procedure"→"Method" terminology shift, however, has become permanent and is now simply the standard 4D vocabulary. Overall, the note is best read today as a historical snapshot of 4D's evolution rather than a current technical reference.
