Kent Wilbur continues his three-part Quick Report editor source-code series, this time covering the code behind the editor's manual mode form page, assuming readers are already familiar with Part 1's virtual-structure and hierarchical-list-building groundwork. The note explains how the manual mode page is organized into layered views — Table and select-from popups, a primary hierarchical field list, and (in a second view) a static table name, a related-table hierarchical list, and cross-tab sort options — with the nqr_table and nqr_filter popups triggering NQR_MP_Get_Fields from Part 1 to rebuild the field lists. A central focus is the NQR_MP_CALL method, which dispatches user interactions with the licensed plug-in report area, and the code that handles drag-and-drop of fields from the hierarchical lists into that plug-in area. Wilbur also documents double-click handling on the field lists as an alternative to drag-and-drop, and the more intricate logic for keeping a list-style report's sort-order indicators synchronized — since the same hierarchical list of sortable fields is effectively displayed in more than one place and must stay consistent, a technique he flags as a genuine "trick" worth studying. A parallel section covers synchronizing the cross-tab report's sorting indicators, which follow similar but distinct rules from the list-style case. The technical note closes by setting up Part 3, which will cover the code behind the Quick Report wizard itself.
