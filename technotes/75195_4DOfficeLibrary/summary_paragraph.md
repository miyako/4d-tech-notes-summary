This Tech Note introduces the 4D Office Library, an updated component for 4D v11 SQL that lets a database exchange data with Microsoft Office 2007 (Windows) or Office 2008 (Mac), replacing the older 4D 2004 Office Object Library which produced only a single XML file per document. Because Office 2007/2008 documents use the Office Open XML format — several XML "parts" (document.xml, styles.xml, sheet1.xml, etc.) compressed together with relationship files inside a ZIP container — the component builds these XML parts with 4D DOM commands, then compresses them using the Mac's built-in `zip` command or the bundled 7-zip utility on Windows via `LAUNCH EXTERNAL PROCESS`, and finally renames the resulting archive to a .docx or .xlsx extension. The library is designed to be dragged onto an output form, letting a user select one or more records and open a GUI where fields are dragged from a list box onto a target area to bind them to the generated Word or Excel document, with options for titles, watermarks, backgrounds, logos, and (for Excel) custom colors. A separate integration handles Outlook Contacts/Calendar (Windows) and Address Book (Mac): the component dynamically generates and executes VBScript (`cscript`) or AppleScript (`osascript`) files via `LAUNCH EXTERNAL PROCESS`, communicating results through standard output parsed by 4D, to import or export contacts and to import appointments within a specified date range. Requirements include Office 2007/2008 (or the Microsoft Compatibility Pack for older Office versions) and, on Windows, the bundled 7-zip tool. The note targets developers needing turnkey Office document generation and Outlook/Address Book synchronization without building the XML/zip and scripting plumbing themselves.
