Written by Jason T. Slack of 4D Inc., this Technical Note demonstrates how to build a rich-internet-application "mashup" — combining external web content/APIs with local 4D data — using the 4D Ajax Framework (4DAF) Client, part of 4D Web 2.0 Pack, framed within the broader Web 2.0 narrative of interactive websites and public APIs from companies like Google, eBay, and Yahoo. Rather than covering 4DAF installation or general developer documentation (pointed to separately at 4D's support documentation site), the note walks step-by-step through building a specific Google Maps mashup from scratch: creating a blank database with an "Address Info" table (Street/City/State/ZipCode fields), generating default forms and entering sample records, installing and testing the 4D Ajax Framework, and logging into the 4DAF Client as Administrator to see the auto-generated Portal and Selection Window UI (fully functional without writing any 4D code). The core technique introduced is the "Developer Defined Window" (DDW), a 4DAF Settings feature letting developers attach a window of arbitrary HTML content or a URL to any field; the note configures a "GoogleMaps" DDW (type "New Window – Link") and, via the Access Control tab, associates it with the Address Info table's Street field so that field renders as a clickable hyperlink in the Selection Window. A short Database Method named "GoogleMaps" is then written to power the DDW, using DAX_Dev_DDW_GetAttributes to retrieve the current table pointer and selected record numbers, building a Google Maps URL query string from the record's Street/City/State/ZipCode fields (using the classic Google Maps "maps.google.com/maps?f=q&...&q=" address-lookup URL pattern) and returning it as the DDW's target link. Clicking the Street link in the running app then opens the corresponding Google Maps location. Featured technology centers on the 4D Ajax Framework Client, its Settings/DDW Manager and Access Control UI, the DAX_Dev_DDW_GetAttributes command, and the classic Google Maps URL-based API, illustrating a lightweight way to embed third-party map data into a 4D web application of that era.
