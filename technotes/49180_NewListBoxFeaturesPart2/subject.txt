Tech Note: New List Box Features in 4D v11 SQL – Part 2 (TN 08-09, 4D Developer v11, March 13, 2008) — A direct follow-up to TN 07-38 (New List Box Features in 4D v11 SQL), this second installment shifts focus from the Form Editor's visual list box configuration to controlling the same new list box data sources and behaviors entirely through code, covering the updated commands developers use to manage List Boxes programmatically for dynamic, code-driven list box content in 4D v11 SQL applications.
