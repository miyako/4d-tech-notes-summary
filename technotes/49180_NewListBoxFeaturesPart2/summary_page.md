# New List Box Features in 4D v11 SQL – Part 2

## Overview
A direct follow-up to TN 07-38 (New List Box Features in 4D v11 SQL), this second installment shifts focus from the Form Editor's visual list box configuration to controlling the same new list box data sources and behaviors entirely through code, covering the updated commands developers use to manage List Boxes programmatically for dynamic, code-driven list box content in 4D v11 SQL applications.

## Key Points
- Published March 13, 2008 as Technical Note 08-09.
- Targets 4D Developer v11 on Mac & Win.
- Author: Tom Fitch, Technical Services Team Member, 4D Inc..

## Featured Technology
- 4D v11 SQL List Box
- List Box programmatic control commands
- Dynamic data sources
- Form Editor vs. code-based configuration

## Historical Context
List Boxes remain a core, actively maintained 4D form object, so the underlying concept here is still directly relevant, though the specific v11 SQL-era command set and data-source model described has been substantially extended and partly superseded by later list box enhancements and ORDA-based data binding.

**Status:** superseded

**Related updates:**
- 4D's List Box object has continued to receive major feature updates in versions well beyond v11 SQL, including collection- and entity-selection-based data sources introduced alongside ORDA (2018+)
- Modern list box data binding commonly uses ORDA collections/entity selections rather than the specific v11 SQL-era commands shown in this note
