A direct follow-up to TN 07-38 (New List Box Features in 4D v11 SQL), this second installment shifts focus from the Form Editor's visual list box configuration to controlling the same new list box data sources and behaviors entirely through code, covering the updated commands developers use to manage List Boxes programmatically for dynamic, code-driven list box content in 4D v11 SQL applications. Published March 13, 2008 as Technical Note 08-09 for 4D Developer v11 (Mac & Win), written by Tom Fitch, Technical Services Team Member, 4D Inc.. List Boxes remain a core, actively maintained 4D form object, so the underlying concept here is still directly relevant, though the specific v11 SQL-era command set and data-source model described has been substantially extended and partly superseded by later list box enhancements and ORDA-based data binding.
