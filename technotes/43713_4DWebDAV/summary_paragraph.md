This Tech Note by Jeremy Sullivan introduces the 4D DAV plug-in, which gives 4D 2004 developers a set of routines for connecting to WebDAV (Web-based Distributed Authoring and Versioning) servers, supporting the full range of standard WebDAV commands, SSL communication, and connections to Apple's iDisk service. It positions the plug-in as a major improvement over hand-rolling WebDAV support using the low-level TCP commands in the Internet Commands plug-in, which would otherwise require developers to manage all HTTP-level communication themselves and buffer downloaded data in memory-hungry BLOBs; instead, the 4D DAV plug-in is built on the cURL library (libcurl) to handle TCP communication and works directly with files on disk, avoiding memory overhead for large file transfers. The note walks through an included example database that acts as a fully functional WebDAV client, supporting connection to any WebDAV server or an Apple iDisk via .Mac, complete with progress-bar transfer feedback and the ability to cancel uploads or downloads mid-transfer. It documents the example client's UI: entering a server address (with optional port) and credentials to connect, browsing folders and files, downloading by double-clicking, navigating back up a directory tree, creating new folders, and locking/unlocking files or folders to prevent concurrent modification (noting that iDisk does not support locking, so those controls are disabled in that mode) and deleting files or folders (which recursively deletes children). The note is squarely aimed at 4D developers who need to integrate remote file collaboration and versioning into a 4D 2004 application using a mid-2000s protocol that was gaining traction for collaborative file editing over HTTP. As both the specific 4D DAV plug-in and Apple's iDisk/.Mac service referenced throughout are long retired, this note is now primarily of historical interest, though WebDAV itself persists in some enterprise and cloud storage systems today.
