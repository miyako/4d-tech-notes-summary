# Tech Note: Converting C Dates into 4D Dates

**Author:** Not specified
**Published:** December 1, 1999 | **Product/Version:** 4D Plugin Wizard | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11855

## Overview
This Tech Note discusses a plug-in for converting between C/GMT date formats and 4D's internal date format, used in the context of URL processing.

## Key Points
- Provides a plug-in for C date to 4D date conversion and vice versa
- Includes GMT (Greenwich Mean Time) date handling
- Plug-in routines are used in an accompanying URL-related example database
- Demonstrates native plug-in development for extending 4D capabilities

## Featured Technology
- 4D Plugin Wizard / native C plug-in development
- Date format conversion (C/GMT ↔ 4D)
- URL processing integration
