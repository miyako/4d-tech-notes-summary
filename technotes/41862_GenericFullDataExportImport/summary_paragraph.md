This Tech Note introduces a single, self-contained 4D method named "ExportImport" that exports or imports an entire 4D database's data, including subtables, pictures, and BLOBs, to and from XML format. Its stated purpose is twofold: to serve as a long-term, format-independent archival mechanism, and to repair or optimize databases by exporting all data in text form and re-importing it into a freshly created data file, which guarantees clean data and indexes and produces a fully defragmented file with faster sequential access. The method restores each table's sequence number automatically and is designed for simple copy-and-paste installation into any existing 4D structure, requiring only that the method be named exactly "ExportImport" (or that references to that name be updated if renamed); if the database is compiled with "All variables are typed," a few C_TEXT/C_POINTER/C_LONGINT/C_BOOLEAN declarations must also be added to a Compiler method, and a single process variable, ExportImport_Stop, allows an in-progress export/import to be cancelled from another process. The method can be run interactively from User mode (prompting for export/import direction and a target folder) or called directly with two parameters, direction ("Export"/"Import") and a folder path, e.g. ExportImport("Export";"C:\\myxmlfolder"). During export it writes one XML file per table, automatically starting new segment files at 1.5GB to avoid known problems on Mac OS despite Windows XP's ability to handle files over 2GB; pictures and BLOB fields are Base64-encoded inline. On import, existing records in the target (expected to be a newly created, empty data file) are deleted, indexes are dropped before import and rebuilt afterward for speed and reduced fragmentation, and sequence numbers are restored. The routine also sanitizes table and field names into XML-safe tags, replacing diacritical characters and leading digits with underscores. The note references a similar, more complex component-based approach from Tech Note 01-43 under 4D 6.7, noting this newer single-method version is simpler to install and adds automatic subtable and sequence number support.
