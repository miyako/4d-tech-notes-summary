# Tech Note 04-10: Using 4D with United States Postal Service (USPS) Web Services

**Author:** Not specified in source teaser
**Published:** March 11, 2004 | **Product/Version:** 4D v2003.3 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31738
**Download:** https://kb.4d.com/DLTN/TN/2004/Windows/TN_2004_10-15_(MAR)/04-10_4D_w_USPS_WebServices.exe

## Overview
This Tech Note shows how to consume the USPS Web Tool Kit API (rates calculation, delivery confirmation, merchandise returns, and more) from a 4D application using 4D Internet Commands, positioning 4D as a client of an external web service rather than only a Web Services publisher.

## Key Points
- Introduces the USPS Web Tool Kit API and its range of services (Domestic Rates Calculator, Delivery Confirmation, Electronic Merchandise Return Service, etc.).
- Demonstrates communicating with these external USPS web services from 4D using **4D Internet Commands**.
- Represents 4D acting as a web service **consumer/client**, complementing other era notes about 4D **publishing** its own SOAP Web Services.

## Featured Technology
- 4D Internet Commands
- USPS Web Tool Kit API
- External (non-4D) web service consumption

## Historical Context
Only the on-page teaser paragraph for this asset could be recovered (the full archived PDF was not accessible in this environment), so this summary reflects the note's stated scope, not its exact code or API call details. As a 2004-era note, it reflects a time when 4D Internet Commands were the primary toolkit for HTTP-based integrations; both the specific USPS API details and the 4D-side networking commands have evolved considerably since, but the underlying pattern — a 4D app calling an external API for shipping/logistics data — remains a common and relevant integration scenario.
