This Tech Note demonstrates how a 4D application can act as a client of an external third-party web service, specifically the United States Postal Service (USPS) Web Tool Kit Application Program Interface (API). It explains that the USPS API allows developers to build both web-based and non-web-based applications that access a range of USPS services online, including the Domestic Rates Calculator, Delivery Confirmation, and the Electronic Merchandise Return Service, among others. The core proposition of the note is to show 4D developers how to communicate with these USPS web services using 4D Internet Commands, 4D's companion toolkit for HTTP/internet protocol operations at the time. This represents a somewhat different use case from many contemporaneous 4D Web Services notes, which focus on 4D publishing its own SOAP-based Web Services; here, 4D is instead the consumer, reaching out to an external, non-4D web API. The featured technology combines 4D Internet Commands for the underlying network communication with the specifics of formatting requests to and parsing responses from the USPS API. As with other notes in this series, it likely ships with an example database (implied by the "Download Complete Tech Note & Example" pattern common to this era) demonstrating at least one of the USPS services in action, giving developers a template for integrating shipping- and postal-related functionality into their own 4D applications.
