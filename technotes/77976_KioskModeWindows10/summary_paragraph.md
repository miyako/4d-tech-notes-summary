This Tech Note explains how to turn a Windows 10 machine into a locked-down "kiosk" running a 4D application, a common requirement for point-of-sale systems or public-facing terminals where users must be prevented from tabbing out, browsing other apps, or otherwise leaving the intended application. It requires Windows 10 Enterprise or Education (version 1709 or later) to access the Windows Configuration Designer tool, which is used to build a provisioning package that configures the assigned-access kiosk shell. The bulk of the note walks step-by-step through the Windows Configuration Designer interface: selecting kiosk-mode settings, configuring which account and application should run as the locked-down shell (in this case a 4D application executable), and tuning advanced settings such as restart behavior. It then covers exporting the resulting provisioning package and installing it onto the target Windows 10 machine to activate kiosk mode. A recovery section explains how to exit kiosk mode if needed — using an admin account, disconnecting the session (e.g., via "tsdiscon" from the command line), restoring a previous system restore point, or reverting the provisioning package changes — and how to clean up any accounts created specifically for the kiosk configuration. The note also notes that equivalent configuration can be scripted with PowerShell as an alternative to the graphical Windows Configuration Designer tool.
