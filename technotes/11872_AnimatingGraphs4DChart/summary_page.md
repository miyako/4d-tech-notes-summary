# Tech Note: Animating Graphs with 4D Chart

**Author:** Not specified
**Published:** June 1, 1998 | **Product/Version:** 4D Chart v6.0 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11872

## Overview
This Tech Note demonstrates how to create 3D animated graphs using only 4D v6 and its built-in 4D Chart module, with no additional plug-ins required. An example database accompanies the note.

## Key Points
- Creates 3D animated graphs entirely within 4D v6 and 4D Chart
- No additional plug-ins required
- Example database provides hands-on learning for 4D Chart features
- Useful for presentations and About Box displays
- Built-in graphing highlighted as a competitive advantage over other database products (which required ~$300 ActiveX controls)

## Featured Technology
- 4D Chart (built-in charting module)
- 3D graph animation techniques
- About Box integration
