This Tech Note demonstrates a technique for creating 3D animated graphs entirely with 4D v6 and its built-in 4D Chart module, requiring no additional plug-ins. The animation is showcased in an accompanying example database, which the author describes as an entertaining way to learn 4D Chart's features. The note highlights that 4D Chart's built-in graphing capability was unusual for database products of the era, noting that competing products typically required purchasing a separate Active-X control at approximately $300.
