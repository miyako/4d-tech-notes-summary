4D v11 SQL Release 3 introduced SQL pass-through, a native direct TCP/IP communication channel between 4D Servers and 4D Professional applications, eliminating the need for ODBC drivers or intervening layers. This feature addressed the discontinuation of the 4D Open plug-in that had previously enabled database-to-database communication. The new SQL LOGIN and SQL LOGOUT commands (renamed from ODBC LOGIN/LOGOUT) allow Professional applications to open synchronous connections to external databases—whether another 4D Server, an ODBC DSN, or the internal database—and execute SQL statements directly on that source via Begin SQL/End SQL blocks with the optional asterisk (*) parameter for external redirection. Communication occurs automatically in synchronous mode, ensuring data integrity and eliminating synchronization questions; only one connection is authorized per process, and direct connections are only honored when the target 4D Server's SQL server is active. The note provides a proof-of-concept demonstrating field-level change tracking with ownership and collision prevention, as well as new BLOB storage capabilities for picture variables and picture arrays introduced in Release 3. SSL encryption is supported if enabled on the SQL Preferences of the target 4D Server. The technical note details the renaming of all ODBC-prefixed commands and constants to SQL-prefixed equivalents and marks USE EXTERNAL DATABASE and USE INTERNAL DATABASE as obsolete.
