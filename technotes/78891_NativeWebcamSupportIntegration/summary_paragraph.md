This Tech Note shows how to add webcam support to a 4D application now that 4D's embedded Web Area rendering engine (updated in v19R3) supports the HTML5 <video> element and JavaScript's getUserMedia API natively, eliminating the need for the third-party frameworks required by an earlier (2015) 4D Tech Note. Developers must enable 'Use embedded Web rendering engine' on the Web Area form object for this to work. The note walks through progressively richer demos: a base HTML/CSS page streaming live video, horizontally flipping the feed via CSS classes toggled from 4D code with WA EXECUTE JAVASCRIPT FUNCTION, enumerating and switching between multiple camera devices with navigator.mediaDevices.enumerateDevices(), and capturing a still photo by drawing the video frame onto an HTML5 canvas and returning a base64 PNG via WA EXECUTE JAVASCRIPT FUNCTION, which 4D then converts to a native picture with BASE64 DECODE and BLOB TO PICTURE. All of this culminates in a polished, reusable 'snapShot' component exposing a single openPhotoBooth(options) method that opens a full Photo Booth window supporting multi-photo or single-photo capture, optional automatic center-cropping, camera-source switching, and horizontal flip — designed to be dropped into any host application needing generic camera capture. This is a complete, componentized solution rather than just a code sample.
