This Tech Note investigates whether replacing a magnetic hard disk drive with a solid-state drive meaningfully improves 4D performance, starting from the premise that 4D is a heavily disk-intensive application: the data file, structure file, data log file, indexes, and the v11 SQL data file cache all depend on storage speed. It explains SSD internals in depth — flash memory cells, the drive controller, wear-leveling and lifespan features, and especially why SSD write performance can degrade over time (every write effectively becoming a read-modify-write cycle as free blocks are consumed) — along with guidance on buying the right SSD for a given workload. The note then presents benchmarks comparing a Western Digital Raptor (HDD), an Intel X25-M, and an OCZ Colossus (both SSDs) across three representative 4D operations: modifying 500,000 records, performing 100,000 random GOTO RECORD calls, and sequentially sorting 6,000,000 records, with test code and results shown for each. The note concludes with practical guidance on when developers can expect SSDs to yield the greatest real-world benefit for 4D applications.
