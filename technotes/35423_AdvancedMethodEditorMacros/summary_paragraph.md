One of the many new features added to 4D 2004 is an expansion to Method Editor Macros with an addition to the tagging language: the method tag. The method tag allows us to call any project method contained in the database calling the macro. This 2005-era Tech Note (TN 05-01) was published for 4D version 2004 on Mac & Win, during the pre-SQL, Design Mode-only period of 4D's history (4D 2004/2004.1, before v11 SQL, ORDA, or Project Mode existed). Featured technology associated with this note includes: 4D Method Editor macros, Macro tagging language (method tag), Project method invocation from macros. This note documents the method tag, a 2004-era enhancement to 4D's Method Editor macro tagging language that let macros invoke any project method in the database, extending macros beyond simple boilerplate code generation. The classic Method Editor and its macro system belong to the binary Design Mode code editor of this era; modern 4D development uses the newer code editor tooling and, in Project Mode, text-based method files, so this specific macro-tag mechanism is now largely superseded even though on-demand code generation remains a useful concept.
