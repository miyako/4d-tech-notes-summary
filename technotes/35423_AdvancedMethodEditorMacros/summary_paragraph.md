This Tech Note by Jonathan Le of 4D Technical Support covers the expansion of 4D's Method Editor Macro language in 4D 2004, centered on the new "method" tag, which lets a macro invoke any project method that exists in the calling database rather than just regurgitating static code snippets. It explains how macros are authored as XML files (with tags such as macro, text, caret, selection, user_os, date, time, method_name, and method) stored in the "Active 4D" folder, and how they can be triggered from the Method Editor toolbar, the Design menu, or type-ahead auto-completion. Two worked examples anchor the note: an "IfWrap" macro extension of the built-in "If" macro that wraps a highlighted code selection in an If/End If block using the selection tag, and a "ReverseIt" macro that uses special process variables (_textSel, _textReplace, _action) to reverse highlighted text via a called project method. A more advanced "Variable Wizard" example shows a macro opening a dialog form, collecting variable names/types from the user, and inserting generated compiler declarations back into the method editor via the _blobReplace and _action output variables -- illustrating the combination of calling a project method, displaying UI, and generating code. The note closes by referencing the bundled Macro Pack component, which supplies ready-made macros for auto-documentation, parameter assignment, and SOAP declaration generation.
