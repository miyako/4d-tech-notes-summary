## Historical Commentary
**Status:** Still Relevant

LDAP remains a still-relevant, widely used directory-service protocol today (e.g., via Active Directory), so the core integration goal of this note is still valid, though modern 4D applications would typically use later, more capable LDAP-related commands and libraries, or delegate authentication to modern identity providers (SSO/OAuth) rather than raw LDAP binds.
