Written by Pierre Bonnais of 4D Inc. as a follow-up to Christian Cypert's earlier LDAP overview (TN 02-54), this note focuses squarely on porting an existing Windows LDAP plug-in to Mac OS X using the Mach-O runtime architecture, the only executable format the OS X kernel loads natively. It walks through using the 4D Plug-in Wizard to scaffold a CodeWarrior project, then transferring the Windows plug-in's resource fork (the '4BNX' command-ID resource, the matching 'STR#' routine-name list, and optional 'FON#'/'THM#' theme resources) to the Mac side using 4D Transporter's PC-to-Mac conversion. On the code side, it shows conditional compilation to swap winsock2.h/winldap.h for the OS X ldap.h/ldap4D.h headers, configuring CodeWarrior to find /usr/include and link against /usr/lib/libldap.dylib, and resolving a notorious 'dyld_stub_bindin_helper' linker error by adding bundle1.o to the project. Finally, the note shows how the ported plug-in can be used in a real 4D web scenario: an incoming 4DAction request triggers the On Web Authentication method, which uses the ldap_Authentication routine to validate a username/password pair (packaged as a Distinguished Name) against a directory server, returning True or False to grant or deny the 4DAction call.
