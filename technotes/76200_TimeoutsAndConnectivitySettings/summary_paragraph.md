Timothy Aaron Penner's extensive Tech Note serves as a master reference for 4D Client/Server network configuration. It systematically covers 4D Server and Remote mode timeout settings, with special attention to the Idle Connections Timeout (Database Parameter 54) — explaining its background, common use cases, default values, and how to safely change it — alongside other settings affecting connectivity such as TCP_NODELAY (Database Parameter 33), Automatic Client Reconnect, Register Clients at Startup, and connection encryption. A large section addresses how routers and firewalls interact with 4D Server/Remote Mode timeouts, with concrete configuration notes for specific hardware/firmware (Cisco, Sonicwall, IPCop, DD-WRT, Tomato) and guidance for diagnosing router-related and internet-wide connectivity problems. The note ends with recommended 'safest settings' and a list of other resources. It is essentially a network administrator's field guide for keeping 4D Client/Server deployments stable across varied, real-world network topologies.
