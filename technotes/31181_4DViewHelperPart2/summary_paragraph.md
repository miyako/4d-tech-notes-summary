This second-part Tech Note, written by Melinda Gallo with routines originally authored by Dave Batton, provides detailed reference documentation for the "4D View Helper" component, a small library of project methods designed to simplify displaying and manipulating arrays or records inside a 4D View spreadsheet-style plug-in area. It documents seven routines in depth: `PV_GetSelectedRow` and `PV_GetSelectedRows`, which wrap `PV GET SELECTED RANGES LIST` to return the first or all selected row numbers as a simple array; `PV_SetColumnWidths`, which accepts either percentage or pixel widths (detecting the mode by checking whether the values sum to 100), computes pixel widths against the area's actual width minus the scrollbar, and calls `PV SET COLUMNS WIDTH` and `PV EXECUTE COMMAND` to resize or hide columns while preserving the current selection; `PV_SetFont`, which sets the font name, size, and style on the "Cells" style sheet via `PV SET STYLE PROPERTY`, falling back to the system font if none is specified; `PV_SetRowHeight`, which applies a uniform row height via `PV SET ROWS HEIGHT` after checking the row count with `PV Get document property`; and `PV_SetSelectedRow`/`PV_SetSelectedRows`, which programmatically select one or many rows via `PV SELECT ROWS` and `PV SELECT RANGES LIST`, temporarily disabling the `PV ON EVENT` selection-changed callback to avoid firing it during the programmatic change. Each routine's parameters, types, and full source code are listed, making this note effectively an API reference for building custom grid-manipulation logic on top of 4D View's native plug-in command set, intended to save developers from re-deriving common selection, sizing, and formatting logic from scratch.
