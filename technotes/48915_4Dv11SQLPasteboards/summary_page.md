# 4D v11 SQL Pasteboards

## Overview
This note documents the new Pasteboard theme introduced in 4D v11 SQL, which extends and replaces the previous Clipboard theme with additional capabilities — most notably the ability to read drag-and-drop data originating from outside 4D itself. It surveys the different pasteboards now available, the new functionality layered on top of the old clipboard model, and the data types each pasteboard type supports.

## Key Points
- Published February 13, 2008 as Technical Note 08-06.
- Targets 4D Developer v11 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D v11 SQL Pasteboard theme
- Clipboard vs. Pasteboard commands
- Drag-and-drop data exchange (external sources)

## Historical Context
Clipboard/pasteboard and drag-and-drop interoperability with the host OS remains a relevant capability in 4D today, so the underlying concept holds up, though the specific v11 SQL-era Pasteboard command set has been extended and refined across many subsequent 4D releases.
