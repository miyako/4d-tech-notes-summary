Building on an earlier introductory note on basic hierarchical lists, this Tech Note focuses entirely on programmatic manipulation of an existing hierarchical list via the sample "Hierarchical List Palette" database. It explains the semantics of core list commands — Count list items, Selected list item, APPEND TO LIST, and INSERT LIST ITEM — and clarifies subtle gotchas, such as list item positions being expressed relative to the top of the main list even when working inside a sublist. The note works through five concrete scenarios: inserting an item before or after the selected item (including edge cases where the selected item is the last in the main list, the last in a sublist, or where the next item is itself an expanded child), inserting a new child item by attaching a freshly created sublist via SET LIST ITEM, appending an item to a list or sublist by resolving the sublist's reference via its parent, and finally the comparatively simple replace (SET LIST ITEM) and delete (DELETE LIST ITEM) operations. Throughout, it emphasizes using List item parent and List item position together with a copied/isolated sublist to get correct positions when siblings and children are mixed. This is a practical companion/reference note for any developer working with 4D's classic hierarchical list object type.
