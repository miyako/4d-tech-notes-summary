Written by Tim Tonooka of ACI Technical Support, this is Part II of a series on building interactive graphic interfaces with 4D Draw using the "v65Trace" example database, following Part I's coverage of creating and converting 4D Draw vector graphics. This installment begins explaining the example database's code, focusing specifically on the "BMP Picture Properties" menu item and its underlying validation logic. The DRW_BMPInfoWindow method demonstrates a "start in a new process if not already running" pattern (using New process, Count parameters, and BRING TO FRONT) before calling DRW_BMPReadF, which shows the user a standard Open File dialog filtered to BMP files (via the ACI_Pack AP Select document command, with platform-specific three vs. four-letter type codes) and reads the chosen file into a BLOB and picture variable — but only after DRW_BMPFileValidateF confirms the file is trustworthy. That validation method is the technical heart of the note: it opens the document with Open document rather than DOCUMENT TO BLOB to avoid loading an unexpectedly huge file into memory, reads just the first 34 bytes with RECEIVE PACKET into a text variable, converts that header into a BLOB with TEXT TO BLOB for fast byte-indexed access, and then runs a cascading series of checks — the "BM" signature bytes, whether the header's stated file size matches the actual file size from Get document size, the BMP header-size field (must equal 40 for Windows 3.x/NT BMP), bits-per-pixel (must be 8), the compression code (must be 0/uncompressed), and positive image width/height — using a custom, byte-order-aware BLB_GetDWordF helper method that can read little-endian (Windows) or big-endian (Mac) DWord values. Only once every test passes does the code proceed to read the BMP into a picture variable via the ACI_Pack AP Get picture type and AP Read picture BLOB commands, with the note emphasizing that this thorough, layered validation makes it extremely unlikely that a malformed or wrong-format file could pass through and cause problems downstream.
