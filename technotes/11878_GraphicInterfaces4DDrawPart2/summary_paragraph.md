This Tech Note is the second installment in a multi-part series on creating interactive graphic interfaces using 4D Draw. It continues from Part I by focusing on the code of the "v65Trace" example database, specifically the validation of BMP pictures: how to thoroughly check a BMP document to confirm it is in the specific format required by the example database and ensure no problems will arise when reading it. The example database features four menu choices: converting pictures to BMP, examining BMP picture properties, tracing BMP pictures to vector graphics, and working with a 4D Draw window. Part II begins the detailed code walkthrough, concentrating on the critical step of input validation before the bitmap-to-vector tracing process begins. The series targets 4D Draw v6.5 on both Mac and Windows platforms. The full PDF was archived as a Windows self-extracting .exe installer and could not be recovered in this environment, so only the teaser description is available. The techniques demonstrated are specific to the now-discontinued 4D Draw plug-in.
