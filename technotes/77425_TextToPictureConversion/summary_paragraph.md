This Tech Note is itself a piece of 4D history revisited: it documents the evolution of JPR's well-known Text2Pict project method, whose first version was written in the year 2000 to convert a text string (with chosen font, style, size, and color) into a picture, at the time built using a BLOB assembled via QuickDraw commands and converted into a PICT-format picture. By 2015, the note explains, QuickDraw and the PICT format were themselves already dying technologies, so this revision rebuilds the same conceptual functionality using SVG (Scalable Vector Graphics) commands to draw the text and produce the resulting picture, preserving support for font, size, style(s), text color, background color, rotation, alignment, and opacity. Separately, the note introduces a parameter-passing modernization: instead of the classic approach of many discrete positional parameters, it shows passing a single JSON-type 4D Object containing named properties, calling this "the lazy way" versus the classic and "the modern way" of parameter passing, and argues this simplifies the calling code considerably. An example database and usage guidance close out the note. This is a genuinely well-aged Tech Note in that it explicitly narrates its own technology transition (QuickDraw/PICT to SVG) and even anticipates the ongoing shift in 4D coding style toward object-based parameter passing that would later be reinforced by 4D's own class/object features. The SVG-based picture generation approach remains entirely valid in current 4D, and the object-parameter pattern it champions is now mainstream practice, arguably ahead of its time for a 2015 note.
