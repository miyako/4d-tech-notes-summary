This Tech Note introduces a 4D plug-in that wraps the open-source ImageMagick framework (via its Magick++ API) to give 4D 2004 developers a rich set of picture-handling commands—resize, crop, rotate, enhance, and format conversion—without requiring end users to install ImageMagick separately, since the plug-in statically links ImageMagick version 6.2.7 directly into its binary. It runs cross-platform on Mac OS and Windows with an identical feature set, and works with either external documents on disk or images stored directly in 4D BLOB fields, making it easy to store and manipulate pictures within a 4D database and display them using 4D's own commands or the companion Pict Container plug-in. The note explains the licensing implications of bundling ImageMagick (a free, open-source, commercially usable library requiring attribution and inclusion of its license file), and describes the plug-in's workflow model built around in-memory "image objects" that can be created, copied, read, written, and manipulated, with commands such as IM New Object, IM Clear Object, and IM Copy Object documented in detail alongside their parameters and error codes. Because all image-processing code is statically bundled, the plug-in trades a larger binary size for guaranteed availability, though it does not support every picture format ImageMagick can normally handle due to licensing or size constraints on some format libraries. The note is written by Thomas Maul and targets 4D 2004 developers on Mac and Windows who need programmatic image processing inside their 4D applications without external dependencies. As a distributable component-style plug-in tied to a long-superseded ImageMagick release and 4D 2004-era plug-in architecture, it is a historical snapshot of how 4D developers extended image capabilities before more modern built-in commands and libraries existed.
