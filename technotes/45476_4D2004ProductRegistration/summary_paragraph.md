This Technical Note is a customer-support-oriented guide to completing the activation/registration process for 4th Dimension (4D) 2004 products, covering both "base products" (4th Dimension, 4D Server, 4D Runtime Single User) and "expansion products" (expansion packs and upgrades that must be linked to a base product). It walks through the three available registration methods — online, offline, and emergency — describing each step of the in-application wizard, from the Welcome screen and License Agreement through the Activation Mode screen, Choose Account screen, and Product Number entry screen, including example product-number formats for different editions (e.g., 4DSE80CXXXXXXX for Standard Edition). Online registration requires an internet connection and a 4D Customer/Partner ID; offline registration is a four-step process (create a seed file, send it to 4D via the register.4d.com website, receive a serialization file by email, and integrate that file back into the product) intended for machines without internet access; emergency registration is a temporary five-day, one-time activation for urgent situations. The note also explains expansion/upgrade registration via the "Update License…" menu option, the contents and naming conventions of the 4D Licenses folder (product-name.html or product-number.html files viewable in a browser), and a substantial troubleshooting section covering errors like "Invalid Customer Code/Password," missing product numbers in Active Licenses, "Expansion already linked to another product," orphaned expansion licenses, "No more seed credit," and issues with the serialization email not arriving. Throughout, it provides direct 4D Customer Service phone numbers and support URLs current to 2007. As a purely administrative/licensing walkthrough tied to the specific 4D 2004 registration UI and register.4d.com workflow, it documents no lasting technical concept or code and describes systems since fully replaced by later 4D licensing schemes.
