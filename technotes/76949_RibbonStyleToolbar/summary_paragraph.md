This Tech Note by Timothy Aaron Penner shows how to recreate the popular Microsoft-Office-style "Ribbon" tabbed toolbar in 4D using new sub-form commands introduced in 4D v13. It first explains what a Ribbon toolbar actually is — a tabbed toolbar (a concept dating back decades) that groups related operations by function and exposes them a page at a time, popularized by Microsoft Office 2007 — and why developers might want one: it packs many operations into limited screen space while increasing feature discoverability for new users. The implementation approach is to build one project form per logical toolbar group (e.g., Main, Devices, Applications), each matching the same dimensions and icon/text placement so switching between them feels seamless, then place a subform object beneath a row of tab buttons on the target form and use the new `OBJECT SET SUBFORM` command inside each tab button's method to swap the subform's source form to the corresponding toolbar page. A final layer of visual polish is described in detail: overlapping line objects positioned along the top of the subform and the buttons are selectively hidden and shown depending on which tab is currently active, creating the illusion that the active toolbar is physically attached to its tab while the others appear detached — closely mimicking the real Ribbon's visual language. A bundled sample database includes both a plain grey demo and a colorized demo illustrating the technique.
