This Tech Note takes stock of an area of 4D functionality that had quietly grown more complex over time: how 4th Dimension handles picture data in fields and variables. It frames this evolution explicitly around a key turning point — the introduction of 4D for Windows — which required 4D to reconcile classic Mac-native picture formats and conventions with the different graphics conventions and formats prevalent on Windows, in order to keep picture-handling behavior consistent (or at least well-understood) across both platforms. The note explores the technical details behind the specific picture formats 4D is able to handle, walks through the history of how 4D's picture support changed as cross-platform support matured, and summarizes 4D's current (as of v6) picture handling capabilities as a result of that evolution. For developers building databases that stored or displayed images — a common requirement even in 1990s business applications, from product photos to signatures — understanding these cross-platform format nuances was important for avoiding surprises when the same database ran on both Macintosh and Windows. As a retrospective-plus-status-summary note, it serves both as a historical explainer and as a practical capabilities reference for 4D v6-era picture handling.
