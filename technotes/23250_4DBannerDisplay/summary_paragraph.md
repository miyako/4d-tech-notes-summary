Written by Jamras Komoncharoensiri of 4D Inc. Technical Support, this Tech Note demonstrates constructing a floating, horizontally-scrolling announcement banner ("4D Banner") that lets an administrator broadcast a message to all connected 4D Client users without leaving the client interface or using e-mail. The Banner form consists of a non-enterable text variable (vMovingText) that starts one pixel wide and is dynamically resized and animated, a rectangular BackGround object marking the scroll boundary, and a hidden button to suppress 4D's default button. A Composer form lets an administrator type a message and either Send it immediately or Save and Send it (checking for duplicates against a BannerTable first); both paths call mLaunchBannerProcess, which opens a local banner process directly for standalone applications or broadcasts to all connected clients via EXECUTE ON CLIENT("@";"mOpenBannerLocal";$1) for 4D Server deployments. The most technically interesting piece is mSetTextBoundary, which uses a 4D Chart offscreen area (CT New offscreen area, CT Draw text, CT SET TEXT ATTRIBUTES, and CT GET BOUNDARY) purely as a text-metrics engine: it repeatedly widens a fixed-height text object by 5 points until the message no longer wraps to a second line, then uses that measured width to resize the real vMovingText object via MOVE OBJECT. A SET TIMER(5)-driven On Timer form event then repeatedly calls MOVE OBJECT to slide vMovingText five pixels left per tick until it exits the visible BackGround rectangle, at which point mUpdateMessage either swaps in a newly queued message or loops the current one back to the right edge to scroll again.
