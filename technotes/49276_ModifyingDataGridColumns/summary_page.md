# Modifying Data Grid Columns

## Overview
Focused on the same 4D Ajax Framework v11.1 Data Grid, this note documents the new API functions for modifying column properties (width, visibility, ordering, formatting, and similar attributes) programmatically, showing how a handful of simple function calls let a developer deliver a richer, more configurable web grid experience with minimal code, with a sample database included.

## Key Points
- Published March 26, 2008 as Technical Note 08-11.
- Targets 4D Web 2.0 Pack v11.1 on Mac & Win.
- Author: Unknown (4D Technical Services team).

## Featured Technology
- 4D Ajax Framework (4DAF) Data Grid v11.1
- Column property API
- Web grid customization

## Historical Context
Another entry in the 4DAF Data Grid documentation series from 2008, covering column-level customization API calls; like the related drag-and-drop and CSS notes from the same era, its specific object model has been fully retired along with the rest of the 4D Ajax Framework.

**Status:** obsolete

**Related updates:**
- 4D Ajax Framework (4DAF) has been discontinued; column-level grid customization in modern 4D web apps is handled by Qodly Studio components or custom JS/HTML5 tables rather than the 4DAF Data Grid API
