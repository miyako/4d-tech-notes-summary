The Technical Note provides information about the new, easy to use, API functions that modify the column properties of the new Data Grid in the 4D Ajax Framework v11 release 1 (11.1). These newly added functionalities allow developers to deliver a rich web experience for users with very minimal code involved. A sample database is included. Published March 26, 2008 as Technical Note 08-11 for 4D Web 2.0 Pack v11.1 (Mac &amp; Win), this note was written by Robert Molina, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
