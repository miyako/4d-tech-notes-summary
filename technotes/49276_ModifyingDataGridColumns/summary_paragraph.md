Focused on the same 4D Ajax Framework v11.1 Data Grid, this note documents the new API functions for modifying column properties (width, visibility, ordering, formatting, and similar attributes) programmatically, showing how a handful of simple function calls let a developer deliver a richer, more configurable web grid experience with minimal code, with a sample database included. Published March 26, 2008 as Technical Note 08-11 for 4D Web 2.0 Pack v11.1 (Mac & Win), written by a 4D Technical Services team member. Another entry in the 4DAF Data Grid documentation series from 2008, covering column-level customization API calls; like the related drag-and-drop and CSS notes from the same era, its specific object model has been fully retired along with the rest of the 4D Ajax Framework.
