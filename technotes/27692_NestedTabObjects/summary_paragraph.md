This Tech Note explores nesting Tab Control objects within other Tab Control objects, building on the Tab Control feature introduced in 4D version 6, which lets a developer present information across multiple pages that change as the user clicks between tabs, either as a page navigation tool or to organize information by category. It shows that individual tabs can be disabled (as illustrated in the example database), and demonstrates a more advanced nested arrangement, where a tab page itself contains another tab control, enabling deeper hierarchical navigation structures within a single form.
