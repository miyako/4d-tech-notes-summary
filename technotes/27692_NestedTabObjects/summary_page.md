# Tech Note 03-18: Tab Objects within Tab Objects

**Author:** Not specified in source document
**Published:** April 16, 2003 | **Product/Version:** 4D v2003 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=27692

## Overview
A Tech Note demonstrating how to nest Tab Control form objects within other Tab Control objects to build multi-level, multi-page form navigation in 4D.

## Key Points
- Builds on 4D v6's Tab Control object to demonstrate nesting tab controls within other tab controls.
- Shows how individual tabs can be disabled within the example database.
- Enables deeper, multi-level page navigation structures within a single form.

## Featured Technology
- Tab control form objects
- Multi-page form navigation

## Historical Context
Tab Control objects were introduced in 4D version 6 and were a significant multi-page form UI improvement at the time; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Still Relevant

Tab Control form objects remain a supported, still-used 4D form object today, so the core technique of nesting tab controls for hierarchical navigation remains directly applicable in current 4D applications, making this a still relevant, if dated in specific presentation, piece of UI guidance.
