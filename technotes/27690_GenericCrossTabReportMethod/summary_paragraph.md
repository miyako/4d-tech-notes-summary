This Tech Note explores 4D 2003's new command theme made up of commands prefixed with "QR", which collectively make up a new Quick Report engine capable of building reports procedurally rather than only through the interactive editor. This new engine specifically added the ability to create cross-tab reports (data summarized across two dimensions), and this note shows how to write a generic method — reusable across different tables and data sets — that leverages the new QR commands to produce a variety of cross-tab reports without hand-coding each one individually. Only the short on-page teaser text could be recovered here, so the exact generic method implementation is not available, but this represents a significant capability upgrade for report-heavy 4D applications of the era.
