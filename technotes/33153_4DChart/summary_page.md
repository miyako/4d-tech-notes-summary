## Overview
This Tech Note introduces 4D Chart, a plug-in that has shipped integrated with 4D since version 6.0 and lets developers graphically represent application data as charts. It observes that while most 4D developers are at least aware that 4D Chart exists, comparatively few actually know how to use it well, and positions itself as a practical introduction to generating charts using 4D Chart's own command set. The note is aimed at helping developers move from passive awareness of the bundled charting capability to actively incorporating charts into their own 4D applications' reporting or dashboard-style output. This reflects 4D's mid-2000s product bundling strategy, where auxiliary companion tools (4D Chart, 4D Write, 4D View, alongside 4D Server, 4D Backup, and 4D Insider) shipped as part of the broader 4D product family to round out an application's capabilities without requiring separate third-party tools. As a command-usage primer, this note targets developers wanting to add basic charting/graphing to a 4D 2003/2004 application.

## Historical Context
**Status:** superseded

4D Chart was the bundled charting solution for 4D applications throughout the classic-language era, but 4D later introduced SVG-based charting components and, more broadly, moved toward web-technology-based visualization (HTML/CSS/JS charting libraries rendered in Web areas) as richer, more modern alternatives, making the specific 4D Chart plug-in and its command set increasingly superseded for new development. Developers building dashboards or reports in current 4D applications are more likely to reach for SVG/JS charting approaches than the original 4D Chart plug-in.
