## Overview
This is Part 2 of a two-part series of tricks and tips for using the 4th Dimension Form Wizard, a form design tool newly introduced with 4D V6. Part 1 covered group boxes, active object styles, and button text; this part focuses on controlling the width of alpha fields in an output form, demonstrated with the MusicPro example database.

## Key Points
- The Form Wizard is described as a powerful new form design tool introduced with 4D V6.
- Part 1 (companion note) covered: using group boxes to organize objects, applying styles to active objects, and adding text to buttons.
- Part 2 specifically teaches how to control the width of alpha fields in an output form.
- Both parts use the MusicPro example database, one of the standard sample applications shipped with 4D.
- No specific step-by-step Form Wizard instructions or code are present in the recovered teaser text.
