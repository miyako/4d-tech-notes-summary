# Tech Note 96-43: Using the Power of the 4th Dimension Quick Report Editor

**Author:** Walt Nelson
**Published:** October 31, 1996 | **Product/Version:** 4D v3.x | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11721
**Download:** https://kb.4d.com/DLTN/TN/1996/Windows/TN_1996_42-44_(OCT)/96-43_Quick_Report.exe

## Overview
This Technical Note demonstrates that 4D's built-in Quick Report Editor, sometimes dismissed as suitable only for simple reports, can handle sophisticated, real-world reporting needs — illustrated through an Aircraft Maintenance Schedule report built for a fictional airport superintendent.

## Key Points
- **Example database:** "QAirline," derived from the standard 4D Airlines sample, containing the Quick Report "AcftSked" (Aircraft Maintenance Schedule).
- **Business scenario:** Replaces a slow, error-prone manual scheduling process, showing all daily flights in time order, calculated maintenance times, per-flight details, and easy update-ability — built in under two hours.
- **Walkthrough:** Opening the database, running the saved "WedFlts" search (66 flights) via the 4D Search Editor, then opening the pre-built report template to study its formatting.
- **Formatting tricks covered:** time column calculation/formatting, blank note columns, alpha justification and placeholders, placeholder-limited text display, calculated columns, numeric prefixes/suffixes, sort levels/break lines/break levels, and boolean-logic cross-tab reporting.

## Featured Technology
- 4D Quick Report Editor
- 4D Search Editor
- 4D Airlines example database

## Historical Context
**Status:** Superseded

This note's core lesson — that a flexible, quickly built ad-hoc report can meet sophisticated formatting needs without resorting to a fully custom, code-driven report — remains a valid general principle for report design. However, the specific Quick Report Editor interface and formatting options demonstrated are tied to 4D 3.x and have been revised across the many 4D versions released since 1996, so the exact steps shown no longer map directly onto current reporting tools.
