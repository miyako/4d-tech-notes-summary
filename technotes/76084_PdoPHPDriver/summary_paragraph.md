This Tech Note introduces PDO_4D, a brand-new open-source driver sponsored by 4D that lets third-party web servers such as Apache and IIS access a 4D database via PHP using the standard PDO (PHP Data Objects) abstraction layer. The note explains what PDO is, why it is useful (letting developers write database-agnostic PHP code that works against 4D, MySQL, SQLite, and others through the same interface), and who benefits — primarily teams that want to split responsibilities between a 4D backend developer and a PHP frontend developer. It walks through requirements, installation, and setup of Apache, PHP, and the PDO_4D driver itself, since many 4D developers would be encountering a third-party web server stack for the first time. Made possible by the SQL Engine introduced in 4D v11 SQL, PDO_4D allows PHP code to execute both SQL statements and 4D methods against a 4D SQL Server. A complete CRUD (Create, Read, Update, Delete) example demonstrates practical usage end-to-end. The note targets developers seeking to expose 4D data to PHP-based web applications without hand-rolling a custom bridge.
