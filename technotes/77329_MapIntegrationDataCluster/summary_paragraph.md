This Tech Note by Thomas Maul (4D Germany) presents a map-based data visualization technique that goes beyond simply pinning a single location, instead clustering multiple customer records on a map by proximity and encoding a secondary metric — such as revenue — into marker color and size. Motivated explicitly by Google Maps' licensing changes making commercial/internal embedding more restrictive, the note chooses Leaflet.js, an open-source JavaScript mapping library, paired with community-driven OpenStreetMap data, avoiding license fees while still supporting geocoding. The feature overview walks through progressively richer visualizations: a single customer pinned on a map inside a customer form, an interactive cluster view where clicking a cluster near a city highlights the underlying customers in a listbox, zoom interactions that reveal individual markers as you zoom in, markers colored/sized by revenue range (with ratio displays when multiple customers share a location), and alternative cluster-level aggregate displays such as total revenue per region rather than per-customer detail. The demo application section walks through the sample database's construction, and the integration section explains how to adapt the included Geo_Geocoding routine and wire it into your own application, covering necessary installation steps to display a map, showing single or multiple customers, and customizing marker appearance. The note specifies the demo requires 4D v15 for its geo-information handling, though it states the underlying code base can be adapted for v14. The conclusion positions this Leaflet-based clustering approach as a flexible, license-friendly alternative to commercial mapping APIs for visualizing geographically distributed business data.
