This Tech Note by Jean-Yves Fock-Hoon is Part I of a two-part series introducing the List Box object, a significant new form control added in 4D 2004 that supersedes the older technique of grouping multiple basic scrollable areas to display multi-column, multi-row-selectable data. Part I focuses specifically on the List Box's properties as configured through 4D's Design mode Form editor, while Part II (a separate note) covers manipulating list boxes through the 4D language. The note explains how to draw a List Box object onto a form from the toolbar, noting a UI quirk where clicking once selects the whole list box but clicking again can select a specific column or header, so developers must be careful to select the intended sub-element before editing its properties. Using the demo's [Contacts]Preview form as a worked example, it walks through the List Box's Property List, covering the object's Name, the Number of columns setting (with new columns inserted using default names/settings whenever the count is increased, provided the backing arrays already exist and are consistently sized), and the Number of Static columns setting, which locks a given number of leading columns in place so users cannot reorder them via drag. It documents the Show Column Header checkbox for toggling header visibility (independent of whether the underlying header variables are otherwise used, and controllable at runtime via SET VISIBLE), and the Multiple Selections checkbox for allowing users to select more than one row at a time (a Design-mode-only property with no language equivalent). It also introduces the Row Style Array, Font Color Array, and Background Font Color Array properties, which let a list box's rows be individually styled via 4D arrays. As foundational documentation for a form object that became central to 4D UI development going forward, this note captures the List Box in its earliest incarnation, before many years of subsequent feature additions.
