Printing Barcodes using 4D v11 SQL and SVG By Thomas Maul, General Manager, 4D Germany TN 08-27 Introduction ------------------------------------------------------------------------------------------------------------------------------------------------------------------ This Technical Note updates Technical Note 05-08 for 4D v11 SQL. Using the new SVG features of 4D v11 SQL to replace 4D Chart to create bar codes, the result is much faster creation with higher quality. It also fixes a bug. See the original Technical Note for a description of the commands and features (included with this document and also available at): http://www.4d.com/knowledgebase?CaseID=36279 Example and Component ------------------------------------------------------------------------------------------------------ Published July 30, 2008 as Technical Note 05-08 for 4D v11.2 (Mac &amp; Win), this note was written by Thomas Maul, General Manager, 4D Germany during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
