As macOS Catalina made notarization a hard requirement for distributing signed Mac applications, manually running the multi-step notary workflow for every build became tedious, so this tech note packages the entire process into a single Bash shell script that developers run once per deployment. It opens with an approachable primer on shell scripting basics — shebang lines, comments, `echo`, variables, parameter substitution, `sleep`, command substitution, arithmetic expansion, if/else, while loops, and case statements — aimed at 4D developers who may be unfamiliar with terminal scripting but already understand `$1`/`$2` parameter conventions from 4D methods. The script itself automates: creating a compressed DMG from a source folder or `.app` bundle via `hdiutil create`, signing it with `codesign` using an automatically detected "Developer ID Application" certificate (`security find-identity`), uploading the signed DMG to Apple's notary service with `xcrun altool --notarize-app` (capturing the returned `RequestUUID` from an XML plist parsed via `PlistBuddy`), and then looping every 60 seconds calling `xcrun altool --notarization-info` to poll status until it reports "success" (at which point `xcrun stapler staple` attaches the notarization ticket and `spctl` verifies the result) or a terminal failure state. The finished script takes two arguments — the source folder/app path and a bundle identifier — and requires the developer to fill in their Apple ID, app-specific password, and optional provider shortname at the top. This automation pattern (archive → sign → upload → poll → staple, wrapped in one script) let 4D developers integrate notarization into CI/CD-style release workflows without manual terminal babysitting.
