Reusable utility forms — a timer dialog, a confirmation prompt, a date-range picker — are common across 4D projects, but sharing one between projects normally requires copying several separate pieces (the form definition, its form method, and each object's method) and keeping them in sync. This note provides a macro-based technique (bundled as project methods plus a set of 'Macros v2' entries) that converts an entire utility form into one self-contained project method, so the whole feature can be copied or emailed as a single file. The core mechanism is codeText_fromObject(formDefinition) -> codeText, which turns a project form's definition object into evaluable 4D code that reconstructs the same form definition at runtime for use with Open form window and DIALOG, paired with meth_mergeObjectFormMethods(tablePointer; formName) -> codeText, which consolidates the form method and all object methods into a single block of code. A macro glues both steps together: selecting 'Build a form definition code' from the macro list and supplying a form name generates a ready-to-run method immediately, and the note walks through both a parameterless case (a self-contained timer feature) and a case requiring manual wiring of input/output parameters (a custom 'request' dialog returning a user-entered value). A noted limitation is that picture content embedded in a form cannot be converted this way and must be re-pointed to an external file manually.
