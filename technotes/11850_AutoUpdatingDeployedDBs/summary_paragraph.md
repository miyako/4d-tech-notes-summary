This Tech Note describes a scheme for building automatic update logic into deployed 4D database applications, ensuring that data files are brought up to par with any structure upgrade. Database development is an evolving process, and while structure and data modifications are straightforward during development, deploying updates to end users can become increasingly problematic. The note presents a system that handles upgrades automatically when the database is opened, including safeguards against problems caused by skipping intermediate revision updates. The included example database demonstrates the entire process with generic, reusable code that developers can adapt to their own applications.
