This Tech Note proposes a solution for simulating a Related One link in 4th Dimension while preserving the standard properties of this relationship type. The technique allows users to choose a record from a list of related records (when multiple records match) and to create a new record (when no match exists), mirroring the behavior of a native Related One relationship. This was important because developers sometimes needed to customize or extend the default relationship behavior during data entry while maintaining user expectations. The solution would have involved programmatic control of the lookup and creation process, providing a more flexible alternative to the built-in automatic relationship resolution. The note addressed a common data entry pattern in 4D v6 applications.
