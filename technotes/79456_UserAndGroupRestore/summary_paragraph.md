This Tech Note tackles a deployment risk in 4D's built-in users-and-groups system: because user/group data is stored as part of the database structure, deploying an updated structure can silently overwrite or revert users, passwords, and group assignments that customers created after initial deployment. It first explains the users/groups model — the elevated Designer and Administrator accounts, project mode's single-designer restriction (versus binary mode's multiple Team Development design users), standard users, and license-restricting groups (which can themselves be nested, e.g., a 4D Write Pro group added under a 4D View Pro group) — then contrasts binary mode's export/import approach (USERS TO BLOB / BLOB TO USERS, or the Users and Groups window) with project mode's flat-file storage in a single "directory.json" file located in the Settings folder (next to Project, or preferentially next to the data file if both exist). The core technical solution is a pair of project methods: backupCurrentUsers, which copies the active directory.json into `{Documents}/4DAppUsers/{Database name}/directory.json` on database exit (guarded by Application type checks for 4D Local mode/4D Server), and restoreCurrentUsers, which on startup compares modification dates (and, if dates match but times imply ambiguity, an MD5 digest via Generate digest) between the active and backed-up files, replacing the active file with the newer backup when appropriate and returning a Boolean indicating whether a RESTART 4D is needed to apply changes. These methods are intended for the On Exit/On Startup methods (standalone) or On Server Shutdown/On Server Startup methods (client-server), explicitly excluded from running on remote clients. Two accompanying demo scenarios (manual button-driven and fully automated) let developers observe the backup/restore cycle in action, and the note positions this pattern as the project-mode equivalent of binary mode's export/import strategy for protecting deployed user credentials and group memberships across structure updates.
