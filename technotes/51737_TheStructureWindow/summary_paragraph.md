Managing the structure of your tables, fields and relations becomes ever more effortless with the growing features of the Structure window in 4D v11 SQL. It is the one stop visual overview and model for your database. This Technical Note will demonstrate all the functionality of the Structure window, and will help you to keep your database structure more organized and legible. Published December 2, 2008 as Technical Note 08-42 for 4D v11.3 (Mac &amp; Win), this note was written by Silvio Belini, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
