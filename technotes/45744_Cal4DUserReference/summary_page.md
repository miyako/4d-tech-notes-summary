# Tech Note 07-09: Cal4D Component - User Reference

**Author:** Dave Batton (Cal4D component author)
**Published:** March 7, 2007 | **Product/Version:** 4D 2004 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=45744
**Download:** https://kb.4d.com/DLTN/TN/2007/Windows/TN_2007_05-09_(FEB)/07-09_Cal4D_Component.exe

## Overview
This is Part One of a two-part Technical Note introducing the Cal4D component, a full-featured calendar add-on written by Dave Batton that a 4D developer could add to any 4D 2004 database, covering installation and basic use.

## Key Points
- Cal4D adds a "full-featured Calendar" to any 4D 2004 database.
- This first part focuses on installing the component and getting started with basic use; the companion Part Two (Tech Note 07-10) covers the language reference for its public methods.
- A sample database, including the component's source code, was distributed alongside the note, offered separately for Windows and Mac.
- The demonstration is explicitly noted as subject to 4D's Partnerware component licensing agreement, indicating Cal4D is a third-party/partner-contributed component rather than a first-party 4D feature.

## Featured Technology
- Cal4D calendar component (installation and basic usage)
- 4D 2004 partnerware component model

## Historical Context

## Historical Commentary
**Status:** Obsolete

As a third-party component built for 4D 2004, and with only teaser text recoverable, this note is of archival interest only; the general idea of adding calendar UI via a reusable component remains common practice, but current 4D projects would use a modern, actively maintained equivalent rather than Cal4D.
