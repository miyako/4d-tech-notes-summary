This Tech Note shows how to build a quick report from scratch using a custom Quick Report wizard, and notably explains an architectural curiosity of 4D 2003: the new Quick Report editor is implemented as a plug-in named "Report", even though — unlike the 4D Write plug-in, which can be removed from a database — it cannot be removed and is not an external file that can simply be copied into the MAC4DX folder or WIN4DX directory like a traditional plug-in. The note poses and presumably answers the question of why it is nonetheless called a plug-in, reflecting an internal architectural choice in how 4D 2003 packaged this core feature. Only the short on-page teaser text could be recovered here, so the wizard's specific implementation is not available; this is Part I, with Part II (also in this batch) extending the wizard to cross-tab reports.
