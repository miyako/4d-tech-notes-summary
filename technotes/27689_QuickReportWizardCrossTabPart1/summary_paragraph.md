Written by Jean-Yves Fock-Hoon of 4D Technical Support, this Tech Note is the first of two on building a custom Quick Report wizard, and explains that 4D 2003 reimagined the Quick Report editor as a "Report" plug-in -- not a removable external plug-in file like 4D Write, but one comparable to how 4D Chart began life externally before being integrated into 4D -- meaning developers can now define plug-in areas in their own forms and drive them entirely with QR commands. Using a sample `[Interface]Wizard` form containing a `QRBuilder` plug-in area, the note walks through a step-by-step wizard invoked via `DIALOG` from the Custom menus' Wizard item, with `Wizard_Changepage` enabling/disabling menu items per step and `Wizard_OnCommand` handling user actions; the first page selects List vs. Cross-tab report type (`QR SET REPORT KIND`) and the target table (`QR SET TABLE`), using the `[Cities]` table as the example. It details field selection and sorting via the contextual menu (which opens the 4D Formula dialog) or via drag-and-drop, decoded with `DRAG AND DROP PROPERTIES` and `QR Get drop column` (positive values insert a new column via `QR INSERT COLUMN`, negative values replace an existing column's contents), with `QR ON COMMAND`/`QR EXECUTE COMMAND` used to intercept and control menu, toolbar, and contextual-menu actions. The note explains the break-level calculation tags available in cells (`#S` sum, `#N` min, `#X` max, `#A` average, `#C` count, and `##N` to reference another column's current value), how to trigger a page break or extra spacing at a given break level via the "Total spacing" dialog or the `QR GET/SET TOTAL SPACING` commands, per-column display formatting using `#`/`0`/`*`/`^` format characters, and per-cell style attributes. It closes by describing how the Report plug-in resolves reports that span relations -- automatically running the report on the "deepest" Many table found among inserted fields via an internal `RELATE MANY SELECTION`, with the caveat that parent records lacking any matching child records (e.g., a country with no invoices) will not appear in the resulting report.
