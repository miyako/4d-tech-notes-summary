# Tech Note 02-21: Working with 4D Dialogs within a Plug-in

**Author:** Not specified in source document
**Published:** May 15, 2002 | **Product/Version:** 4D Open v6.8 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=23238

## Overview
A Tech Note demonstrating how to use a 4D Dialog from within a 4D plug-in, illustrated via a security dialog that requires username/password entry to access a database.

## Key Points
- Demonstrates using a 4D Dialog from within a 4D plug-in.
- Worked example: a username/password security prompt controlling database access.

## Featured Technology
- 4D Dialog
- 4D Open plug-in
- Custom security dialogs

## Historical Context
Reflects the classic 4D plug-in API's ability to invoke 4D Dialog windows, foundational for any plug-in developer needing native UI interaction from plug-in code.

## Historical Commentary
**Status:** Superseded

The classic 4D plug-in API and 4D Dialog mechanism described here have been superseded by 4D's modern component architecture, meaning the specific plug-in integration approach is dated; the general concept of a password-gated security dialog remains a common, still-relevant application feature, though modern implementations would rely on 4D's more capable and secure current authentication options rather than a bespoke plug-in dialog.
