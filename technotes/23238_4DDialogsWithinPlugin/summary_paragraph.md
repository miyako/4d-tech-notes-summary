This Tech Note walks through a practical example of using a 4D Dialog within a 4D plug-in, demonstrating how to add a security dialog to a database that requires the user to enter a valid username and password to gain access. This shows how developers building or extending 4D plug-ins (such as 4D Open, the plug-in category this note is filed under) could surface native, dialog-based user interaction from within plug-in code, rather than being limited to whatever built-in UI a plug-in's host framework exposed by default.
