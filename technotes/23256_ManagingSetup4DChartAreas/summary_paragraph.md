Written by Tim Tonooka, a 4D Solution Partner, this Tech Note explains the full range of techniques for configuring the appearance and behavior of 4D Chart areas, whether displayed on a form or in a plug-in ("external") window. It starts from the fact that 4D Chart is document-oriented (like a word processor with an underlying document), and enumerates the seven ways a 4D Chart area's setup can be performed: object method or form method code (form-based areas only), the Open external window command, disk templates, custom code via the default area, and a custom event handler installed with CT ON EVENT. It carefully documents the precedence order in which these settings are applied -- default area first, then disk template, then the CT ON EVENT handler (gated by CT EVENT FILTER), then object method, then form method -- and clarifies what happens (and doesn't) when a document is cleared with CT NEW DOCUMENT. A major focus is the CT ON EVENT event handler, the only place to run setup code for 4D Chart areas in plug-in windows, which the accompanying "ChartSetup" demo database uses with CT SET DISPLAY to toggle interface elements from a Preferences palette. The note also demonstrates intercepting 4D Chart's own menu bar via CT ON MENU to substitute custom code (e.g., custom print logic) for a chosen menu command like Print, and closes with a reference list of the many CT SET/CT ON/CT GET-style commands available for configuring an area's display, editability, size, and default line/fill/text attributes.
