This Technical Note by Tim Penner of 4D Inc. is a practical, video-supported walkthrough of customizing the Data Grid object found in the 4D Ajax Framework (4DAF), built against the 4D Web 2.0 Pack "Contacts" demo database downloadable from 4D's site. Starting from a bare HTML skeleton, it shows how to wire a page into a 4D database by loading the framework's localization and compile JavaScript files plus a basic stylesheet, attaching login/logout hooks to the `<body>` tag's onload/onunload events, and defining an `onAfterInit` callback where a `DataWindow` JavaScript object is instantiated against a target table and bound to a `<div>` element, at which point the Data Grid becomes functional. It then covers granular UI customization via the DataWindow's `.customize()` function, which toggles the Toolbar, Tabbar, Statusbar, and Editor controls on or off, and via `.hideColumns([colNumbers])`, which hides specific zero-indexed columns; column widths are set through a `.grid.onafterload` callback that calls `.grid.column(colNum).setWidth(pixels)` for each column. A larger section addresses building a tab-driven layout using the 4DAF Admin Control Panel's Query Manager: "Dynamic Queries" auto-generate tabs from the distinct values of a chosen column (e.g., State), while "Template Queries" apply prebuilt templates such as an "A-Z Steps" alphabetic tab layout to a chosen field, with the DataWindow's `.customize()` call adjusted to show the Tabbar while keeping other controls hidden. The note closes with a brief note on setting a database's default "Home Page" via 4th Dimension's Preferences window (available in User Mode, Design Mode, and optionally exposed in Custom Menus Mode). Six short companion videos accompany the discrete steps: enabling the basic grid, hiding controls, hiding columns, setting column widths, tab-driven layouts, and setting the home page, making this a granular, code-and-demo-driven reference to the 4DAF Data Grid's JavaScript customization surface.
