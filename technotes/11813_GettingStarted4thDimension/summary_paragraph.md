This Tech Note provides a comprehensive overview of how 4th Dimension products work and interact, designed to bridge the documentation gap between opening the 4D product box and using the manuals. It covers basic 4th Dimension products (including the main development environment, 4D Server, and companion modules), installation procedures, network components for client/server deployment, available documentation, and 4th Dimension resources for further learning. The note was targeted at new users who needed a high-level orientation before diving into the detailed product manuals. It reflects the era of boxed software distribution where physical documentation was the primary reference material. The product overview would have covered the ecosystem of companion products available in the v6 era, including 4D Server, 4D Compiler, and various plug-in modules.
