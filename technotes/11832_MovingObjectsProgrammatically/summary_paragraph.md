This Tech Note demonstrates the new MOVE OBJECT and SET TIMER commands introduced in 4th Dimension version 6.5, which enabled developers to programmatically move objects on a form for the first time. The note shows how to combine these commands with the new On Timer form event to create an animated effect where a form object follows the mouse cursor. Presented as a fun April Fools' Day demo for 1999, the note nonetheless illustrates genuinely useful new capabilities for building dynamic, interactive user interfaces in 4D. The ability to reposition form objects at runtime opened possibilities for drag-and-drop interfaces, custom layout editors, and other dynamic UI patterns. The technique of using SET TIMER to create periodic callbacks for animation or polling became a common pattern in 4D development. These commands represented a significant step forward in 4D's form object manipulation capabilities during the v6.5 era.
