# Tech Note 99-07: Programmatically Moving Objects in 4D

**Author:** Not specified
**Published:** April 1, 1999 | **Product/Version:** 4D v6.5.x | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=11832

## Overview
This Tech Note demonstrates how to use the new 4D v6.5 commands MOVE OBJECT and SET TIMER, combined with the On Timer event, to programmatically move form objects as the user moves the mouse cursor.

## Key Points
- 4D v6.5 introduced the MOVE OBJECT command for runtime repositioning of form objects.
- SET TIMER and the On Timer event enable periodic callbacks for animation-like effects.
- The demo tracks mouse position and moves an object to follow the cursor.
- Presented as an April Fools' Day 1999 demo, but illustrates real UI development capabilities.
- Opens possibilities for custom screens, drag-and-drop, and dynamic layout interfaces.

## Featured Technology
- 4D v6.5
- MOVE OBJECT command
- SET TIMER command
- On Timer form event

## Historical Context
**Status:** Historical interest only

MOVE OBJECT and SET TIMER remain available in modern 4D, and the On Timer event is still supported. However, modern 4D provides far more comprehensive object manipulation via commands like OBJECT SET COORDINATES and a much richer form event model.
