This Tech Note describes how to list and count instances of unique values in a 4D table, and how to replicate the behavior of the SQL GROUP BY command using 4D's procedural language. Published in 1999 for 4D v6.5, this was written in an era before 4D had any built-in SQL engine — developers had to use 4D's native set-based and array-based commands to achieve what SQL handles declaratively. The DISTINCT VALUES command, which populates an array with unique values from a field across the current selection, was the key tool for this task. Counting instances of each distinct value required additional procedural logic, typically involving queries and selection counting within loops. This was a common data analysis need for developers building reporting and analytics features in 4D applications. The note essentially served as a bridge document for developers familiar with SQL concepts who needed to implement equivalent logic in 4D's procedural paradigm. Only the teaser text survives; the full PDF with implementation code could not be recovered.
