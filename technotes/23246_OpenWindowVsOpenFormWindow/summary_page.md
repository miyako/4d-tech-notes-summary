# Tech Note 02-29: Open Window Vs. Open Form Window

**Author:** Not specified in source document

## Overview
A Tech Note comparing the OPEN WINDOW and OPEN FORM WINDOW commands in classic 4D, clarifying their similarities, differences, and a shared window-content constraint.

## Key Points
- Compares OPEN WINDOW and OPEN FORM WINDOW: similar capabilities, different underlying mechanics.
- Concludes the choice between them is mostly a matter of developer preference.
- Notes a shared constraint: a new window must display or be ready to accept content, or it will close automatically.

## Featured Technology
- OPEN WINDOW
- OPEN FORM WINDOW

## Historical Context
Reflects classic 4D's window-management command set in the pre-Project-Mode, pre-web-area era.

## Historical Commentary
**Status:** Still Relevant

Both OPEN WINDOW and OPEN FORM WINDOW remain part of current 4D's language, so this note's core comparative guidance remains directly applicable to developers working with classic 4D window management today, even as many modern 4D UIs increasingly rely on web areas instead of native windows.
