This Tech Note combines two "hot" web technologies of the time — SVG and tag clouds — to show how 4D v11 SQL's newly introduced SVG support can generate data-driven visualizations. It explains what SVG is (a W3C XML-based vector graphics specification) and how 4D's DOM XML commands can be used to build SVG documents programmatically, which are then rendered via DOM EXPORT TO PICTURE into a 4D picture variable or displayed in the new Web Area form object, with the added benefit that individual SVG elements can respond to click and mouseover events. Because writing raw SVG/XML by hand can be daunting, the note also references a 4D SVG component that offers a more user-friendly way to design SVG graphics from within 4D. The bulk of the note walks through a sample Tag Cloud (TCL) demonstration database that builds a data-driven tag cloud — sizing and coloring sales associates' names according to their total sales — covering the TCL_madeCloud_arrays method, creating SVG from data, wrapping text within SVG, color shading, the tag-cloud weighting algorithm itself, and handling mouse click events so that clicking a tag cloud element displays the corresponding records. The note targets developers who want a compelling, data-driven visual alternative to a plain sorted list.
