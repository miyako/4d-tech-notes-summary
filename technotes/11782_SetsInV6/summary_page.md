## Overview
This note discusses the new way that Sets — compact in-memory representations of record selections supporting fast logical operations — are created and maintained in 4th Dimension version 6, and addresses compatibility issues for routines migrating from version 3 databases. Only the on-page teaser is available; the full PDF could not be recovered for this asset.

## Key Points
- Sets provide a compact in-memory representation of record selections.
- Sets enable extremely fast logical operations (e.g., union/intersection/difference) between selections.
- V6 introduced a new, more powerful way of creating and maintaining Sets compared to V3.
- The note addresses compatibility considerations for routines originally written against V3 databases.
