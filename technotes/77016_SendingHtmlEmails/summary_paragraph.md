This third-party Tech Note by Dave Terry of Pacific Data Management explains how to send HTML-formatted emails with embedded images using the 4D Internet Commands (4DIC) plug-in, whose v14 update made this considerably easier. It first grounds the reader in the underlying protocols: SMTP transmits only 7-bit ASCII, and MIME extends it to carry richer content (like HTML and attachments) by encoding/decoding additional data and describing how each part should be interpreted. The core problem addressed is that HTML emails referencing external images (e.g., a company logo hosted on a public URL) are unreliable — many email clients block external image loading by default for privacy, and links can break if the hosted image ever moves. The MIME-compliant solution is to embed images as specially-marked attachments referenced from the HTML via `cid:` (content-ID) URIs, so the email client displays them inline rather than as separate attachments. The note provides a complete working 4D code example: a regex (`Match regex`) scans HTML for `<img>` tag sources, de-duplicates and replaces each with a unique `cid:` reference, attaches the corresponding local image files via `SMTP_Attachment`, and sends the composed message (with both HTML and plain-text bodies) using the `SMTP_` command family, while also producing a parallel HTML variant suitable for live preview in a 4D Web Area.
