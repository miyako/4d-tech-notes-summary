This Tech Note explains how to safely share data between database triggers and the code that triggers them, using a utility record as the shared data-passing mechanism rather than relying on global variables, which can behave inconsistently between different execution contexts. It states this technique works consistently whether the database is interpreted or compiled, and on both 4D and 4D Server, and comes with a sample database demonstrating the pattern.
