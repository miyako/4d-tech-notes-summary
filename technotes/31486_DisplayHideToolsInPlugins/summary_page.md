# Tech Note 04-08: Displaying and Hiding Tool Features Inside Plug-in Areas

**Author:** Not specified in source teaser
**Published:** February 26, 2004 | **Product/Version:** 4D v2003 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31486

## Overview
This Tech Note demonstrates how to manually and procedurally show or hide interface chrome — menu bar, toolbars, and scrollbars — within 4D's productivity plug-in areas: 4D Chart, 4D Draw, 4D Write, and 4D View.

## Key Points
- All four productivity plug-ins ship interface elements (menu bar, toolbars, scrollbars) visible by default.
- These elements can be toggled **manually** by the end user or **procedurally** via specific plug-in commands in 4D code.
- Procedural control is especially useful when a plug-in area is used in **read-only mode**, where interactive chrome is unnecessary.
- Demonstrates the technique consistently across all four plug-ins: 4D Chart, 4D Draw, 4D Write, and 4D View.

## Featured Technology
- 4D Chart, 4D Draw, 4D Write, 4D View (classic productivity plug-ins)
- Plug-in area interface element display commands

## Historical Context

All four plug-ins covered here belong to 4D's early-2000s companion product lineup; 4D Write and 4D View were each later superseded by ground-up successors — 4D Write Pro (2016) and 4D View Pro (2018) — while 4D Chart and 4D Draw are largely legacy technology today. The general UI concept of controlling embedded-tool chrome for read-only display contexts persists in the newer Pro-generation areas, but this note's specific commands are obsolete.
