This Tech Note addresses the user-interface chrome that comes bundled with all of 4D's classic productivity plug-ins — 4D Chart, 4D Draw, 4D Write, and 4D View — namely interface elements such as a menu bar, toolbars, and scrollbars, which are set to appear by default so end users have quick access to the most commonly used features. It explains that these elements can be toggled in two ways: manually, by the end user directly interacting with the plug-in area, or procedurally, by the developer executing a specific plug-in command from 4D method code. The note frames the practical motivation for controlling this display programmatically: depending on how a plug-in area is being used within an application, a developer may need fine-grained control over which interface elements appear, and this becomes especially important when a plug-in area is being used in a read-only capacity, where interactive toolbars or menus would be unnecessary or even confusing to the end user. The core deliverable of the tech note is a demonstration, across all four supported plug-ins (4D Chart, 4D Draw, 4D Write, and 4D View), of exactly how to control these display options both manually and procedurally, giving developers a consistent reference for managing plug-in area chrome across 4D's full suite of embedded productivity tools. As with other notes of this era, it is accompanied by a downloadable example database for both Windows and Mac platforms.
