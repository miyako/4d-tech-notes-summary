4D View Pro v18R2 introduced the ability to programmatically set freeze panes and, combined with new style commands, this tech note shows how to give frozen rows/columns a distinct visual style so users can more easily tell frozen data apart from scrollable data in large spreadsheets. The core commands are `VP SET FROZEN PANES` (taking an object with `columnCount`, `rowCount`, `trailingColumnCount`, `trailingRowCount`) and its counterpart `VP Get frozen panes`, which the sample database uses to compute the exact cell ranges (via `VP Column`/`VP Row`) that need styling or reverting. A custom style — including font family, size, weight/italic built from `VP Font to object`/`VP Object to font`, plus colors — is captured through a small "Edit Style" form, persisted as JSON, and then applied automatically any time panes are frozen or unfrozen using `VP SET CELL STYLE`, passing `Null` as the style to revert a pane's look to its original state. Because font changes can alter text metrics and cause clipped cell contents, the note also compares before/after fonts for each affected range and conditionally triggers `VP COLUMN AUTOFIT`/`VP ROW AUTOFIT` only when a font actually changed, avoiding the performance cost of unconditional autofitting on large documents. The result is a reusable pattern — save style to JSON, compute affected/reverted ranges, apply/remove styles, and conditionally autofit — that developers can adapt for their own View Pro-based spreadsheet UIs. This showcases 4D's ongoing expansion of the View Pro command surface for building rich, programmatically controlled spreadsheet experiences without leaving the 4D language.
