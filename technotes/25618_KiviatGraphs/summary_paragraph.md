Kiviat (radar/spider) graphs plot several data series on multiple axes radiating from a common center, giving an at-a-glance shape-based comparison between items — the note's example compares cameras across resolution, color, sensitivity, flash, and autofocus scores. Because 4D Chart has no built-in Kiviat graph type and cannot natively draw two overlapping graphs in one area, this Tech Note shows how to construct one manually using 4D Chart's lower-level drawing primitives (lines, circles, rectangles, polygons) driven by the 4th Dimension language. The technique initializes the chart area with CT DO COMMAND, defines a center point and radius, stores series values and axis legends in arrays, and then uses basic trigonometry to compute each axis's endpoint coordinates around the circle before drawing the connecting polygon that represents the item's shape. It is a good example of extending 4D Chart's built-in graph types with custom math-driven drawing code when the desired visualization isn't natively supported.
