This Tech Note is Part I of a two-part series that shows how to build a custom, guided Wizard interface for 4D's Quick Report feature, rather than exposing users to 4D v11 SQL's built-in Quick Report environment directly. It explains why a developer might want to recreate this interface — to control which options are shown, tailor terminology to the application's context, or shield less confident users from an intimidating blank-slate report builder — and introduces the Report Plug-in Area, a built-in (non-external) plug-in similar to Web Area or 4D Chart that hosts the report canvas. Using the included sample database, it walks step by step through building a List Report: selecting the source table and record set, dragging fields into the report area (detected via DRAG AND DROP PROPERTIES and QR Get drop column), defining break-level calculations with special tags (#S, #N, #X, #A, #C), adding break-level actions like page breaks, applying cell formats and style attributes, setting borders and column widths, and defining page headers/footers before generating the final report. It briefly introduces Cross-Tab Reports (covered in more depth in Part II) as a two-dimensional alternative to List Reports for summarizing data. Throughout, it maps each wizard step back to the underlying QR command(s) (QR SET REPORT KIND, QR SET TABLE, QR INSERT COLUMN, QR GET/SET INFO COLUMN, QR GET/SET TOTAL SPACING, and others) so developers can replicate identical functionality programmatically.
