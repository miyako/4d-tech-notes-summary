This Tech Note introduces a 4D v6.5 feature: the ability to place objects in the header area of list forms. Prior versions did not support this, and v6.5's addition of header objects expanded what developers could achieve with list form layouts. The note provides a cross-platform sample database demonstrating three different ways to use objects in headers. The playful title ('Objects in Headers are Closer Than They Appear') reflects the informal style common in 4D technical notes of this era. Only the teaser text survives; the full PDF could not be recovered.
