## Overview
An introduction to placing interactive objects in the header area of list forms in 4D v6.5, with a cross-platform sample database showing three approaches.

## Key Points
- 4D v6.5 introduced the ability to place objects in list form headers
- Includes a cross-platform sample database
- Demonstrates three different approaches to using header objects
- Expanded layout flexibility for list-based interfaces

## Historical Context
**Status:** Still Relevant

The ability to place objects in the header area of list forms was a new feature in 4D v6.5, expanding form layout flexibility. Modern 4D list forms continue to support header/footer areas with objects, though the form editor and available object types have expanded enormously. The basic concept remains valid.

### Related Updates
- Header/footer areas in list forms remain a standard feature in modern 4D
- The form editor and object types available for headers have been significantly expanded
