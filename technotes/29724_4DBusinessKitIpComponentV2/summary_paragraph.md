This Tech Note documents the IP Component for 4D Business Kit v2.x, a stand-alone, double-clickable e-commerce application built using 4D 2003.x. The IP Component is a 4D code component built specifically for 4DBK v2.0, comprising 19 methods, and can be installed into any 4D 2003 application using 4D Insider, 4D's component packaging/installation tool of the era. It depends on three plug-ins: 4D Internet Commands, 4D Pack, and Yapee, a special plug-in dedicated to 4D Business Kit. This note gives developers the technical detail needed to extend or embed 4DBK's e-commerce logic into their own 4D applications rather than treating it as a closed, black-box product.
