## Overview
A technical reference Tech Note on the 4D Business Kit v2.x IP Component, a 19-method 4D code component (installable via 4D Insider) that extends the 4DBK e-commerce application, along with its plug-in dependencies (4D Internet Commands, 4D Pack, Yapee).

## Key Points
- Documents the 4D Business Kit v2.x IP Component: a 19-method 4D code component for 4DBK v2.0.
- Installable into any 4D 2003 application via 4D Insider.
- Requires three plug-ins: 4D Internet Commands, 4D Pack, and the Yapee 4DBK-specific plug-in.

## Featured Technology
- 4D Business Kit
- 4D Internet Commands
- 4D Pack
- 4D Insider (components)

## Historical Context
4D Business Kit was 4D's turnkey e-commerce application product of the early 2000s, and 4D Insider was the classic component packaging/distribution tool used before 4D's modern component architecture; only the short teaser text for this note could be recovered here.

## Historical Commentary
**Status:** Obsolete

4D Business Kit, 4D Insider, 4D Pack, and the Yapee plug-in are all long-discontinued products specific to this era of 4D's e-commerce and component tooling, making this note's specific technical content obsolete; 4D's component architecture and e-commerce integration approaches have been completely reworked in the decades since, and any modern 4D e-commerce solution would be built from scratch using current web/ORDA/REST tooling rather than this legacy stack.
