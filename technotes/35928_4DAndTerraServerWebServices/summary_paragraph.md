Thang Nguyen, a 4D Technical Support Engineer, demonstrates integrating with TerraServer-USA, a Microsoft/USGS web service exposing 3.3 terabytes of high-resolution aerial photography and topographic maps, from a 4D 2004 database. The note opens with background on SOAP (its XML envelope of Header and Body, and the difference between synchronous, tightly-coupled RPC-style messages and document-driven, loosely-coupled DOC-style messages) and WSDL as the XML contract 4D's Web Service Wizard parses to auto-generate proxy method code. Of TerraService's sixteen available operations, the accompanying demo database focuses on five — ConvertLonLatPtToNearestPlace, ConvertPlaceToLonLatPt, GetAreaFromPt, GetPlaceList, and GetTileMetaFromLonLatPt — each shown with its 4D SOAP-Wizard-generated source, lightly modified with ON ERR CALL error handling. Each method follows the same pattern: build a request XML document with DOM Create XML Ref/DOM Create XML element/DOM SET XML ELEMENT VALUE, submit it via SET WEB SERVICE PARAMETER and CALL WEB SERVICE against the TerraService2.asmx or TerraService.asmx endpoint, then parse the XML response with DOM Parse XML variable and DOM Find XML element/DOM GET XML ELEMENT VALUE to extract fields like longitude/latitude, tile metadata, or a nearest-place description. The note closes by describing the demo database's UI — a dialog offering Navigate Map, Select Image, and Search City options, letting the user pick between Topo and Photo imagery and either click to zoom into the US map or search by city/state/country to jump to a location.
