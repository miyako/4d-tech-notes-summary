This Tech Note by Omid Tavallai of 4D, Inc. shows how to connect a 4th Dimension 2003 database to a Macromedia Flash MX Professional 2004 front-end using 4D's SOAP Web Services, illustrated with a simple demo built for the 2003 4D Summit Conference. The 4D side contains a single `Sessions` table with a `Name` field holding HTML-formatted session titles, and a method, `getSessionName`, that picks a random record and returns its name; this method is exposed by checking "Offered as a Web Service" and "Published in WSDL" in the Method Properties, which publishes a WSDL file from 4D's built-in web server (configured to port 8080, reachable at `http://127.0.0.1:8080/4dwsdl`). On the Flash side, a `WebServiceConnector` component (from the Data Components palette) is bound to the WSDL endpoint and the `getSessionName` operation, with its "result" output bound as HTML text to a Label component so the returned session names render with formatting. Because Flash only calls the web service once by default, a single line of ActionScript, `this.FlashDemo.trigger();`, is placed in the first frame of the timeline so each loop of the movie re-triggers the web service call and displays a new session name. The note walks through publishing the finished Flash file as a Macintosh/Windows standalone executable or as a browser-playable .SWF file. It concludes by suggesting the pattern generalizes to much richer Flash front-ends — with graphics, audio, and video — layered over a 4D backend, and that it offers a fast way to build client demos, prototypes, or vertical-market interfaces.
