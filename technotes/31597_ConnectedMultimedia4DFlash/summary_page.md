# Tech Note 04-09: Connected Multimedia Apps with 4D and Flash

**Author:** Not specified in source teaser
**Published:** March 4, 2004 | **Product/Version:** 4D v2003.3 | **Platform:** Mac & Win
**Page:** https://kb.4d.com/assetid=31597
**Download:** https://kb.4d.com/DLTN/TN/2004/Windows/TN_2004_05-09_(FEB)/04-09_Connected_Multimedia.exe

## Overview
This Tech Note gives developers "a taste" of combining a 4th Dimension application backend with a Macromedia Flash front-end, using a simple example originally demonstrated at the 2003 4D Summit Conference.

## Key Points
- Frames web services as enabling new connectivity between 4D and other application/front-end technologies, including Flash.
- Uses a deliberately simple Flash application and 4D database pairing to minimize the amount of new code developers must learn.
- Example originates from a live demonstration at the 2003 4D Summit Conference.
- Positioned as an approachable starting point rather than an exhaustive integration guide.

## Featured Technology
- Macromedia Flash front-end
- 4D as an application/data backend
- 4D web/communication layer bridging Flash and 4D (consistent with the era's Web Services/Web server focus)

## Historical Context
Only the on-page teaser paragraph for this asset could be recovered (the full archived PDF could not be retrieved in this environment), so this summary reflects only the note's stated framing, not its exact implementation details. Macromedia Flash was later acquired by Adobe and officially discontinued at the end of 2020, with modern browsers dropping support entirely — making this note's specific front-end technology obsolete today. The broader idea of pairing a 4D backend with a rich, interactive client front-end remains conceptually relevant, but is now realized with modern web/mobile frameworks rather than Flash.
