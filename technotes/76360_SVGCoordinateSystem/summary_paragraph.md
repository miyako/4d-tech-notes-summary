This Tech Note introduces the SVG coordinate system as it applies to 4D's SVG component, laying the groundwork developers need before attempting to move, rotate, or scale SVG objects on screen. It explains the default (initial) user coordinate system as a theoretically infinite 2D canvas, then shows how the "viewport" constrains SVG drawing to a finite rectangle appropriate for computer screens, 4D forms, and 4D picture objects, and how the "viewBox" maps user-space coordinates onto that viewport. It ties these three concepts — user coordinate system, viewport, and viewBox — together before introducing the "transform" attribute, which can move, rotate, scale, and skew SVG objects, and focuses specifically on the "translate" and "scale" transform values in this installment (leaving "rotate" and "skew" for a follow-up Tech Note). A demo accompanies the explanation so developers can see the concepts applied directly. The note is aimed at 4D developers working with the 4D SVG component who need a solid conceptual foundation before building more advanced, dynamically positioned or scaled vector graphics.
