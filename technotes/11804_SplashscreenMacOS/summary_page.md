# Tech Note 98-21: Creating a Splashscreen on Mac OS

**Author:** Not specified in source document
**Published:** June 1, 1998 | **Product/Version:** 4D v6.0 | **Platform:** Mac
**Page:** https://kb.4d.com/assetid=11804
**Download:** Not available

## Proposition
This Tech Note explains how to create custom splash screens for 4D databases on Mac OS, using Macintosh resource management to replace the default launch image.

## Key Points
- Replaces 4D's default splash screen (the '4' image shown since Version 1)
- Uses Macintosh resource management for splash image customization
- Mac OS-only technique (resources were best managed on Mac)
- Addresses a frequently requested developer feature for application branding

## Featured Technology
- Splash Screen
- Mac OS Resources
- 4th Dimension
- Macintosh

## Context / Positioning
Resource forks were a distinctive feature of the classic Macintosh file system, allowing structured data to be stored alongside file content. This technique was emblematic of the Mac-centric development culture that 4D originated from.

## Historical Commentary
**Status:** Obsolete

This Mac-only technique relied on Macintosh resource fork manipulation, a concept that has been entirely deprecated in modern macOS. The desire for custom splash screens persists, but modern approaches use completely different mechanisms. Resource forks were a unique feature of classic Mac OS file systems.
