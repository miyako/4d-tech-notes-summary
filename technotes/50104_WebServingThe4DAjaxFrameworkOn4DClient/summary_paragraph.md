This Technical Note covers information about web serving the 4D Ajax Framework (4DAF) on 4D Client. This setup has a few differences with installation when compared to a standalone application, but also offers some added advantages. Published June 12, 2008 as Technical Note 08-22 for 4D Web 2.0 Pack v11.2 (Mac &amp; Win), this note was written by Jason Zajdel, Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
