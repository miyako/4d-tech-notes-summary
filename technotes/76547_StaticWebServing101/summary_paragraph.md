This Technical Note by Darrell Draper opens a multi-part series on 4D v13's built-in Web Server by focusing purely on serving static HTML content, deferring dynamic pages, session management, and security to later notes in the series. It begins by defining "Web Content" broadly, then explains the Web Root folder and how 4D determines the default home page for a site. A substantial section demystifies web addressing: the anatomy of a URL, the difference between absolute and relative URLs, and the distinction between URIs and URLs, all illustrated with practical 4D examples. The note then walks through the mechanics of enabling the 4D Web Server and produces a basic "Hello World" static page as a hands-on starting point. It closes with two important performance topics: Web caching, covering both server-side caching configuration and browser-side caching behavior, and HTTP compression, explaining how enabling compression reduces bandwidth for served content. Overall the note serves as an accessible on-ramp for developers new to the 4D Web Server, establishing the fundamentals needed before tackling more advanced dynamic web publishing techniques covered in subsequent Tech Notes in the series.
