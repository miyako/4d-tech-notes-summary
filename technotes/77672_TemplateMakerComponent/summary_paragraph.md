Written by Charlie Vass of 4D Inc. in October 2016, this tech note documents the TemplateMaker component, a tool inspired by an internal 4D engineering technique introduced in v15 R4 that allows developers to add new report/export/graph capabilities to an already-deployed database with little to no downtime, by leveraging 4D Transformation Tags rather than shipping a new compiled structure. The workflow is: a developer or support engineer writes the desired output logic as a normal general-purpose project method in the host database, then uses TemplateMaker to capture and wrap that method inside a <!--#4DCODE--> transformation tag block, turning it into a portable "template." The component provides a security key mechanism to protect the resulting template from external tampering, and lets the developer export the finished template either as clear text or Base64-encoded for distribution. Three shared, hidden methods — 4DTM_Macro, 4DTM_Macro_Selection, and 4DTM_Execute — support the workflow: the first two are exposed as Macros v2 menu items directly inside the host database's project method editor for easy capture, while 4DTM_Execute is called from host database code to run a saved template against live data and produce output. The note documents installation (drop the component into the host database's Components folder; requires 4D v15 R4+), the TemplateMaker dialog's options (Add Component Wrapper, Add Security, Copy, Reduce to Selection, Encrypt BASE64, Export), a demo host database, and mentions related prior notes on "Smart Templates" and an "Enhanced Graph Component." This is a distinctly classic-4D-era pattern: it exists specifically to work around the constraints of binary Design Mode databases, where deploying new code traditionally meant redistributing an entire compiled structure file. With 4D's move to Project Mode (v17+, 2018) and Git-friendly text-based method files, teams can now deploy incremental code changes through ordinary source control and CI/CD pipelines, making this transformation-tag-and-macro workaround largely a historical curiosity rather than a technique most current 4D shops would adopt.
