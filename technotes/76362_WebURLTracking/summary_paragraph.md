This Tech Note addresses a common marketing-campaign problem: knowing how many times each link in a campaign was clicked, even when the destination page is not hosted or logged by the developer's own server. It presents an approach built entirely on a 4D database: each distributed link is stored as its own record with an associated counter, and links are presented to end users referenced by an obfuscating UUID rather than the real destination URL. When a user clicks a tracked link, the 4D database silently translates the UUID back to the true destination, increments the click counter, and redirects the browser, all transparently to the end user. The Tech Note includes a sample database implementing this pattern, an HTML source converter tool for tagging campaign links with trackable UUIDs, a campaign statistics viewer for reviewing click counts, and an explanation of how tracked links are both stored in the database and resolved through the web layer. It targets developers who need to measure marketing campaign effectiveness without depending on external hosting or server log access.
