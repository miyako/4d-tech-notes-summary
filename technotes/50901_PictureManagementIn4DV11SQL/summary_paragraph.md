------------------------------------------------------------------------------------------------------------------------------------------------------------ Picture Management in 4D v11 SQL has been enhanced to offer native support of Mac OS X and Windows picture formats. It is now possible to combine pictures without losing their original characteristics, as well as apply much more sophisticated transformations on a picture. This Technical Note explores this new functionality. A sample database is provided. Published August 27, 2008 as Technical Note 08-31 for 4D v11.2 (Mac &amp; Win), this note was written by Luis Pineiros Technical Services Team Member, 4D Inc. during the 4D v11 SQL era, when 4D's newly integrated SQL engine (introduced 2007) and the 4D Ajax Framework (4DAF) for AJAX-based web UIs were the platform's flagship modern capabilities. It reflects the pre-ORDA, pre-Project-Mode 4D development model, in which the binary Design Mode structure file was the only structure format and 4D's own SQL layer was still new relative to the classic procedural/set-based language that had defined 4D since the 1980s.
