This Tech Note documents version 2004-3 of the OCI Mapper, an open-source 4D component (source code included) originally introduced in TN 03-44 to help 4D Oracle developers migrate to 4D for OCI (the plug-in required starting with 4D 2004, after 4D Oracle was discontinued) without rewriting their database's source code. The note explains the architectural relationship between the three layers involved — the OCI Mapper (framework, developer-owned), 4D for OCI (plug-in, provided by 4D), and the Oracle Call Interface library (API, provided by Oracle) — and contrasts 4D Oracle's higher-level but more restrictive command set against 4D for OCI's flexible but far more verbose low-level commands, noting that 4D for OCI is also markedly faster. It documents this release's bug fixes and design notes across many individual OCI Mapper methods, including a completely rewritten CheckError error handler that now iterates multiple OCI error records and supports OD Last Error; corrections to previously-unreliable cursor-state tracking (OD Cursor state) and OD Last Error; a workaround note for OD GET SERVER LIST, which fails to locate Oracle Home under Oracle 10g due to a changed registry key location; and a list of former 4D Oracle OD SET OPTIONS values (kNoWait, kWithLock, kDistinctLines, kDeferred) that no longer apply per-object the way they did in 4D Oracle, but only globally. It calls out important limitations for developers to be aware of: the Mapper does not reliably support multiple concurrent cursors with independent output parameter sets, does not support Large Object (BLOB/CLOB/RAW) binding without extra custom OCI code, and does not support executing objects inside Oracle packages. Throughout, the note repeatedly frames the OCI Mapper not as a finished production solution but as a "learning tool" and migration bridge, explicitly encouraging developers to read, modify, and extend its commented source code. It positions itself as the first half of a two-part release, with a companion debug-logging edition covered separately in TN 06-12.
