This Tech Note by Hugo Fournier (4D, Inc. Technical Support Engineer) is Part II of a two-part series on the Contact Manager example database's calendar, focusing on how the interface reacts to user actions after Part I covered how its objects are placed and displayed. It walks through `Calendar_TextObjectMethod`, the single method that fires on the `On Clicked` form event for every calendar event object, and explains how selection is drawn using up to six `SelectRect1`–`SelectRect6` overlay rectangles (needed because a multi-day "banner" event can span up to six form objects), positioned via `GET OBJECT RECT` and `MOVE OBJECT`. Two parallel arrays, `<>Cal_aVariableNames` and `<>Cal_aRecIDs`, map each on-screen object to its underlying `[Calendar]` record so the correct record can be loaded, deselected, or deleted. The note then covers drag-and-drop: the `On Drag Over` event validates the drop target isn't the event's current date, and `On Drop` either duplicates the record via `DUPLICATE RECORD` (if the Macintosh Option/Shift key is held) or updates the existing record's date in place, followed by a call to `Calendar_PlaceEvents` to redraw. Finally it documents `Calendar_DisplayRecord`, which opens the Input form as a modal dialog via `Open form window`/`INPUT FORM` and calls either `ADD RECORD` or `MODIFY RECORD` depending on whether a new or existing record is being edited, and covers banner-resizing via 30 pairs of invisible `DragBttnL`/`DragBttnR` buttons.
