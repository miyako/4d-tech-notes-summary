This Tech Note explains how to analyze and monitor the built-in 4D Web Server using WEB Get server info, a command newly introduced in 4D v16 R5 that returns comprehensive web server metrics and information as a single 4D object in one line of code. It first covers 4D Web Server fundamentals — its settings, and how to start and stop it — before diving into WEB Get server info's technical properties and how to obtain and interpret the information it returns. A sample database demonstrates practical use, building a monitoring interface that polls the command's output and displays live web-server status/metrics, plus a logging subsystem that records this information over time for later analysis, such as generating metrics lists from stored records or graphing changes between successive log entries. The note frames this custom tooling as valuable because the 4D Web Server is a "complex system" with settings ranging from configuration to live runtime metrics, and having both real-time monitoring and historical logging available makes it easier to confirm the web server is healthy and to diagnose issues over time. It closes by emphasizing that WEB Get server info makes previously hard-to-obtain server information trivially accessible via 4D object notation, enabling developers to build whatever custom monitoring or alerting system suits their deployment.
