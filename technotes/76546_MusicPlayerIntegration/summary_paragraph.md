This Technical Note by Sonya Rackwitz demonstrates how to integrate a music/media player into a 4D application by embedding an Apple QuickTime player inside a 4D Web area using the HTML <EMBED> tag, then layering JavaScript on top to give the 4D application programmatic control over playback. The note explains what QuickTime is and why it was a reasonable choice at the time (broad file type support), and separately introduces JavaScript's role in the solution — giving developers a way to start/stop playback, track progress, and adjust volume by calling JavaScript functions from 4D code. A provided component database packages a ready-to-use control bar (play/stop, progress display and scrubbing, volume control), and a separate host/sample database shows how simply that component's control bar can be dropped into another 4D application. The note walks through the JavaScript function calls used to bridge 4D and the embedded player, and closes by pointing to related "See Also" resources for developers wanting to explore the topic further. Overall the note packages a full working solution for adding audio playback controls to a 4D application without leaving the 4D development environment.
