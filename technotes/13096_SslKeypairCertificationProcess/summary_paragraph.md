This Tech Note introduces SSL (Secure Sockets Layer), the Internet protocol of the era used to secure communications between a web server and HTTP clients such as browsers, enabling a 4D-served site to safely accept credit card numbers or handle sensitive data like medical or HR records. It explains that both 4D and its companion web server product WebSTAR relied on the RSA algorithm, one of five algorithms qualified under the US federal Advanced Encryption Standard evaluation process, widely used at the time for authentication and encryption. The bulk of the note covers the practical mechanics: the basics of SSL technology, how 4D and WebSTAR each generate key pairs, and the steps required to install SSL support for both products. Its featured technology is therefore SSL/RSA cryptography as integrated into the 4D + WebSTAR web-serving stack of 2001, aimed at developers and administrators needing to stand up a secure, credit-card-capable 4D web site during the early e-commerce boom.
