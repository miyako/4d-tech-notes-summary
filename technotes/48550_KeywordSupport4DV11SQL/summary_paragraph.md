4D v11 SQL introduced native keyword-search support through three new features: keyword indexes, a new "contains keyword" comparison operator, and support for regular expressions (regex), extending beyond the older, more limited "contains" search available in previous 4D versions. This note explains how each of these tools works and how developers can use them together to build fast, efficient keyword- and pattern-based searches over 4D data. Published January 9, 2008 as Technical Note 08-01 for 4D Developer v11 (Mac & Win), written by Josh Fletcher, Technical Support Engineer, 4D Inc.. Keyword indexing, regex support, and efficient text search are foundational, still-relevant capabilities that 4D has continued to build on; the specific v11 SQL-era feature set described here has been substantially extended in later versions with more advanced full-text search and regex capabilities.
