# Keyword Support in 4D v11 SQL

## Overview
4D v11 SQL introduced native keyword-search support through three new features: keyword indexes, a new "contains keyword" comparison operator, and support for regular expressions (regex), extending beyond the older, more limited "contains" search available in previous 4D versions. This note explains how each of these tools works and how developers can use them together to build fast, efficient keyword- and pattern-based searches over 4D data.

## Key Points
- Published January 9, 2008 as Technical Note 08-01.
- Targets 4D Developer v11 on Mac & Win.
- Author: Josh Fletcher, Technical Support Engineer, 4D Inc..

## Featured Technology
- 4D v11 SQL keyword indexes
- "Contains keyword" comparison operator
- Regular expressions (regex) support
- Full-text/keyword search

## Historical Context
Keyword indexing, regex support, and efficient text search are foundational, still-relevant capabilities that 4D has continued to build on; the specific v11 SQL-era feature set described here has been substantially extended in later versions with more advanced full-text search and regex capabilities.

**Status:** still relevant

**Related updates:**
- 4D's text search and regex capabilities have been extended considerably in versions since v11 SQL, including further additions to the regex command set
