This Tech Note addresses a common 4D Server administration pain point in 1997: how to get saved Quick Reports (and other files) onto every 4D Client machine without needing a separate file server or manually copying files to each client. ACI Technical Support's answer, per the note, is to place such files into the special Mac4DX and Win4DX folders on the 4D Server machine. Anything placed in these folders is automatically copied down to the corresponding client machine whenever a user launches 4D Client and logs on, effectively turning the server into its own lightweight file-distribution mechanism for client-side assets. The note specifically calls out that saved Quick Reports can be stored this way and will be automatically present on the client after logon, without any extra deployment infrastructure. This was a practical, low-friction solution aimed squarely at customers who lacked (or didn't want to rely on) a separate network file server for distributing supplementary 4D Client files, and reflects the constrained, self-contained client/server deployment model characteristic of 4D Server in the mid-to-late 1990s.
