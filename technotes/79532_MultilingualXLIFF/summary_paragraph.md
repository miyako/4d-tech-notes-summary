This Tech Note is a comprehensive guide to localizing 4D application interfaces for a global audience using XLIFF (XML Localization Interchange File Format), an OASIS-standardized XML format for managing translation data, required for 4D 20.4 LTS or later. It covers foundational context — Unicode's role in enabling multilingual text storage/display, and 4D's shift away from legacy .RSR/.4DR resource files toward standard XLIFF (.xlf) and .png files stored in a Resources folder next to the project — plus OS-level language configuration, including 4D's "English-US" default for code editor language (to keep methods portable across regions and version-control-friendly, toggleable via "Use regional system settings") and macOS per-application language overrides. The core technical mechanism is the <xliff>/<file>/<body>/<trans-unit> XML structure, where each translatable string gets a unique resname (e.g., "day_1") mapped to source and target text; developers reference these in form object properties via `:xliff:day_1` syntax, and 4D resolves the correct translation at runtime based on the active language and lproj folder structure (en.lproj, es.lproj, fr.lproj, etc.). Language selection follows a documented four-tier priority: system language (macOS), current 4D application language, English default, or the first lproj folder found — illustrated through three deployment scenarios covering Client/Server environments with mismatched OS/application/available-language combinations. The note details programmatic control via SET DATABASE LOCALIZATION (to force a specific language per RFC 3066/ISO639/ISO3166 codes, e.g., "fr") and Get database localization/Get localized string for reading the current language and retrieving specific translated strings by resName. It closes with Asian-language considerations (Windows IME support, macOS's now-universal MeCab library for Japanese text) and a worked procedure for importing Arabic Excel data into 4D as UTF-8 text via DOCUMENT TO BLOB and Convert to text, positioning XLIFF-based localization as 4D's modern, maintainable path to internationalized business applications.
