This Technical Note walks the 4D developer step-by-step through building a Web 2.0 apartment-listing application using the 4D Ajax Framework (4DAF), part of the 4D Web 2.0 Pack, structured as five progressive sections (Setup, Add Login Information, Declare the Image Matrix object, the OnClick event, and the OnDblClick event), each with an accompanying "before/after" folder of completed files so developers can check their progress. After installing the 4DAF into the provided "AptDemo.4DB" source database and copying the HTML/image assets into the dax folder, the guide shows how to add a hardcoded guest login (via the onload body attribute and a matching change in the DAX_DevHook_Login developer hook) so visitors can access the page without a real account. It then covers declaring a 4DAF Image Matrix (dataMatrix) JavaScript object bound to the [Listing] table/selection, configuring header and content templates from field values, and embedding it into a page `<div>`. Two interactive behaviors are added next: an onCellClick handler that uses the 4DAF Data Filler to populate a details panel with the clicked record's data, and an onCellDblClick handler that additionally loads a Google Maps URL (built from the record's address) into an iframe. The note closes by highlighting the Data Filler as an underused but powerful 4DAF feature for binding record data into arbitrary HTML areas. As with other Web 2.0 Pack notes of the period, it flags that the subscription-based, fast-iterating 4DAF product may make specifics obsolete quickly — which did in fact occur once the entire 4DAF/Web 2.0 Pack line was later discontinued.
