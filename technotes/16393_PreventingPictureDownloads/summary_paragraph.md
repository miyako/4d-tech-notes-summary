This Tech Note (TN 01-40, 4D v6.7, Mac & Win, published August 31, 2001) by Chiheb Nasr of 4D S.A. describes a two-layer, admittedly incomplete scheme for discouraging (not truly preventing) web visitors from saving images served by a 4D-published web site. The note opens with a candid disclaimer that no browser-side technique can fully stop a determined user (drag-and-drop, browser cache inspection, and screenshots all still work), then presents the actual mechanism: a JavaScript disableclick handler attached to every <img> element's onmousedown event intercepts right-clicks (or Ctrl-click on Mac) and shows an alert instead of the browser's native "Save Image" context menu, while the image itself is served through a 4DACTION call (Web_Display) rather than a static file. On the 4D side, the image-fetch URL embeds the timestamp of the page that referenced it, and Web_Display compares that timestamp to the current time, serving the actual GIF only if the request arrives within a short window (1-2 seconds); requests arriving later -- as would happen if a user copied the raw image URL out of View Source and pasted it into the address bar much later -- instead receive an error page with no image. The note closes by pointing out that genuine image protection requires digital watermarking rather than this kind of client-side interface trick.
