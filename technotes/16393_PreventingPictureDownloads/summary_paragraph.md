This Tech Note (TN 01-40, 4D v6.7, Mac & Win, published August 31, 2001) presents a JavaScript/4D integration trick intended to discourage web users from downloading a displayed picture. Only a short on-page teaser paragraph survives in this archive rather than the full downloadable PDF and example database, because the original download was an old Windows self-extracting .exe installer (https://kb.4d.com/ftp://ftp.4D.com/ACI_TECHNICAL_NOTES/2001/Windows/TN_2001_36-40_(AUG)/01-40_Preventing_Picture_DL.exe) that could not be extracted in this environment; the original 4D Tech Notes site offered separate Windows and Mac downloads of the complete note and its companion example database, but neither is retrievable here. Based on the surviving teaser text, the note's proposition is: This Tech Note illustrates an interesting way of integrating 4D and JavaScript to prevent a user from downloading an image via the download command. However, other ways of saving pictures locally are available to the determined user. Its featured technology centers on 4D built-in Web Server, JavaScript/4D integration, Web area image protection, reflecting typical concerns of the 4D 6.7 (4D 2000/2001 era) developer community working in binary Design Mode on classic Mac OS/early Mac OS X and Windows 98/2000/NT. This note demonstrates a JavaScript trick combined with 4D's web server to make it harder for a casual user to download an image via the browser's built-in download command, while acknowledging determined users could still save it another way. Browser technology, image-protection expectations, and 4D's own web-serving mechanisms have all changed enormously since 2001, and the specific JavaScript-era anti-download tricks shown no longer meaningfully deter modern browsers, so this note is now of historical interest only regarding actual image protection.
