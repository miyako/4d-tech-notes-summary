This Tech Note by Vance Villanueva introduces the new Save Geometry feature added in 4D v14, which automatically memorizes and restores the appearance of a form display — window position, size, separators, expandable areas, tabs, and (via the companion "Save Value" object property) the last-entered values of variables, list box headers, popup selections, tab selections, and button/checkbox states. Prior to v14, achieving this required custom programmatic code to track and reapply every coordinate and value; the new feature eliminates that work by persisting the state to a JSON-formatted preference file, one of the first user-facing uses of JSON in 4D's form engine. The note explains how to enable the feature (via the form's Property List and the OPEN FORM WINDOW command with the "*" parameter), documents the JSON preference file's storage locations on Mac and Windows for standalone, compiled, merged, and client/server deployments, and details how the feature behaves differently across 4D's various runtime modes (standalone/compiled, merged application, interpreted single-user, and interpreted client-server). It closes by enumerating the productivity benefits: less rework, no extra code, per-client isolation of saved state in client/server deployments, and the ability to export/restore preference files externally for debugging or migration.
