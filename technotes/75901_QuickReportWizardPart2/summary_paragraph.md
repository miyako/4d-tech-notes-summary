This Tech Note is the programming-focused sequel to Part I (asset #75840), which covered the interface and functionality of a custom Quick Report Wizard; Part II dives into the actual implementation using 4D v11 SQL's built-in Report Plug-in and its more than 40 Quick Report (QR) commands. It distinguishes the two report types the wizard supports — List Reports (record listings with break levels and per-group calculations) and Cross-Tab Reports (two-dimensional tables driven by two categorical data sources) — and explains that the Report Plug-in, unlike third-party plug-ins, is integrated directly into 4D v11 SQL and cannot be removed. The bulk of the note walks step-by-step through building each report type via a multi-page wizard dialog: selecting fields and sort order, defining break-level values and actions, choosing cell formats/styles/borders/column widths, setting page headers and footers, and finally generating the report; the Cross-Tab section adds steps for choosing data-source, total-column, and grand-total computations. A "Navigation" section shows how the wizard dynamically shows/hides floating windows (menu bar, toolbar, font, computation, background, move/hide, contextual menu) per wizard page using a `Wizard_SetFloattingwindows` helper keyed on the current page number. The note frames this as letting developers build a "Print Center" offering both built-in and end-user-customizable reports, replacing 4D v11 SQL Release 4's stock Quick Report capability with a more controllable custom implementation.
