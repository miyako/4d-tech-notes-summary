# Tech Note: Windows Keyboard Shortcuts in 4th Dimension/4D Server v6.5

## Overview
- **Technical Note 00-31**
- **Author:** Steve Hartman, 4D, Inc. Technical Support
- **Published:** July 1, 2000
- **Product/Version:** 4D v6.5
- **Platform:** Win
- **Content source:** Full PDF text recovered

## Key Points
This Tech Note is the Windows-platform companion to a parallel Macintosh keyboard-shortcut reference note (also archived here as asset 11979), compiling every keyboard shortcut available across 4D's Windows application family circa v6.5: 4th Dimension and 4D Server themselves, plus the companion utilities 4D Tools and Customizer Plus. Structured identically to its Macintosh counterpart, it is organized into sections covering shortcuts available while opening a structure file (such as holding ALT to select a different data file, or SHIFT to force the password dialog), shortcuts for all environments (including a CTRL+double-click technique for moving off-screen windows, and a multi-step technique for bringing a hidden window into view before repositioning it with the ALT key), shortcuts for the Design environment, the Debugger, the User and Custom Menus environments, and the standalone 4D utility applications. Its proposition, like its Mac counterpart, is purely reference-oriented: a single authoritative listing to boost developer productivity within the Windows-specific conventions of 4D's Design/Debug/User environments. The featured technology is the classic Windows-era 4D application UI as a whole, highlighting how thoroughly 4D's developer tools of the period leaned on keyboard-driven workflows across both supported platforms.

## Featured Technology
- 4th Dimension Design Environment
- 4D Debugger
- 4D Tools / Customizer Plus

## Historical Context
This is the Windows counterpart to the Macintosh keyboard-shortcut reference (asset 11979 in this same archive), covering 4th Dimension/4D Server v6.5 and companion utilities 4D Tools and Customizer Plus on Windows 98/2000/NT of that era. Customizer Plus has been discontinued, and 4D's Design environment interface, menu structure, and shortcut conventions have changed considerably across two decades of subsequent releases, so while historically informative, this reference is no longer directly usable with current 4D software.

## What's Changed Since
- Customizer Plus, a companion utility referenced throughout, has been discontinued
- 4D's Design environment interface and keyboard shortcuts on Windows have changed substantially since v6.5
