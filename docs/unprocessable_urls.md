## Methodology note: Mac `.hqx` mirror recovery

For pre-2006 legacy Tech Notes, the KB page usually lists both a Windows self-extracting `.exe` archive and a Mac BinHex `.hqx` alternate (originally hosted at `ftp://ftp.4d.com/...`). When the Windows `.exe` failed to yield a PDF via `unar`, we found that kb.4d.com also mirrors the Mac alternate at a predictable HTTPS path -- swapping `Windows` for `MacOS` in the `/DLTN/TN/<year>/...` URL structure (the raw `ftp://` URL itself is dead, but this HTTPS mirror works). `.hqx` files are BinHex-encoded StuffIt 5 archives; `unar` decodes and extracts them in one step, same as the `.exe` case.

Applying this to all 257 "no PDF in archive" entries recovered full text for **215 of them (84%)** -- a large quality improvement across the 1998-2005 era. The remaining 42 are documented above. This technique is worth trying first for any future "archive extraction failed" case in this legacy era before giving up.
